# 术语表（官方英文 ↔ 中文教学说法）

> **这份表是给谁看的**：两本教程（[《中文仓颉程序设计》](中文仓颉程序设计/README.md)、[zhc 教程](tutorial/README.md)）统一用词；带官方英文的读者，想对照官方文档时在此反查。
>
> **与附录的关系**：本表只收**概念与工具术语**——中文**关键字**（`函数`/`如果`/`开放`…）的官方映射以[附录 A](中文仓颉程序设计/附录/附录A-关键字速查字典.md)为准，标准库方法（`打印行`/`修剪`…）以[附录 B](中文仓颉程序设计/附录/附录B-标准库速查字典.md)为准。某词两边都有时，词表以附录 A/B 为权威，本表给「为什么叫这个」的背景。

## 一、类型与值

| 官方术语 | 本书说法 | 说明 |
|---|---|---|
| value type / reference type | 值类型 / 引用类型 | 数据直接存放 vs 变量持有引用；`结构体` 值语义、`类` 引用语义（第二卷 09/12） |
| literal | 字面量 | 代码里直接写的值（`1`、`"你好"`、`真的`） |
| type inference | 类型推断 | `让 x = 1` 自动推出类型；方言强调显式标注也不拦你（第二卷 09） |
| generic | 泛型 | 类型参数化，如 `类 盒子<T>`（第二卷 15） |
| tuple | 元组 | 把多个值打包成一个值（第二卷 13、附录 B） |
| range | 区间 | `(1..10)` 半开区间、`(1..=10)` 闭区间（第二卷 11、附录 B） |
| destructuring | 解构 | 一次性取出元组/对象里的值（第二卷 13） |
| enum | 枚举 | 有限取值集合，可带数据载荷（第二卷 13） |
| pattern matching | 模式匹配（`匹配`） | 按结构拆值并分支；编译器做**穷尽性检查**（第二卷 13） |
| exhaustiveness | 穷尽性检查 | 所有分支必须覆盖全部可能，写漏一个编译器就报错（第二卷 13） |
| Option | 选项（`有值`/`无值`） | 可空概念的显式化，杜绝 null（第二卷 14、附录 B） |
| unwrap | 解包 | 从 `选项` 里取值：`有值 x` 取出 `x`，`无值` 走兜底/报错（第二卷 14） |
| string interpolation | 字符串插值 | `${名字}` 把变量嵌进字符串（第二卷 10） |
| immutable / mutable | 不可变 / 可变 | `让` 默认不可变，`可变` 显式申请（第一卷、第三卷 16） |
| memory safety | 内存安全 | 无 null、无悬垂引用、无手工释放——编译器兜底（第三卷 16） |

## 二、函数与组合

| 官方术语 | 本书说法 | 说明 |
|---|---|---|
| function | 函数（`函数`） | 带名字的代码块；`主函数()` 是程序入口（第一卷） |
| parameter / argument | 形参 / 实参 | 参数列表里的名字 vs 调用时传入的值；方言支持命名参数（第二卷 08） |
| lambda | lambda（匿名函数） | 作为表达式的函数字面量，可传给 `映射`/`过滤` 等（第二卷 08） |
| closure | 闭包 | lambda 捕获外层变量一起带走（第二卷 08） |
| higher-order function | 高阶函数 | 函数作参数或返回值（第二卷 08、附录 B 管道） |
| pipeline | 管道（`\|>`） | 左值作为右函数最后一个参数：`名单 \|> 过滤(...) \|> 求和`（附录 B） |
| overload | 重载 | 同名函数、不同参数个数/类型（第二卷 08） |
| recursion | 递归 | 函数调用自己（第二卷 08） |
| break / continue | 跳出 / 继续 | 跳出结束整个循环；继续跳过本轮（第一卷、附录 A） |

## 三、面向对象与抽象

| 官方术语 | 本书说法 | 说明 |
|---|---|---|
| struct / class | 结构体 / 类 | 组织数据的两种方式：值语义 vs 引用语义（第二卷 12） |
| field / member | 字段 / 成员 | 类型里存放数据的变量（第二卷 12） |
| constructor | 构造器 | `类名(...)` 初始化实例；`this` 即 `本对象`（第二卷 12） |
| method | 方法 | 定义在类型里的函数（第二卷 12） |
| property | 属性（`属性`/`修改 属性`） | 外部像字段读写、内部由 `获取()`/`设置(值)` 控制的成员（第二卷 12.8、附录 A） |
| getter / setter | 获取 / 设置 | 属性访问器的读/写方法（第二卷 12.8、附录 A） |
| inheritance | 继承 | 需要父类 `开放` + 子类显式继承的特权（第二卷 12） |
| override | 重写 | `重写` 覆盖父类方法；父类方法须 `开放`（第二卷 12、附录 A） |
| interface | 接口 | 方法契约，可多实现（第二卷 12/15） |
| polymorphism | 多态 | 同一接口多种实现；配合类型测试安全转型（第二卷 12） |
| extension | 扩展（`扩展`） | 不修改原类型，给它外挂方法（第二卷 12/第三卷 16、附录 A） |
| annotation | 注解（`@名字`） | 给声明挂元数据/宏行为，如 `@派生`（第二卷 15） |
| macro | 宏 | 编译期生成代码；`宏 包` 定义、`@宏名` 调用、`zhc expand` 看展开（第二卷 15、zhc 教程 07 章） |

## 四、错误处理与并发

| 官方术语 | 本书说法 | 说明 |
|---|---|---|
| exception | 异常 | 运行时错误对象，可 `抛出`/`捕获`（第二卷 14） |
| throw / try / catch | 抛出 / 尝试 / 捕获 | 抛出错误、尝试执行、捕获处理（第二卷 14、附录 A） |
| concurrency | 并发 | 多线程/多任务；`同步` 与原子操作保证安全（第二卷 14） |
| thread | 线程 | 并行执行的最小单位（第二卷 14） |
| generator | 生成器 | 惰性产出序列的机制（第二卷 14） |
