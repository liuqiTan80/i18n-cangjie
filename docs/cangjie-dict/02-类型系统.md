# 02 类型系统

> 类型（type）是数据的「分类标签」：它决定了数据能存什么、能做什么运算、占多大空间。
> 本卷词条：整数族 / 浮点族 / 布尔 / 字符串 / 字符 / 单元 / 空类型 / 字节 / 数组 / 元组 / 范围 / 选项 / 类型推断 / 类型标注 / 类型转换 / 字面量细节。

## 词条 2.1 整数族（整数/整数32/无符号整数 → Int64/Int32/UInt64 等）

- **是什么**：整数的多种位宽与符号组合。方言常用：`整数`（Int64，默认）、`整数32`（Int32）、`无符号整数`（UInt64）；官方还有 Int8/Int16/UInt8/UInt16/UInt32/UInt128。
- **为什么**：位宽 = 存储空间与取值范围。默认 64 位是「最不会溢出的通用选择」；处理大量数据或协议格式时才用更窄的类型省内存。
- **怎么用**：
  ```cangjie
  主函数() {
      让 a: 整数 = 100          // 64 位
      让 b: 整数32 = 100        // 32 位
      让 c: 无符号整数 = 100    // 非负
      打印行(a)
      打印行(b)
      打印行(c)
  }
  ```
- **注意**：不同位宽**不能直接混算**——`整数32` + `整数` 报「类型不匹配」，需要显式转换（`整数(b)` 构造器转换，见 2.15）。无符号数 `-1` 是编译错误（范围检查）。

## 词条 2.2 浮点族（浮点/浮点32 → Float64/Float32）

- **是什么**：带小数点的数。`浮点` = Float64（默认，双精度），`浮点32` = Float32（单精度）；官方还有 Float16。
- **为什么**：科学计算需要小数；双精度是「够用且通用」的默认。浮点用 IEEE 754 表示，**有精度误差**——设计上接受误差换取超大动态范围（10⁻³⁰⁸ ~ 10³⁰⁸）。
- **怎么用**：
  ```cangjie
  主函数() {
      让 身高: 浮点32 = 1.75f32
      让 体重: 浮点32 = 65.5f32
      打印行(身高 * 体重)
  }
  ```
- **注意**：`整数` 与 `浮点` 混算 OK（整数自动提升）；`浮点32` 与 `浮点` 混算报错（精度提升不是隐式的）。判等用「误差范围」：`绝对值(a - b) < 0.0001`。

## 词条 2.3 布尔（布尔 / Bool）

- **是什么**：真/假两值类型，占 1 字节。
- **为什么**：判断与逻辑的载体。仓颉把布尔作为一等类型（不是 0/1），杜绝 C 语言里 `如果 (x = 1)` 赋值误写这种坑——条件必须是真正的 `布尔` 表达式。
- **怎么用**：
  ```cangjie
  主函数() {
      让 成年 = 真
      让 结果 = 成年 与 年龄判断(18)     // 见 4.3 逻辑运算
      打印行(结果)
  }
  函数 年龄判断(岁: 整数): 布尔 { 返回 岁 >= 18 }
  ```
- **注意**：方言别名 `真`/`假`；**条件里不能用数字**（`如果 (1)` 报错，必须是布尔表达式）。

## 词条 2.4 字符串（字符串 / String）

- **是什么**：不可变的 Unicode 字符序列。
- **为什么**：见 1.6——不可变设计让字符串在线程间安全共享、可被编译器优化（字符串池）。代价是「修改」产生新对象，但对现代硬件可忽略。
- **怎么用**：详见 7.25 字符串方法群。基本能力：
  ```cangjie
  主函数() {
      让 s = "仓颉"
      打印行(s.长度)             // 6（字节数，UTF-8 下每汉字 3 字节）
      打印行(s[0..3])            // 仓（切片按字节，1 个汉字 = 3 字节）
      打印行(s + "编程")         // 仓颉编程
  }
  ```
- **注意**：`长度` 是**字节数**（UTF-8 编码，中文 1 字 = 3 字节；按字符用 `字符流()`/`字符数组()`，见 2.5）；`+` 拼接字符串要求两侧都是字符串（数字要插值或转换）；字符串切片 `s[起..止]` 按**字节**切——起止必须落在汉字边界上，否则运行时抛异常（见 7.25）。

## 词条 2.5 字符（字符 / Rune）

- **是什么**：单个 Unicode 字符。
- **为什么**：以「字符」为单位的处理（而不是字节）是 Unicode 时代的正确抽象——`'仓'` 就是一个单元，不会被拆成 3 个字节。
- **怎么用**：
  ```cangjie
  导入 标准集合.*
  主函数() {
      让 c = '颉'
      打印行(c)                  // 颉
      打印行("ABC"[0])           // 97（字节 UInt8，ASCII 下等于字符）
      打印行("仓颉".字符流() |> 第一个)   // 仓（按字符取第一个）
  }
  ```
- **注意**：`字符串[i]` 返回的是**字节**（UInt8）——中文会取到半个字！这是新手最容易踩的坑；按**字符**遍历用 `字符串.字符流()`（runes，返回字符迭代器）。

## 词条 2.6 单元（单元 / Unit）

- **是什么**：只有一个值 `空`（`()`）的类型，表示「没有有意义的值」。
- **为什么**：C/Java 用 `void` 表示无返回值；仓颉用真正的类型 `单元`——无返回值的函数返回它。这让「函数都有返回值」成为统一规则（可链式、可作表达式值）。
- **怎么用**：
  ```cangjie
  函数 打招呼(): 单元 {
      打印行("你好")     // 函数体没有返回，默认返回单元
  }
  ```
- **注意**：`单元` 类型的值可以忽略；声明 `让 x: 单元 = 空` 合法但基本没用——它主要出现在「函数签名」和「泛型占位」里。

## 词条 2.7 空类型（空类型 / Nothing）

- **是什么**：**没有值**的类型——比「没有意义的值」更彻底：它连一个值都没有。
- **为什么**：`Nothing` 是「永不返回」的函数（如 `退出`、无限循环）的返回类型。因为没有任何值，任何类型都能「收下」它——`退出()` 可以用在任何需要值的地方。
- **怎么用**：
  ```cangjie
  函数 直接退出(): 空类型 {
      退出(1)          // 永不返回
  }
  ```
- **注意**：`空类型`（Nothing）≠ `空`（Unit）≠ `无值`（None）：Nothing 没有值、Unit 有一个值、None 是 Option 家族的「没有」；三者用途完全不同。

## 词条 2.8 字节（字节 / UInt8）

- **是什么**：0~255 的整数，一个字节：`[1u8, 2u8, 3u8]` 是字节数组（`数组<字节>`）。
- **为什么**：文件、网络、加密等底层操作的对象是「字节流」不是「字符」。仓颉区分字符串（文本）与字节数组（二进制），防止把二进制当文本处理的经典 bug。官方 1.0.5 **没有** `ByteArray` 类型——字节数组就是 `数组<字节>`（Array<UInt8>）。
- **怎么用**：
  ```cangjie
  主函数() {
      让 数据 = [1u8, 2u8, 3u8]
      打印行(数据.长度)        // 3
      打印行(数据[1])          // 2（字节）
  }
  ```
- **注意**：`u8` 后缀表示字节字面量（见 1.12）；字节 ↔ 字符串转换：`字符串.从UTF8(字节数组)` 把字节解码成文本（见 11.11）。

## 词条 2.9 数组（数组 / Array）

- **是什么**：**定长**、**连续内存**的同类型元素序列：`[1, 2, 3]`。
- **为什么**：数组是最贴近硬件的容器——连续存储、下标 O(1) 访问。定长换性能；需要动态增减用 `向量`（ArrayList，见 7.4）。
- **怎么用**：
  ```cangjie
  主函数() {
      让 固定 = [10, 20, 30]
      打印行(固定[1])              // 20
      对于 (项 in 固定) { 打印行(项) }
      让 空数组: 数组<整数> = []
  }
  ```
- **注意**：数组**不可改变长度**（没有添加/删除）；下标越界运行时抛异常（编译期检查不出动态下标）；空数组必须标注类型（`[]` 无法推断）。

## 词条 2.10 元组（元组 / Tuple）

- **是什么**：把**不同类型**的若干值打包成一个：`(1, "小明", 真)`。
- **为什么**：相关数据不想建类时的轻量方案——「临时打包」。函数多返回值（见 5.4）底层就是元组。
- **怎么用**：
  ```cangjie
  主函数() {
      让 学生 = (1, "小明", 真)
      打印行(学生[0])            // 1
      打印行(学生[1])            // 小明
      让 (编号, 名字, 在籍) = 学生   // 解构
      打印行(名字)
  }
  ```
- **注意**：元组元素用 `[下标]` 访问（不是 `.字段`）；`(1)` 是普通数字不是元组——单元素元组要写 `(1,)`；超过 12 个元素编译器有内部上限，考虑建类。

## 词条 2.11 范围（范围 / Range）

- **是什么**：连续的整数区间：`1..5`（含头不含尾）、`1..=5`（含头含尾）。
- **为什么**：循环、切片、判断归属的通用抽象——「从哪到哪」。半开区间 `a..b` 是主流语言约定（长度 = b - a，无歧义）。
- **怎么用**：
  ```cangjie
  导入 标准集合.*
  主函数() {
      对于 (i in 1..5) { 打印行(i) }     // 1 2 3 4
      对于 (i in 1..=5) { 打印行(i) }    // 1 2 3 4 5
      打印行((1..10) |> 包含(3))         // 真（区间包含判断）
  }
  ```
- **注意**：范围默认**升序**；`5..1` 是空范围（不会报错）；`..=` 的等号在方言中照常（运算符不翻译）；判断「某个数在不在区间里」用管道 `(区间) |> 包含(数)`（官方 `(1..10) |> contains(3)`，注意区间要加括号）。

## 词条 2.12 选项（选项 / Option）

- **是什么**：**可空包装**：要么 `有值(x)`，要么 `无值`。
- **为什么**：**消灭空指针**——这是仓颉最核心的安全设计（见 00 卷）。C/Java 的 `null` 会让程序随时崩溃；仓颉把「可能没有」变成**类型的一部分**，编译器强制你用 `匹配`/`获取或默认` 处理两种可能。
- **怎么用**：
  ```cangjie
  函数 找名字(编号: 整数): 选项<字符串> {
      如果 (编号 == 1) { 返回 有值("小明") }
      返回 无值
  }
  主函数() {
      匹配 (找名字(2)) {
          情况 有值(名字) => 打印行("找到：${名字}")
          情况 无值 => 打印行("没找到")
      }
  }
  ```
- **注意**：`无值` 可赋给任意 `选项<T>`；**不要用 `匹配` 之外的裸取**——`获取或抛出()` 会抛异常（相当于把 null 重新引入）；`选项` 是值类型语义，拷贝不共享。

## 词条 2.13 类型推断（让 自动推断）

- **是什么**：声明变量时不写类型，编译器从初始值推断：`让 分数 = 90`。
- **为什么**：类型标注是给编译器与读者的信息；初始值已含类型信息时再写一遍是噪音。仓颉的推断是**全量推断**（局部变量可省、函数返回可省），同时保持强静态类型——「写起来像动态语言，查起来像静态语言」。
- **怎么用**：
  ```cangjie
  导入 标准集合.{向量}
  主函数() {
      让 分数 = 90              // 推断为 整数
      让 名字 = "小明"          // 推断为 字符串
      让 列表 = [1, 2, 3]       // 推断为 数组<整数>
      让 成绩单 = 向量<整数>()  // 显式泛型参数（空容器无法推断）
  }
  ```
- **注意**：空容器、空数组、`无值` 无法推断——必须显式标注；函数参数**必须**标注类型（不推断，见 5.3 为什么）；推断发生在编译期，不牺牲类型安全。

## 词条 2.14 类型标注（`: 类型`）

- **是什么**：显式声明变量/参数/返回值的类型：`让 分数: 整数 = 90`。
- **为什么**：类型标注是「契约」：声明了 `: 字符串` 就保证它是字符串。需要标注的场景：空容器、接口类型变量（见 6.17 多态）、需要特定位宽（`整数32`）时。
- **怎么用**：
  ```cangjie
  导入 标准集合.{向量}
  主函数() {
      让 年龄: 整数32 = 12      // 强制 32 位
      让 名字: 字符串 = "旺财"  // 显式标注类型
      让 空表: 向量<字符串> = 向量<字符串>()
  }
  ```
- **注意**：标注与推断冲突时以标注为准（`让 x: 浮点 = 1` 合法，`1` 提升为 1.0）；标注错了类型（`让 x: 整数 = "abc"`）报「类型不匹配」——这是 zhc 最常出现的教学诊断之一。

## 词条 2.15 类型转换（转换 / 构造器转换）

- **是什么**：显式把值从一种类型转成另一种：`整数(3.9)`、`分数.转换字符串()`。
- **为什么**：仓颉**不做隐式窄化/异构转换**（整数→字符串、浮点→整数都需显式）——隐式转换是 bug 温床（`"1" + 1` 到底是啥？）。显式转换让每个转换点都「可见、可控、可审」。
- **怎么用**：
  ```cangjie
  导入 转换.*
  主函数() {
      让 分数 = 95
      打印行(分数.转换字符串())        // "95"（toString）
      让 比例: 浮点 = 浮点(分数)       // 整数 → 浮点
      让 整 = 整数(3.9)                // 3（截断小数）
      打印行(整)
      打印行(整数.解析("12"))         // 字符串 → 整数（需 导入 转换.*）
  }
  ```
- **注意**：数字族互转用**构造器**（`整数(x)`、`浮点(x)`、`整数32(x)`）；整数→浮点截断是**向零截断**（`整数(-3.9)` → `-3`）；字符串 ↔ 数字用 `整数.解析("42")` / `.格式化("${0}")`（见 2.15）；`作为`（as）只用于**类型层次**转换（见 6.15），不能用于数字（`3.9 as 整数` 是 `无值`）。

## 词条 2.16 字面量类型细节

- **是什么**：数字字面量的类型由**上下文与后缀**共同决定。
- **为什么**：`42` 默认 `整数`（Int64）、`3.14` 默认 `浮点`（Float64）；给标注了其他类型的变量赋值时，字面量会**自适应**（`让 x: 整数32 = 42` 合法，不报错）。这是「字面量多态」——字面量没有固定类型，按需取型。
- **怎么用**：
  ```cangjie
  主函数() {
      让 a: 整数32 = 42        // 字面量适配 32 位
      让 b: 无符号整数 = 42u64  // 后缀强制
      让 c: 浮点32 = 3.14f32   // 后缀强制
      让 d: 整数 = 42i64      // i64 后缀显式 64 位整数
      打印行(a)
      打印行(c)
  }
  ```
- **注意**：字面量超出目标类型范围（`让 x: 整数8 = 300`）报「字面量超出范围」；`3.14` 赋值给 `浮点32` 变量不报错（字面量自适应），但 `浮点32` 变量 + `浮点` 变量会报错（**变量**间不隐式转换）。
