# 01 词法与字面量

> 词法（lexical）是编程语言的「最小积木」：程序由哪些符号组成、这些符号怎么写。
> 本卷词条：标识符 / 注释 / 整数 / 浮点 / 字符 / 字符串 / 插值 / 转义 / 布尔字面量 / 空值 / 数字分隔符 / 字面量后缀 / 关键字表 / 分号规则 / Unicode 与中文。

## 词条 1.1 标识符（identifier）

- **是什么**：给变量、函数、类型、参数取的名字。
- **为什么**：名字是程序世界的「门牌号」——没有名字就没法引用任何东西。仓颉允许 **Unicode 标识符**（包括中文），这正是 zhc 方言「用中文写代码」的根基：`让 总分 = 100` 中 `总分` 是合法标识符，编译器完全接受。
- **怎么用**：
  - 由字母、数字、下划线 `_`、中文（及任意 Unicode 字母）组成；**不能以数字开头**。
  - 不能与关键字重名（`让 让 = 1` 非法）。
  - 官方允许 `$` 开头（编译器内部用），建议不用。
  ```cangjie
  主函数() {
      让 总分 = 100
      让 平均分2 = 总分 / 2
      打印行(平均分2)
  }
  ```
- **注意**：中文标识符与英文标识符是**不同的名字**（`总分` ≠ `zongfen`）；推荐「见名知义」，中文就用有含义的词，别用 `a1`、`b2`。

## 词条 1.2 注释（comment）

- **是什么**：写给**人**看的说明文字，编译器完全忽略。
- **为什么**：代码是写给人看的（机器只是顺便执行）。注释记录「为什么这么写」——几个月后的你，就是另一个需要被帮助的读者。
- **怎么用**：
  | 形式 | 含义 | 示例 |
  |---|---|---|
  | `//` | 单行注释 | `// 这是注释` |
  | `/* ... */` | 块注释（可跨行） | `/* 多行 */` |
  | `/** ... */` | 文档注释（`zhc doc` 可提取） | `/** 计算平均分 */` |
  ```cangjie
  // 单行注释：把上面的代码改成中文试试
  主函数() {
      /* 块注释可以
         跨多行 */
      打印行("有注释的程序")  // 行尾注释
  }
  ```
- **注意**：块注释**不能嵌套**（`/* /* */` 里内层先闭合）；注释里写中文毫无障碍，这正是本项目的理念——注释、错误提示、代码全是中文。

## 词条 1.3 整数（整数 / Int64）

- **是什么**：没有小数点的数，如 `12`、`-3`、`0`。
- **为什么**：计算机里整数按固定位数存储（二进制补码）。默认整数是 64 位有符号（`整数` = Int64），范围约 ±9.2×10¹⁸。
- **怎么用**：直接写数字即可；`-` 表示负数；`_` 可以分隔大数字（见 1.12）。
  ```cangjie
  主函数() {
      让 年龄 = 12
      让 负数 = -5
      让 大数 = 9_000_000_000
      打印行("${年龄} ${负数} ${大数}")
  }
  ```
- **注意**：**溢出**——超过范围会按补码绕回（`整数` 最大值 + 1 变成最小值）。编译器默认检测运算溢出并报错（`-check-overflow` 选项控制）。

## 词条 1.4 浮点（浮点 / Float64）

- **是什么**：带小数点的数，如 `3.14`、`-0.5`、`1e3`（科学计数法 = 1000）。
- **为什么**：小数在计算机里用 IEEE 754 二进制浮点表示——**不是精确的十进制**（0.1 在二进制里是无限循环小数）。
- **怎么用**：
  ```cangjie
  主函数() {
      让 π = 3.14159
      让 科学 = 1.5e2     // 150.0
      打印行(π + 科学)
  }
  ```
- **注意**：**不要用 `==` 比较浮点**（`0.1 + 0.2 == 0.3` 是 `假`！）；整数与浮点混合运算会提升为浮点；`7 / 2` 是整数除法得 `3`，`7.0 / 2` 才是 `3.5`。

## 词条 1.5 字符（字符 / Rune）

- **是什么**：**一个** Unicode 字符，用单引号：`'中'`、`'A'`、`'\n'`。
- **为什么**：字符与字符串的区别是「一个 vs 一串」。仓颉的 `字符`（Rune）是完整 Unicode 码点——一个汉字就是一个字符（不拆成字节）。
- **怎么用**：
  ```cangjie
  主函数() {
      让 字 = '仓'
      打印行(字)          // 仓
      让 字2 = '\u{4E2D}'  // 用转义直接写码点 4E2D = 中
      打印行(字2)
  }
  ```
- **注意**：`'ab'` 非法（一个引号只能装一个字符）；转义序列（`'\n'`）算一个字符；官方 1.0.5 没有「字符 ↔ 数字」转换 API——要表示某码点的字符用 `'\u{十六进制}'` 转义。

## 词条 1.6 字符串（字符串 / String）

- **是什么**：一串 Unicode 字符，用双引号 `"..."`。
- **为什么**：字符串是程序与人交流的主要载体。仓颉字符串**不可变**（immutable）——所有「修改」操作都返回新字符串，这保证多线程下字符串天然安全。
- **怎么用**：单行用双引号；多行用三个双引号：
  ```cangjie
  主函数() {
      让 单行 = "你好"
      让 多行 = """
      第一行
      第二行
      """
      打印行(单行)
      打印行(多行)
  }
  ```
- **注意**：字符串与 `字符` 类型不同（`"中"` ≠ `'中'`）；多行字符串的缩进会保留，但首尾换行会被去掉。

## 词条 1.7 字符串插值（`${}`）

- **是什么**：在字符串里用 `${表达式}` 把值「填」进文字。
- **为什么**：拼接字符串的更好写法。`"a" + 变量` 需要手动转换类型，插值自动完成，且可读性更高——像填空题。
- **怎么用**：
  ```cangjie
  主函数() {
      让 名字 = "小明"
      让 分数 = 95
      打印行("${名字}考了${分数}分")     // 小明考了95分
      打印行("1+1=${1 + 1}")             // 里面可以放任意表达式
  }
  ```
- **注意**：`${}` 里可以放表达式但不能放语句；想输出字面 `$` 用 `\$`；方言转译时插值段整体保护（不会把插值里的中文当关键字误改）——`"${函数}"` 里的「函数」是字符串内容，不会被替换。

## 词条 1.8 转义序列（escape）

- **是什么**：用 `\` 开头的特殊写法，表示引号、换行等无法直接书写的字符。
- **为什么**：`"` 在字符串里需要区分「字符串结束」与「内容里的引号」——转义就是「我说的是内容」的标记。
- **怎么用**：
  | 写法 | 含义 |
  |---|---|
  | `\n` | 换行 |
  | `\t` | 制表符（Tab） |
  | `\\` | 反斜杠本身 |
  | `\"` | 双引号 |
  | `\'` | 单引号 |
  | `\u{4E2D}` | Unicode 码点 |
  ```cangjie
  主函数() {
      打印行("他说：\"你好\"\n下一行")
  }
  ```
- **注意**：多行字符串（`"""`）里不需要转义普通引号；`\$` 输出美元符号。

## 词条 1.9 布尔字面量（真 / true、假 / false）

- **是什么**：只有两个值的类型：`真`（true）与 `假`（false）。
- **为什么**：计算机的一切判断最终都是「是/否」。布尔是条件判断（`如果`）和逻辑运算的基础。
- **怎么用**：
  ```cangjie
  主函数() {
      让 下雨 = 真
      如果 (下雨) { 打印行("带伞") }
      打印行(3 > 5)        // 假
  }
  ```
- **注意**：`真`/`假` 是方言别名，官方写法 `true`/`false` 同样可用；**不要写 `如果 (x == 真)`**，直接 `如果 (x)`。

## 词条 1.10 空值（无值 / None、空 / Unit）

- **是什么**：两个「什么都没有」的表示：`无值`（None）表示「选项没有值」；`空`（Unit）表示「没有返回值的函数的结果」。
- **为什么**：仓颉**没有空指针**（null）——这是它的核心安全设计。没有值的情况用 `选项<类型>` 显式表达（见 8.1），编译器强制你处理「可能没有」的情况，从根上消灭空指针崩溃。
- **怎么用**：
  ```cangjie
  函数 找名字(编号: 整数): 选项<字符串> {
      如果 (编号 == 1) { 返回 有值("小明") }
      返回 无值
  }
  主函数() {
      让 结果 = 找名字(2)
      打印行(结果 == 无值)     // 真
  }
  ```
- **注意**：`空` 类型（Unit）的表达式只有一个值，常用于「函数无返回值」；`无值`（None）属于 `选项<T>` 类型家族。

## 词条 1.11 数字分隔符（`_`）

- **是什么**：数字中允许用 `_` 分隔，纯为可读性，不影响值。
- **为什么**：`1000000000` 容易数错位数；`1_000_000_000` 一目了然（像中文习惯的千分位）。
- **怎么用**：
  ```cangjie
  主函数() {
      让 人口 = 1_400_000_000
      让 长数 = 0xFFFF_FFFF
      打印行(人口)
  }
  ```
- **注意**：`_` 不能连用（`1__0` 非法）、不能在开头结尾（`_1`、`1_` 非法）；但 `_` 单独是合法的「忽略」标识符。

## 词条 1.12 字面量后缀

- **是什么**：给数字指定精确类型：`42i64`（长整数）、`7u64`（无符号）、`3.14f32`（单精度浮点）、`1u8`（字节）——整数后缀有 i8/i16/i32/i64/u8/u16/u32/u64，浮点后缀有 f16/f32/f64。
- **为什么**：默认整数是 `整数`（Int64）、默认小数是 `浮点`（Float64）。需要其他位宽时用后缀显式声明，避免隐式转换歧义。
- **怎么用**：
  ```cangjie
  主函数() {
      让 a: 整数32 = 42        // 字面量自动适配 32 位
      让 b: 浮点32 = 3.14f32   // 后缀 f32
      让 c: 无符号整数 = 7u64   // 后缀 u64
      让 d: 数组<字节> = [1u8, 2u8, 3u8]   // 字节数组（见 2.8）
      打印行(a)
      打印行(d)
  }
  ```
- **注意**：后缀**必须小写**（`42U8`、`3.14F` 是语法错误——官方只认小写后缀）；字节字面量用 `u8` 后缀（`[1u8, 2u8]`）；后缀类型要与标注一致（`浮点32` 配 `f32`、`浮点64` 配 `f64`）；不同类型**不要直接混算**（见 2.1），需要转换用构造器（`整数(3.9)`、见 2.15）。

## 词条 1.13 关键字表（方言 ↔ 官方）

- **是什么**：语言预留的名字，不能用作标识符。zhc 方言把绝大多数关键字翻译成中文。
- **为什么**：关键字是语法骨架。方言翻译的关键字让「中文编程」成为可能；少数保留官方原样（如 `in`、`&`、`|`），因为它们在语法里太「符号化」。
- **怎么用**（完整对照见 [13-词条速查](13-词条速查.md) 关键字段）：
  | 方言 | 官方 | 方言 | 官方 |
  |---|---|---|---|
  | 函数 | func | 如果/否则/否则如果 | if/else/else if |
  | 主函数 | main | 匹配/情况 | match/case |
  | 类/结构体/接口 | class/struct/interface | 当/对于 | while/for |
  | 枚举/扩展 | enum/extend | 继续/跳出 | continue/break |
  | 让/可变/常量 | let/var/const | 返回 | return |
  | 导入/包 | import/package | 抛出/尝试/捕获/最终 | throw/try/catch/finally |
  | 公开/私有/受保护/内部 | public/private/protected/internal | 是/作为/属于 | is/as/is |
  | 静态/抽象/同步/生成 | static/abstract/synchronized/spawn | 开放/重写/重定义 | open/override/redef |
  | 属性/类型/宏/初始化 | prop/type/macro/init | 本对象/超类 | this/super |
  | 修改/外部/不安全/约束 | mut/foreign/unsafe/where | 获取/设置/引用/派生 | get/set/quote/Derive |
  | 测试/期望 | Test/Expect | 官方原样：`in` | in |
- **注意**：方言关键字**不能用作标识符**（`让 函数 = 1` 非法——需要时用官方名或换词）；字符串内关键字不受影响。

## 词条 1.14 分号规则

- **是什么**：语句之间用分号 `;` 分隔；换行时可以省略。
- **为什么**：仓颉采用「换行即分号」（ASI）规则——大多数语句行尾的 `;` 可省。写法更干净，但有时会踩「换行歧义」。
- **怎么用**：
  ```cangjie
  主函数() {
      打印行("第一句")      // 行尾可不写分号
      打印行("第二句")      // 同一行多个语句必须分号分隔
      让 x = 1; 让 y = 2
  }
  ```
- **注意**：`返回` 换行后写值可能被当成独立语句——`返回` 与值写在同一行；`(` 开头的行会被当作上一行的延续。

## 词条 1.15 Unicode 与中文

- **是什么**：仓颉源码是 UTF-8 编码，标识符、字符串、注释全部支持 Unicode（包括中文、emoji 之外的任意字母表）。
- **为什么**：这是 zhc 方言的**技术基石**。zhc 做的不是「新语言」，而是「同一门语言的中文界面」——编译产物仍是标准仓颉，任何标准工具链都能编译运行（`zhc expand` 可查看转译后的官方代码）。
- **怎么用**：
  ```cangjie
  主函数() {
      让 圆周率 = 3.14        // 中文标识符
      打印行("你好，世界！")    // 中文内容
  }
  ```
- **注意**：全角符号（`（`、`。`）不是语法符号——括号、分号、引号必须用半角；zhc 转译器按「源码字符流」工作，中文标识符与字符串会原样保留（字符串保护机制保证不误改）。
