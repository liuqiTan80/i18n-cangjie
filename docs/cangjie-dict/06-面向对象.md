# 06 面向对象

> 面向对象（OOP）是把「数据 + 操作数据的方法」打包成对象，再用类、继承、接口组织对象的编程范式。
> 本卷词条：类 / 开放 / 重写 / 重定义 / 继承与超类 / 本对象 / 接口 / 抽象 / 静态 / 属性 / 访问器 / 枚举 / 结构体 / 修改 / 类型测试 / 类型转换 / 多态。

## 词条 6.1 类（类 / class）

- **是什么**：**引用类型**的模板：`类 名称 { 字段 + 方法 }`——用 `类名(...)` 构造实例。
- **为什么**：把状态（字段）与行为（方法）绑定在一起。类实例是**引用共享**的（多个变量指向同一对象，见 3.8），适合表达「同一份数据多方使用」的现实对象。
- **怎么用**：
  ```cangjie
  类 学生 {
      公开 可变 名字: 字符串
      公开 可变 分数: 整数
      初始化(名字: 字符串, 分数: 整数) {
          本对象.名字 = 名字
          本对象.分数 = 分数
      }
      公开 函数 评级(): 字符串 {
          如果 (本对象.分数 >= 90) { 返回 "优秀" }
          返回 "加油"
      }
  }
  主函数() {
      让 小明 = 学生("小明", 95)
      打印行("${小明.名字}：${小明.评级()}")
  }
  ```
- **注意**：字段默认**私有**（类外不可见，除非标 `公开`）；`初始化` 是构造器（方言名，官方 init）；类默认**不可继承**（要 `开放`，见 6.2）。

## 词条 6.2 开放（open）

- **是什么**：标记类/方法可被继承/重写：`开放 类 动物 { 公开 开放 函数 叫声() ... }`。
- **为什么**：**默认封闭**是仓颉的安全设计：继承会打破封装（子类依赖父类内部），所以继承是需要显式申请的特权。`开放` 就是「我允许别人扩展我」的声明——写类时想清楚哪些部分设计为扩展点。
- **怎么用**：
  ```cangjie
  开放 类 动物 {
      公开 可变 名字: 字符串
      初始化(名字: 字符串) { 本对象.名字 = 名字 }
      公开 开放 函数 叫声(): 字符串 { 返回 "……" }
  }
  ```
- **注意**：非 `开放` 类被继承 → 编译错误「非开放类型不能被继承」；类与方法都要 `开放`（只开类不开方法，方法也不能重写）。

## 词条 6.3 重写（重写 / override）

- **是什么**：子类把父类的 `开放` 方法**换成自己的实现**：`公开 重写 函数 叫声(): 字符串 { 返回 "汪汪" }`。
- **为什么**：多态的基石——同一个「叫声」消息，不同动物给不同回应。`重写` 关键字是**强制声明**（不写就报错），防止「想重写却拼错名字变成新方法」的经典 bug。
- **怎么用**：
  ```cangjie
  开放 类 动物 {
      公开 开放 函数 叫声(): 字符串 { 返回 "……" }
  }
  类 狗 <: 动物 {
      公开 重写 函数 叫声(): 字符串 { 返回 "汪汪" }
  }
  主函数() {
      让 旺财: 动物 = 狗()
      打印行(旺财.叫声())       // 汪汪（动态分派）
  }
  ```
- **注意**：重写方法签名必须与父类**一致**（参数类型/个数/返回类型）；父类方法没标 `开放` 时子类不能重写；重写时可用 `超类.方法名()` 调用父类版本。

## 词条 6.4 重定义（重定义 / redef）

- **是什么**：**静态方法/静态属性**在子类里的换实现：`公开 重定义 静态 函数 版本(): 字符串 { ... }`。
- **为什么**：`重写` 管「实例方法的动态分派」，`重定义` 管「静态成员的遮蔽」——两条通道分开：实例方法跟着对象走（多态），静态方法跟着类名走（编译期决定）。
- **怎么用**（静态方法重定义）：
  ```cangjie
  开放 类 基类 {
      公开 静态 函数 版本(): 字符串 { 返回 "1.0" }
  }
  类 子类 <: 基类 {
      公开 重定义 静态 函数 版本(): 字符串 { 返回 "2.0" }
  }
  主函数() {
      打印行(基类.版本())      // 1.0
      打印行(子类.版本())      // 2.0
  }
  ```
- **注意**：官方 1.0.5 中 `重定义`（redef）**只能修饰静态成员**——实例方法重写用 `重写`（override）；接口默认实现被类顶掉也用 `重写`（见 6.7）。

## 词条 6.5 继承与超类（继承 `类 A <: 类 B`、超类 / super）

- **是什么**：子类继承父类的一切（字段/方法），并可用 `超类(...)` 调用父类构造器、`超类.方法()` 调父类方法。
- **为什么**：**代码复用 + 多态**——「狗是动物」的 is-a 关系。`<:` 读作「小于冒号」= 子类型关系。
- **怎么用**：
  ```cangjie
  开放 类 动物 {
      公开 可变 名字: 字符串
      初始化(名字: 字符串) { 本对象.名字 = 名字 }
      公开 开放 函数 介绍(): 字符串 { 返回 "我是${本对象.名字}" }
  }
  类 狗 <: 动物 {
      初始化(名字: 字符串) {
          超类(名字)          // 先调父类构造器
      }
      公开 重写 函数 介绍(): 字符串 {
          返回 "${超类.介绍()}，一只狗"   // 复用父类逻辑
      }
  }
  主函数() { 打印行(狗("旺财").介绍()) }
  ```
- **注意**：仓颉**单继承**（一个类只能有一个父类）；构造器必须先调 `超类.\`init\`(参数)`（或 `本类型(...)` 委托）再初始化自己的字段；父类没有无参构造器时子类必须显式调 `超类.\`init\`(参数)`；`init` 是关键字，作为方法名要用反引号转义（`超类.\`init\`(名字)`）。

## 词条 6.6 本对象（本对象 / this）

- **是什么**：方法内指向「当前对象自己」的引用：`本对象.字段`。
- **为什么**：区分「对象的字段」与「同名参数/局部变量」——`初始化(名字: 字符串)` 里 `本对象.名字 = 名字` 左边是字段、右边是参数。
- **怎么用**：
  ```cangjie
  类 计数器 {
      公开 可变 值: 整数 = 0
      公开 函数 加(增量: 整数) {
          本对象.值 += 增量
      }
  }
  主函数() {
      让 计数 = 计数器()
      计数.加(5)
      打印行(计数.值)
  }
  ```
- **注意**：字段与参数同名时**必须**用 `本对象.` 区分（否则 `名字 = 名字` 是给自己赋值，字段没被初始化——编译器会报「未初始化」）；静态方法里没有 `本对象`。

## 词条 6.7 接口（接口 / interface）

- **是什么**：**纯行为契约**：只声明方法签名（可带默认实现），不含状态：`接口 会飞 { 函数 飞(): 字符串 }`。
- **为什么**：**多继承的能力**——类只能单继承，但可以实现**多个接口**（`类 蝙蝠 <: 动物 <: 会飞` 之类）。接口是「能力清单」：任何类只要实现清单就能被当作该能力使用（面向接口编程）。
- **怎么用**：
  ```cangjie
  接口 会叫 {
      函数 叫声(): 字符串
  }
  类 狗 <: 会叫 {
      公开 函数 叫声(): 字符串 { 返回 "汪汪" }
  }
  类 猫 <: 会叫 {
      公开 函数 叫声(): 字符串 { 返回 "喵" }
  }
  主函数() {
      让 宠物: 会叫 = 狗()
      让 猫咪: 会叫 = 猫()
      打印行(宠物.叫声() + 猫咪.叫声())
  }
  ```
- **注意**：接口方法默认**公开**；实现接口的类必须实现所有无默认方法（漏一个报错）；接口可以有**默认实现**（见 6.4）；接口变量只能调用接口声明的方法。

## 词条 6.8 抽象（抽象 / abstract）

- **是什么**：标记类/方法为「未完成品」：`抽象 类 形状 { 抽象 函数 面积(): 浮点 }`。
- **为什么**：「形状」没有具体的面积公式——只有子类（圆/方）才知道。抽象类不能被实例化（`形状()` 报错），只用来被继承；抽象方法没有实现，强制子类实现。
- **怎么用**：
  ```cangjie
  抽象 类 形状 {
      公开 函数 面积(): 浮点    // 抽象方法：不写函数体即可
  }
  类 正方形 <: 形状 {
      公开 可变 边长: 浮点
      初始化(边长: 浮点) { 本对象.边长 = 边长 }
      公开 重写 函数 面积(): 浮点 { 返回 边长 * 边长 }
  }
  主函数() { 打印行(正方形(3.0).面积()) }
  ```
- **注意**：抽象类里可以有具体方法（部分实现）；子类不实现全部抽象方法就必须也标 `抽象`；抽象类**必须有** `开放`（抽象就是允许继承的声明）——仓颉中 `抽象` 类自动开放。

## 词条 6.9 静态（静态 / static）

- **是什么**：属于**类本身**（而非实例）的成员：`静态 函数 创建(...)`、`静态 可变 计数`。
- **为什么**：工厂方法（`从文本解析`）、工具函数（`最大值`）、全局共享计数器——不需要对象就有意义的功能。静态成员用 `类名.成员` 访问。
- **怎么用**：
  ```cangjie
  类 工具 {
      静态 函数 两倍(数: 整数): 整数 { 返回 数 * 2 }
      静态 可变 调用次数: 整数 = 0
  }
  主函数() {
      工具.调用次数 += 1
      打印行(工具.两倍(21))
  }
  ```
- **注意**：静态方法**不能访问实例字段/`本对象`**（没有对象上下文）；静态可变成员是全局状态（并发需同步）；子类可「重定义」静态成员（见 6.4）。

## 词条 6.10 属性（属性 / prop）

- **是什么**：类里用 `属性` 声明的成员——外部像字段一样读写，内部由 `获取`（get）实现控制：`公开 属性 名字: 字符串 { 获取() { ... } }`。
- **为什么**：封装的两个方向：`公开 可变`（全开放）与 `属性`（可控）之间取平衡——「数据可见但不可篡改」是最常见需求。prop 只读（只有 get），`可变 属性`（mut prop）可读写（get + set）。
- **怎么用**：
  ```cangjie
  类 书 {
      私有 可变 书名值: 字符串 = ""
      公开 属性 书名: 字符串 {
          获取() { 返回 书名值 }
      }
      初始化(书名: 字符串) { 本对象.书名值 = 书名 }
  }
  主函数() {
      让 书 = 书("仓颉字典")
      打印行(书.书名)
      // 书.书名 = "别的"  ← 错误：prop 只读，不能赋值
  }
  ```
- **注意**：`属性`（prop）**只读**——只能定义 `获取()`，赋值会报错；要可读可写用 `可变 属性`（mut prop，见 6.11）；`获取()` 的括号不能省略（官方 1.0.5 语法）。

## 词条 6.11 访问器（获取 get / 设置 set）

- **是什么**：自定义「读/写」行为的可变属性：`公开 可变 属性 摄氏度: 浮点 { 获取() { ... } 设置(值) { ... } }`。
- **为什么**：字段的读写需要**附加逻辑**（校验、缓存、通知）时，访问器让「调用方无感」——外部照样 `对象.属性`，内部偷偷做校验。比暴露字段 + 到处改调用方优雅得多。
- **怎么用**：
  ```cangjie
  类 温度计 {
      私有 可变 摄氏值: 浮点 = 0.0
      公开 修改 属性 摄氏: 浮点 {
          获取() { 返回 摄氏值 }
          设置(值) { 摄氏值 = 值 }      // 设置 参数是赋入的新值
      }
  }
  主函数() {
      让 温度计 = 温度计()
      温度计.摄氏 = 36.5
      打印行(温度计.摄氏)      // 36.5
  }
  ```
- **注意**：`可变 属性`（mut prop）**必须同时提供 `获取()` 和 `设置(参数)`**；`设置` 的隐含参数名是 `值`（可显式命名）；访问器可访问私有字段（它在类内部）；`设置` 里可以加校验（非法值抛异常或忽略）。

## 词条 6.12 枚举（枚举 / enum）

- **是什么**：**有限取值集合**的类型：`枚举 方向 { 上 | 下 | 左 | 右 }`，也可带数据：`枚举 通知 { 文本(字符串) | 退出 }`。
- **为什么**：比「魔法数字」（`1` 表示上、`2` 表示下……）安全得多——编译器穷尽性检查保证所有取值都被处理（见 4.14）。带数据的枚举（标签联合）是「多种形态的数据」的经典建模。
- **怎么用**：
  ```cangjie
  枚举 方向 { 上 | 下 | 左 | 右 }
  枚举 通知 {
      文本(字符串) | 数字(整数) | 结束
  }
  主函数() {
      让 朝向 = 方向.上
      匹配 (朝向) {
          情况 方向.上 => 打印行("向上")
          情况 _ => 打印行("其他方向")
      }
      让 内容 = 通知.文本("你好")
      匹配 (内容) {
          情况 通知.文本(文字) => 打印行("文本：${文字}")
          情况 通知.数字(数) => 打印行("数字：${数}")
          情况 通知.结束 => 打印行("结束")
      }
  }
  ```
- **注意**：枚举取值用 `枚举名.成员`（`方向.上`）；带数据枚举的成员像构造器（`通知.文本("你好")`）；穷尽性检查对枚举**强制全分支**（除非有 `_`）。

## 词条 6.13 结构体（结构体 / struct）

- **是什么**：**值类型**的数据打包：`结构体 点 { 公开 可变 x: 整数 ... }`。
- **为什么**：与类的本质区别——**值语义**：赋值/传参是**整体拷贝**，不是共享引用（见 3.8）。适合「小数据 + 无多态」的场景（坐标、颜色、金额）：拷贝安全、无别名问题、性能可控。**经验法则：数据小且独立用结构体，需要多态/共享用类。**
- **怎么用**：
  ```cangjie
  结构体 点 {
      公开 可变 x: 整数
      公开 可变 y: 整数
      初始化(x: 整数, y: 整数) {
          本对象.x = x
          本对象.y = y
      }
      公开 函数 距离平方(): 整数 { 返回 x * x + y * y }
  }
  主函数() {
      让 原点 = 点(3, 4)
      可变 拷贝 = 原点
      拷贝.x = 100           // 只改拷贝，原点不受影响
      打印行("${原点.x} ${拷贝.x}")    // 3 100
  }
  ```
- **注意**：结构体**不能继承**、不能有抽象成员、不能有 `本对象` 的多态分派（它是值）；结构体字段默认私有；结构体可以嵌套在类里（组合优于继承）。

## 词条 6.14 修改（mut）——结构体可变成员函数

- **是什么**：修饰结构体/接口的**实例成员函数**：`公开 修改 函数 自增()`——被标记的函数可以修改 `本对象` 的字段（官方 mut）。
- **为什么**：结构体是**值类型**，`让` 绑定又不可变——若成员函数能悄悄改写字段，拷贝出的副本会「偷偷变化」。`修改` 把「这个函数会改变自身」变成**可见的许可**：调用方看到 `修改` 就知道要小心副本语义。类（class）是引用类型，方法天然能改字段，所以**禁止**加 mut。
- **怎么用**：
  ```cangjie
  结构体 计数器 {
      公开 可变 值: 整数
      初始化(值: 整数) { 本对象.值 = 值 }
      公开 修改 函数 自增() {
          值 += 1            // mut 函数才能修改结构体自身
      }
  }
  主函数() {
      可变 数 = 计数器(1)
      数.自增()
      打印行(数.值)          // 2
  }
  ```
- **注意**：mut 函数只能在**可变实例**上调用（`让 数 = 计数器(1); 数.自增()` 报错——`让` 绑定不可变，需 `可变 数`）；`可变` 字段同样只在可变实例上可改；mut **只能**修饰结构体/接口的实例成员函数——不能修饰参数、成员变量、静态函数，class 的方法也不能加 mut（官方 1.0.5）。

## 词条 6.15 类型测试（是 / is）

- **是什么**：检查对象是否为某类型：`对象 是 类型`，结果是 `布尔`。
- **为什么**：多态世界的「身份确认」——拿到 `动物` 变量，想知道它到底是不是 `狗`。配合 `作为` 使用（先 `是` 判断再 `作为` 转换，安全）。
- **怎么用**：
  ```cangjie
  开放 类 动物 {}
  类 狗 <: 动物 {}
  类 猫 <: 动物 {}
  主函数() {
      让 宠物: 动物 = 狗()
      如果 (宠物 是 狗) { 打印行("是狗") }
      打印行(宠物 是 猫)       // 假
  }
  ```
- **注意**：`是` 也用于**模式匹配**（`情况 x 是 字符串 => ...`，官方叫 is pattern）；对值类型（结构体）用 `是` 会做装箱比较，慎用。

## 词条 6.16 类型转换（作为 / as，类型层次）

- **是什么**：类型层次上的显式转换：**向上**（子→父，自动隐式）与**向下**（父→子，必须 `作为`）。
- **为什么**：向上转换永远安全（狗一定是动物）——自动；向下转换可能失败（动物不一定是狗）——必须显式 `作为`，失败抛异常（类型转换异常）。
- **怎么用**：
  ```cangjie
  开放 类 动物 {}
  类 狗 <: 动物 {
      公开 函数 摇尾巴(): 字符串 { 返回 "摇尾巴" }
  }
  主函数() {
      让 宠物: 动物 = 狗()         // 向上：自动
      让 旺财 = (宠物 作为 狗).获取或抛出()   // 向下：显式（as 返回 选项，需解包）
      打印行(旺财.摇尾巴())
  }
  ```
- **注意**：官方 1.0.5 的 `作为`（as）返回 **`选项<T>`**（`宠物 as 狗` 得 `选项<狗>`）——成功是 `有值(狗)`、失败是 `无值`，用 `.获取或抛出()` 解包或 `匹配` 处理；向下转换前先用 `是` 判断（6.15）更稳妥；**数字转换与类型层次转换是两回事**（`整数(3.9)` 是数值转换，`宠物 作为 狗` 是类型层次）。

## 词条 6.17 多态与动态绑定（polymorphism）

- **是什么**：**接口/父类类型变量**可以装任意实现/子类对象，调用方法时**运行时**决定执行哪个版本。
- **为什么**：面向对象的核心价值——**面向接口编程**：代码依赖「抽象」而不是「具体」。`打印` 任何 `动物` 的叫声，不需要知道它具体是什么动物——新增猫/鸟时**调用方代码一行不改**。
- **怎么用**：
  ```cangjie
  接口 会叫 {
      函数 叫声(): 字符串
  }
  类 狗 <: 会叫 {
      公开 函数 叫声(): 字符串 { 返回 "汪汪" }
  }
  类 猫 <: 会叫 {
      公开 函数 叫声(): 字符串 { 返回 "喵" }
  }
  函数 齐声叫(宠物们: 数组<会叫>) {
      对于 (宠物 in 宠物们) {
          打印行(宠物.叫声())       // 动态绑定：各自叫各自的
      }
  }
  主函数() {
      齐声叫([狗(), 猫()])
  }
  ```
- **注意**：多态只对**引用类型**（类/接口）有效，结构体是值类型没有动态绑定；`开放`/`重写`/接口实现共同构成多态三件套；动态绑定意味着调用有轻微开销（虚表查找），现代硬件可忽略。
