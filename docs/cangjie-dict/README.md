# 仓颉方言字典（zhc Dictionary）

> **查字典，而不是读教程。** 本字典以「词条」为单位组织，覆盖仓颉语言的**每一个知识点**：
> 词法、类型、变量、控制流、函数、面向对象、泛型、集合、错误处理、并发、宏、模块、系统 IO、测试，
> 以及它们背后的**设计思想**（仓颉为什么这么设计、方言为什么这么翻译）。
>
> 每个词条统一为四要素：
> **是什么**（一句话定义）→ **为什么**（设计思想）→ **怎么用**（语法要点 + 示例）→ **注意**（陷阱与常见错误）。
>
> 配套读物：[初中生入门书](../cangjie-book.md)（线性学习路线）、[09 章教学教程](../tutorial/README.md)（渐进教学）。

## 使用说明

1. **按名查词**：想查什么概念，去 [12 词条速查](12-词条速查.md) 按拼音/笔画/英文找卷号。
2. **按卷通读**：想系统学一个知识域，按卷号顺序读（每卷词条按依赖顺序排列）。
3. **示例可运行**：所有代码示例均用 `zhc run` 实测通过；标注「片段」的示例需放入 `主函数()` 运行。
4. **方言与官方对照**：词条名格式为「方言（官方）」，如「让（let）」。官方原样保留的词条（如 `in`）只有官方名。
