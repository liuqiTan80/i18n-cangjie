# 11 系统与 IO

> 程序与外部世界打交道：屏幕（输出）、键盘（输入）、文件、进程、时间、网络、正则。
> 本卷词条：打印 / 打印行 / 读取行 / 文件系统 / 读取与写入 / 进程 / 时间 / 环境变量 / 网络 / 正则 / 编码与序列化 / 标准流。

## 词条 11.1 打印（打印 / print）

- **是什么**：向屏幕输出**不换行**：`打印("你好")`。
- **为什么**：与 `打印行` 的区别只在换行——`打印("a") 打印("b")` 输出 `ab`。适合进度提示、连续输出。
- **怎么用**：
  ```cangjie
  主函数() {
      打印("你好")
      打印("，世界")
      打印行("！")
  }
  ```
- **注意**：输出到标准输出（stdout）；数字直接打印（自动转字符串）；`打印` 接受任意可转字符串的值。

## 词条 11.2 打印行（打印行 / println）

- **是什么**：输出一行**并换行**：`打印行("内容")`。
- **为什么**：最常用的输出——一行一条信息，日志友好。本质是 `打印(内容 + "\n")` 的封装。
- **怎么用**：
  ```cangjie
  主函数() {
      打印行("第一行")
      打印行("第二行")
  }
  ```
- **注意**：方言别名 `打印行` → 官方 `println`；`打印行()` 空参数输出一个空行；字符串插值（1.7）是它的最佳搭档。

## 词条 11.3 读取行（读取行 / readln）

- **是什么**：从键盘读**一行**文本（直到回车）：`让 输入 = 读取行()`，返回 `字符串`。
- **为什么**：交互式程序的输入通道（猜数字游戏、问答程序）。读进来的是字符串——要数字需 `解析`（见 11.11 与 2.15）。
- **怎么用**：
  ```cangjie
  主函数() {
      打印("请输入你的名字：")
      让 名字 = 读取行()
      打印行("你好，${名字}！")
  }
  ```
- **注意**：读入的内容**不含换行符**；输入流结束（Ctrl+D）时返回空串——写循环时要处理（见 11.12）；`读取行` 返回 `字符串`，不是 `选项`。

## 词条 11.4 文件系统（文件系统 / std.fs）

- **是什么**：操作文件与目录的标准库：路径、存在性、创建、删除、列出、读写。
- **为什么**：数据持久化（保存成绩、读取配置）是程序的基本能力。`std.fs` 提供跨平台的文件 API——同一份代码在 Windows/Linux/macOS 都能跑。
- **怎么用**（路径与存在性）：
  ```cangjie
  导入 文件系统.*
  主函数() {
      让 路径 = 文件路径("数据/成绩.txt")
      打印行(路径.转换字符串())               // 数据/成绩.txt
      打印行(是否存在("数据/成绩.txt"))       // 真/假（顶层函数）
      打印行(路径.父目录)                     // 数据（属性，不带括号）
      打印行(路径.扩展名)                     // txt（属性，不带括号）
  }
  ```
- **注意**：方言模块路径 `文件系统` → 官方 `std.fs`（见 module_paths.toml）；`文件路径`（官方 Path）**单参数**构造（`文件路径("数据/成绩.txt")`，不要手拼 `/`——跨平台）；`父目录`/`扩展名` 是**属性**（不带括号）；文件 API 失败会抛异常（用 8.8 捕获）。

## 词条 11.5 读取与写入（读取 / read、写入 / write）

- **是什么**：文件内容读写：`文件.写入文件(路径, 字节数组)` / `文件.读取文件(路径)`（官方 File.writeTo/readFrom 静态方法，返回字节数组）。
- **为什么**：读文件 = 打开 → 读取 → 关闭；写文件 = 打开 → 写入 → 关闭。**文件读写的是字节**（`数组<字节>`），文本要经 UTF-8 编解码（见 11.11）。
- **怎么用**（示意）：
  ```cangjie
  导入 文件系统.*
  主函数() {
      让 字节 = [65u8, 66u8, 67u8]        // "ABC" 的字节
      文件.写入文件("成绩.txt", 字节)     // 写入（覆盖）
      让 内容 = 文件.读取文件("成绩.txt") // 读回字节数组
      打印行(内容)                         // [65, 66, 67]
      文件.追加写入("成绩.txt", [68u8])   // 追加一个字节
  }
  ```
- **注意**：`写入文件` 默认**覆盖**（追加用 `追加写入`，官方 appendTo）；读取文件返回 `数组<字节>`（字节数组）；文本文件要转字符串用 `字符串.从UTF8(字节)`（见 11.11）；官方 1.0.5 文件 API 是**一次性读写**（写小文件最方便）——大文件/流式读写用 `文件(路径, 打开模式)` 对象 + `读取字节`/`写入`/`关闭`（见官方文档，本教程不展开）。

## 词条 11.6 进程（进程 / std.os.process）

- **是什么**：启动/管理子进程：执行命令、读输出、退出码。
- **为什么**：程序调用系统命令（`ls`、`git`）或外部工具的能力——脚本化的基础。
- **怎么用**（示意）：
  ```cangjie
  导入 进程.*
  主函数() {
      让 命令 = 命令构造("echo", ["你好"])
      让 输出 = 命令.执行并读取()
      打印行(输出.标准输出)
  }
  ```
- **注意**：方言模块路径 `进程` → 官方 `std.os.process`；子进程错误通过退出码与标准错误报告；执行外部命令是安全敏感操作（路径注入——参数传数组而不是拼字符串）。

## 词条 11.7 时间（时间 / std.time）

- **是什么**：获取当前时间、单调计时：`日期时间.当前时间()`（官方 DateTime.now）、`单调时间.当前时间()`（MonoTime.now，适合计时）。
- **为什么**：日志时间戳、计时、定时任务都靠它。`日期时间` 是**日历时间**（年/月/日/时区），`单调时间` 是**纯计时器**（只适合算间隔，不适合显示）。
- **怎么用**：
  ```cangjie
  导入 时间.*
  主函数() {
      让 现在 = 日期时间.当前时间()
      打印行(现在)
      让 开始 = 单调时间.当前时间()
      // 干点活
      让 结束 = 单调时间.当前时间()
      打印行("耗时 ${结束 - 开始}")   // 如 20ns（Duration 类型）
  }
  ```
- **注意**：`日期时间.当前时间()` → 官方 `DateTime.now()`（返回当前时区日历时间）；`单调时间.当前时间()` → `MonoTime.now()`；时间格式化/解析用 `时间格式化`（官方 DateTimeFormat，见官方文档）。

## 词条 11.8 环境变量（环境 / env）

- **是什么**：读取程序环境：`获取环境变量("HOME")`（官方 getVariable，返回**选项**）、命令行参数 `参数`（官方 args）。
- **为什么**：程序运行环境的配置通道（语言、路径、开关）——不硬编码配置，读环境。
- **怎么用**：
  ```cangjie
  导入 环境.*
  主函数() {
      让 用户目录 = 获取环境变量("HOME")
      打印行("用户目录：${用户目录.获取或默认({ => "未知" })}")
  }
  ```
- **注意**：`获取环境变量` 返回 **`选项<字符串>`**（变量不存在 → `无值`）——用 `.获取或默认(默认值)` 或 `匹配` 处理；命令行参数：`参数()` 返回参数数组（第 0 个是程序名）；同模块还有 `设置环境变量`/`环境变量表`/`进程编号`/`命令行`。

## 词条 11.9 网络（网络 / std.net）

- **是什么**：TCP/UDP 网络通信：`TcpSocket`/`UdpSocket` 类型 + `连接`/`监听`/`发送`/`接收` 等方法（官方 std.net 包）。
- **为什么**：程序之间的通信（客户端-服务器）——聊天、下载、API 调用。
- **怎么用**（示意，**需服务器配合，本教程不实测**）：
  ```
  官方 std.net 的核心形态（伪代码示意）：
  TcpSocket() 创建套接字
  .连接(地址, 端口)  连接服务器（connect）
  .发送(字节数组)    发送数据（send）
  .接收(缓冲区)     接收数据（receive，返回收到的字节数）
  .监听(端口)       服务器端监听（listen）
  .接受()           接受连接（accept，返回新套接字）
  .关闭()           关闭连接（close）
  ```
- **注意**：网络收发的是**字节数组**（`数组<字节>`），文本要先 UTF-8 编码（见 11.11）；网络是**阻塞**操作（考虑并发 8.12 多路处理）；协议细节（HTTP）需自行组装或第三方库；完整可运行示例见官方文档 std.net 教程。

## 词条 11.10 正则（正则 / std.regex）

- **是什么**：正则表达式匹配：`正则("\\d+").匹配正则(文本)`（方言）→ 官方 `Regex(pattern).matches(str): Bool`——判断「是否匹配」；官方另有 `find` 返回 `选项<匹配数据>`（取匹配到的内容），方言未收录，需要时直接写官方名。
- **为什么**：文本模式匹配（校验手机号、提取邮箱、替换脏词）——比手写字符串遍历强大得多。
- **怎么用**：
  ```cangjie
  导入 正则.*
  主函数() {
      让 手机号 = "13812345678"
      打印行(正则("^1\\d{10}$").匹配正则(手机号))   // 真
      打印行(正则("\\d+").匹配正则("a1b2"))        // 真（含数字）
      打印行(正则("\\d").替换全部("a1b2", "#"))   // a#b#（替换全部）
  }
  ```
- **注意**：方言 `匹配正则` → 官方 `matches`（返回布尔）、`替换全部` → `replaceAll`——都是**正则对象的方法**（`正则(模式).匹配正则(文本)`）；要取匹配到的内容用官方 `find`（返回 `选项<匹配数据>`）；正则里的 `\` 在字符串里要**双写**（`"\\d"`）；正则表达式本身是门语言——复杂模式先测试再上（`zhc run` 快速验证）。

## 词条 11.11 编码与序列化（编码 / UTF-8、字符流 / runes）

- **是什么**：文本 ↔ 字符 ↔ 字节的关系：**字符串内部就是 UTF-8 字节**；`字符数组()`（官方 toRuneArray）按**字符**拆；`字符串.从UTF8(字节数组)` 把字节解码回文本。
- **为什么**：文件与网络传输的都是**字节**——理解「字符数 ≠ 字节数」（中文 1 字符 = 3 字节）就不会踩切片/长度/编码的坑。官方 1.0.5 没有独立的 `编码()`/`解码()`/`打包`/`解包` 便捷 API。
- **怎么用**（示意）：
  ```cangjie
  主函数() {
      让 文本 = "中文"
      打印行(文本.字符数组().长度)    // 2（字符数）
      打印行(文本.长度)               // 6（字节数，UTF-8 下每汉字 3 字节）
      让 还原 = 字符串.从UTF8([228u8, 184u8, 173u8])  // “中”的 UTF-8 字节
      打印行(还原)                     // 中
  }
  ```
- **注意**：`长度` 是字节数、`字符数组()` 得字符数组——需要字符时用后者（或 `字符流()` 惰性版）；官方 1.0.5 **没有**公开的「文本→字节」便捷方法（`字符串.从UTF8` 只管解码）；序列化/JSON 等用第三方库（`JSON` 模块）处理；默认编码 UTF-8（中文安全）。

## 词条 11.12 标准流（标准输入 / getStdIn、标准输出 / getStdOut、标准错误 / getStdErr）

- **是什么**：三个预定义流：`标准输入()`（键盘）、`标准输出()`（屏幕）、`标准错误()`（错误信息）——官方 std.env 的 `getStdIn()/getStdOut()/getStdErr()`。
- **为什么**：**输出分流**是 Unix 哲学：正常结果走标准输出（可重定向到文件），错误提示走标准错误（始终显示）——管道与脚本靠这个区分「数据」与「日志」。
- **怎么用**（示意）：
  ```cangjie
  导入 环境.{标准输入, 标准输出, 标准错误}
  主函数() {
      标准输出().写入("正常结果\n")
      标准错误().写入("警告：这不是数据\n")
  }
  ```
- **注意**：`打印行` 走标准输出；zhc 自己的错误提示与「💡 教学诊断」走标准错误（重定向 `> 文件` 时看不到错误是正常的）；`标准输入().读取行()`（官方 readln）返回**选项**——`无值` 表示输入流结束（Ctrl+D），逐行处理大输入时用 `匹配` 判断结束。
