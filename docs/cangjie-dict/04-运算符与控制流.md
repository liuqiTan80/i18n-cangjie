# 04 运算符与控制流

> 运算符是「动作」，控制流是「路线」——程序不是直线，而是有岔路（判断）、有绕圈（循环）、有分岔（匹配）的路线图。
> 本卷词条：算术 / 比较 / 逻辑 / 赋值 / 复合赋值 / 区间 / 如果 / 否则 / 否则如果 / 当 / 对于 / 跳出 / 继续 / 匹配 / 情况 / 匹配守卫 / 表达式值。

## 词条 4.1 算术运算符

- **是什么**：`+` 加、`-` 减、`*` 乘、`/` 除、`%` 取余。
- **为什么**：数学运算人人都会；需要注意**整数的 `/` 与 `%`**——`7 / 2 == 3`（整除，小数丢弃）、`7 % 2 == 1`（余数）。判断奇偶、取末位数字全靠 `%`。
- **怎么用**：
  ```cangjie
  主函数() {
      打印行(7 / 2)        // 3
      打印行(7 % 2)        // 1
      打印行(7.0 / 2.0)    // 3.5
      打印行((1 + 2) * 3)  // 9（括号优先）
  }
  ```
- **注意**：运算符优先级与数学一致（先 `*` `/` `%`，后 `+` `-`）；`/ 0` 运行时抛异常（整数）或得到无穷（浮点）；溢出默认被检测（见 1.3）。

## 词条 4.2 比较运算符

- **是什么**：`==` 相等、`!=` 不等、`>` `>=` `<` `<=`。
- **为什么**：比较产生 `布尔`——控制流的燃料。两个易错点：**`==` 是双等号**（单等号是赋值）、**浮点别用 `==`**（见 1.4）。
- **怎么用**：
  ```cangjie
  主函数() {
      让 分数 = 85
      打印行(分数 == 85)    // 真
      打印行(分数 != 60)    // 真
      打印行(分数 >= 90)    // 假
  }
  ```
- **注意**：字符串可以用 `==`（比较内容，不是地址——这比 C/Java 更符合直觉）；`==` 不能用于 `浮点` 精确比较；`无值`/`有值` 用 `==` 与模式匹配都行。

## 词条 4.3 逻辑运算符

- **是什么**：`与`（&&）、`或`（||）、`非`（!）——方言名：`与`/`或`/`非`；官方写法 `&&`/`||`/`!`。
- **为什么**：组合多个条件。**短路求值**是核心设计：`假 与 任何` 直接得 `假`（右边不执行）、`真 或 任何` 直接得 `真`——因此可以安全写 `列表.大小 > 0 与 列表[0] > 1`（第一个条件假时不会访问越界）。
- **怎么用**：
  ```cangjie
  主函数() {
      让 年龄 = 15
      让 有票 = 真
      如果 (年龄 >= 12 与 有票) { 打印行("可以入场") }
      如果 (年龄 < 6 或 年龄 > 80) { 打印行("免费") }
      如果 (非 有票) { 打印行("请买票") }
  }
  ```
- **注意**：方言 `与`/`或` 转译为 `&&`/`||`——**优先级与官方一致**（`与` 高于 `或`，同数学的乘除优先于加减）；条件必须整体是 `布尔`（`如果 (x 与 y)` 中 x/y 都须是布尔，不能是数字）。

## 词条 4.4 赋值运算符

- **是什么**：`=` 把右边的值放进左边的盒子。
- **为什么**：赋值是「放入」不是「等于」——`x = x + 1` 合法且常见（先取旧值，算完放回）。这是新手最容易困惑的点（数学里 `x = x + 1` 无解）。
- **怎么用**：
  ```cangjie
  主函数() {
      可变 计数 = 1
      计数 = 计数 + 1      // 取出 1，加 1，放回 2
      打印行(计数)
  }
  ```
- **注意**：`=` 左边必须是**可变**的（`让 x = 1; x = 2` 报错）；`==` 才是比较——写 `如果 (x = 1)` 直接编译报错（条件必须是布尔，而 `x = 1` 的值是整数）——这个设计帮你挡住经典 bug。

## 词条 4.5 复合赋值

- **是什么**：`+=` `-=` `*=` `/=` `%=` 等——`x += 2` 等价于 `x = x + 2`。
- **为什么**：短、快、清楚——「给 x 加上 2」一步表达。是循环计数（`总和 += i`）的标配。
- **怎么用**：
  ```cangjie
  主函数() {
      可变 总和 = 0
      对于 (i in 1..6) { 总和 += i }
      打印行(总和)          // 15
  }
  ```
- **注意**：复合赋值同样要求左边可变；`+=` 用于字符串是拼接（`s += "!"`）。

## 词条 4.6 区间运算符

- **是什么**：`a..b`（含 a 不含 b）、`a..=b`（含 a 含 b）——见 2.11 完整讲解。
- **为什么**：循环与切片的「区间」抽象；半开区间是主流程派的约定（长度 = b - a，两个区间无缝拼接）。
- **怎么用**：
  ```cangjie
  主函数() {
      对于 (i in 0..3) { 打印行(i) }       // 0 1 2
      对于 (i in 0..=3) { 打印行(i) }      // 0 1 2 3
  }
  ```
- **注意**：区间只能用于整数；`in` 是官方关键字（方言原样保留）。

## 词条 4.7 如果（if）

- **是什么**：条件成立则执行分支：`如果 (条件) { ... }`。
- **为什么**：程序做决策的基本单元。注意条件必须带**布尔表达式**（杜绝 C 的 0/1 陷阱）。
- **怎么用**：
  ```cangjie
  主函数() {
      让 分数 = 85
      如果 (分数 >= 60) {
          打印行("及格")
      }
  }
  ```
- **注意**：分支体即使只有一条语句也**推荐写花括号**（避免悬空 else 歧义）；`如果` 可以作为**表达式**（见 4.17）。

## 词条 4.8 否则（else）

- **是什么**：`如果` 不成立时执行的兜底分支。
- **为什么**：二选一的「否则」让判断完整——没有 `否则`，条件为假时什么都不做；有 `否则`，程序保证二路必走其一。
- **怎么用**：
  ```cangjie
  主函数() {
      让 分数 = 40
      如果 (分数 >= 60) { 打印行("及格") }
      否则 { 打印行("不及格") }
  }
  ```
- **注意**：`否则` 必须紧跟 `如果` 块结束的 `}` 之后（同一行或换行均可，但中间不能插入其他语句）。

## 词条 4.9 否则如果（else if）

- **是什么**：多条件依次判断的连锁：`如果 ... 否则如果 ... 否则如果 ... 否则 ...`。
- **为什么**：多档位分类（优/良/及格/不及格）的自然写法。**从上到下只命中第一个成立的分支**——顺序就是优先级。
- **怎么用**：
  ```cangjie
  函数 评级(分数: 整数): 字符串 {
      如果 (分数 >= 90) { 返回 "优秀" }
      否则如果 (分数 >= 80) { 返回 "良好" }
      否则如果 (分数 >= 60) { 返回 "及格" }
      否则 { 返回 "加油" }
  }
  主函数() { 打印行(评级(85)) }
  ```
- **注意**：条件顺序很重要——`>= 60` 写在 `>= 90` 前面会吞掉所有及格以上；条件互斥时顺序无所谓。

## 词条 4.10 当（while）

- **是什么**：**条件为真就重复**执行的循环：`当 (条件) { ... }`。
- **为什么**：适合「不知道要循环多少次，只知道什么时候停」的场景（读文件直到末尾、等待用户输入有效值）。循环前先判断条件——**可能一次都不执行**。
- **怎么用**：
  ```cangjie
  主函数() {
      可变 剩下面条 = 3
      当 (剩下面条 > 0) {
          打印行("吃第${剩下面条}根")
          剩下面条 -= 1
      }
  }
  ```
- **注意**：**死循环**——条件永不假时无限执行（忘记更新循环变量）；按 Ctrl+C 中断；`当 (真)` 配 `跳出` 是「直到」循环的惯用写法（见 11 章猜数字游戏）。

## 词条 4.11 对于（for）

- **是什么**：遍历**可迭代对象**（区间/数组/向量/哈希映射的键等）的循环：`对于 (元素 in 容器) { ... }`。
- **为什么**：相比 `当`，「对于」不需要手动管理「计数器变量」——遍历容器是最高频的循环场景，语法越简单越不容易错（不会忘写 `i += 1`）。
- **怎么用**：
  ```cangjie
  导入 标准集合.{向量}
  主函数() {
      对于 (i in 0..3) { 打印行(i) }        // 区间
      可变 名单 = 向量<字符串>()
      名单.添加("小明")
      名单.添加("小红")
      对于 (名字 in 名单) { 打印行(名字) }   // 容器
  }
  ```
- **注意**：`对于` 的循环变量是**只读绑定**（`名字 = "x"` 报错，想改用下标循环）；遍历时**不要修改容器结构**（删除/添加会改变迭代行为）。

## 词条 4.12 跳出（break）

- **是什么**：立即**结束整个循环**，跳到循环后的第一条语句。
- **为什么**：提前退出——找到目标就不必继续找（搜索场景的性能与语义必需）。配合 `当 (真)` 实现「直到满足才停」。
- **怎么用**：
  ```cangjie
  主函数() {
      对于 (i in 0..100) {
          如果 (i * i > 50) {
              打印行("第一个平方超 50 的是${i}")
              跳出
          }
      }
  }
  ```
- **注意**：`跳出` 只跳出**最近一层**循环（嵌套循环需逐层跳出或提取函数用 `返回`）；`跳出` 不能跳出 `匹配`（用 `返回`）。

## 词条 4.13 继续（continue）

- **是什么**：跳过**本次**循环的剩余部分，进入**下一次**迭代。
- **为什么**：过滤型逻辑——「不合条件就跳过」比「用大 if 包住全部逻辑」更平铺直叙。
- **怎么用**：
  ```cangjie
  主函数() {
      可变 偶数总和 = 0
      对于 (i in 0..10) {
          如果 (i % 2 != 0) { 继续 }    // 奇数跳过
          偶数总和 += i
      }
      打印行(偶数总和)      // 0+2+4+6+8 = 20
  }
  ```
- **注意**：`继续` 在 `当` 循环里会**回到条件判断**（不是直接下一轮）；在 `对于` 里跳到下一个元素。

## 词条 4.14 匹配（match）

- **是什么**：把值与多个**模式**逐一比对，命中则执行对应分支：`匹配 (值) { 情况 模式 => 代码 }`。
- **为什么**：这是仓颉（继承 Rust/OCaml 传统）最强大的控制结构——**穷尽性检查**：编译器强制你覆盖所有情况（枚举/选项必须全列），漏掉一种就编译失败。比 `如果` 链更安全：`如果` 可能漏写，`匹配` 不会。
- **怎么用**：
  ```cangjie
  函数 找名字(编号: 整数): 选项<字符串> {
      如果 (编号 == 1) { 返回 有值("小明") }
      返回 无值
  }
  主函数() {
      匹配 (找名字(1)) {
          情况 有值(名字) => 打印行("找到：${名字}")
          情况 无值 => 打印行("没找到")
      }
  }
  ```
- **注意**：分支体多条语句时用 `{ ... }` 包住；`匹配` 是**表达式**（可赋值给变量，见 4.17）；模式可以是字面量/变量绑定/枚举构造器/元组/通配符（见 4.15）。

## 词条 4.15 情况（case）与模式

- **是什么**：`情况` 是 `匹配` 的每个分支；**模式**是分支的「匹配规则」。
- **为什么**：模式比「等于比较」强大得多——一次匹配可以同时完成**判断 + 解构 + 绑定**（`情况 有值(名字)` 既判断是有值、又取出里面的名字）。这是函数式语言的核心设计。
- **怎么用**（常见模式）：
  ```cangjie
  主函数() {
      让 点 = (3, 4)
      匹配 (点) {
          情况 (0, 0) => 打印行("原点")
          情况 (x, 0) => 打印行("在 x 轴上：${x}")
          情况 (0, y) => 打印行("在 y 轴上：${y}")
          情况 (x, y) => 打印行("普通点（${x}，${y}）")
      }
  }
  ```
- **注意**：模式匹配顺序从上到下，**第一个命中生效**；`_` 通配符匹配任意（`情况 _ => ...` 兜底）；穷尽性检查要求：匹配元组/枚举时所有可能都要有分支或 `_` 兜底。

## 词条 4.16 匹配守卫（match guard）

- **是什么**：`情况` 后跟 `其中`（官方 where）附加条件：`情况 模式 其中 (条件) => ...`。
- **为什么**：模式只能匹配「形状」，守卫能匹配「形状 + 条件」——把「这个值满足什么额外条件」直接写在分支上，避免在分支体里再套一层 `如果`。
- **怎么用**：
  ```cangjie
  主函数() {
      让 分数 = 95
      匹配 (分数) {
          情况 x 其中 (x >= 90) => 打印行("优秀")
          情况 x 其中 (x >= 60) => 打印行("及格")
          情况 _ => 打印行("加油")
      }
  }
  ```
- **注意**：守卫**不参与穷尽性检查**（`_` 兜底通常仍需保留）；守卫里绑定的变量（`x`）在分支体内可用。

## 词条 4.17 表达式值（if/match 是表达式）

- **是什么**：`如果`/`匹配`/`块` 都**有值**，可以直接赋值：`让 结果 = 如果 (a > b) { "大" } 否则 { "小" }`。
- **为什么**：表达式化让代码更紧凑且更安全（没有「忘记初始化」的问题——分支必须都有值）。这是函数式风格渗透到命令式结构的体现。
- **怎么用**：
  ```cangjie
  主函数() {
      让 分数 = 85
      让 评语 = 如果 (分数 >= 60) { "及格" } 否则 { "不及格" }
      打印行(评语)

      让 描述 = 匹配 (分数) {
          情况 x 其中 (x >= 90) => "优秀"
          情况 x 其中 (x >= 60) => "及格"
          情况 _ => "加油"
      }
      打印行(描述)
  }
  ```
- **注意**：作为表达式时，**所有分支必须返回同一类型**（或可推断的公共类型）；分支是 `打印行(...)`（返回单元）时整个表达式是单元类型——此时用语句风格即可。
