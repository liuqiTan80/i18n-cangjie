# 07 泛型与集合

> 泛型是「类型的参数化」——写一次，适用于所有类型；集合是「装东西的容器」。两者组合出标准库的绝大多数能力。
> 本卷词条：泛型函数 / 泛型类 / 约束 / 接口作为约束 / 向量 / 哈希映射 / 哈希集合 / 数组 / 区间 / 迭代器 / 惰性序列 / 添加 / 删除 / 包含 / 键 / 映射 / 过滤 / 遍历 / 求和 / 累加 / 排序 / 倒序 / 去重 / 分组 / 滑窗 / 字符串方法群。

## 词条 7.1 泛型函数

- **是什么**：函数参数类型用**类型参数**占位：`函数 相同(甲: T, 乙: T): 布尔`——`<: T` 表示「任意类型」。
- **为什么**：`打印列表` 对 `向量<整数>` 和 `向量<字符串>` 的逻辑完全相同——为每个类型复制一遍代码违背 DRY。泛型让**一份代码适用所有类型**，且类型安全在编译期检查（比 `对象` 强转安全）。
- **怎么用**：
  ```cangjie
  导入 标准集合.{向量}
  函数 打印每个<T>(列表: 向量<T>): 单元 约束 T <: 可打印 {
      对于 (项 in 列表) { 打印行(项) }
  }
  主函数() {
      可变 整数列表 = 向量<整数>()
      整数列表.添加(1)
      可变 文本列表 = 向量<字符串>()
      文本列表.添加("你好")
      打印每个(整数列表)
      打印每个(文本列表)
  }
  ```
- **注意**：类型参数习惯用单个大写字母（T、K、V）；调用时类型**自动推断**（`打印每个(整数列表)` 推出 T=整数）；类型参数声明在函数名后 `<T>`。

## 词条 7.2 泛型类

- **是什么**：类/结构体带类型参数：`结构体 盒子<T> { 公开 可变 内容: T }`。
- **为什么**：容器（向量、哈希映射）是最典型的泛型类——「装什么由使用者决定」。泛型类把「存储结构」与「元素类型」解耦。
- **怎么用**：
  ```cangjie
  结构体 盒子<T> {
      公开 可变 内容: T
      初始化(内容: T) { 本对象.内容 = 内容 }
  }
  主函数() {
      让 整数盒 = 盒子<整数>(42)
      让 文本盒 = 盒子<字符串>("你好")
      打印行(整数盒.内容)
      打印行(文本盒.内容)
  }
  ```
- **注意**：实例化必须给出类型参数（`盒子(42)` 可推断时也行——构造器参数可推）；类型参数可以是嵌套（`向量<盒子<整数>>`）。

## 词条 7.3 约束（约束 / where）

- **是什么**：限定类型参数必须满足的条件：`函数 求最大值<T>(列表: 向量<T>) 约束 T <: 可比较`——`T` 必须是可比较的子类型。
- **为什么**：泛型代码往往需要「类型有某个能力」（比较大小、转字符串）。没有约束，编译器不允许你调用 T 上的任何方法；约束把「T 是什么」说清楚，编译器才能安全放行。
- **怎么用**：
  ```cangjie
  导入 标准集合.{向量}
  函数 拼接<T>(列表: 向量<T>): 字符串 约束 T <: 可打印 {
      可变 结果 = ""
      对于 (项 in 列表) { 结果 += "${项}" }
      返回 结果
  }
  主函数() {
      可变 列表 = 向量<整数>()
      列表.添加(1); 列表.添加(2)
      打印行(拼接(列表))
  }
  ```
- **注意**：约束写在**参数列表之后**：`函数 名<T>(...) 约束 T <: 接口`；多个约束用逗号；约束接口可以是标准库接口（`可打印`、`可比较`、`可哈希`、`可相等`）。

## 词条 7.4 向量（向量 / ArrayList）

- **是什么**：**可动态增删**的列表：`向量<整数>()`；`添加`/`删除`/`[下标]` 访问。
- **为什么**：数组定长不方便（不知道会加多少元素）；向量 = 数组 + 自动扩容，是「动态列表」的默认选择。
- **怎么用**：
  ```cangjie
  导入 标准集合.{向量}
  主函数() {
      可变 成绩单 = 向量<整数>()
      成绩单.添加(95)
      成绩单.添加(88)
      成绩单.添加(76)
      打印行(成绩单.大小)         // 3（属性）
      打印行(成绩单[0])           // 95
      成绩单.删除(1..2)            // 删下标 1（remove 只收区间）
      打印行(成绩单.大小)         // 2
  }
  ```
- **注意**：`大小` 是**属性**不是方法（`.大小`，不带括号）；下标越界运行时抛异常；向量 `删除` 只收**区间**（官方 remove(Range)：`删除(1..2)` 删一个、`删除(1..3)` 删两个）；哈希集合/哈希映射的 `删除` 按值/键删（见 7.12）。

## 词条 7.5 哈希映射（哈希映射 / HashMap）

- **是什么**：**键 → 值**的对应表：`哈希映射<字符串, 整数>()`；`映射[键] = 值` 存、`映射[键]` 取。
- **为什么**：按**名字**查数据是最高频需求（学号→学生、单词→次数）。哈希表平均 O(1) 查询——比遍历列表快得多。
- **怎么用**：
  ```cangjie
  导入 标准集合.{哈希映射}
  主函数() {
      可变 宠物年龄 = 哈希映射<字符串, 整数>()
      宠物年龄["旺财"] = 3
      宠物年龄["咪咪"] = 5
      打印行(宠物年龄["旺财"])       // 3
      打印行(宠物年龄.大小)          // 2
      对于 (名字 in 宠物年龄.键()) {
          打印行("${名字}${宠物年龄[名字]}岁")
      }
  }
  ```
- **注意**：取不存在的键**运行时抛异常**（先 `包含` 判断或 `获取或默认`）；键必须可哈希（字符串/整数天然可）；遍历顺序**不保证**（哈希无序）。

## 词条 7.6 哈希集合（哈希集合 / HashSet）

- **是什么**：**不重复元素**的集合：`哈希集合<整数>()`；`添加` 重复元素被忽略。
- **为什么**：去重、成员判断（`包含` O(1)）——「这个值在不在」是常见需求。
- **怎么用**：
  ```cangjie
  导入 标准集合.{哈希集合}
  主函数() {
      可变 已读 = 哈希集合<整数>()
      已读.添加(1)
      已读.添加(1)          // 重复，被忽略
      已读.添加(2)
      打印行(已读.大小)      // 2
      打印行(已读.包含(2))   // 真
  }
  ```

## 词条 7.7 数组（数组 / Array）

- **是什么**：定长容器：`[1, 2, 3]` 或 `数组<整数>(3, { i => 0 })`（3 个元素，第 i 个由 lambda 算出）。
- **为什么**：见 2.9——连续内存、下标 O(1)、定长。与向量互转：`向量.from(数组)`。
- **怎么用**：
  ```cangjie
  主函数() {
      让 数据 = [10, 20, 30]
      让 全零 = 数组<整数>(3, { i => 0 })   // 3 个 0
      让 翻倍 = 数组<整数>(3, { i => i * 2 })  // [0, 2, 4]
      打印行(数据.长度)      // 3
      打印行(全零[1])        // 0
      打印行(翻倍[2])        // 4
  }
  ```
- **注意**：官方 1.0.5 的 `数组<整数>(个数, 初始化函数)`——**第二个参数是函数**（对每个下标算初始值），不是固定值；下标从 0 开始；定长数组不能增删（用向量）。

## 词条 7.8 区间（范围 / Range）

- **是什么**：`1..5`（1~4）、`1..=5`（1~5）——见 2.11 与 4.6。
- **为什么**：循环与切片共用同一抽象；`范围` 本身也是可迭代对象。
- **怎么用**：
  ```cangjie
  主函数() {
      对于 (i in 1..=5) { 打印行(i) }
      让 文本 = "仓颉字典"
      打印行(文本[0..3])    // 仓（字节切片，见 7.25）
  }
  ```

## 词条 7.9 迭代器（迭代器 / iterator）

- **是什么**：提供「逐个取元素」能力的对象：`容器.迭代器()`；`下一个()` 返回**选项**（`有值(元素)` 或 `无值`——用完了）。
- **为什么**：**遍历与容器解耦**——`对于` 循环底层就是迭代器协议。任何实现了迭代器的类型都能被 `对于` 遍历。官方 1.0.5 的 `下一个()` 直接返回 `选项<T>`（没有单独的「有无下一个」判断——用 `匹配` 判断）。
- **怎么用**：
  ```cangjie
  主函数() {
      让 数组 = [5, 6, 7]
      让 迭代 = 数组.迭代器()
      当 (真) {
          匹配 (迭代.下一个()) {
              情况 有值(数) => 打印行(数)
              情况 无值 => 跳出      // 没有元素了，结束循环
          }
      }
  }
  ```
- **注意**：迭代器是**一次性**的（用完后需重新获取）；`对于` 循环是迭代器的语法糖，绝大多数场景不用手写。

## 词条 7.10 惰性序列（官方无 generator 语法）

- **是什么**：**惰性**产出的序列——`映射`/`过滤` 返回的是迭代器，**被消费时才真正计算**（`收集数组` 触发计算）。
- **为什么**：官方 1.0.5 **没有** `产生器`（generator/yield）语法——惰性由「迭代器 + 高阶函数」实现：不一次性全算，用多少算多少（省内存），还能无限链式组合。
- **怎么用**：
  ```cangjie
  导入 标准集合.*
  主函数() {
      可变 名单 = 向量<整数>()
      名单.添加(1); 名单.添加(2); 名单.添加(3)
      让 翻倍器 = 名单 |> 映射({ x => x * 2 })   // 惰性：此刻还没计算
      让 结果 = 翻倍器 |> 收集数组               // 消费时才逐个算
      打印行(结果)                              // [2, 4, 6]
  }
  ```
- **注意**：迭代器是**一次性**的——`收集数组` 消费后不能再用；想无限序列可自己实现迭代器接口（本教程不展开）；需要「生成式」逻辑时用循环 + 向量收集（`可变 结果 = 向量<...>()` + `添加`）。

## 词条 7.11 添加（添加 / add）

- **是什么**：向集合追加元素：`向量.添加(值)`、`哈希集合.添加(值)`、`哈希映射.添加(键, 值)`。
- **为什么**：动态容器的基本写操作。
- **怎么用**：
  ```cangjie
  导入 标准集合.{向量}
  主函数() {
      可变 列表 = 向量<整数>()
      列表.添加(1)
      列表.添加(2)
      打印行(列表.大小)
  }
  ```

## 词条 7.12 删除（删除 / remove）

- **是什么**：移除元素：`向量.删除(区间)`、`哈希集合.删除(值)`、`哈希映射.删除(键)`。
- **怎么用**：
  ```cangjie
  导入 标准集合.{向量}
  主函数() {
      可变 列表 = 向量<字符串>()
      列表.添加("甲"); 列表.添加("乙")
      列表.删除(0..1)           // 删第 0 个
      打印行(列表[0])          // 乙
  }
  ```
- **注意**：向量删中间元素会**移动后续元素**（O(n)）；循环中边遍历边删容易跳元素——倒序删或收集要删的下标。

## 词条 7.13 包含（包含 / contains）

- **是什么**：判断集合是否含某元素：`列表.包含(值)`、`映射.包含(键)`。
- **怎么用**：
  ```cangjie
  导入 标准集合.{向量}
  主函数() {
      可变 名单 = 向量<字符串>()
      名单.添加("小明")
      如果 (名单.包含("小明")) { 打印行("在") }
  }
  ```

## 词条 7.14 键（键 / keys）

- **是什么**：取出哈希映射的**全部键**：`映射.键()` → 哈希集合。
- **为什么**：遍历字典的入口（拿键取值）；配合 `对于` 是字典遍历的标配。
- **怎么用**：
  ```cangjie
  导入 标准集合.{哈希映射}
  主函数() {
      可变 表 = 哈希映射<字符串, 整数>()
      表["甲"] = 1
      表["乙"] = 2
      对于 (名 in 表.键()) { 打印行("${名}=${表[名]}") }
  }
  ```
- **注意**：`键()` 是方法（带括号）；返回的键集合是**视图**——遍历时不要改映射结构。

## 词条 7.15 映射（映射 / map）

- **是什么**：对每个元素**做变换**产生新集合：`名单 |> 映射({ x => x * 2 })`（方言管道写法，官方 `map(f)`）。
- **为什么**：把「遍历 + 收集结果」压缩成一步——声明式地表达「每个元素怎么变」。这是函数式风格的核心操作。
- **怎么用**：
  ```cangjie
  导入 标准集合.*
  主函数() {
      可变 名单 = 向量<整数>()
      名单.添加(1); 名单.添加(2); 名单.添加(3)
      让 翻倍 = 名单 |> 映射({ x => x * 2 }) |> 收集数组
      打印行(翻倍[0])         // 2
  }
  ```
- **注意**：`映射` 返回**惰性迭代器**（原容器不变），用 `|> 收集数组` 收成数组；lambda 的参数类型自动推断；类型可以变（`映射({ x => "${x}" })` 得字符串列表）；lambda 参数是只读的。

## 词条 7.16 过滤（过滤 / filter）

- **是什么**：**保留满足条件**的元素：`成绩 |> 过滤({ x => x >= 60 }) |> 收集数组`。
- **为什么**：筛选是「遍历 + 条件判断 + 收集」的压缩——条件和收集分离，读起来像自然语言。
- **怎么用**：
  ```cangjie
  导入 标准集合.*
  主函数() {
      可变 成绩 = 向量<整数>()
      成绩.添加(95); 成绩.添加(45); 成绩.添加(70)
      让 及格 = 成绩 |> 过滤({ x => x >= 60 }) |> 收集数组
      打印行(及格.大小)       // 2
  }
  ```

## 词条 7.17 遍历（遍历 / forEach）

- **是什么**：对每个元素**执行副作用**：`名单 |> 遍历({ 名字 => 打印行(名字) })`。
- **为什么**：`映射` 要结果、`过滤` 要筛选，`遍历` 只做「过程」（打印、记录）不要结果。
- **怎么用**：
  ```cangjie
  导入 标准集合.*
  主函数() {
      可变 名单 = 向量<字符串>()
      名单.添加("甲"); 名单.添加("乙")
      名单 |> 遍历({ 名字 => 打印行("你好，${名字}") })
  }
  ```
- **注意**：`遍历` 返回单元；与 `对于` 循环等价，纯偏好；lambda 里想用 `跳出`/`继续` 不行（不是循环）——用 `对于`。

## 词条 7.18 求和（求和 / fold）

- **是什么**：从**初始值**开始逐个元素累积：`成绩 |> 求和(0, { 累积, 分 => 累积 + 分 })`。
- **为什么**：求和/乘积/拼接的通用形态——「一个累积器 + 一个合并函数」。比手写 `可变 总和 = 0; 对于 ...` 更声明式。
- **怎么用**：
  ```cangjie
  导入 标准集合.*
  主函数() {
      可变 成绩 = 向量<整数>()
      成绩.添加(95); 成绩.添加(85)
      让 总和 = 成绩 |> 求和(0, { 累积, 分 => 累积 + 分 })
      打印行(总和)            // 180
  }
  ```
- **注意**：方言 `求和` 对应官方 fold——官方是柯里化工厂 `fold(初始值, 合并函数)(容器)`，方言用管道 `容器 |> 求和(...)` 书写；lambda 第一个参数是累积值、第二个是元素；初始值类型决定返回类型（`0` → 整数）。

## 词条 7.19 累加（累加 / reduce）

- **是什么**：与 `求和` 类似但**无初始值**（用第一个元素起步）：`成绩 |> 累加({ 累积, 分 => 累积 + 分 })`。
- **为什么**：元素已有「自然起点」时（求和、求最大值）不需要额外初始值；空列表时返回 `选项`（没有元素就没有结果）。
- **怎么用**：
  ```cangjie
  导入 标准集合.*
  主函数() {
      可变 成绩 = 向量<整数>()
      成绩.添加(95); 成绩.添加(85)
      让 总和 = 成绩 |> 累加({ 累积, 分 => 累积 + 分 })
      打印行(总和.获取或抛出())    // 180（选项需解包）
  }
  ```
- **注意**：`累加`（官方 reduce）返回 **`选项<T>`**（空容器 → `无值`）——用 `.获取或抛出()` 解包，或先 `匹配` 处理空情况；空容器上调用会得到 `无值`（不崩溃）。

## 词条 7.20 排序（排序 / sort）

- **是什么**：**原地排序**数组：`排序(数据)`（升序）或 `排序(数据, 降序: 真)`（降序）——官方 1.0.5 的全局函数 `sort`（std.sort 包）。
- **为什么**：排序是最高频的算法需求——官方提供**稳定排序**（相等元素保持原相对顺序）与不稳定排序（更快）。注意 `排序` 直接**修改原数组**（原地），不产生新数组。
- **怎么用**：
  ```cangjie
  导入 排序.*
  主函数() {
      可变 成绩 = [88, 95, 70]
      排序(成绩)                       // 原地升序
      打印行(成绩[0])                  // 70
      排序(成绩, 降序: 真)             // 原地降序
      打印行(成绩[0])                  // 95
  }
  ```
- **注意**：`排序` 接受数组（`[88, 95, 70]`）且要求元素可比较；向量要先 `收集数组`/`转数组` 再排（或排完拷回）；`降序` 是命名参数（官方 `descending: true`）；官方旧 API `稳定排序`（stableSort）已废弃，用 `排序(数据, 稳定: 真)` 表达稳定需求。

## 词条 7.21 倒序（官方无 reversed，用手写循环）

- **是什么**：把容器**倒过来**——官方 1.0.5 **没有** `反序`（reversed）方法，用**下标倒着取**即可：`原[原.长度 - 1 - i]`。
- **怎么用**：
  ```cangjie
  导入 标准集合.{向量}
  主函数() {
      让 原 = [1, 2, 3]
      可变 倒 = 向量<整数>()
      对于 (i in 0..原.长度) {
          倒.添加(原[原.长度 - 1 - i])   // 从最后一个往前取
      }
      打印行(倒[0])            // 3
      打印行(原[0])            // 1（原容器不变）
  }
  ```
- **注意**：倒序不改变原容器（新容器收集）；对称地，`排序(数据, 降序: 真)` 能得到降序排列（但那是排序不是倒序）；下标 `原.长度 - 1` 是最后一个元素。

## 词条 7.22 去重（官方无 distinct，用哈希集合）

- **是什么**：去掉重复元素——官方 1.0.5 **没有** `去重`（distinct）方法，**哈希集合**天然去重（见 7.6）：逐个添加，重复的自动被忽略。
- **怎么用**：
  ```cangjie
  导入 标准集合.{向量, 哈希集合}
  主函数() {
      可变 名单 = 向量<整数>()
      名单.添加(1); 名单.添加(2); 名单.添加(1)
      可变 唯一 = 哈希集合<整数>()
      对于 (数 in 名单) { 唯一.添加(数) }   // 重复的 1 被忽略
      打印行(唯一.大小)        // 2
  }
  ```
- **注意**：哈希集合**无序**（不保证原顺序）；要保序去重就手写循环 + `包含` 判断（`如果 (非 结果.包含(数)) { 结果.添加(数) }`）。

## 词条 7.23 分组（官方无 groupBy，手写哈希映射）

- **是什么**：把元素按**分组函数**归组——官方 1.0.5 **没有** `分组`（groupBy），用**哈希映射**手写：组名作键、计数作值。
- **怎么用**：
  ```cangjie
  导入 标准集合.{向量, 哈希映射}
  主函数() {
      可变 成绩 = 向量<整数>()
      成绩.添加(95); 成绩.添加(45); 成绩.添加(70)
      可变 分组 = 哈希映射<字符串, 整数>()
      对于 (分 in 成绩) {
          让 组名 = 如果 (分 >= 60) { "及格" } 否则 { "不及格" }
          分组[组名] = 分组.获取(组名).获取或默认({ => 0 }) + 1
      }
      打印行(分组.大小)       // 2
      打印行(分组["及格"])    // 2
  }
  ```
- **注意**：`获取或默认(键, 默认值)`（官方 getOrDefault）是「统计计数」的标配——键不存在时用 0 起步；想分组后保留顺序用向量代替映射（键顺序按插入）。

## 词条 7.24 滑窗（官方无 windowed，手写相邻对）

- **是什么**：滑动窗口取**连续子序列**——官方 1.0.5 **没有** `滑窗`（windowed），相邻元素比较用下标手写：`数列[i]` 与 `数列[i + 1]`。
- **怎么用**：
  ```cangjie
  主函数() {
      让 数列 = [1, 2, 3, 4]
      对于 (i in 0..(数列.长度 - 1)) {
          打印行("(${数列[i]}, ${数列[i + 1]})")
      }
  }
  ```
- **注意**：窗口大小为 2 的相邻对：`[1,2] [2,3] [3,4]`（共 长度-1 个）；更大窗口或步长自己用双层循环实现；「移动平均」等场景直接套这个模式。

## 词条 7.25 字符串方法群

- **是什么**：字符串常用方法一览（方言 → 官方 → 作用）。
- **为什么**：字符串处理是编程最高频场景；这些方法覆盖**查询/裁剪/变换/拆分**四大类。
- **怎么用**：
  ```cangjie
  导入 正则.*
  主函数() {
      让 文本 = "  仓颉 编程 语言  "
      // 查询
      打印行(文本.长度)                     // 16（字节数，UTF-8 下每汉字 3 字节）
      打印行(文本.查找("编程"))             // 下标（找不到返回 -1）
      打印行(文本.以开头("  仓颉"))         // 真
      打印行(文本.以结尾("语言  "))         // 真
      // 裁剪（字符串切片按字节——中文要 3 字节，见 7.8）
      打印行("仓颉编程"[0..3])              // 仓（前 3 字节 = 1 汉字）
      打印行(文本.修剪())                    // 去首尾空白
      // 变换
      打印行("abc".大写())                   // ABC
      打印行("ABC".小写())                   // abc
      打印行("甲-乙".替换("-", "→"))        // 甲→乙
      // 拆分
      让 部分 = 文本.修剪().分割(" ")
      打印行(部分.长度)                      // 3
      // 判断（正则匹配：Regex 的 matches 方法，见 11.10）
      打印行(正则("\\d+").匹配正则("123"))  // 真
  }
  ```
- **注意**：`长度` 是**字节数**（中文按 3 字节计，按字符用 `字符流()`/`字符数组()`）；`查找` 返回下标（`-1` 表示没有）；`分割` 返回数组；`大小写` 转换是**纯 ASCII** 的（`toAsciiUpper`——非 ASCII 字母不转换）；正则匹配用 `正则(模式).匹配正则(文本)`（`匹配正则` = 官方 `matches`，返回布尔；取匹配到的内容见 11.10）。

## 词条 7.26 拼接与收集（拼接 / collectString）

- **是什么**：`收集字符串` 把元素**连成字符串**（官方 collectString，柯里化工厂：`列表 |> 收集字符串(分隔符: "")`）。
- **为什么**：`收集字符串` 是「数组 → 字符串」的标准动作（输出 CSV、报告行）；字符串插值 `${}`（见 1.7）覆盖「拼模板」需求。
- **怎么用**：
  ```cangjie
  导入 标准集合.*
  主函数() {
      可变 名单 = 向量<字符串>()
      名单.添加("甲"); 名单.添加("乙"); 名单.添加("丙")
      打印行(名单 |> 收集字符串(分隔符: ""))   // 甲乙丙（无分隔符）
      打印行("圆周率 = ${3.14159}")      // 字符串插值输出浮点数
  }
  ```
- **注意**：官方 1.0.5 **没有** `拼接`（join）——要带分隔符先 `映射({ x => x + "、" })` 再收集（末尾多一个分隔符，可自行去掉）；`收集字符串` 的分隔符是**命名参数**（方言「分隔符」= 官方 delimiter）；`格式化`（format）是**数字的成员方法**（`42.格式化("${0}")`，默认 6 位小数，需 `导入 转换.*`）——**没有**独立的 `std.format` 包，别写 `导入 格式化.*`。
