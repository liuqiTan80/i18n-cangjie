# 03 变量与作用域

> 变量是「贴了标签的盒子」。本卷讲盒子的三种类型（让/可变/常量）、盒子的摆放位置（全局/块内）、盒子的可见范围（作用域）、以及把盒子一次拆开的技巧（解构）。

## 词条 3.1 让（let）——不可变绑定

- **是什么**：声明一个**值不可改变**的变量：`让 分数 = 90`。
- **为什么**：**默认不可变**是仓颉的核心理念（见 00 卷「内存安全」）。理由：
  1. 不可变变量不可能被意外修改——少一类 bug；
  2. 编译器知道值不变，可以做更多优化；
  3. 多线程共享不可变数据天然安全。
  需要「能改」时才显式用 `可变`——**把可变性变成需要申请的特权**。
- **怎么用**：
  ```cangjie
  主函数() {
      让 出生年 = 2012
      打印行(出生年)
  }
  ```
- **注意**：`让` 之后赋值（`出生年 = 2013`）报错「不能给不可变值赋值」——想改就用 `可变`；`让` 的不可变是**绑定不可变**：如果绑定的是引用类型，对象内部可能仍是可变的（见 6.14 `修改` 与引用语义）。

## 词条 3.2 可变（var）——可变绑定

- **是什么**：声明一个**值可以改变**的变量：`可变 计数 = 0`。
- **为什么**：计数、累加、遍历指针等天然需要「更新」。仓颉把可变声明为显式关键字，让「哪里可能变化」在代码里一目了然——读代码时扫一眼 `可变` 就知道哪些盒子可能被改。
- **怎么用**：
  ```cangjie
  主函数() {
      可变 计数 = 0
      计数 = 计数 + 1
      计数 += 10
      打印行(计数)          // 11
  }
  ```
- **注意**：`可变` 声明的变量可以整体换值（`计数 = "abc"` 不行——**类型不变**，换的是值不是类型）；`可变` 是「声明时」的权限，后续不需要改时没有「降级」语法（官方无 freeze）。

## 词条 3.3 常量（const）——编译期常量

- **是什么**：在**编译期**就确定值的不可变绑定：`常量 圆周率 = 3.14159`。
- **为什么**：区别于 `让`：`常量` 的值在编译期已知（字面量或常量表达式），编译器可以直接内联、做常量折叠。适合数学常数、配置上限等「铁打的值」。
- **怎么用**：
  ```cangjie
  常量 圆周率 = 3.14159
  常量 最大次数 = 100

  主函数() {
      打印行(圆周率 * 2.0)
      对于 (i in 0..最大次数) { /* 循环体 */ }
  }
  ```
- **注意**：`常量` 必须用**编译期常量**初始化（`常量 x = 读取行()` 非法）；函数内也可声明 `常量`；它与 `让` 的区别在于「何时确定」而非「能否修改」。

## 词条 3.4 全局声明（顶层声明）

- **是什么**：在 `主函数`/任何函数之外声明的变量、常量、函数、类型——属于整个文件（包）级别。
- **为什么**：共享状态与公共工具放顶层，避免重复声明。但**全局可变状态是并发 bug 温床**（见 8.12），仓颉推荐：能用参数传递就不开全局。
- **怎么用**：
  ```cangjie
  常量 项目名 = "仓颉字典"
  可变 全局计数 = 0          // 全局可变（慎用）

  函数 取项目名(): 字符串 { 返回 项目名 }

  主函数() {
      全局计数 += 1
      打印行(取项目名())
  }
  ```
- **注意**：全局 `让`/`常量` 是安全的（不可变共享）；全局 `可变` 在多线程下需要同步（见 8.13 同步/8.14 锁）；顶层声明顺序无关（可以先调用后定义）。

## 词条 3.5 块作用域（`{}` 内可见）

- **是什么**：每个 `{}` 块（函数体、`如果` 分支、`当`/`对于` 循环体）都是**独立作用域**：块内声明的变量，块外不可见。
- **为什么**：作用域隔离防止「变量泄漏」——块内临时变量不该污染外层；同名变量在不同块互不干扰（见 3.6 遮蔽）。
- **怎么用**：
  ```cangjie
  主函数() {
      让 外层 = 1
      如果 (外层 > 0) {
          让 内层 = 2          // 只在 if 块内可见
          打印行(内层)
      }
      // 打印行(内层)  ← 错误：内层不在这里
  }
  ```
- **注意**：`对于 (i in 1..5)` 的 `i` 是**循环体作用域**变量，循环外不可见；块内可声明与块外同名的变量（遮蔽），但**推荐避免**（易读错）。

## 词条 3.6 遮蔽（shadowing）

- **是什么**：内层作用域声明与外层同名变量时，内层名字「遮住」外层。
- **为什么**：遮蔽是双刃剑：合理使用可以「局部重定义」（如格式化后的临时变量），滥用则让代码难读（读者不知道你指的是哪个）。
- **怎么用**：
  ```cangjie
  主函数() {
      让 分数 = 60
      如果 (真) {
          让 分数 = 90       // 遮蔽外层
          打印行(分数)       // 90
      }
      打印行(分数)           // 60（外层未变）
  }
  ```
- **注意**：zhc 方言转译器有「豁免集」机制保护声明名——**遮蔽不会让方言转译出错**；但读者会困惑，能改名就改名。

## 词条 3.7 解构（destructuring）

- **是什么**：声明时直接把元组/对象/枚举的字段**拆开**赋给多个变量：`让 (编号, 名字) = 学生`。
- **为什么**：取元组/对象的多个字段不用逐个 `学生[0]`、`学生[1]`——一次拆包，代码更短更清晰。
- **怎么用**：
  ```cangjie
  主函数() {
      让 学生 = (1, "小明")
      让 (编号, 名字) = 学生       // 元组解构
      打印行("${编号}:${名字}")

      匹配 (找名字(1)) {            // 匹配中的解构（8.1 常见）
          情况 有值(名字) => 打印行(名字)
          情况 无值 => 打印行("无")
      }
  }
  函数 找名字(编号: 整数): 选项<字符串> {
      如果 (编号 == 1) { 返回 有值("小明") }
      返回 无值
  }
  ```
- **注意**：解构声明用 `让 (a, b) = ...`（整体是一个声明）；解构的变量数必须与元组元素数一致；对象解构（`让 (x, y) = 点`）需要对象是**公开字段**的结构体/类。

## 词条 3.8 值传递与引用传递

- **是什么**：函数传参时，值类型的参数是**拷贝**（改了不影响外面）；引用类型的参数是**共享引用**（改了影响外面）。
- **为什么**：这是理解「为什么我的函数没改掉外面的变量」的关键。仓颉规则：
  - 值类型（整数/浮点/布尔/字符/结构体/枚举/元组）→ 按值拷贝；
  - 引用类型（类/数组/向量/字符串/接口/函数）→ 按引用共享。
  - **参数一律不可变绑定**：函数内不能给参数重新赋值（`mut` 声明可解除，见 6.14）。
- **怎么用**：
  ```cangjie
  结构体 计数器 {
      公开 可变 值: 整数
      初始化(值: 整数) { 本对象.值 = 值 }
  }
  类 计数器类 {
      公开 可变 值: 整数
      初始化(值: 整数) { 本对象.值 = 值 }
  }
  函数 改值型(计数: 计数器): 计数器 {
      返回 计数器(计数.值 + 1)   // 结构体按值传递：改的是副本
  }
  函数 改引用型(计数: 计数器类) {
      计数.值 += 1              // 类按引用传递：外面能看到变化
  }
  主函数() {
      让 值型 = 计数器(1)
      改值型(值型)               // 返回新副本，外面还是 1
      打印行(值型.值)            // 1
      让 引用型 = 计数器类(1)
      改引用型(引用型)           // 共享引用
      打印行(引用型.值)          // 2
  }
  ```
- **注意**：字符串是引用类型但**不可变**（改它产生新串，外面看不到变化）；想让引用类型的「对象本体」不被改，用不可变字段 + 不暴露可变接口。
