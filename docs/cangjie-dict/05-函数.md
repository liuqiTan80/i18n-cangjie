# 05 函数

> 函数是「装进盒子的代码」——输入（参数）→ 加工（函数体）→ 输出（返回值）。
> 本卷词条：函数声明 / 主函数 / 参数与类型标注 / 返回 / 多返回值 / 命名参数 / 函数重载 / lambda / 闭包 / 局部函数 / 扩展函数 / 函数类型。

## 词条 5.1 函数声明（函数 / func）

- **是什么**：定义一段可复用的代码块：`函数 名称(参数): 返回类型 { 函数体 }`。
- **为什么**：**复用**（同一逻辑只写一次）、**抽象**（调用方只关心输入输出）、**可测**（小函数容易验证）。函数是组织代码的第一级单位。
- **怎么用**：
  ```cangjie
  函数 两倍(数: 整数): 整数 {
      返回 数 * 2
  }
  主函数() {
      打印行(两倍(21))     // 42
  }
  ```
- **注意**：函数名用「动词+对象」风格（`计算总分`、`读取文件`）；方言 `函数` 与 `主函数` 不同——`主函数` 是程序入口（官方 main 不带 `函数` 前缀，见 5.2）。

## 词条 5.2 主函数（主函数 / main）

- **是什么**：程序入口：`主函数() { ... }`——运行程序从这里开始。
- **为什么**：一个程序必须有一个「从哪里开始执行」的约定。官方仓颉写 `main() { }`（**不带** `func`——`func main` 是语法错误）；方言直接写 `主函数()`。
- **怎么用**：
  ```cangjie
  主函数() {
      打印行("程序从这里开始")
  }
  ```
- **注意**：一个可执行程序**有且只有一个** `主函数`；它没有参数、没有返回值（官方可接受 `Array<String>` 参数与 `Int64` 返回，方言教程不展开）；库（lib）不需要主函数。

## 词条 5.3 参数与类型标注

- **是什么**：参数是函数接收的「原料」，每个参数必须标注类型：`函数 求面积(宽: 浮点, 高: 浮点): 浮点`。
- **为什么**：**参数必须显式标注类型**（不推断）——这是接口契约的一部分：调用方需要知道传什么、编译器需要检查调用是否正确。参数默认是**只读绑定**（不能给参数重新赋值）。
- **怎么用**：
  ```cangjie
  函数 求面积(宽: 浮点, 高: 浮点): 浮点 {
      返回 宽 * 高
  }
  主函数() {
      打印行(求面积(3.0, 4.0))     // 12.0
  }
  ```
- **注意**：参数类型写错（`求面积("宽", 4)`）报「类型不匹配」——zhc 教学诊断会给出修复示例；参数个数必须一致（缺参数报「参数个数不匹配」）。

## 词条 5.4 返回（return）

- **是什么**：把结果交出去并**立即结束**函数：`返回 值`。
- **为什么**：返回是函数与调用方的「交接仪式」。**函数体最后一条表达式的值会自动作为返回值**（尾部表达式）——但推荐显式 `返回` 更清楚。
- **怎么用**：
  ```cangjie
  函数 判断(分数: 整数): 字符串 {
      如果 (分数 >= 60) { 返回 "及格" }
      返回 "不及格"      // 提前返回也合法
  }
  ```
- **注意**：无返回值的函数可以不写 `返回`（隐式返回单元）；`返回` 后不能有语句（不可达代码警告）；声明了 `: 字符串` 就必须所有路径都返回字符串——漏写一条路径编译器会报「函数缺少返回」。

## 词条 5.5 多返回值（元组返回）

- **是什么**：用元组一次返回多个值：`返回 (最小值, 最大值)`。
- **为什么**：有些函数天然产出多个结果（统计的 min/max、除法的高/余）。元组是最轻量的打包方式，不用为一次性结果建类。
- **怎么用**：
  ```cangjie
  函数 求最值(列表: 数组<整数>): (整数, 整数) {
      返回 (列表[0], 列表[列表.长度 - 1])
  }
  主函数() {
      让 (最小, 最大) = 求最值([3, 7, 2, 9])
      打印行("最小${最小} 最大${最大}")
  }
  ```
- **注意**：返回类型要写元组形式 `(整数, 整数)`；解构接收（见 3.7）最顺手；超过 3 个返回值考虑定义结构体。

## 词条 5.6 命名参数

- **是什么**：调用时用「参数名 = 值」指定：`打招呼(名字 = "小明", 语气 = "嗨")`。
- **为什么**：参数多的函数按名传参可读性更高（不怕记错顺序）；命名参数在声明时用 `!` 标记（官方语法），调用时写 `名字: 值`。
- **怎么用**：
  ```cangjie
  函数 设置(年龄: 整数, 名字!: 字符串, 班级!: 字符串) {
      打印行("${名字} ${年龄} ${班级}")
  }
  主函数() {
      设置(12, 名字: "小明", 班级: "初一2班")
  }
  ```
- **注意**：命名参数与位置参数混用时，命名参数**必须放在位置参数之后**；参数名写错报「找不到参数」。

## 词条 5.7 函数重载（overload）

- **是什么**：同名函数、**参数不同**（个数或类型），编译器按调用实参选版本。
- **为什么**：同一操作对不同类型有不同实现（`打印` 一个整数 vs 一个字符串）——重载让「一个名字、多种语义」。
- **怎么用**：
  ```cangjie
  函数 描述(x: 整数): 字符串 { 返回 "整数：${x}" }
  函数 描述(x: 字符串): 字符串 { 返回 "文本：${x}" }
  主函数() {
      打印行(描述(1))        // 整数：1
      打印行(描述("嗨"))     // 文本：嗨
  }
  ```
- **注意**：**仅返回类型不同不能重载**（`描述(x: 整数): 字符串` 与 `描述(x: 整数): 整数` 冲突）；重载解析有歧义时报错（如 `描述(1)` 同时匹配 `整数` 与 `浮点` 参数版本时，编译器优先精确匹配）。

## 词条 5.8 lambda（`{ }` 匿名函数）

- **是什么**：没有名字的函数字面量：`{ x => x * 2 }`。
- **为什么**：临时逻辑不想起名字（尤其传给 `映射`/`过滤` 这类高阶函数时）——「一次性函数」不该占用命名空间。
- **怎么用**：
  ```cangjie
  导入 标准集合.*
  主函数() {
      可变 名单 = 向量<整数>()
      名单.添加(1); 名单.添加(2); 名单.添加(3)
      让 翻倍 = 名单 |> 映射({ x => x * 2 }) |> 收集数组
      打印行(翻倍)        // [2, 4, 6]
  }
  ```
- **注意**：官方写法是**花括号包整体**（`{ 参数 => 表达式 }`），`\x => ...` 是其他语言的语法、仓颉不认；多参数 `{ x, y => x + y }`；lambda 参数类型可推断（`映射` 的上下文知道元素类型）；`映射`/`过滤` 返回**迭代器**，用 `|> 收集数组` 收成数组（见 7.15）。

## 词条 5.9 闭包（closure）

- **是什么**：lambda 能**捕获**定义时所在作用域的变量，并在之后使用：`让 增量 = 5; 让 加 = { x => x + 增量 }`。
- **为什么**：函数与数据的组合——「随身携带环境」的函数。让配置参数（如步长、阈值）不用每次显式传递。
- **怎么用**：
  ```cangjie
  函数 造加法器(增量: 整数): (整数) -> 整数 {
      返回 { x => x + 增量 }       // 捕获 增量
  }
  主函数() {
      让 加5 = 造加法器(5)
      打印行(加5(10))          // 15
  }
  ```
- **注意**：捕获的是**引用**——如果捕获了 `可变` 变量，其值变化会影响闭包（反之亦然）；闭包捕获不可变变量最安全（推荐 `让`）。

## 词条 5.10 局部函数

- **是什么**：在函数体内定义的函数。
- **为什么**：只在当前函数内使用的辅助逻辑，不需要暴露到外层——「局部私有的小工具」。
- **怎么用**：
  ```cangjie
  主函数() {
      函数 内层计算(数: 整数): 整数 {
          返回 数 * 数 + 1
      }
      打印行(内层计算(3))    // 10
  }
  ```
- **注意**：局部函数可以访问外层函数的变量（也是闭包）；递归的局部函数可以自调用。

## 词条 5.11 扩展函数（扩展 / extend）

- **是什么**：给**已有类型**（包括标准库类型）添加方法：`扩展 字符串 { 函数 是否问句(): 布尔 { ... } }`。
- **为什么**：不修改原类型（可能没源码）也能「像它本来就有这个方法」一样调用——程序员的**方法雨刮器**：把散落各处的工具方法挂到类型上，代码更内聚。
- **怎么用**：
  ```cangjie
  扩展 字符串 {
      函数 是否问句(): 布尔 {
          返回 以结尾("？") 或 以结尾("?")
      }
  }
  主函数() {
      打印行("今天下雨？".是否问句())    // 真
  }
  ```
- **注意**：扩展方法**不能访问私有字段**（只能通过公开接口）；同名扩展方法冲突时按可见性解析；`扩展` 是方言关键字（官方 extend），常见于给 `字符串`/`整数` 等内置类型加工具。

## 词条 5.12 函数类型（`(参数类型) -> 返回类型`）

- **是什么**：函数也是一种类型：`(整数) -> 整数` 表示「吃一个整数吐一个整数」的函数。
- **为什么**：函数是**一等公民**——可以存进变量、作为参数、作为返回值。这是高阶函数（`映射`/`过滤`）与策略模式的基础。
- **怎么用**：
  ```cangjie
  函数 应用两次(f: (整数) -> 整数, x: 整数): 整数 {
      返回 f(f(x))
  }
  主函数() {
      让 翻倍 = { x => x * 2 }
      打印行(应用两次(翻倍, 3))    // 12
  }
  ```
- **注意**：函数类型箭头写法 `(整数) -> 整数`；普通函数名可直接作为函数值传递（`应用两次(翻倍, 3)` 中 `翻倍` 是 lambda）；声明函数类型变量：`让 f: (整数) -> 整数 = { x => x }`。
