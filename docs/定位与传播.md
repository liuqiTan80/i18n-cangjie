# zhc 定位与传播（产品视角）

## 一句话定位

**zhc 是仓颉的 i18n 基础设施**：官方把仓颉带给中文开发者，zhc 把边界推到全球——
让每个开发者都能用母语读代码、写代码、读懂报错。

## 回答必然的质疑：「为什么不直接学英文编程？」

1. **认知科学**：用母语学习编程能显著降低认知负荷——学习者的工作记忆应该花在
   编程概念上，而不是翻译上（母语教学有大量实证研究支撑）；
2. **生态时机**：仓颉是年轻语言，全球非中文开发者与官方站在同一起跑线——
   此时建立母语入口的成本最低、归属感最强；
3. **不是替代，是桥梁**：zhc 的双向映射（方言 ↔ 官方）让学习者在母语中入门、
   在官方语言中进阶——错误字典与 compare 对照视图就是桥梁本身。

## 渠道与节奏

1. **首发**：Show HN / r/programming / dev.to（英文）+ 掘金/知乎（中文），
   统一用「四语同跑」视频开场；
2. **联动**：仓颉官方社区（华为开发者论坛）——zhc 填补的正是官方全球化教育空白；
3. **持续**：每上线一个新语言包 = 一篇「用 X 语写仓颉」（含该语言维护者署名）；
4. **度量**：lang install / share fetch / 教程页访问量（P2 埋点）。
