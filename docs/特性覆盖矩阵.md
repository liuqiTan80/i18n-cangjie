## 统计与维护

- 覆盖状态：✅ 22 域 / 🟡 3 域 / ❌ 3 域（截至 2026-09，SDK 1.0.5）。
- 三个 ❌ + 两个 🟡 的「第 20 章候选」：运算符重载（词表已备 `重定义`）、FFI（词表已备 `外部`/`不安全`）、自动微分（词表缺）、extend 实操专章、自定义属性宏机制——新增教程章节后回填本表并同步 00-大纲.md。
- 维护触发条件：
  1. 教程新增章节/小节 → 更新对应行与统计；
  2. zhc 词表新增关键字 → 核对是否有对应特性域处于 ❌/🟡 需回填；
  3. SDK 升级出现新特性 → 新增行并评估优先级（官方书籍目录是现成特性清单来源）。
- 关联文档：[教程大纲](中文仓颉程序设计/00-大纲.md)（章节结构）；词表结构见 `zhc/lang-packs/zh/keywords.toml`（7 节）与 `stdlib.toml`（模块路径/标识符 2 节）。
