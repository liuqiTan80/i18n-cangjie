# 用中文写代码——仓颉编程入门（初中生版）

> 零基础？没学过任何编程？完全没关系。
> 这本书用**中文**教你编程。你不需要认识任何英文单词，只需要认识汉字和加减乘除。
>
> 我们用的编程语言叫**仓颉**（cangjie），它是我们中国人自己造的编程语言。
> 再配合 **zhc 工具**，我们可以**用中文来写仓颉代码**——关键字是「函数」「主函数」「让」「如果」「当」「对于」……连电脑报错都是中文的。
> 读完这本书，你会写出能自己跑起来的程序，还会修好自己犯的错误。

## 第 1 章 编程是什么？

### 电脑很聪明，也很笨

电脑能瞬间算出几亿次加减法，但它**听不懂人话**。你喊「帮我做个游戏」，它一头雾水。
电脑只听得懂一种特别简单的语言，里面只有两个符号：`0` 和 `1`。这就像古代打仗用的烽火台——**点着了（1）** 或者 **没点着（0）**，就靠这两个状态传递消息。

那么问题来了：我们怎么指挥这么笨的电脑？

### 编程 = 写菜谱

想象你在教一个从没做过饭的朋友做西红柿炒蛋。你会怎么写？

```
第一步：把两个鸡蛋打进碗里，搅匀
第二步：西红柿切块
第三步：锅里倒油，烧热
第四步：倒鸡蛋，炒熟盛出
第五步：倒西红柿，炒出汁，放鸡蛋，加盐
第六步：出锅
```

**编程就是干这个**：把你想让电脑做的事，一步一步写清楚，写成它看得懂的「菜谱」。这份菜谱，就叫**程序**（program）。

### 编程语言 = 翻译官

电脑只懂 `0` 和 `1`，我们直接用 `0` 和 `1` 写程序？那就像用摩斯密码写作文，太痛苦了。
于是聪明人发明了**编程语言**：一种接近人类语言的「中间话」，电脑通过**编译器**（相当于翻译官）把编程语言翻译成 `0` 和 `1`。

世界上有很多编程语言，英文的居多。但是！

### 中文也能编程

**仓颉**就是中国人开发的编程语言。而 **zhc**（仓颉方言框架）让它更进一步：关键字、函数名、报错提示，全部可以用中文！

| 英文编程语言会看到 | 我们用 zhc 写 |
|---|---|
| `func main()` | `主函数()` |
| `print("你好")` | `打印行("你好")` |
| `let x = 1` | `让 x = 1` |
| `if ... else ...` | `如果 ... 否则 ...` |

**你写代码的时候，不用查英文字典。** 这是这本书最大的底气。

### 安装你的工具

1. 下载并安装仓颉编译器（cjc）与 zhc 工具（项目 README 有详细步骤）。
2. 打开「终端」（Windows 是 PowerShell，macOS 是「终端」App，Linux 是 Terminal）。
3. 试试输入 `zhc --help`，如果看到中文帮助信息，就成功了！

> **术语小词典**
> - **程序**：写给电脑看的「菜谱」
> - **代码**：程序的另一个名字，像「作文」和「文章」的关系
> - **运行**：让电脑执行你的程序
> - **编译器**：把中文代码翻译成电脑能懂的 `0` 和 `1` 的翻译官

## 第 2 章 第一个程序：你好，世界！

### 约定俗成的第一句话

全世界学编程的人，第一个程序都是让电脑说一句话：「你好，世界！」（Hello, World!）。这是编程界的传统，像学书法先写「人」字一样。

### 创建你的项目

在终端里输入：

```bash
zhc init 我的第一个程序
```

这会帮你建好一个叫「我的第一个程序」的文件夹，里面已经放好了一个能运行的小程序。

然后进入这个文件夹，打开 `src/main.zc` 文件（用记事本或任意文本编辑器）：

```cangjie
主函数() {
    打印行("你好，世界！")
}
```

就三行！我们来拆解：

### 主函数：程序的入口

`主函数()` 是**程序的入口**——电脑运行你的程序时，从这里开始，像进家门先迈进门一样。

它后面的 `{` 和 `}`（花括号）像一扇门的**门框**：`{` 表示「门开了，里面的代码开始执行」，`}` 表示「门关了，到这里结束」。

### 打印行：让电脑说话

`打印行("你好，世界！")` 的意思是：**让电脑把「你好，世界！」显示在屏幕上**。
- 里面的 `"`（双引号）是文字的「包装盒」，告诉电脑：引号里面是一句话，不是代码。
- `打印行` 比 `打印` 多一个「行」，因为它打完字还会**换行**——像写完一行字按回车。

### 运行你的程序

在终端输入：

```bash
zhc run src/main.zc
```

你会看到：

```
你好，世界！
```

**成功啦！** 你刚刚完成了所有程序员的第一课。

> 小实验：把引号里的字改成你的名字，再运行一次。比如 `打印行("我是小明")`。电脑就会说「我是小明」。

### 动手练一练

1. 让电脑连续说三句话：你的名字、你的年龄、你最喜欢吃的东西。
2. 猜一猜：如果去掉引号，写成 `打印行(你好)`，会发生什么？去试试！看看第 12 章能不能帮上忙。

## 第 3 章 记忆盒子：变量

### 让电脑帮你记东西

你做题的时候，会先在草稿纸上写「已知：x = 5」。**变量**就是电脑的草稿纸：一个贴了名字标签的盒子，可以往里面放东西，随时拿出来用。

### 让：一个不可改动的盒子

```cangjie
主函数() {
    让 我的年龄 = 12
    打印行("我的年龄是${我的年龄}")
}
```

- `让 我的年龄 = 12`：拿出一个盒子，贴上「我的年龄」的标签，放进数字 `12`。
- `"我的年龄是${我的年龄}"`：`${}` 是**插值**——像填空一样，把盒子里东西的值填进这句话里。运行结果：`我的年龄是12`。

`让` 的意思是「**定下来，不改了**」——盒子里的东西放进去了就不能换。

### 可变：一个可以改的盒子

有时候我们确实要改，比如数数：

```cangjie
主函数() {
    可变 计数 = 0
    计数 = 计数 + 1      // 从盒子里取出 0，加上 1，放回 1
    计数 = 计数 + 1      // 再取一次，现在变成 2
    打印行("数了两下：${计数}")
}
```

- `可变`：盒子里的东西可以**随时更换**。
- `=` 是**赋值**：把右边的东西放进左边名字的盒子里。注意它不是数学里的「等于」，而是「把……放进……」。

> 类比：`让` 像是刻在石头上的字（改不了），`可变` 像是写在黑板上的字（能擦掉重写）。

### 给盒子起名字的规矩

- 可以用中文！`我的年龄`、`总分`、`答案` 都行。
- 名字要**一看就懂**。`总分` 比 `a` 好一百倍——过两天你自己都看不懂 `a` 是什么。
- 不能是数字开头（`123abc` 不行），不能有空格。

### 动手练一练

1. 用 `让` 存你的生日，用 `可变` 存你的零花钱，然后打印出来。
2. 猜一猜：`让 分数 = 90` 之后，再写 `分数 = 95`，会发生什么？试试看！中文错误提示会告诉你答案。

## 第 4 章 数字和文字

### 盒子里可以放什么？

到目前为止我们放了数字和文字，其实有四种基本「材料」：

| 材料 | 名字 | 例子 |
|---|---|---|
| 整数（没有小数点） | `整数` | `12`、`-3`、`0` |
| 小数（浮点） | `浮点` | `3.14`、`-0.5` |
| 文字（字符串） | `字符串` | `"你好"`、`"abc"` |
| 真/假（布尔） | `布尔` | `真`、`假` |

电脑分得清清楚楚：`12` 是数字，`"12"` 是文字（不信你把它们加一加试试，会报错！）。

### 电脑是计算器

```cangjie
主函数() {
    让 苹果价格 = 3
    让 梨价格 = 4
    让 一共 = 苹果价格 + 梨价格
    打印行("一共${一共}元")
    打印行("三个苹果${苹果价格 * 3}元")
    打印行("比梨多${梨价格 - 苹果价格}元")
}
```

运算符号：`+` 加、`-` 减、`*` 乘、`/` 除。
跟数学一样，**先乘除后加减**，想先算的加括号：`(苹果价格 + 梨价格) * 2`。

> 注意：整数除以整数，结果还是整数（多余的部分直接丢掉）。`7 / 2` 得到 `3`，不是 `3.5`！想要 `3.5`，得用浮点：`7.0 / 2`。

### 把文字拼起来：插值

想组合文字和数字，用 `${}` 填空最方便：

```cangjie
主函数() {
    让 名字 = "小明"
    让 分数 = 95
    打印行("${名字}考了${分数}分")
}
```

### 动手练一练

1. 算一算：你一周的零花钱如果每天多 2 元，一年（365 天）多多少？用程序算。
2. 打印一句话：`"我的身高是"` + 你的身高（用插值 `${}`）。
3. 试试 `打印行(1 + "2")`，看看中文错误提示说什么。

## 第 5 章 电脑会思考：判断

### 如果……就……

电脑最厉害的本事之一，就是**做判断**。语法跟说话一样：

```cangjie
主函数() {
    让 分数 = 85
    如果 (分数 >= 60) {
        打印行("及格了！")
    }
}
```

- `如果 (条件)`：**如果条件成立**，就执行花括号里的代码。
- `>=` 是「大于等于」。比较符号有：`==`（等于）、`!=`（不等于）、`>`（大于）、`<`（小于）、`>=`、`<=`。

### 否则如果、否则：多分支判断

```cangjie
主函数() {
    让 分数 = 85
    如果 (分数 >= 90) {
        打印行("优秀！")
    } 否则如果 (分数 >= 60) {
        打印行("及格")
    } 否则 {
        打印行("加油，别灰心")
    }
}
```

像判断题：第一个条件不成立就试第二个，都不成立就走 `否则`。**从上到下，只走一条路。**

### 真与假

判断的结果只有两种：`真`（成立）和 `假`（不成立）。这就是 `布尔` 类型：

```cangjie
主函数() {
    让 下雨 = 真
    如果 (下雨) {
        打印行("带伞！")
    }
}
```

> 类比：判断就像岔路口的路牌，电脑根据条件决定走哪条路。条件只有「真」和「假」两个方向。

### 动手练一练

1. 写一个程序：输入你的身高，如果超过 150 打印「可以玩过山车」，否则打印「再长高一点」。
2. 给分数评级：`>=90` 优秀，`>=80` 良好，`>=60` 及格，否则加油——用上 `否则如果`。
3. 想一想：`如果 (5 > 3)` 和 `如果 (3 > 5)`，哪个会执行里面的代码？

## 第 6 章 让电脑重复干活：循环

### 重复的事交给电脑

让电脑从 1 加到 100？手动写 100 行？**循环**就是干这个的——让同一段代码反复执行。

### 对于：数着数着做

```cangjie
主函数() {
    对于 (i in 1..5) {
        打印行("第${i}次")
    }
}
```

- `1..5` 是一个**范围**：从 1 到 5（注意：到 5 就停，不包含 5）。
- `对于 (i in 1..5)`：每次把 `i` 依次变成 1、2、3、4，执行一遍花括号里的代码。
- 输出：`第1次`、`第2次`、`第3次`、`第4次`（没有第5次！）。

> 传奇故事：数学家高斯 8 岁那年，老师让全班算 1 加到 100，别的小朋友埋头苦算，高斯几秒就写完了——他发现 `1+100=101`、`2+99=101`……一共 50 组，所以答案是 `50 × 101 = 5050`。我们用循环写出来：

```cangjie
主函数() {
    可变 总和 = 0
    对于 (i in 1..101) {
        总和 = 总和 + i
    }
    打印行("1 加到 100 等于${总和}")
}
```

### 当：直到不满足才停

`当` 循环：**只要条件为真，就一直做**。

```cangjie
主函数() {
    可变 剩下面条 = 10
    当 (剩下面条 > 0) {
        打印行("还有${剩下面条}根面条")
        剩下面条 = 剩下面条 - 1
    }
    打印行("吃完了！")
}
```

> 危险提醒：如果忘了写 `剩下面条 = 剩下面条 - 1`，条件永远为真，程序会一直循环下去——这叫**死循环**。看到程序不停刷屏，按 Ctrl+C 强制停止。

### 跳出和继续

- `跳出`：立刻结束整个循环（不想数了，直接走）。
- `继续`：跳过这一次，进入下一次。

```cangjie
主函数() {
    对于 (i in 1..10) {
        如果 (i == 3) { 继续 }      // 跳过 3
        如果 (i == 7) { 跳出 }      // 到 7 就停
        打印行("数到${i}")
    }
}
// 输出：数到1 数到2 数到4 数到5 数到6
```

### 动手练一练

1. 用 `对于` 打印九九乘法表的某一列：`1×7=7`、`2×7=14`……`9×7=63`。
2. 用 `当` 倒计时：从 10 数到 1，然后打印「发射！」。
3. 把「1 加到 100」改成「1 加到 1000」，看看答案对不对（公式：n×(n+1)/2）。

## 第 7 章 装进盒子：函数

### 重复写的代码，收进函数

你发现「成绩评级」这段判断要被用三次。复制粘贴三遍？代码会又臭又长，改一处要改三处。
**函数**就是解决方案：把一段代码装进一个「工具箱」，起个名字，随用随取。

### 定义函数

```cangjie
函数 评级(分数: 整数): 字符串 {
    如果 (分数 >= 90) { 返回 "优秀" }
    否则如果 (分数 >= 60) { 返回 "及格" }
    否则 { 返回 "加油" }
}

主函数() {
    打印行("小明的评级：${评级(85)}")
    打印行("小红的评级：${评级(95)}")
}
```

拆开看：

- `函数 评级`：定义一个叫「评级」的函数。
- `(分数: 整数)`：**参数**——函数工作需要的「原料」。这里要一个整数，叫 `分数`。
- `: 字符串`：**返回类型**——函数交出的「成品」是文字。
- `返回 "优秀"`：把成品交出去，函数立刻结束。
- `评级(85)`：**调用**（使用）函数，把 85 递给它。

> 类比：函数像自动售货机——投币（参数），出货（返回）。投不同的币，出不同的货。

### 没有原料也没有成品也行

不需要参数和返回值时，直接空着：

```cangjie
函数 打招呼() {
    打印行("你好呀！")
}

主函数() {
    打招呼()
    打招呼()
}
```

### 为什么用函数？

1. **不重复**：同样的逻辑只写一次。
2. **好修改**：改一处，所有用到的地方都变。
3. **好读**：`评级(85)` 一眼看懂在干什么，比一长串 `如果` 清爽。

### 动手练一练

1. 写一个 `求和(最大数: 整数): 整数` 函数，用循环算 `1+2+…+最大数`，然后调用它算 100 和 1000。
2. 写一个 `判断奇偶(数: 整数): 字符串` 函数：偶数返回「偶数」，奇数返回「奇数」。（提示：`数 % 2 == 0` 表示能被 2 整除，`%` 是取余数。）
3. 想一想：`评级(85)` 里的 85 和函数里的 `分数`，是不是同一个盒子？——不是！调用时电脑会新建一个「分数」盒子放进 85，函数结束盒子就消失了。

## 第 8 章 收集东西：列表

### 一个盒子装不下怎么办？

班里 45 个同学的成绩，难道写 45 个变量？**向量**（列表）就是用来装一长串东西的「书包」：

```cangjie
导入 标准集合.{向量}

主函数() {
    可变 成绩单 = 向量<整数>()
    成绩单.添加(95)
    成绩单.添加(88)
    成绩单.添加(76)
    打印行("一共有${成绩单.大小}个成绩")
    打印行("第一个成绩：${成绩单[0]}")
}
```

- `向量<整数>()`：一个专门装整数的空书包。
- `成绩单.添加(95)`：往书包里放一个。
- `成绩单.大小`：数一数有几个（注意：`大小` 是直接读的属性，不用加括号）。
- `成绩单[0]`：取第 1 个（**编号从 0 开始**！0 是第一个，1 是第二个……这是编程界的规矩，记住它）。

### 遍历：把书包里的东西一个个拿出来

```cangjie
导入 标准集合.{向量}

主函数() {
    可变 成绩单 = 向量<整数>()
    成绩单.添加(95)
    成绩单.添加(88)
    成绩单.添加(76)
    可变 总和 = 0
    对于 (成绩 in 成绩单) {
        总和 = 总和 + 成绩
    }
    打印行("平均分：${总和 / 成绩单.大小}")
}
```

`对于 (成绩 in 成绩单)`：把书包里的东西**从头到尾**一个一个取出来，每次放进「成绩」这个盒子。

### 动手练一练

1. 建一个装你一周零花钱的向量，算总和和平均。
2. 写一个函数 `求最大(列表: 向量<整数>): 整数`：遍历列表，找出最大的数（提示：用一个 `可变 最大 = 列表[0]`，遇到更大的就换）。
3. 想一想：`成绩单[成绩单.大小 - 1]` 是第几个？

## 第 9 章 一一对应：字典

### 名字对应信息：点名册

向量按「第几个」找东西。但有时候你想按「名字」找——比如输入「旺财」马上知道它几岁。
**哈希映射**（字典）就是干这个的：一个格子放**钥匙**（名字），另一个格子放**值**（信息）：

```cangjie
导入 标准集合.{哈希映射}

主函数() {
    可变 宠物年龄 = 哈希映射<字符串, 整数>()
    宠物年龄["旺财"] = 3
    宠物年龄["咪咪"] = 5
    宠物年龄["小黄"] = 1
    打印行("旺财${宠物年龄["旺财"]}岁")
    打印行("家里有${宠物年龄.大小}只宠物")
}
```

- `哈希映射<字符串, 整数>()`：钥匙是文字、值是整数的点名册。
- `宠物年龄["旺财"] = 3`：登记「旺财 3 岁」。
- `宠物年龄["旺财"]`：查「旺财」几岁。

> 类比：向量像排队（第 0 个、第 1 个……），哈希映射像点名册（按名字找人，不用排队）。

### 遍历字典

```cangjie
导入 标准集合.{哈希映射}

主函数() {
    可变 宠物年龄 = 哈希映射<字符串, 整数>()
    宠物年龄["旺财"] = 3
    宠物年龄["咪咪"] = 5
    对于 (名字 in 宠物年龄.键()) {
        打印行("${名字}${宠物年龄[名字]}岁")
    }
}
```

`键()`：把所有钥匙（名字）取出来。取出钥匙，就能查到对应的值。

2. 想一想：什么时候用向量，什么时候用哈希映射？（提示：按顺序 → 向量；按名字找 → 哈希映射。）
3. 查一查：`宠物年龄["大象"]` 会怎样？——字典里没有这个钥匙。试试运行，看中文错误提示怎么说！

## 第 10 章 认识结构体和类

### 相关的东西，捆在一起

描述一个点：横坐标 x、纵坐标 y。分开写两个变量，还得记住「x 配 y」。**结构体**把相关的数据捆成一个整体：

```cangjie
结构体 点 {
    公开 可变 x: 整数
    公开 可变 y: 整数
    初始化(x: 整数, y: 整数) {
        本对象.x = x
        本对象.y = y
    }
    公开 函数 距离平方(): 整数 {
        返回 本对象.x * 本对象.x + 本对象.y * 本对象.y
    }
}

主函数() {
    让 原点 = 点(3, 4)
    打印行("坐标（${原点.x}，${原点.y}）")
    打印行("到原点距离的平方：${原点.距离平方()}")
}
```

- `结构体 点`：定义一种「点」形状的盒子，里面装 x 和 y。
- `初始化(...)`：**构造**——造这个盒子时，把原料放进去。
- `本对象`：指「当前这个盒子自己」。`本对象.x` 就是「我自己里面的 x」。
- `点(3, 4)`：按图纸造一个 x=3、y=4 的点。
- `原点.距离平方()`：用点自己的方法算距离（勾股定理：3²+4²=25，输出 25！）。

> 类比：结构体像一张**体检表**——表格把所有项目（身高、体重、视力）固定在一起，填表（初始化）后用起来很方便。

### 类：结构体 + 本领（还能继承）

**类**和结构体很像，但更强大。它最酷的是**继承**：狗是动物的一种，所以狗「继承」动物的一切，再加上自己的特点：

```cangjie
开放 类 动物 {
    公开 可变 名字: 字符串
    初始化(名字: 字符串) {
        本对象.名字 = 名字
    }
    公开 开放 函数 叫声(): 字符串 { 返回 "……" }
}

类 狗 <: 动物 {
    初始化(名字: 字符串) {
        超类(名字)
    }
    公开 重写 函数 叫声(): 字符串 { 返回 "汪汪" }
}

主函数() {
    让 旺财: 动物 = 狗("旺财")
    打印行("${旺财.名字}说：${旺财.叫声()}")
}
```

- `类 狗 <: 动物`：狗「小于冒号」动物——**狗是动物的一种**，继承动物的所有东西。
- `超类(名字)`：把名字交给「爸爸」动物去处理（借爸爸的构造方法）。
- `重写`：狗把「叫声」从「……」改成「汪汪」——这叫**重写**（覆盖）。

> 为什么需要类和继承？现实世界本身就是一层一层的：「动物 → 狗」「车 → 电动车」。程序照现实写，就好懂、好扩展。以后你想加一只猫，不用改动物，只需要新写一个「猫」类。

## 第 11 章 综合实战：让程序猜你心里的数字

### 游戏规则

你在心里想一个 1 到 100 的整数（**别告诉电脑**）。电脑来猜，你告诉它「大了」「小了」还是「猜对了」。电脑要在 7 次以内猜中。

你可能会想：电脑难道瞎猜？不！它用的是**二分法**——每次猜中间的数，一下排除一半可能：

- 猜 50：你说「小了」→ 答案在 51~100，排除 50 个
- 猜 75：你说「大了」→ 答案在 51~74，排除 25 个
- 猜 62：你说「小了」→ 答案在 63~74……

每猜一次，可能性减半。100 个数字，最多 7 次就能锁定！

### 完整代码

```cangjie
主函数() {
    可变 最低 = 1
    可变 最高 = 100
    可变 次数 = 0
    打印行("想一个 1 到 100 的整数，我来猜！")
    当 (真) {
        次数 = 次数 + 1
        让 猜 = (最低 + 最高) / 2
        打印行("第${次数}次：我猜${猜}，是大了、小了，还是对了？")
        让 回答 = 读取行()
        如果 (回答 == "大了") {
            最高 = 猜 - 1
        } 否则如果 (回答 == "小了") {
            最低 = 猜 + 1
        } 否则如果 (回答 == "对了") {
            打印行("哈哈，${次数}次猜中！")
            跳出
        } 否则 {
            打印行("请输入：大了 / 小了 / 对了")
            次数 = 次数 - 1    // 回答无效不算次数
        }
    }
}
```

运行：`zhc run src/main.zc`，然后和电脑对话：

```
想一个 1 到 100 的整数，我来猜！
第1次：我猜50，是大了、小了，还是对了？
小了
第2次：我猜75，是大了、小了，还是对了？
大了
第3次：我猜62，是大了、小了，还是对了？
对了
哈哈，3次猜中！
```

### 这个游戏用到了什么？

| 知识点 | 用在哪 |
|---|---|
| `可变` | 最低/最高/次数 要不断改 |
| `当 (真)` | 无限循环，直到猜对 `跳出` |
| `如果/否则如果` | 根据回答缩小范围 |
| `读取行` | 读取你的回答 |
| `跳出` | 猜对了立刻结束 |
| 数学 | 二分法：每次取中间 `(最低+最高)/2` |

**这就是一个真正的程序**：有输入、有判断、有循环、有策略。你已经入门了！

### 拓展挑战

1. 把范围改成 1 到 1000（想想最多几次能猜中？提示：2¹⁰=1024）。
2. 统计：如果每次回答前先打印一个提示语（比如「记住要说真话哦」），`次数` 会怎样？怎么修？
3. 终极挑战：让电脑当「出题者」，你当「猜题者」——电脑想一个数，你输入猜的数，电脑告诉你大了小了。怎么让电脑「想」一个数？（提示：用第 3 章的 `可变` 先存一个数，比如 42……但这不随机。想想还能怎么改？）

## 第 12 章 出错不可怕：读懂中文错误提示

### 错误是电脑在帮你

程序报错，不是电脑在惩罚你，而是**电脑在帮你找问题**。全世界的程序员每天都会遇到一堆错误。**会修错误，才算会编程。**

我们用的 zhc 工具最贴心的地方：**错误提示是中文的**，而且带着 💡 教学提示和修复示例。

### 故意写错，看看会怎样

```cangjie
主函数() {
    让 分数 = 90
    打印行("我考了${分数}分")
    打印行(分数2)
}
```

运行 `zhc run src/main.zc`，你会看到：

```
[错误] 未声明的标识符 `分数2`  /home/me/项目/src/main.zc:4:9
  💡 使用了未定义的名称：检查拼写；变量需先声明后使用……
  修复示例（可直接粘贴）：
  ...
```

拆开看这个提示的每一部分：

| 提示内容 | 什么意思 |
|---|---|
| `[错误]` | 这是错误，不是警告（警告是「最好改但能运行」） |
| 未声明的标识符 `分数2` | 电脑不认识 `分数2` 这个名字 |
| `main.zc:4:9` | **位置**：第 4 行第 9 个字符附近 |
| 💡 教学提示 | 为什么会有这个错误 + 怎么改 |
| 修复示例 | 可以直接照着粘贴的正确代码 |

> 类比：错误提示像医生开的**化验单**——哪里不舒服（位置）、什么病（原因）、怎么治（修复示例），都写清楚了。

### 三种最常见的错误

**1. 名字写错了**
`分数` 写成 `分数2`、`打印行` 写成 `打印`（少一个字）。
→ 提示「未声明的标识符」。检查拼写。

**2. 类型不匹配**
```cangjie
让 年龄: 整数 = "12"    // 文字放进了数字盒子
```
→ 提示「类型不匹配」。盒子的标签和放进去的东西要对上。

**3. 括号/引号没配对**
```cangjie
打印行("你好"      // 少了一个括号
```
→ 提示「未闭合的分隔符」。数一数 `(` 和 `)`、`"` 和 `"` 是不是成双成对。

### 调试三步法

1. **读提示**：先读 `[错误]` 后面那句话——它在说什么名字、什么类型、什么符号？
2. **看位置**：找到 `文件:行:列`，跳到那一行，前后看看。
3. **动手修**：照着 💡 提示和修复示例改，再运行。**一次改一处**，改完立刻运行。

> 温馨提示：报错的第一条往往才是真正的原因，后面的可能是「连锁反应」。先修第一条。

### 动手练一练

1. 把第 2 章的程序里的 `打印行` 故意改成 `打印行2`，运行，读一读错误提示的每一部分。
2. 写 `让 x: 整数 = "你好"`，运行，看看「类型不匹配」的提示长什么样。
3. 把花括号 `{` 故意漏掉一个，运行，看看提示怎么帮你定位。
4. 修好上面三个错误，让程序跑通——**你现在会调试了！**
