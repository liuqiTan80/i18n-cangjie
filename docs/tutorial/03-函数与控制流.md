# 03 函数与控制流

目标：定义函数，使用分支、匹配与循环。

## 3.1 函数

普通函数用 `函数` 声明（注意：入口 `主函数` 不带前缀）：

```cangjie
函数 加法(左: 整数, 右: 整数): 整数 {
    返回 左 + 右
}

主函数() {
    让 结果 = 加法(3, 4)
    打印行("3 + 4 = ${结果}")
}
```

要点：

- 参数写法 `名字: 类型`，与官方一致；
- 返回类型在 `): 类型` 处标注；
- `返回` = `return`；无返回值（`单元`）时可省略。

## 3.2 如果 / 否则如果 / 否则

```cangjie
函数 评级(分数: 整数): 字符串 {
    如果 (分数 >= 90) {
        返回 "优秀"
    } 否则如果 (分数 >= 60) {
        返回 "及格"
    } 否则 {
        返回 "加油"
    }
}

主函数() {
    打印行(评级(95))
    打印行(评级(70))
    打印行(评级(40))
}
```

## 3.3 匹配（match）

`匹配` 是仓颉强大的分支结构，`情况` + 模式：

```cangjie
函数 星期名(数字: 整数): 字符串 {
    匹配 (数字) {
        情况 (1) => 返回 "一"
        情况 (2) => 返回 "二"
        情况 (3) => 返回 "三"
        情况 (_) => 返回 "未知"     // _ 通配
    }
}

主函数() {
    对于 (i in 1..4) {              // 1..4 是左闭右开范围：1, 2, 3
        打印行("星期${i}：${星期名(i)}")
    }
}
```

## 3.4 循环：对于（for）与当（while）

`对于` 遍历范围或集合：

```cangjie
主函数() {
    可变 和 = 0
    对于 (值 in 0..100) {          // 0 到 99
        和 += 值
    }
    打印行("0+...+99 = ${和}")     // 4950

    对于 (字符 in "仓颉") {         // 遍历字符串的字符（Rune）
        打印行("字符：${字符}")
    }
}
```

`当` 是条件循环：

```cangjie
主函数() {
    可变 回合 = 0
    当 (回合 < 3) {
        打印行("第 ${回合 + 1} 回合")
        回合 += 1
    }
}
```

循环控制：`跳出`（break）提前退出，`继续`（continue）进入下一轮：

```cangjie
主函数() {
    对于 (i in 0..10) {
        如果 (i == 2) { 继续 }
        如果 (i == 5) { 跳出 }
        打印行(i)
    }
    // 输出：0 1 3 4
}
```

## 3.5 函数是一等公民

函数可赋值、可作参数（与官方一致）：

```cangjie
函数 双倍(x: 整数): 整数 { 返回 x * 2 }

函数 应用(处理: (整数) -> 整数, 值: 整数): 整数 {
    返回 处理(值)
}

主函数() {
    打印行(应用(双倍, 21))          // 42
}
```

## 3.6 官方对照

```cangjie
// 官方仓颉
func add(left: Int64, right: Int64): Int64 {
    return left + right
}

main() {
    for (i in 1..4) {
        println(i)
    }
}
```

## 练习

1. 写 `阶乘` 函数（递归或循环皆可）；
2. 用 `匹配` 把成绩等级映射为「优秀/良好/及格/不及格」；
3. 用 `当` 循环打印 1 到 10 中的偶数。

## 小结

- `函数` 声明 + `返回`；`如果`/`否则如果`/`否则` 分支；
- `匹配` + `情况` 模式匹配；`对于`/`当` 循环，`跳出`/`继续` 控制；
- 函数是一等公民，可赋值可传参。
