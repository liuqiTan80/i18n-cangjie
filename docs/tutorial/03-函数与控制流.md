# 03 函数与控制流

> 本章目标：掌握「组织逻辑」的两大工具——**函数**（把代码装进盒子复用）与**控制流**（判断、匹配、循环让程序会走岔路、会绕圈）。
> 读完你能回答：为什么函数参数必须标注类型？匹配为什么比 `如果` 链安全？短路求值有什么用？

## 3.1 函数：装进盒子的代码

- **是什么**：`函数 名称(参数): 返回类型 { 函数体 }`——一段可复用、有名字、可调用的代码块：
  ```cangjie
  函数 两倍(数: 整数): 整数 {
      返回 数 * 2
  }
  函数 求面积(宽: 浮点, 高: 浮点): 浮点 {
      返回 宽 * 高
  }
  主函数() {
      打印行(两倍(21))          // 42
      打印行(求面积(3.0, 4.0))  // 12.0
  }
  ```
- **为什么**：**复用**（同一逻辑只写一次）、**抽象**（调用方只关心输入输出）、**可测**（小函数容易验证）。函数是组织代码的第一级单位。
- **注意**：
  - 入口叫 `主函数()`（**不带**「函数」前缀——`函数 主函数` 是语法错误，官方 `func main` 同样错误）；
  - **参数必须显式标注类型**（不推断）——参数是接口契约：调用方需要知道传什么、编译器需要检查调用是否正确；
  - 参数默认**只读绑定**（不能给参数重新赋值）；
  - 函数名用「动词+对象」风格（`计算总分`、`读取文件`）。

## 3.2 返回：交出结果并立即结束

- **是什么**：`返回 值` 把结果交出去并**立即结束**函数。
- **为什么**：返回是函数与调用方的「交接仪式」。**函数体最后一条表达式的值会自动作为返回值**（尾部表达式）——但推荐显式 `返回` 更清楚。
- **多返回值**用元组（见 2.7）：
  ```cangjie
  函数 求最值(列表: 数组<整数>): (整数, 整数) {
      返回 (列表[0], 列表[列表.长度 - 1])
  }
  主函数() {
      让 (最小, 最大) = 求最值([3, 7, 2, 9])
      打印行("最小${最小} 最大${最大}")   // 最小3 最大9
  }
  ```
- **注意**：无返回值的函数可以不写 `返回`（隐式返回 `单元`）；`返回` 后不能有语句（不可达代码警告）；声明了 `: 字符串` 就必须**所有路径**都返回——漏一条编译器报「函数缺少返回」。

## 3.3 命名参数：不怕记错顺序

参数多的时候，按位置传参容易记错顺序。仓颉用 `!` 标记命名参数：

- **声明**：参数名后加 `!` 表示「调用时按名传」：
  ```cangjie
  函数 设置(年龄: 整数, 名字!: 字符串, 班级!: 字符串) {
      打印行("${名字} ${年龄}岁 ${班级}")
  }
  主函数() {
      设置(12, 名字: "小明", 班级: "初一2班")
  }
  ```
- **规则**：**未命名参数必须在前**（`设置(12, ...)`），命名参数写在后、按 `名字: 值` 传；参数名写错报「找不到参数」。
- **为什么**：调用处直接看到「这个名字配这个值」，比一串裸值好读得多——这是接口**自文档化**的手段（第 11 章还会讲）。

## 3.4 函数重载：一个名字，多种语义

同名函数、**参数不同**（个数或类型），编译器按实参选版本：

```cangjie
函数 描述(x: 整数): 字符串 { 返回 "整数：${x}" }
函数 描述(x: 字符串): 字符串 { 返回 "文本：${x}" }
主函数() {
    打印行(描述(1))        // 整数：1
    打印行(描述("嗨"))     // 文本：嗨
}
```

- **注意**：**仅返回类型不同不能重载**（会冲突）；重载解析有歧义时编译器优先精确匹配。

## 3.5 lambda：没有名字的函数

- **是什么**：函数字面量：`{ x => x * 2 }`——花括号包整体，`参数 => 表达式`：
  ```cangjie
  导入 标准集合.*
  函数 应用两次(f: (整数) -> 整数, x: 整数): 整数 {
      返回 f(f(x))
  }
  主函数() {
      让 翻倍 = { x => x * 2 }
      打印行(应用两次(翻倍, 3))      // 12（函数是一等公民：可赋值、可传参）
      可变 名单 = 向量<整数>()
      名单.添加(1); 名单.添加(2); 名单.添加(3)
      让 双倍后 = 名单 |> 映射({ x => x * 2 }) |> 收集数组
      打印行(双倍后)                   // [2, 4, 6]
  }
  ```
- **为什么**：临时逻辑不想起名字（尤其传给 `映射`/`过滤` 这类高阶函数）——「一次性函数」不该占用命名空间。
- **闭包**：lambda 能**捕获**定义处作用域的变量：
  ```cangjie
  函数 造加法器(增量: 整数): (整数) -> 整数 {
      返回 { x => x + 增量 }       // 捕获 增量
  }
  主函数() {
      让 加5 = 造加法器(5)
      打印行(加5(10))              // 15
  }
  ```
- **注意**：`\x => ...` 是其他语言的语法，仓颉**不认**；多参数 `{ x, y => x + y }`；lambda 参数类型通常由上下文推断；函数类型写法 `(整数) -> 整数`。

## 3.6 运算符：算术、比较、逻辑

**算术**：`+ - * / %`，优先级与数学一致（先 `*` `/` `%`，后 `+` `-`）：

```cangjie
主函数() {
    打印行(7 / 2)        // 3（整数除法，小数丢弃）
    打印行(7 % 2)        // 1（取余——判断奇偶、取末位数字全靠它）
    打印行(7.0 / 2.0)    // 3.5（浮点除法）
    打印行((1 + 2) * 3)  // 9
}
```

**比较**：`==`（相等）`!=` `>` `>=` `<` `<=`，结果都是 `布尔`：

```cangjie
主函数() {
    让 分数 = 85
    打印行(分数 == 85)    // true
    打印行(分数 != 60)    // true
    打印行(分数 >= 90)    // false
}
```

- 字符串可以用 `==`（**比较内容**不是地址——比 C/Java 更符合直觉）；
- **浮点别用 `==`**（精度误差），用误差范围：`绝对值(a - b) < 0.0001`（第 2 章）。

**逻辑**：方言 `与`（&&）、`或`（||）、`非`（!）：

```cangjie
主函数() {
    让 年龄 = 15
    让 有票 = 真
    如果 (年龄 >= 12 与 有票) { 打印行("可以入场") }
    如果 (年龄 < 6 或 年龄 > 80) { 打印行("免费") }
    如果 (非 有票) { 打印行("请买票") }
}
```

- **短路求值**：`假 与 任何` 直接得 `假`（右边**不执行**）、`真 或 任何` 直接得 `真`——所以可以安全写 `列表.大小 > 0 与 列表[0] > 1`（第一个条件假时不会越界访问）；
- 优先级：`与` 高于 `或`（同数学的乘除优先于加减）；
- 条件必须整体是 `布尔`——`如果 (x = 1)` 直接编译报错，这个设计帮你挡住 C 语言的经典赋值误写 bug。

**赋值**：`=` 是「放入」不是「等于」（`x = x + 1` 合法：先取旧值、算完放回）；`+=` `-=` `*=` 是复合赋值（`总和 += i` 是循环计数标配）：

```cangjie
主函数() {
    可变 总和 = 0
    对于 (i in 1..6) { 总和 += i }
    打印行(总和)          // 15
}
```

## 3.7 分支：如果 / 否则如果 / 否则

```cangjie
函数 评级(分数: 整数): 字符串 {
    如果 (分数 >= 90) { 返回 "优秀" }
    否则如果 (分数 >= 80) { 返回 "良好" }
    否则如果 (分数 >= 60) { 返回 "及格" }
    否则 { 返回 "加油" }
}
主函数() {
    打印行(评级(95))     // 优秀
    打印行(评级(70))     // 及格
    打印行(评级(40))     // 加油
}
```

- **从上到下只命中第一个成立的分支**——顺序就是优先级（`>= 60` 写在 `>= 90` 前会吞掉所有及格以上）；
- 分支体即使只有一条语句也**推荐写花括号**（避免悬空 else 歧义）；
- **`如果`/`匹配` 是表达式**——直接赋值：

```cangjie
主函数() {
    让 分数 = 85
    让 评语 = 如果 (分数 >= 60) { "及格" } 否则 { "不及格" }
    打印行(评语)          // 及格
}
```

表达式化让代码更紧凑且更安全（没有「忘记初始化」的问题——分支必须都有值）。

## 3.8 匹配：模式匹配 + 穷尽性检查

- **是什么**：`匹配 (值) { 情况 模式 => ... }`——比 `如果` 链更结构化的分支：
  ```cangjie
函数 星期名(数字: 整数): 字符串 {
    匹配 (数字) {
        情况 1 => 返回 "一"
        情况 2 => 返回 "二"
        情况 3 => 返回 "三"
        情况 _ => 返回 "未知"     // _ 通配符：匹配任意
    }
}
主函数() {
    对于 (i in 1..4) {              // 1..4 是半开区间：1, 2, 3
        打印行("星期${i}：${星期名(i)}")
    }
}
```
- **元组模式**（同时判断 + 解构）：
  ```cangjie
  主函数() {
      让 点 = (3, 4)
      匹配 (点) {
          情况 (0, 0) => 打印行("原点")
          情况 (x, 0) => 打印行("在 x 轴上：${x}")
          情况 (0, y) => 打印行("在 y 轴上：${y}")
          情况 (x, y) => 打印行("普通点（${x}，${y}）")
      }
  }
  ```
- **匹配守卫**（`其中` = where）：模式匹配「形状」+ 守卫匹配「形状 + 条件」：
  ```cangjie
  主函数() {
      让 分数 = 95
      匹配 (分数) {
          情况 x 其中 (x >= 90) => 打印行("优秀")
          情况 x 其中 (x >= 60) => 打印行("及格")
          情况 _ => 打印行("加油")
      }
  }
  ```
- **为什么**：`如果` 链是「手动管理分支」——漏写一个 `否则` 编译器不吭声，运行时悄悄走错路。**穷尽性检查**把「分支完整性」变成**编译错误**：匹配枚举/选项/元组必须覆盖所有可能（或 `_` 兜底），编译器替你检查「所有情况都处理了吗」——这是仓颉从函数式语言继承的最强安全设计之一（第 10 章详述）。

## 3.9 循环：对于 / 当 / 跳出 / 继续

**`对于`（for）**遍历范围或集合：

```cangjie
主函数() {
    可变 和 = 0
    对于 (值 in 0..100) {          // 0 到 99
        和 += 值
    }
    打印行("0+...+99 = ${和}")     // 4950

    对于 (字符 in "仓颉".字符流()) {   // 按字符遍历（注意：直接遍历字符串是字节！）
        打印行("字符：${字符}")
    }
}
```

**`当`（while）**条件循环：

```cangjie
主函数() {
    可变 回合 = 0
    当 (回合 < 3) {
        打印行("第 ${回合 + 1} 回合")
        回合 += 1
    }
}
```

**`跳出`（break）提前退出、`继续`（continue）跳过本轮**：

```cangjie
主函数() {
    对于 (i in 0..10) {
        如果 (i == 2) { 继续 }
        如果 (i == 5) { 跳出 }
        打印行(i)
    }
    // 输出：0 1 3 4
}
```

- **为什么**：循环 = 重复劳动的自动化。`跳出`/`继续` 让「提前终止」写在循环里而不是靠条件变量绕弯——**控制流的每个出口都应可见**。

## 3.10 官方对照

```cangjie
// 官方仓颉
func 评级(分数: Int64): String {
    if (分数 >= 90) { return "优秀" }
    else if (分数 >= 60) { return "及格" }
    else { return "加油" }
}
main() {
    for (i in 1..4) { println(i) }
    let f = { x => x * 2 }
    println(f(21))    // 42
}
```

## ✳ 本章的设计思想

1. **多范式融合**：同一门语言同时支持命令式（`如果`/`当`）、函数式（lambda/匹配/不可变）、面向对象（第 5 章）——逻辑用命令式写、数据处理用函数式写，各取所长而不是强迫皈依某一派。
2. **表达式即值**：`如果`/`匹配`/`块` 都有值——「分支必须都有值」从源头消灭「忘记初始化」；函数式风格渗透到命令式结构。
3. **穷尽性检查**：把「分支完整性」从运行时责任变成**编译期检查**——编译器替你数清楚所有情况。这是「错误挡在编译期」哲学的最强体现。
4. **显式接口契约**：函数参数必须标注类型、命名参数 `!` 标记——接口的每个细节都写在明面上，调用方与编译器看到的是同一份契约。
5. **短路求值**：逻辑运算按需求值——`假 与 任何` 不执行右边，这是「安全组合条件」的基石（也解释了为什么 `列表.大小 > 0 与 列表[0] > 1` 安全）。

## 小结

- 函数：`函数 名(参数: 类型): 类型`；参数必须标注；元组多返回 + 解构；命名参数 `!`；重载按参数区分；lambda 花括号整体；
- 运算符：整数 `/` 整除、`%` 取余；`与`/`或`/`非` 短路；`=` 是放入、`==` 才是比较；
- 分支：`如果`/`否则如果`/`否则`（也是表达式）；`匹配` + `情况` 模式 + `其中` 守卫 + 穷尽性检查；
- 循环：`对于` 范围/集合、`当` 条件、`跳出`/`继续` 控制。
