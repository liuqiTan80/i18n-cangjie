# 02 变量与类型

目标：掌握 `让`/`可变`、基础类型与类型标注，理解**可变性**教学主题。

## 2.1 让（let）：不可变绑定

`让` 声明的绑定**创建后不可修改**（这是仓颉的默认选择，也是教学三主题之一）：

```cangjie
主函数() {
    让 出生年 = 2000          // 类型自动推断为 整数（Int64）
    打印行("出生年 = ${出生年}")
    // 出生年 = 2001          // ❌ 不能给不可变值赋值
}
```

## 2.2 可变（var）：可修改变量

需要修改时用 `可变`：

```cangjie
主函数() {
    可变 计数 = 0
    计数 += 1
    计数 += 1
    打印行("计数 = ${计数}")    // 计数 = 2
}
```

💡 **教学提示**：如果编译器报「不能给不可变值赋值」，把 `让` 改成 `可变` 即可。
反之，若变量从未修改，把 `可变` 改成 `让` 更符合惯用法。

## 2.3 基础类型

| 方言类型 | 官方类型 | 说明 |
|---|---|---|
| `整数` | `Int64` | 64 位有符号整数 |
| `浮点` | `Float64` | 64 位浮点数 |
| `字符串` | `String` | 文本 |
| `布尔` | `Bool` | `真` / `假` |
| `字符` | `Rune` | Unicode 字符 |
| `单元` | `Unit` | 无返回值（如 `主函数`） |

类型标注写在变量名后（与官方一致）：

```cangjie
主函数() {
    让 年龄: 整数 = 18
    让 分数: 浮点 = 95.5
    让 名字: 字符串 = "小明"
    让 在学: 布尔 = 真
    打印行("${名字} ${年龄} 岁，分数 ${分数}，在学：${在学}")
}
```

## 2.4 常量（const）

编译期常量用 `常量`：

```cangjie
常量 圆周率 = 3.14159

主函数() {
    打印行("圆周率 ≈ ${圆周率}")
}
```

## 2.5 类型转换

仓颉**不会自动转换类型**，需要显式转换。用 `作为`（as）做安全转换，
数值转换用内建函数（如 `到整数`）：

```cangjie
主函数() {
    让 文本数字 = "42"
    让 数字 = 整数.parse(文本数字).getOrThrow()   // 官方 parse 原样可用
    打印行("数字 + 1 = ${数字 + 1}")

    让 宽 = 10
    让 高 = 3
    让 面积 = 宽 * 高                        // 整数乘法
    打印行("面积 = ${面积}")
}
```

> 说明：`整数.parse` 是官方 API（`Int64.parse`），未映射的词保持官方写法即可。

## 2.6 官方对照

```cangjie
// 官方仓颉
main() {
    let age: Int64 = 18
    let name: String = "小明"
    var count = 0
    count += 1
    println("${name} ${age} 岁")
}
```

## 练习

1. 声明 `让` 与 `可变` 各一个，观察把 `可变` 改为 `让` 后的诊断（中文提示）；
2. 写一个类型不匹配的赋值（如 `让 x: 整数 = "文本"`），看 zhc 的教学提示与修复示例；
3. 用 `常量` 声明圆周率并计算圆面积。

## 小结

- `让` 不可变、`可变` 可修改、`常量` 编译期常量；
- 类型：`整数`/`浮点`/`字符串`/`布尔`/`字符`/`单元`；
- 类型不匹配是初学者第一类高频错误——诊断会给出中文提示与修复示例。
