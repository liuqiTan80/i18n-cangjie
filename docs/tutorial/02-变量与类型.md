# 02 变量与类型

> 本章目标：掌握「存数据」的全部基础——`让`/`可变`/`常量` 三种绑定，以及从整数到元组的类型体系。
> 读完你能回答：为什么默认用 `让` 而不是 `可变`？为什么仓颉不做隐式类型转换？类型标注什么时候必须写？

## 2.1 让（let）：默认的不可变绑定

- **是什么**：`让 名字 = 值` 声明一个**创建后不可修改**的绑定。这是仓颉的**默认选择**：
  ```cangjie
  主函数() {
      让 出生年 = 2000          // 类型自动推断为 整数（Int64）
      打印行("出生年 = ${出生年}")
      // 出生年 = 2001          // ❌ 不能给不可变值赋值
  }
  ```
- **为什么**：可变性是 bug 的主要来源（意外修改、并发竞争、难以推理）。把「不可变」设为默认，**可变就变成需要申请的特权**——扫一眼代码里的 `可变`，就知道哪里可能变化。
- **注意**：`让` 是绑定不是「变量」——它把名字绑到一个值上，这个绑定关系不可变；但绑定的**对象**如果是引用类型（类），对象内部仍可变化（第 5 章详述）。

## 2.2 可变（var）：需要修改时才用

```cangjie
主函数() {
    可变 计数 = 0
    计数 += 1
    计数 += 1
    打印行("计数 = ${计数}")    // 计数 = 2
}
```

💡 **教学提示**：编译器报「不能给不可变值赋值」→ 把 `让` 改成 `可变`；反之，变量从未被修改 → 把 `可变` 改回 `让`（更符合惯用法，lint 会提醒）。

## 2.3 常量（const）：编译期常量

```cangjie
常量 圆周率 = 3.14159
常量 学校名 = "第一中学"

主函数() {
    打印行("${学校名}，圆周率 ≈ ${圆周率}")
}
```

- **是什么**：`常量`（官方 const）的值在**编译期**确定，且必须能编译期算出。
- **注意**：`常量` 与 `让` 的区别：常量是「编译期字面量」（可被编译器直接替换进代码、零运行时开销）；`让` 是「运行期绑定」。能用 `常量` 就用 `常量`。

## 2.4 基础类型总览

| 方言类型 | 官方类型 | 说明 | 例子 |
|---|---|---|---|
| `整数` | `Int64` | 64 位有符号整数（默认） | `42` |
| `整数32` | `Int32` | 32 位整数 | `42`（标注后） |
| `无符号整数` | `UInt64` | 非负整数 | `7u64` |
| `浮点` | `Float64` | 64 位浮点数（默认） | `3.14` |
| `浮点32` | `Float32` | 32 位浮点数 | `1.75f32` |
| `字符串` | `String` | 不可变 Unicode 文本 | `"仓颉"` |
| `布尔` | `Bool` | 真/假 | `真`、`假` |
| `字符` | `Rune` | 单个 Unicode 字符 | `'颉'` |
| `单元` | `Unit` | 无返回值的类型 | `空` |
| `空类型` | `Nothing` | 没有值的类型 | `退出(1)` 的返回 |

**类型是数据的「分类标签」**：它决定数据能存什么、能做什么运算、占多大空间。下面逐个看关键类型。

### 整数族与浮点族

```cangjie
主函数() {
    让 a: 整数 = 100          // 64 位（默认）
    让 b: 整数32 = 100        // 32 位
    让 c: 无符号整数 = 100    // 非负
    让 身高: 浮点32 = 1.75f32
    让 体重: 浮点32 = 65.5f32
    打印行(a + 整数(b))        // 不同位宽不能直接相加：显式转成 整数（见 2.10）
    打印行(身高 * 体重)        // 同类型（浮点32 × 浮点32）直接算
}
```

- **为什么**：位宽 = 存储空间与取值范围。默认 64 位是「最不会溢出的通用选择」；处理大量数据或协议格式时才用更窄的类型省内存。
- **注意**：`整数32`/`浮点32` 与默认位宽类型**不能直接混算**（官方不自动提升，报「二元表达式无效」——要显式转换，见 2.10）；无符号数 `-1` 是编译错误（范围检查）。

### 布尔

```cangjie
主函数() {
    让 成年 = 真
    打印行(成年 与 年龄判断(18))   // true
}
函数 年龄判断(岁: 整数): 布尔 { 返回 岁 >= 18 }
```

- **注意**：方言别名 `真`/`假`；**条件里不能用数字**——`如果 (1)` 报错，条件必须是真正的 `布尔` 表达式。这杜绝了 C 语言 `if (x = 1)` 赋值误写这类坑。
- **注意**：运行时输出保持**官方格式**（`打印行(真)` 输出 `true`）——方言只转译代码，不翻译运行时的输出文本。

### 字符与单元与空类型

```cangjie
函数 打招呼(): 单元 {
    打印行("你好")     // 无返回值的函数返回 单元
}

函数 直接退出(): 空类型 {
    退出(1)            // 永不返回（Nothing 可赋给任何类型）
}
```

- **注意**：三个「空」别混淆——`空类型`（Nothing，没有值）、`空`（Unit 的唯一值）、`无值`（Option 家族的「没有」，见第 6 章）。

## 2.5 字面量与后缀

数字字面量的类型由**上下文与后缀**共同决定：

```cangjie
主函数() {
    让 a: 整数32 = 42        // 字面量自动适配 32 位（字面量多态）
    让 b: 浮点32 = 3.14f32   // 后缀 f32 强制
    让 c: 无符号整数 = 7u64   // 后缀 u64 强制
    让 d: 整数 = 42i64       // i64 后缀显式 64 位
    打印行(a)
    打印行(d)
}
```

- **后缀全表**：整数 `i8/i16/i32/i64/u8/u16/u32/u64`，浮点 `f16/f32/f64`；
- **后缀必须小写**（`42U8`、`3.14F` 是语法错误）；
- 后缀类型要与标注一致（`浮点32` 配 `f32`、`浮点64` 配 `f64`）；
- 字节字面量用 `u8`（`[1u8, 2u8]` 是 `数组<字节>`）。

## 2.6 字符串深入：字节 vs 字符

字符串是**不可变**的 Unicode 字符序列。但它有几个新手必踩的坑：

```cangjie
主函数() {
    让 s = "仓颉"
    打印行(s.长度)             // 6 —— 是【字节数】！UTF-8 下每个汉字 3 字节
    打印行(s[0..3])            // 仓（切片按字节切，1 汉字 = 3 字节）
    打印行(s + "编程")         // 仓颉编程（+ 拼接）
}
```

- **坑 1**：`字符串[i]` 返回的是**字节**（UInt8）——中文会取到半个字！`"仓颉"[0]` 不是「仓」。
- **坑 2**：切片 `s[起..止]` 按字节切——起止必须落在汉字边界上，否则**运行时抛异常**。
- **按字符处理**的正确姿势——`字符流()`（惰性迭代器）：

```cangjie
导入 标准集合.*
主函数() {
    让 c = '颉'
    打印行(c)                          // 颉（字符字面量用单引号）
    打印行("仓颉".字符流() |> 第一个)  // 仓（按字符取第一个）
    对于 (字 in "仓颉".字符流()) { 打印行(字) }   // 仓 / 颉
}
```

- **为什么这么设计**：仓颉区分「文本」（字符）与「字节」（二进制）——文件、网络、加密处理的是字节流，不是字符。把两者混为一谈是经典 bug 来源（见第 11 章「编码知识」）。

## 2.7 数组与元组

**数组**（`数组<T>`）：定长、连续内存、下标 O(1)：

```cangjie
主函数() {
    让 固定 = [10, 20, 30]
    打印行(固定[1])              // 20
    对于 (项 in 固定) { 打印行(项) }
    让 空数组: 数组<整数> = []   // 空数组必须标注类型
}
```

- **注意**：数组**不可改变长度**（动态增删用 `向量`，见第 4 章）；下标越界运行时抛异常。

**元组**（`(T1, T2, ...)`）：把不同类型打包成一个，函数多返回值的底层就是元组：

```cangjie
主函数() {
    让 学生 = (1, "小明", 真)
    打印行(学生[0])            // 1（元组用 [下标] 访问，不是 .字段）
    让 (编号, 名字, 在籍) = 学生   // 解构：一次拆包
    打印行(名字)               // 小明
}
```

- **注意**：`(1)` 是普通数字不是元组——单元素元组要写 `(1,)`；超过 12 个元素考虑建类（见第 5 章）。

## 2.8 范围（Range）

```cangjie
导入 标准集合.*
主函数() {
    对于 (i in 1..5) { 打印行(i) }     // 1 2 3 4（半开区间，不含尾）
    对于 (i in 1..=5) { 打印行(i) }    // 1 2 3 4 5（闭区间）
    打印行((1..10) |> 包含(3))         // 真（区间包含判断，注意区间要加括号）
}
```

- **为什么**：循环、切片、判断归属的通用抽象——「从哪到哪」。半开区间 `a..b` 的长度 = b - a，无歧义。
- **注意**：范围默认升序；`5..1` 是空范围（不报错）；判断归属用柯里化管道 `(1..10) |> 包含(3)`（官方 `(1..10) |> contains(3)`）。

## 2.9 类型推断与标注

- **推断**：局部变量不写类型，编译器从初始值推断（全量推断 + 强静态类型——「写起来像动态语言，查起来像静态语言」）：
  ```cangjie
  主函数() {
      让 分数 = 90              // 推断为 整数
      让 名字 = "小明"          // 推断为 字符串
      让 列表 = [1, 2, 3]       // 推断为 数组<整数>
  }
  ```
- **必须标注的场景**：空容器/空数组（`[]`、`向量<整数>()` 无法推断）、需要特定位宽（`整数32`）、接口类型变量：
  ```cangjie
  导入 标准集合.{向量}
  主函数() {
      让 年龄: 整数32 = 12      // 强制 32 位
      让 空表: 向量<字符串> = 向量<字符串>()
  }
  ```
- **注意**：函数参数**必须**标注类型（不推断——参数是接口契约的一部分，见第 3 章）；标注与推断冲突时以标注为准（`让 x: 浮点 = 1` 合法，字面量自适应为 1.0）。

## 2.10 类型转换：全部显式

仓颉**不做隐式转换**（整数→字符串、浮点→整数都需显式）——隐式转换是 bug 温床（`"1" + 1` 到底是啥？）。显式转换让每个转换点可见、可控、可审：

```cangjie
导入 转换.*
主函数() {
    让 分数 = 95
    打印行(分数.转换字符串())        // "95"（toString）
    让 比例: 浮点 = 浮点(分数)       // 整数 → 浮点（构造器）
    让 整 = 整数(3.9)                // 3（截断小数，向零截断：整数(-3.9) → -3）
    打印行(整)
    打印行(整数.解析("12"))         // 12（解析返回 整数；输入非法会抛异常——先判断再解析更安全，见第 6 章）
}
```

- **数字族互转**用构造器：`整数(x)`、`浮点(x)`、`整数32(x)`；
- **字符串 ↔ 数字**：`整数.解析("42")`（解析，返回 整数——输入非法会抛异常，想安全解析先判断或捕获，见第 6 章）、`42.格式化("${0}")`（format 成员方法，需 `导入 转换.*`）；
- `作为`（as）只用于**类型层次**转换（第 5 章），不能用于数字。

## 2.11 官方对照

```cangjie
// 官方仓颉：同样的代码
main() {
    let age: Int64 = 18
    let name: String = "小明"
    var count = 0
    count += 1
    let tuple = (1, "小明", true)
    let (id, n, ok) = tuple
    println("${name} ${age} 岁")
}
```

## ✳ 本章的设计思想

1. **不可变默认（let 优先）**：可变性 = 意外修改 + 并发竞争 + 难以推理。把「不可变」设为默认，`可变` 变成需要申请的特权——读代码时扫一眼 `可变` 就知道哪里可能变化。
2. **强类型 + 全量推断**：兼得两派优点——动态语言的书写体验（少写标注）+ 静态语言的安全性（编译期全查）。原则：**可推断处不写，关键处必写**（参数、边界、契约）。
3. **消灭隐式转换**：隐式转换让「类型」失去意义（编译器不知道、读者不知道、运行时才知道）。显式转换是「把错误挡在编译期」哲学的落地。
4. **值类型与引用类型分工**（第 5 章展开）：值类型拷贝语义（可预测、线程安全），引用类型共享语义（高效、多态）。类型作者决定语义，而不是调用方。
5. **字面量多态**：`42` 没有固定类型、按上下文取型——「数字就是数字」，位宽是使用场景的事。但**变量**间绝不隐式转换——字面量是「没有过去」的值，变量有。

## 练习

1. 声明 `让` 与 `可变` 各一个，把 `可变` 改成 `让` 后故意修改，读中文诊断；
2. 写一个类型不匹配赋值（`让 x: 整数 = "文本"`），看教学提示与修复示例；
3. 用 `常量` 声明圆周率计算圆面积；用后缀写 `整数32`/`无符号整数`/`浮点32` 各一；
4. 用 `字符流()` 遍历你的名字并逐字打印；试试 `"你好"[0]` 看输出什么字节、`"你好"[0..2]` 会怎样；
5. 用元组 + 解构返回一个学生的（编号、名字、成绩）并打印。

## 小结

- 三种绑定：`让`（默认，不可变）/ `可变`（申请来的特权）/ `常量`（编译期）；
- 类型体系：整数族/浮点族/字符串/布尔/字符/单元/空类型；后缀小写（i64/u64/f32/u8）；
- 字符串按**字节**计长与切片——按字符用 `字符流()`；数组定长、元组打包、范围半开；
- 推断可省标注，但空容器/特定位宽/参数必须标注；转换全部显式（构造器/解析/格式化）。
