# 01 入门：第一个方言程序

目标：安装 zhc，写出并运行第一个母语程序。

## 1.1 安装

zhc 是仓颉的**转译代理**：方言代码先转译为官方仓颉，再交给 `cjc` 编译运行。
安装方式（任选其一）：

- 离线发布包：解压后把 `bin/zhc` 放入 PATH（无网络教学环境推荐）；
- 源码构建：`cd zhc && cjpm build`，可执行文件在 `target/release/bin/`；
- 校验：`zhc --help` 能看到所有子命令即成功。

## 1.2 第一个程序

新建 `hello.zc`：

```cangjie
// hello.zc —— 第一个方言程序
主函数() {
    打印行("你好，仓颉！")
}
```

运行：

```bash
zhc run hello.zc
```

输出：

```
你好，仓颉！
```

## 1.3 逐行讲解

| 方言 | 官方仓颉 | 说明 |
|---|---|---|
| `主函数()` | `main()` | 程序入口，**不带**「函数」前缀（官方 `main` 也不带 `func`） |
| `打印行(...)` | `println(...)` | 打印并换行；`打印` = `print` 不换行 |
| `//` | `//` | 行注释，内容不转译 |

zhc 的转译是**词法级**的：注释、字符串字面量里的中文关键字绝不误改。
试试故意在字符串里写关键字：

```cangjie
主函数() {
    打印行("函数 让 可变 打印行 —— 这些只是文本")
}
```

输出原样，不会报错。

## 1.4 字符串插值：${}

仓颉用 `${表达式}` 做字符串插值（这是仓颉独有能力），方言原样支持，
且插值段内的母语别名会被继续转译：

```cangjie
主函数() {
    让 问候 = "你好"
    打印行("${问候}，世界！")
}
```

输出：`你好，世界！`

## 1.5 官方对照

```cangjie
// 官方仓颉
main() {
    println("你好，仓颉！")
}
```

## 练习

1. 修改 1.2 的程序打印你的名字；
2. 用 `打印`（不换行）连续输出两段文字，观察与 `打印行` 的区别；
3. 在字符串里写满关键字运行，确认不被误改。

## 小结

- 入口是 `主函数()`，输出是 `打印行()`；
- `${}` 插值在方言中直接可用；
- 字符串与注释中的关键字受保护。
