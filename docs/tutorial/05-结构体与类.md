# 05 结构体与类

目标：用 `结构体` 组织数据，用 `类` 实现面向对象，理解仓颉的开放/重写规则。

## 5.1 结构体（struct）：值类型

```cangjie
结构体 点 {
    公开 可变 x: 整数
    公开 可变 y: 整数

    初始化(x: 整数, y: 整数) {
        本对象.x = x
        本对象.y = y
    }

    公开 函数 距离原点的平方(): 整数 {
        返回 本对象.x * 本对象.x + 本对象.y * 本对象.y
    }
}

主函数() {
    让 原点 = 点(3, 4)
    打印行("点坐标：(${原点.x}, ${原点.y})")
    打印行("距离平方：${原点.距离原点的平方()}")   // 25
}
```

要点：

- `结构体` = `struct`；成员用 `公开`/`私有` 限定可见性；
- `初始化` = `init`（结构体的构造）；
- `本对象` = `this`；
- 结构体是**值语义**：赋值即拷贝。

## 5.2 类（class）：引用类型

```cangjie
开放 类 动物 {
    公开 可变 名字: 字符串

    初始化(名字: 字符串) {
        本对象.名字 = 名字
    }

    公开 开放 函数 叫声(): 字符串 {  // 可被重写的方法须加 开放
        返回 "..."
    }
}

类 狗 <: 动物 {
    初始化(名字: 字符串) {
        超类(名字)                     // 调用父类构造函数
    }

    公开 重写 函数 叫声(): 字符串 {
        返回 "汪汪"
    }
}

主函数() {
    让 宠物: 动物 = 狗("旺财")
    打印行("${宠物.名字} 说：${宠物.叫声()}")
}
```

要点：

- 继承用 `<:`（左尖括号加冒号）；`开放` = `open`（可被继承的类与方法才加 `开放`，这是仓颉的显式设计）；
- 子类构造函数第一句 `超类(...)` 调用父类构造（父类无无参构造时**必须**显式调用）；
- `重写` = `override`——重写方法时若父类方法未标 `开放` 会编译报错。

## 5.3 接口（interface）

```cangjie
接口 会飞 {
    函数 飞行速度(): 整数
}

结构体 鸟 <: 会飞 {
    公开 函数 飞行速度(): 整数 {
        返回 60
    }
}

主函数() {
    让 飞鸟: 会飞 = 鸟()
    打印行("飞行速度：${飞鸟.飞行速度()} km/h")
}
```

要点：

- 接口成员隐含 `公开`，无需重复标注；
- 用 `<:` 实现接口（结构与类一致）。

## 5.4 属性（prop）与扩展（extend）

属性把字段包装为读写接口（可写属性需 `修改` = mut，访问器 `获取`/`设置` 是上下文词）：

```cangjie
结构体 温度计 {
    公开 可变 摄氏度: 浮点

    初始化(摄氏度: 浮点) {
        本对象.摄氏度 = 摄氏度
    }

    公开 修改 属性 华氏度: 浮点 {
        获取() { 返回 本对象.摄氏度 * 9.0 / 5.0 + 32.0 }
        设置(值) { 本对象.摄氏度 = (值 - 32.0) * 5.0 / 9.0 }
    }
}

主函数() {
    可变 计 = 温度计(25.0)
    打印行("25℃ = ${计.华氏度}℉")
    计.华氏度 = 100.0
    打印行("100℉ = ${计.摄氏度}℃")
}
```

`扩展` 给已有类型追加方法：

```cangjie
扩展 整数 {
    公开 函数 加倍(): 整数 {
        返回 本对象 * 2
    }
}

主函数() {
    打印行(21.加倍())   // 42
}
```

## 5.5 官方对照

```cangjie
// 官方仓颉
open class Animal {
    public var name: String
    public init(name: String) {
        this.name = name
    }
    open func speak(): String { return "..." }
}
class Dog <: Animal {
    public init(name: String) {
        super(name)
    }
    override func speak(): String { return "汪汪" }
}
```

## 小结

- `结构体` 值语义、`类` 引用语义；`初始化` 构造，`本对象` 指自身、`超类(...)` 调父类构造；
- 继承与接口实现用 `<:`；继承/重写需父类 `开放`、方法 `重写` 显式标注；
- `属性` 用 `获取()`/`设置(值)` 访问器；`扩展` 追加方法。
