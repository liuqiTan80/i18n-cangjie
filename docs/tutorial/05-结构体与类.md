# 05 结构体与类

> 本章目标：掌握仓颉组织数据的两种方式——`结构体`（值语义）与 `类`（引用语义），理解开放/重写/接口/多态的显式设计，学会用属性、枚举、类型测试写出安全的面向对象代码。
> 读完本章你能回答：结构体和类有什么区别？为什么仓颉的类默认不能继承？`重写` 忘写会发生什么？

## 5.1 结构体（结构体 / struct）：值类型

**是什么**：把一组数据打包成值类型。**赋值/传参是整体拷贝**，不是共享引用——改副本不影响原件：

```cangjie
结构体 点 {
    公开 可变 x: 整数
    公开 可变 y: 整数

    初始化(x: 整数, y: 整数) {
        本对象.x = x
        本对象.y = y
    }

    公开 函数 距离平方(): 整数 {
        返回 本对象.x * 本对象.x + 本对象.y * 本对象.y
    }
}

主函数() {
    让 原点 = 点(3, 4)
    打印行("点坐标：(${原点.x}, ${原点.y})")
    打印行("距离平方：${原点.距离平方()}")   // 25

    可变 拷贝 = 原点                        // 值语义：整体拷贝
    拷贝.x = 100                            // 只改拷贝
    打印行("${原点.x} ${拷贝.x}")           // 3 100（原点不受影响）
}
```

- `结构体` = `struct`；`初始化` = `init`（构造器）；`本对象` = `this`；
- 成员默认**私有**，对外可见要标 `公开`；
- 结构体**不能继承**、不能有抽象成员——它是「小数据 + 无多态」场景的默认选择（坐标、颜色、金额）。

## 5.2 类（类 / class）：引用类型

**是什么**：把状态（字段）与行为（方法）绑定在一起的**引用类型**。多个变量指向**同一对象**，改一处处处可见——适合「同一份数据多方使用」的现实对象：

```cangjie
类 学生 {
    公开 可变 名字: 字符串
    公开 可变 分数: 整数

    初始化(名字: 字符串, 分数: 整数) {
        本对象.名字 = 名字
        本对象.分数 = 分数
    }

    公开 函数 评级(): 字符串 {
        如果 (本对象.分数 >= 90) { 返回 "优秀" }
        返回 "加油"
    }
}

主函数() {
    让 小明 = 学生("小明", 95)
    打印行("${小明.名字}：${小明.评级()}")    // 小明：优秀
}
```

**注意**：字段默认私有（类外不可见）；类默认**不可继承**（要 `开放`，见 5.3）——这两条都是仓颉的显式安全设计。

## 5.3 开放与重写：默认封闭的继承

**为什么默认封闭**：继承会打破封装（子类依赖父类内部细节），所以仓颉把继承做成**需要显式申请的特权**——`开放` 就是「我允许别人扩展我」的声明：

```cangjie
开放 类 动物 {
    公开 开放 函数 叫声(): 字符串 { 返回 "……" }
}

类 狗 <: 动物 {
    公开 重写 函数 叫声(): 字符串 { 返回 "汪汪" }
}

主函数() {
    让 旺财: 动物 = 狗()       // 父类类型装子类对象
    打印行(旺财.叫声())        // 汪汪（动态分派：运行时决定用哪个实现）
}
```

三条硬规则（官方 1.0.5 实测）：

| 规则 | 后果 |
|---|---|
| 非 `开放` 类被继承 | 编译错误「非开放类型不能被继承」 |
| 父类方法没标 `开放` 却重写 | 编译错误（不能重写） |
| 重写时不写 `重写` 关键字 | 编译错误——`重写` 是**强制声明**，防止「想重写却拼错名字变成新方法」的经典 bug |

重写方法签名必须与父类**一致**；重写时用 `超类.方法名()` 调用父类版本（见 5.4）。

## 5.4 继承与超类（<: 与 超类 / super）

**是什么**：「狗是动物」的 is-a 关系用 `类 狗 <: 动物` 表达（`<:` 读作「子类型于」）。子类继承父类的一切，并可用 `超类(...)` 调父类构造器、`超类.方法()` 复用父类逻辑：

```cangjie
开放 类 动物 {
    公开 可变 名字: 字符串
    初始化(名字: 字符串) { 本对象.名字 = 名字 }
    公开 开放 函数 介绍(): 字符串 { 返回 "我是${本对象.名字}" }
}

类 狗 <: 动物 {
    初始化(名字: 字符串) {
        超类(名字)              // 第一句：调用父类构造器
    }
    公开 重写 函数 介绍(): 字符串 {
        返回 "${超类.介绍()}，一只狗"    // 复用父类逻辑再扩展
    }
}

主函数() {
    打印行(狗("旺财").介绍())   // 我是旺财，一只狗
}
```

**注意**：

- 仓颉**单继承**（一个类只能有一个父类）；
- 子类构造器**必须先调 `超类(...)`** 再初始化自己的字段；父类没有无参构造器时必须显式调用（官方写法 `超类.\`init\`(名字)`，方言 `超类(名字)` 即可）；
- 字段与构造参数同名时**必须**用 `本对象.` 区分——否则 `名字 = 名字` 是自己赋自己，字段未初始化，编译器报错。

## 5.5 接口（接口 / interface）：能力清单

**是什么**：只声明方法签名（可带默认实现）、不含状态的**纯行为契约**。类只能单继承，但可以实现**多个接口**——接口是「能力清单」：

```cangjie
接口 会叫 {
    函数 叫声(): 字符串
}

类 狗 <: 会叫 {
    公开 函数 叫声(): 字符串 { 返回 "汪汪" }
}

类 猫 <: 会叫 {
    公开 函数 叫声(): 字符串 { 返回 "喵" }
}

主函数() {
    让 宠物: 会叫 = 狗()
    让 猫咪: 会叫 = 猫()
    打印行(宠物.叫声() + 猫咪.叫声())   // 汪汪喵
}
```

- 接口方法默认**公开**，无需重复标注；`<:` 同时用于继承与实现接口；
- 实现接口的类**必须实现所有无默认方法**（漏一个编译报错）；
- 接口变量只能调用接口声明的方法（看不见实现类特有的方法）。

## 5.6 抽象与静态

**抽象类**：标记「未完成品」——`形状` 没有具体的面积公式，只有子类（圆/方）才知道。抽象类**不能实例化**，只用来被继承；抽象方法没有函数体，强制子类实现：

```cangjie
抽象 类 形状 {
    公开 函数 面积(): 浮点        // 抽象方法：不写函数体即可
}

类 正方形 <: 形状 {
    公开 可变 边长: 浮点
    初始化(边长: 浮点) { 本对象.边长 = 边长 }
    公开 重写 函数 面积(): 浮点 { 返回 本对象.边长 * 本对象.边长 }
}

主函数() {
    打印行(正方形(3.0).面积())    // 9.0
}
```

> 抽象类**自动开放**（抽象就是允许继承的声明）；子类不实现全部抽象方法就必须也标 `抽象`。

**静态成员**：属于**类本身**（而非实例）——工厂方法、工具函数、全局共享计数器：

```cangjie
类 工具 {
    静态 函数 两倍(数: 整数): 整数 { 返回 数 * 2 }
    静态 可变 调用次数: 整数 = 0
}

主函数() {
    工具.调用次数 += 1
    打印行(工具.两倍(21))        // 42
}
```

**注意**：静态方法**不能访问实例字段/`本对象`**（没有对象上下文）；静态可变成员是全局状态（并发要加同步）；子类「换掉」父类静态成员用 `重定义`（redef，只能修饰静态成员——实例方法的重写走 `重写`）。

## 5.7 属性与访问器：封装的平衡点

**属性（prop）**：外部像字段一样读写、内部由 `获取()` 控制的成员——「数据可见但不可篡改」是最常见需求：

```cangjie
类 书 {
    私有 可变 书名值: 字符串 = ""
    公开 属性 书名: 字符串 {
        获取() { 返回 本对象.书名值 }
    }
    初始化(书名: 字符串) { 本对象.书名值 = 书名 }
}

主函数() {
    让 书 = 书("仓颉字典")
    打印行(书.书名)              // 仓颉字典
    // 书.书名 = "别的"  ← 编译错误：prop 只读，不能赋值
}
```

**可变属性（mut prop）**：可读可写，`获取()` 与 `设置(值)` 成对出现——写逻辑时加校验/缓存/通知，调用方无感：

```cangjie
类 温度计 {
    私有 可变 摄氏值: 浮点 = 0.0
    公开 修改 属性 摄氏: 浮点 {
        获取() { 返回 本对象.摄氏值 }
        设置(值) { 本对象.摄氏值 = 值 }    // 参数是赋入的新值
    }
}

主函数() {
    让 计 = 温度计()
    计.摄氏 = 36.5               // 走 设置
    打印行(计.摄氏)              // 36.5（走 获取）
}
```

**注意**：`属性`（prop）**只读**——只能定义 `获取()`；`可变 属性`（mut prop）必须同时提供 `获取()` 和 `设置(参数)`；`获取()` 的括号**不能省略**（官方 1.0.5 语法）；访问器在类内部，可以访问私有字段。

## 5.8 修改（mut）：结构体可变成员函数

**是什么**：结构体是值类型，`让` 绑定又不可变——若成员函数能悄悄改写字段，拷贝出的副本会「偷偷变化」。`修改` 把「这个函数会改变自身」变成**可见的许可**：

```cangjie
结构体 计数器 {
    公开 可变 值: 整数
    初始化(值: 整数) { 本对象.值 = 值 }
    公开 修改 函数 自增() {
        本对象.值 += 1           // mut 函数才能修改结构体自身
    }
}

主函数() {
    可变 数 = 计数器(1)
    数.自增()
    打印行(数.值)               // 2
}
```

**三条硬规则（官方 1.0.5 实测）**：

| 规则 | 后果 |
|---|---|
| `让` 绑定的实例上调 mut 函数 | 编译错误（`让` 不可变，需 `可变`） |
| mut 修饰 class 的方法 | 编译错误（类的方法天然能改字段，禁止加 mut） |
| mut 修饰参数/成员变量/静态函数 | 编译错误（mut **只能**修饰结构体/接口的实例成员函数） |

## 5.9 枚举（枚举 / enum）：有限取值集合

**是什么**：比「魔法数字」安全得多的取值集合——编译器穷尽性检查保证所有取值都被处理；枚举还能**携带数据**（标签联合），是「多种形态的数据」的经典建模：

```cangjie
枚举 方向 { 上 | 下 | 左 | 右 }

枚举 通知 {
    文本(字符串) | 数字(整数) | 结束
}

主函数() {
    让 朝向 = 方向.上
    匹配 (朝向) {
        情况 方向.上 => 打印行("向上")
        情况 _ => 打印行("其他方向")
    }

    让 内容 = 通知.文本("你好")
    匹配 (内容) {
        情况 通知.文本(文字) => 打印行("文本：${文字}")
        情况 通知.数字(数) => 打印行("数字：${数}")
        情况 通知.结束 => 打印行("结束")
    }
}
```

**注意**：取值用 `枚举名.成员`（`方向.上`）；带数据成员像构造器（`通知.文本("你好")`）；匹配枚举时**强制全分支**（除非有 `_` 兜底）——漏分支编译报错，这是枚举的核心价值。

## 5.10 类型测试与转换（是 / 作为）

多态世界的「身份确认」：拿到 `动物` 变量，想知道它到底是不是 `狗`：

```cangjie
开放 类 动物 {}

类 狗 <: 动物 {
    公开 函数 摇尾巴(): 字符串 { 返回 "摇尾巴" }
}

类 猫 <: 动物 {}

主函数() {
    让 宠物: 动物 = 狗()            // 向上转换（子→父）：自动、永远安全
    如果 (宠物 是 狗) {             // 是 = is：类型测试，返回布尔
        打印行("是狗")
    }
    打印行(宠物 是 猫)               // false（运行时输出官方格式）

    让 旺财 = (宠物 作为 狗).获取或抛出()   // 向下转换（父→子）：必须 作为
    打印行(旺财.摇尾巴())
}
```

**注意**：向下转换可能失败（动物不一定是狗）——官方 1.0.5 的 `作为`（as）返回 **`选项<T>`**（失败是 `无值`），用 `.获取或抛出()` 解包或 `匹配` 处理；更稳妥的写法是先 `是` 判断再 `作为`；**数字转换与类型层次转换是两回事**（`整数(3.9)` 是数值转换，见第 2 章）。

## 5.11 多态与动态绑定

**是什么**：接口/父类类型变量可以装任意实现/子类对象，调用方法时**运行时**决定执行哪个版本——面向接口编程：代码依赖「抽象」而不是「具体」，新增猫/鸟时**调用方代码一行不改**：

```cangjie
接口 会叫 {
    函数 叫声(): 字符串
}

类 狗 <: 会叫 {
    公开 函数 叫声(): 字符串 { 返回 "汪汪" }
}

类 猫 <: 会叫 {
    公开 函数 叫声(): 字符串 { 返回 "喵" }
}

函数 齐声叫(宠物们: 数组<会叫>) {
    对于 (宠物 in 宠物们) {
        打印行(宠物.叫声())        // 动态绑定：各自叫各自的
    }
}

主函数() {
    齐声叫([狗(), 猫()])
}
```

**注意**：多态只对**引用类型**（类/接口）有效——结构体是值类型，没有动态绑定；`开放` + `重写` + 接口实现共同构成多态三件套。

## 5.12 官方对照

```cangjie
// 官方仓颉
open class Animal {
    public var name: String
    public init(name: String) {
        this.name = name
    }
    open func speak(): String { return "..." }
}

class Dog <: Animal {
    public init(name: String) {
        super(name)
    }
    override func speak(): String { return "汪汪" }
}

interface Speaker {
    func speak(): String
}

struct Point {
    public var x: Int64
    public var y: Int64
    public init(x: Int64, y: Int64) { this.x = x; this.y = y }
}
```

方言与官方一一对应：`结构体`→struct、`类`→class、`初始化`→init、`本对象`→this、`超类`→super、`开放`→open、`重写`→override、`接口`→interface、`属性`→prop、`修改`→mut、`枚举`→enum、`是`→is、`作为`→as。

## ✳ 设计思想

**① 值语义 vs 引用语义：先想清「数据怎么被共享」**。结构体赋值即拷贝——适合「小、独立、要安全」的数据（坐标、颜色）；类实例引用共享——适合「同一份数据多方使用」的对象（学生档案、银行账户）。**经验法则：数据小且独立用结构体，需要多态/共享用类。**

**② 默认封闭：安全设计让「继承」变昂贵而显式**。继承会打破封装——子类与父类内部耦合。仓颉要求 `开放` 才可继承、`重写` 才可覆盖，把「扩展点」变成类作者的显式决策：写类时想清楚哪些部分是留给后人扩展的，其余默认封死。

**③ 封装的三个层次**：`公开 可变`（全开放）→ `属性`/`可变 属性`（数据可见但读写受控）→ `私有`（完全隐藏）。从裸字段到访问器是渐进增强——先用最简的，需要校验/缓存再升级成属性，调用方代码不用改。

**④ 组合优于继承**：结构体可以嵌套在类里（`类 车 { 公开 可变 引擎: 引擎结构体 }`）。能用组合表达的「has-a」关系不要硬造继承——继承适合「is-a」且确有多态需求时。

**⑤ 面向接口编程**：`齐声叫` 只依赖 `会叫`，不知道也不关心具体是狗还是猫。把「变化的部分」抽象成接口，是软件可扩展性的核心手段（依赖倒置原则的雏形，详见第 11 章）。

**⑥ 显式优于隐式**：`重写` 强制声明防止拼错名字、`修改` 可见许可防止副本悄悄变化、`作为` 显式转换防止类型错配——仓颉把「可能出错的地方」都变成显式的编译期检查，代价是多敲几个词，收益是少一类 bug。

## 练习

1. 定义 `结构体 矩形`（宽/高 + `面积()` 方法），验证赋值拷贝互不影响；
2. 定义 `类 学生`（名字/成绩 + `评级()`），用 `向量` 保存 3 个学生，遍历打印平均分（提示：`求和` 见第 4 章）；
3. 给 `字符串` 写一个 `扩展`（如「倒序」），验证扩展语法；
4. 定义 `接口 会移动`（`移动(距离: 整数)`），让 `类 汽车` 和 `类 自行车` 实现它，写一个接受接口数组并让全部移动的函数；
5. 思考：为什么 `让 数 = 计数器(1); 数.自增()` 会编译报错？`可变 数` 后为什么就好了？

## 小结

- `结构体` 值语义（赋值即拷贝）、`类` 引用语义（赋值共享）；字段默认私有；
- 继承/接口实现用 `<:`；继承与重写需父类 `开放` + 子类 `重写` 双显式标注；
- `超类(...)` 调父类构造器（必须第一句）、`超类.方法()` 复用父类逻辑；单继承、可多实现接口；
- `属性` 只读、`可变 属性` 可读写（`获取()`/`设置(值)` 成对）；`修改`（mut）只修饰结构体/接口的实例成员函数；
- `枚举` 可带数据、匹配强制穷尽；`是` 测试类型、`作为` 向下转换（返回 `选项`）；
- 多态 = 接口/父类变量 + 运行时动态绑定，只对引用类型有效。
