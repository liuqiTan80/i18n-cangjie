# 仓颉方言（zhc）教程

> 一部**字典级**的仓颉方言教程：细而全——每个知识点都写到「是什么 / 为什么 / 怎么用 / 注意」四段，每步操作都给出**可照做的命令与验证方法**（比如第 1 章的源码构建，新手能对着一步步把项目构建出来）。
> **全部代码示例用母语（中文）书写**，可直接复制运行：`zhc run 章节文件`（单文件）或先 `zhc init` 建项目再 `zhc run`。

## 学习建议

1. **边读边跑**：每章示例都保存为 `.zc` 文件并 `zhc run`，看输出再继续——教程里的代码块都是**实测通过**的完整程序，可直接运行；
2. **照做每一步**：第 1 章的环境搭建按步骤执行，每步都有「验证方法」（期望输出），任何一步对不上就去排查表找答案；
3. **故意犯错**：zhc 的诊断会把官方错误翻译成中文并附教学提示（💡）与可粘贴修复示例——错误是最好的老师（见第 9 章）；
4. **对照官方**：每章「官方对照」小节展示同一代码的仓颉写法，用于理解方言的映射关系；
5. **先学语法，再学思想**：01-09 章是「怎么用」，10 章讲「为什么这么设计」，11 章讲「怎么把代码做成软件」；
6. **进阶工具**：学完 08 章后用 `zhc expand` 查看宏展开教学视图，用 `zhc mapping check` 验证语言包一致性。

## 方言速查

```cangjie
主函数() {
    让 名字: 字符串 = "仓颉"
    可变 次数 = 3
    如果 (次数 > 1) {
        打印行("你好，${名字}！")
    } 否则 {
        打印行("再见")
    }
}
```
