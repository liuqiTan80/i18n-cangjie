# zhc 仓颉方言 — 教学教程

按章节递进学习仓颉方言编程。**全部代码示例用母语（中文）书写**，可直接复制运行：
`zhc run 章节文件`（单文件）或先 `zhc init` 建项目再 `zhc run`。

## 学习建议

1. **边读边跑**：每章示例都保存为 `.zc` 文件并 `zhc run`，看输出再继续；
2. **故意犯错**：zhc 的诊断会把官方错误翻译成中文并附教学提示（💡）与可粘贴修复示例——错误是最好的老师；
3. **对照官方**：每章「官方对照」小节展示同一代码的仓颉写法，用于理解方言的映射关系；
4. **进阶工具**：学完 08 章后用 `zhc expand` 查看宏展开教学视图，用 `zhc mapping check` 验证语言包一致性。

## 方言速查

```cangjie
主函数() {
    让 名字: 字符串 = "仓颉"
    可变 次数 = 3
    如果 (次数 > 1) {
        打印行("你好，${名字}！")
    } 否则 {
        打印行("再见")
    }
}
```
