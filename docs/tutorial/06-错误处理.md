# 06 错误处理

目标：掌握 `选项`（Option）空安全模式与 `尝试`/`捕获` 异常机制，理解**空安全**教学主题。

## 6.1 选项（Option）：可能没有值

仓颉用 `选项<T>`（Option）表达「可能有值，也可能没有」。这是空安全的核心：

```cangjie
函数 找名字(编号: 整数): 选项<字符串> {
    如果 (编号 == 1) {
        返回 有值("小明")        // Some = 有值
    }
    返回 无值                   // None = 无值
}

主函数() {
    让 第一个 = 找名字(1)
    让 第二个 = 找名字(2)
    打印行(第一个.getOrThrow())        // 小明（确定有值时取出）
    打印行(第二个.getOrThrow("默认"))  // 无值时给默认
}
```

要点：

- `选项<字符串>` = `Option<String>`；`有值(v)` = `Some(v)` 包装值，`无值` = `None`；
- `.getOrThrow()` 取出值（无值会抛异常）；`.getOrThrow("默认")` 无值返回默认；
- 语言包「空安全」教学提示：对可能为空的返回值**先判断再取值**。

用 `匹配` 安全地分支处理：

```cangjie
函数 找名字(编号: 整数): 选项<字符串> {
    如果 (编号 == 1) { 返回 有值("小明") }
    返回 无值
}

主函数() {
    匹配 (找名字(2)) {
        情况 有值(名字) => 打印行("找到了：${名字}")
        情况 无值 => 打印行("没有这个人")
    }
}
```

## 6.2 异常：尝试 / 捕获 / 抛出 / 最终

```cangjie
函数 除以(被除数: 整数, 除数: 整数): 整数 {
    如果 (除数 == 0) {
        抛出 异常("除数不能为零")
    }
    返回 被除数 / 除数
}

主函数() {
    尝试 {
        让 结果 = 除以(10, 0)
        打印行("结果：${结果}")
    } 捕获 (错误: 异常) {
        打印行("捕获到异常：${错误.message}")
    } 最终 {
        打印行("无论成败都会执行")
    }
}
```

要点：

- `抛出` = `throw`、`尝试` = `try`、`捕获` = `catch`、`最终` = `finally`；
- `异常` 是官方类型 `Exception`（未映射时保持官方名）；
- 空安全提示：能被 0 整除、下标越界等场景优先用 `选项` 或提前判断，异常留给真正「意外」的情况。

## 6.3 断言与前置检查

```cangjie
函数 设置年龄(年龄: 整数): 整数 {
    如果 (年龄 < 0 || 年龄 > 150) {
        抛出 异常("年龄不合法：${年龄}")
    }
    返回 年龄
}

主函数() {
    打印行(设置年龄(30))
    // 打印行(设置年龄(-5))   // 会抛出异常
}
```

## 6.4 官方对照

```cangjie
// 官方仓颉
func findName(id: Int64): Option<String> {
    if (id == 1) {
        return Some("小明")
    }
    return None
}

main() {
    match (findName(2)) {
        case Some(name) => println("找到了：${name}")
        case None => println("没有这个人")
    }
}
```

## 练习

1. 用 `选项` 实现「按索引取数组元素」：越界返回 `无值` 而不是抛异常；
2. 用 `尝试`/`捕获` 包住一次整数除法，除零时打印友好提示；
3. 写一个解析整数的函数：非法输入返回 `无值`。

## 小结

- `选项<T>` + `有值`/`无值` 表达可空值，`匹配` 分支处理或 `.getOrThrow()` 取值；
- `尝试`/`捕获`/`最终`/`抛出` 处理异常；`异常` 类型直接使用官方名；
- 空安全是仓颉教学三主题之一，诊断会在可空值误用时给出中文提示。
