# 04 字符串与集合

> 本章目标：熟练使用字符串插值与字符串方法群，掌握向量（ArrayList）、哈希映射（HashMap）、哈希集合（HashSet）三种容器，学会用 `映射`/`过滤`/`求和`/`排序` 等高阶函数做声明式数据处理。
> 读完本章你能回答：字符串长度为什么和字数不一样？取不存在的键会发生什么？`映射` 为什么不立刻出结果？

## 4.1 字符串插值：${}

字符串里用 `${表达式}` 嵌入**变量或表达式**，这是仓颉拼字符串的主要方式：

```cangjie
主函数() {
    让 名字 = "仓颉"
    让 版本 = 1
    打印行("${名字} 语言，版本 ${版本}.0")   // 仓颉 语言，版本 1.0
    打印行("四则：${3 + 4 * 2}")             // 四则：11（里面可以是任意表达式）
    打印行("嵌套：${名字.长度}")             // 嵌套：6（方法调用也支持）
}
```

- **插值段内会二次转译**：方言词（`长度`、`大小` 等）在 `${}` 里同样被翻译成官方名。
- **注意（易错）**：插值里**只放变量和表达式**，别放关键字。`"${函数}"` 会被转译成 `"${func}"` 而编译报错——插值不是给你写语句的。
- **注意**：插值会调用值的字符串化；运行时输出保持官方格式（如 `真` 变量会输出 `true`，见第 2 章）。

字符串拼接用 `+`（只适合少量拼接；批量拼接见 4.9）：

```cangjie
主函数() {
    让 欢迎 = "你好，" + "世界"
    打印行(欢迎)            // 你好，世界
}
```

## 4.2 字符串方法群：查询 / 裁剪 / 变换 / 拆分

字符串处理是最高频的编程场景。方言把常用方法全部母语化，覆盖四大类：

```cangjie
导入 正则.*
主函数() {
    让 文本 = "  仓颉 编程 语言  "
    // ① 查询
    打印行(文本.长度)                     // 24（字节数！UTF-8 下每个汉字 3 字节）
    打印行(文本.查找("编程"))             // 8（字节下标；找不到返回 -1）
    打印行(文本.以开头("  仓颉"))         // true（运行时输出官方格式）
    打印行(文本.以结尾("语言  "))         // true
    // ② 裁剪（字符串切片按字节——1 个汉字要切 3 字节）
    打印行("仓颉编程"[0..3])              // 仓（前 3 字节 = 1 个汉字）
    打印行("(${文本.修剪()})")            // (仓颉 编程 语言)（去首尾空白）
    // ③ 变换
    打印行("abc".大写())                  // ABC
    打印行("ABC".小写())                  // abc
    打印行("甲-乙".替换("-", "→"))        // 甲→乙
    // ④ 拆分
    让 部分 = 文本.修剪().分割(" ")
    打印行(部分.长度)                     // 3（分割返回数组）
    // ⑤ 判断（正则匹配：正则(模式).匹配正则(文本)）
    打印行(正则("\\d+").匹配正则("123"))  // true
}
```

需要记住的四条真相：

| 真相 | 说明 |
|---|---|
| **长度是字节数** | `"仓颉".长度` 是 6 不是 2；按字符数遍历用 `"仓颉".字符流()`（见第 3 章） |
| **切片按字节** | `文本[0..3]` 切 1 个汉字；切错字节边界会得到乱码 |
| **大小写是纯 ASCII** | `大写()`/`小写()` 只转换英文字母，中文没有大小写概念 |
| **正则用 `匹配正则`** | = 官方 `matches`，返回布尔；`正则("\\d+")` 里的 `\\` 是转义后的 `\` |

## 4.3 导入（import）语句

`导入` = `import`，路径用 `.` 分隔。两种写法：

```cangjie
导入 标准集合.{向量, 哈希映射};    // 精确导入：只引入花括号里的名字
导入 标准集合.*                     // 通配导入：引入该模块全部名字
```

- `标准集合` = `std.collection`（语言包「模块路径」节）；花括号里的母语名逐个被替换；
- 结尾分号可省可留（与官方一致）；
- 本章常用模块路径：

| 方言路径 | 官方路径 | 里面有什么 |
|---|---|---|
| `标准集合` | `std.collection` | 向量/哈希映射/哈希集合 + 高阶函数工厂 |
| `正则` | `std.regex` | `正则` 类型与 `匹配正则` |
| `排序` | `std.sort` | `排序` 顶层函数 |
| `转换` | `std.convert` | `格式化` 等转换工具 |

> **什么时候用通配**：高阶函数（`映射`/`过滤`/`求和`/`收集数组`）是一组柯里化工厂，逐个精确导入写起来长，本章 4.7-4.9 统一用 `导入 标准集合.*`。

## 4.4 向量（向量 / ArrayList）：动态列表

**是什么**：可动态增删的列表。数组定长（见第 2 章），不知道会加多少元素时用向量——它是「动态列表」的默认选择。

**怎么用**：

```cangjie
导入 标准集合.{向量}
主函数() {
    可变 成绩单 = 向量<整数>()
    成绩单.添加(95)               // 追加 = add
    成绩单.添加(88)
    成绩单.添加(76)
    打印行(成绩单.大小)           // 3（大小 是属性，不带括号）
    打印行(成绩单[0])             // 95（下标访问）
    成绩单.删除(1..2)             // 删除只收区间：删下标 1（88）
    打印行(成绩单.大小)           // 2
    对于 (成绩 in 成绩单) {
        打印行("成绩：${成绩}")   // 遍历
    }
}
```

**注意（易错）**：

- `大小` 是**属性**不是方法（`.大小`，不带括号；但 `.长度` 用在字符串/数组上也是属性）；
- 下标越界**运行时抛异常**（如 `成绩单[9]`）——先看 `大小` 再取；
- **向量 `删除` 只收区间**（官方 remove(Range)）：`删除(1..2)` 删 1 个、`删除(1..3)` 删 2 个；按「值」删除没有现成方法，先找下标再删；
- 数组 ↔ 向量互转：`向量.from(数组)`；
- 官方**没有** `反序`（reversed）方法，倒序用下标倒着取：

```cangjie
导入 标准集合.{向量}
主函数() {
    让 原 = [1, 2, 3]
    可变 倒 = 向量<整数>()
    对于 (i in 0..原.长度) {
        倒.添加(原[原.长度 - 1 - i])   // 从最后一个往前取
    }
    打印行(倒[0])                      // 3（原容器不变）
}
```

## 4.5 哈希映射（哈希映射 / HashMap）：键值对

**是什么**：`键 → 值` 的对应表，按名字查数据（学号→学生、单词→次数）。哈希表平均 O(1) 查询，比遍历列表快得多。

**怎么用**：

```cangjie
导入 标准集合.{哈希映射}
主函数() {
    可变 宠物年龄 = 哈希映射<字符串, 整数>()
    宠物年龄["旺财"] = 3               // 存：映射[键] = 值
    宠物年龄["咪咪"] = 5
    打印行(宠物年龄["旺财"])           // 3（取：映射[键]）
    打印行(宠物年龄.大小)              // 2
    对于 (名字 in 宠物年龄.键()) {      // 键() 取全部键，遍历字典的标配
        打印行("${名字}${宠物年龄[名字]}岁")
    }
}
```

**注意（易错）**：

- **取不存在的键会运行时抛异常**（`宠物年龄["不存在"]` 崩溃）——取之前先 `包含` 判断，或用 `获取或默认` 兜底；
- 键必须可哈希：字符串、整数天然可以；自定义类型要实现 `可哈希`（见第 5 章）；
- **遍历顺序不保证**（哈希无序）：同一映射两次遍历顺序可能不同，别依赖顺序；
- 改值用 `映射[键] = 新值`；删除用 `映射.删除(键)`（按键删，与向量的区间删除不同）；
- `键()` 是方法（带括号）；返回的是**视图**——遍历时不要增删映射。

**综合实战：统计分组**（官方没有 groupBy，用哈希映射手写——「组名 → 计数」是标准套路）：

```cangjie
导入 标准集合.{向量, 哈希映射}
主函数() {
    可变 成绩 = 向量<整数>()
    成绩.添加(95); 成绩.添加(45); 成绩.添加(70)
    可变 分组 = 哈希映射<字符串, 整数>()
    对于 (分 in 成绩) {
        让 组名 = 如果 (分 >= 60) { "及格" } 否则 { "不及格" }
        分组[组名] = 分组.获取(组名).获取或默认({ => 0 }) + 1
    }
    打印行(分组.大小)       // 2
    打印行(分组["及格"])    // 2
}
```

> `获取(键)` 返回 `选项`，`.获取或默认({ => 0 })` 在键不存在时用 0 起步——这是「计数」的标配写法（`选项` 详解见第 6 章）。

## 4.6 哈希集合（哈希集合 / HashSet）：不重复集合

**是什么**：只关心「这个值在不在」的容器，元素**不重复**，`包含` 判断 O(1)。

**怎么用**：

```cangjie
导入 标准集合.{哈希集合}
主函数() {
    可变 已读 = 哈希集合<整数>()
    已读.添加(1)
    已读.添加(1)            // 重复，被忽略
    已读.添加(2)
    打印行(已读.大小)       // 2
    打印行(已读.包含(2))    // true
}
```

**典型应用：去重**（官方没有 distinct 方法，哈希集合天然去重）：

```cangjie
导入 标准集合.{向量, 哈希集合}
主函数() {
    可变 名单 = 向量<整数>()
    名单.添加(1); 名单.添加(2); 名单.添加(1)
    可变 唯一 = 哈希集合<整数>()
    对于 (数 in 名单) { 唯一.添加(数) }   // 重复的 1 被忽略
    打印行(唯一.大小)       // 2
}
```

**注意**：哈希集合**无序**（不保证原顺序）；要「保序去重」就手写循环 + `包含` 判断（`如果 (非 结果.包含(数)) { 结果.添加(数) }`，`非` = `!`）。

## 4.7 高阶函数：映射 / 过滤 / 遍历

三个高频「声明式」操作，方言用管道 `容器 |> 函数` 书写（官方是柯里化工厂）：

| 操作 | 作用 | 返回 |
|---|---|---|
| `映射({ x => ... })` | 每个元素做变换 | 惰性迭代器 |
| `过滤({ x => ... })` | 保留满足条件的元素 | 惰性迭代器 |
| `遍历({ x => ... })` | 对每个元素执行动作（打印等） | 单元 |

```cangjie
导入 标准集合.*
主函数() {
    可变 名单 = 向量<整数>()
    名单.添加(1); 名单.添加(2); 名单.添加(3)
    // 映射：每个元素 ×2
    让 翻倍 = 名单 |> 映射({ x => x * 2 }) |> 收集数组
    打印行(翻倍[0])                // 2
    // 过滤：保留 ≥60 的
    可变 成绩 = 向量<整数>()
    成绩.添加(95); 成绩.添加(45); 成绩.添加(70)
    让 及格 = 成绩 |> 过滤({ x => x >= 60 }) |> 收集数组
    打印行(及格.大小)              // 2
    // 遍历：只做动作不要结果
    可变 名单2 = 向量<字符串>()
    名单2.添加("甲"); 名单2.添加("乙")
    名单2 |> 遍历({ 名字 => 打印行("你好，${名字}") })
}
```

**三条真相**：

- **惰性**：`映射`/`过滤` 返回**迭代器**，此刻还没计算——`|> 收集数组` 消费时才逐个算（省内存，可无限链式组合）；
- **原容器不变**：它们产生新序列，不改动原向量；
- `遍历` 返回单元，与 `对于` 循环等价（纯偏好）；lambda 里**不能用** `跳出`/`继续`（它不是循环）——需要提前结束就用 `对于`。

## 4.8 求和 / 累加 / 排序

**求和（fold）**：从初始值开始逐个累积，是「累积器 + 合并函数」的通用形态：

```cangjie
导入 标准集合.*
主函数() {
    可变 成绩 = 向量<整数>()
    成绩.添加(95); 成绩.添加(85)
    让 总和 = 成绩 |> 求和(0, { 累积, 分 => 累积 + 分 })
    打印行(总和)                   // 180（初始值 0 决定返回类型）
}
```

**累加（reduce）**：没有初始值，用第一个元素起步——**返回 `选项`**（空容器没有结果），需解包：

```cangjie
导入 标准集合.*
主函数() {
    可变 成绩 = 向量<整数>()
    成绩.添加(95); 成绩.添加(85)
    让 总和 = 成绩 |> 累加({ 累积, 分 => 累积 + 分 })
    打印行(总和.获取或抛出())      // 180（选项需解包；空容器 → 无值，不崩溃）
}
```

**排序（sort）**：**原地排序**（直接修改原数组），顶层函数，需 `导入 排序.*`：

```cangjie
导入 排序.*
主函数() {
    可变 成绩 = [88, 95, 70]
    排序(成绩)                       // 原地升序
    打印行(成绩[0])                  // 70
    排序(成绩, 降序: 真)             // 原地降序（降序 是命名参数）
    打印行(成绩[0])                  // 95
}
```

- `排序` 接受数组，要求元素可比较；向量要先 `收集数组`/`转数组` 再排；
- 官方旧 API `稳定排序` 已废弃——用 `排序(数据, 稳定: 真)` 表达「相等元素保持原顺序」；
- 想不改变原数据？排序前先拷贝一份（`排序(数据.拷贝())` 之类）。

## 4.9 拼接与收集：收集字符串

**是什么**：`收集字符串` 把元素**连成字符串**（官方 collectString，柯里化工厂）；字符串插值 `${}` 覆盖「拼模板」需求：

```cangjie
导入 标准集合.*
主函数() {
    可变 名单 = 向量<字符串>()
    名单.添加("甲"); 名单.添加("乙"); 名单.添加("丙")
    打印行(名单 |> 收集字符串(分隔符: ""))   // 甲乙丙（无分隔符）
    打印行("圆周率 = ${3.14159}")            // 字符串插值输出浮点数
}
```

**注意**：官方 1.0.5 **没有** `拼接`（join）——要带分隔符就 `映射({ x => x + "、" })` 再收集（末尾会多一个分隔符，可自行去掉）；`分隔符` 是**命名参数**（官方 delimiter）；`格式化`（format）是**数字的成员方法**（`42.格式化("${0}")`，默认 6 位小数，需 `导入 转换.*`）——**没有**独立的 `格式化` 包，别写 `导入 格式化.*`。

## 4.10 官方对照

```cangjie
// 官方仓颉
import std.collection.{HashMap, ArrayList}

main() {
    var scores = ArrayList<Int64>()
    scores.add(90)
    scores.add(80)
    println("size = ${scores.size}")
    println("first = ${scores[0]}")

    let book = HashMap<String, Int64>()
    book["小明"] = 10086
    println("小明号码：${book["小明"]}")
}
```

方言与官方一一对应：`向量`→ArrayList、`哈希映射`→HashMap、`添加`→add、`大小`→size、`放入`/`映射[键]=`→put、`获取`→get、`键()`→keys()。

## ✳ 设计思想

**① 容器选择是「数据结构」决策**。四类容器各回答一个问题：

| 容器 | 回答的问题 | 代价 |
|---|---|---|
| 数组/向量 | 「按顺序存什么」 | 查找要遍历 O(n) |
| 哈希映射 | 「这个键对应什么」 | 无序、键要可哈希 |
| 哈希集合 | 「这个值在不在」 | 无序、不能重复 |

先想清「我要查什么、按什么查」，再选容器——这比记住 API 重要得多。

**② 可变性纪律：原地 vs 新容器**。`排序` 原地修改（不产生新值），`映射`/`过滤` 产生新序列（不动原容器）。两种风格没有对错，但**要明确约定**：函数式风格偏向后一种（原数据是「输入」，不会被悄悄改掉），调试时心智负担小。

**③ 声明式 > 命令式**。`成绩 |> 过滤({ x => x >= 60 }) |> 收集数组` 读起来就是「过滤掉不及格的，收集成数组」——意图直说；手写 `可变 结果 = ...; 对于 ... { 如果 ... { 结果.添加(...) } }` 则要读者自己「翻译」意图。声明式代码把「做什么」与「怎么做」分开。

**④ 惰性求值：用多少算多少**。迭代器不一次性算完，链式组合（映射→过滤→映射）时每个元素只过一遍管道——这是函数式语言的高性能秘密，也是「映射为什么不出结果」的答案：它还没被消费。

**⑤ 编码意识：字节 ≠ 字符**。中文在 UTF-8 下占 3 字节，「字符串长度」是字节数——这是新手最容易踩的坑。字符串本质是字节序列，按字符处理要走 `字符流()`。

## 小结

- 插值 `${}` 内放变量和表达式，会二次转译；字符串方法群分查询/裁剪/变换/拆分四类；
- `长度` 是字节数（中文 3 字节/字）、切片按字节、大小写纯 ASCII；
- 三容器：向量（动态列表，`删除` 只收区间）、哈希映射（键值对，取不存在的键**抛异常**）、哈希集合（去重）；
- 高阶函数管道：`容器 |> 映射/过滤/遍历/求和/累加 |> 收集数组`——惰性、不动原容器；
- `排序` 是顶层函数（`导入 排序.*`），原地修改，`降序` 命名参数；
- 运行时输出保持官方格式（`真` → `true`）。
