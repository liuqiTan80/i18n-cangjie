# 04 字符串与集合

目标：熟练使用字符串插值、向量（ArrayList）与哈希映射（HashMap），掌握 `导入` 语句。

## 4.1 字符串插值：${}

仓颉的 `${表达式}` 插值在方言中直接可用，插值段内还会继续做母语转译：

```cangjie
主函数() {
    让 名字 = "仓颉"
    让 版本 = 1
    打印行("${名字} 语言，版本 ${版本}.0")   // 仓颉 语言，版本 1.0
    打印行("四则：${3 + 4 * 2}")             // 四则：11
}
```

字符串拼接用 `+`：

```cangjie
主函数() {
    让 欢迎 = "你好，" + "世界"
    打印行(欢迎)
}
```

## 4.2 导入（import）语句

`导入` = `import`，路径用 `.` 分隔 + 花括号导入列表（方言语法与官方一致）：

```cangjie
导入 标准集合.{哈希映射, 向量};
```

- `标准集合` = `std.collection`（语言包「模块路径」节）；
- `哈希映射`/`向量` 等母语名在花括号内被替换；
- 结尾分号可省可留（与官方一致）。

## 4.3 向量（ArrayList）：可变数组

```cangjie
导入 标准集合.{向量};

主函数() {
    可变 成绩 = 向量<整数>()
    成绩.添加(90)          // 添加 = add
    成绩.添加(80)
    成绩.添加(70)
    打印行("长度 = ${成绩.长度}")      // 长度 = size
    打印行("第 2 项 = ${成绩[1]}")     // 下标访问
    对于 (成绩项 in 成绩) {
        打印行("成绩：${成绩项}")
    }
}
```

## 4.4 哈希映射（HashMap）：键值对

```cangjie
导入 标准集合.{哈希映射};

主函数() {
    可变 电话本 = 哈希映射<字符串, 整数>()
    电话本.放入("小明", 10086)      // 放入 = put
    电话本.放入("小红", 10010)
    打印行("小明号码：${电话本.获取("小明")}")   // 获取 = get
    打印行("含小红：${电话本.包含("小红")}")     // 包含 = contains
    打印行("长度：${电话本.长度}")
    电话本.删除("小红")              // 删除 = remove
    打印行("删除后长度：${电话本.长度}")
}
```

## 4.5 范围与常用工具

```cangjie
导入 标准集合.{向量};

主函数() {
    让 全范围 = 1..6                    // 1,2,3,4,5（左闭右开）
    让 闭范围 = 1..=6                   // 1..6（双闭）
    可变 和 = 0
    对于 (i in 全范围) { 和 += i }
    打印行("1..6 之和 = ${和}")         // 15

    让 数字们 = 向量<整数>([3, 7, 2])
    打印行("最大值：${最大值(数字们).getOrThrow()}")   // 最大值 = max（顶层函数）
    打印行("最小值：${最小值(数字们).getOrThrow()}")   // 最小值 = min
}
```

> 注意：`最大值`/`最小值` 是**顶层函数**（返回 `选项`，用 `.getOrThrow()` 取 值），不是数组的成员方法。

## 4.6 官方对照

```cangjie
// 官方仓颉
import std.collection.{HashMap, ArrayList}

main() {
    var scores = ArrayList<Int64>()
    scores.add(90)
    scores.add(80)
    println("size = ${scores.size}")
    println("first = ${scores[0]}")
}
```

## 练习

1. 用 `哈希映射` 实现「单词 → 释义」小字典，遍历打印全部条目；
2. 用 `向量` 收集 1 到 100 的偶数，再求和；
3. 字符串插值里嵌套方法调用（如 `${电话本.获取("键")}`）验证插值态转译。

## 小结

- `${}` 插值内做二次转译；`导入 标准集合.{...}` 引入容器；
- `向量` 用 `添加`/`长度`/下标；`哈希映射` 用 `放入`/`获取`/`包含`/`删除`；
- 范围 `1..6` 左闭右开，`1..=6` 双闭。
