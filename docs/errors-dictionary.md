# zhc 错误信息字典附录

> 本附录由 `tools/gen_error_dict.py` 从语言包 `errors.toml` 自动生成，与教学诊断行为严格一致。

## 使用说明

zhc 把官方编译器（cjc）的错误翻译为中文教学诊断，两级匹配：

1. **诊断码表**（第一优先级）：cjc JSON 诊断的 `DiagKind` 字段（1.0.5 实测稳定），如 `sema_mismatched_types`；
2. **消息翻译表**（兜底）：官方消息原文按 精确 → 最长前缀 → `~` 后缀三级匹配；未收录消息原样回退（不崩溃、不瞎译）。

反查方法：看到诊断中的稳定错误码（或官方错误文本），在本附录定位条目，阅读教学提示与修复示例。

## 一、诊断码表（14 条）

### `chir_dce_unused_variable`

- **中文消息**：变量 `{q0}` 从未被使用
- **教学提示**：未使用的声明会被编译器警告。删除它，或确认是否拼写错误（比如把名字写成了别的变量）。
- **修复示例**（方言，可直接粘贴）：

```cangjie
可变 未使用的变量: 字符串 = "hi"
// 方案一：删除该行
// 方案二：使用它
打印行(未使用的变量)
```

---

### `lex_unrecognized_escape`

- **中文消息**：无法识别的转义 `{q0}`
- **教学提示**：字符串转义序列不支持 `\q`：仓颉支持 `\
`（换行）、`\t`（制表）、`\\`、`\"`、`\uXXXX`（Unicode）等。
- **修复示例**（方言，可直接粘贴）：

```cangjie
打印行("第一行\
第二行")  // 换行用 \

```

---

### `package_search_error`

- **中文消息**：找不到包 `{q0}`
- **教学提示**：导入的模块不存在。先确认标准库包名（如 `标准集合`/`数学`），再检查是否安装了对应用户库。
- **修复示例**（方言，可直接粘贴）：

```cangjie
导入 标准集合.{向量}
导入 标准库.{打印行}
// 确认导入的路径在标准库或已安装的库中
```

---

### `parse_expected_character`

- **中文消息**：缺少 `{q0}`
- **教学提示**：语法不完整：检查这一行的括号、分号或关键字是否漏写。每行语句以分号 `;` 或换行结尾。
- **修复示例**（方言，可直接粘贴）：

```cangjie
函数 甲() {
    打印行(1)  // 语句以分号或换行结尾
}
```

---

### `parse_expected_right_delimiter`

- **中文消息**：未闭合的分隔符 `{q0}`
- **教学提示**：括号/方括号/花括号必须成对闭合：检查嵌套与缩进，每打开一个 `(`/`[`/`{` 都要有对应的 `)`/`]`/`}`。
- **修复示例**（方言，可直接粘贴）：

```cangjie
函数 甲() {
    打印行(1)
}  // 括号成对
```

---

### `sema_cannot_assign_to_immutable`

- **中文消息**：不能给不可变值赋值
- **教学提示**：`让`（let）绑定一旦创建就不可修改。需要修改时把 `让` 改成 `可变`（var）。
- **修复示例**（方言，可直接粘贴）：

```cangjie
让 计数器: 整数 = 1
// 修改值前，把 让 改为 可变：
可变 计数器: 整数 = 1
计数器 = 2
```

---

### `sema_exceed_num_value_range`

- **中文消息**：数字 `{q0}` 超出类型 `{q1}` 的取值范围
- **教学提示**：字面量数值超出目标类型的取值范围：改用更大的类型（如 `整数` 超出时用 `无符号整数`），或改为运行时计算。
- **修复示例**（方言，可直接粘贴）：

```cangjie
让 大数: 无符号整数 = 9223372036854775808
```

---

### `sema_generic_type_without_type_argument`

- **中文消息**：泛型类型缺少类型参数
- **教学提示**：泛型类型（如 `向量`/`哈希映射`/`选项`）使用时必须给出类型参数：`向量<整数>`、`选项<字符串>`。
- **修复示例**（方言，可直接粘贴）：

```cangjie
让 列表: 向量<整数> = 向量<整数>()
让 可能值: 选项<字符串> = 无值
```

---

### `sema_mismatched_types`

- **中文消息**：类型不匹配
- **教学提示**：检查声明与赋值两侧类型是否一致。需要转换时使用 `作为`（as），仓颉不会自动做类型转换。
- **修复示例**（方言，可直接粘贴）：

```cangjie
可变 整数变量: 整数 = 1
可变 文本变量: 字符串 = "1"
// 声明与赋值两侧类型必须一致
```

---

### `sema_missing_entry`

- **中文消息**：缺少程序入口 `{q0}`
- **教学提示**：可执行程序必须提供入口 `主函数()`：每个工程有且只有一个 `主函数()`，参数与返回类型保持默认。
- **修复示例**（方言，可直接粘贴）：

```cangjie
主函数() {
    打印行("你好，仓颉！")
}
```

---

### `sema_redefinition`

- **中文消息**：重复声明 `{q0}`
- **教学提示**：同一作用域内名字只能声明一次：检查是否有重复定义，或与导入的标识符冲突（改名或去掉多余声明）。
- **修复示例**（方言，可直接粘贴）：

```cangjie
让 变量 = 1
// 让 变量 = 2  // 重复声明报错，改名：
可变 变量2 = 2
```

---

### `sema_undeclared_identifier`

- **中文消息**：未声明的标识符 `{q0}`
- **教学提示**：使用了未定义的名称：检查拼写；变量需先声明后使用；块作用域（`{}`）内声明的名字仅块内可见。
- **修复示例**（方言，可直接粘贴）：

```cangjie
函数 主() {
    可变 总数: 整数 = 1
    打印行(总数)  // 先声明，再使用
}
```

---

### `sema_undeclared_type_name`

- **中文消息**：未声明的类型名 `{q0}`
- **教学提示**：类型必须已声明或已导入：检查类型名拼写；自建类型需先定义；标准库类型需导入对应模块（如 `标准集合`）。
- **修复示例**（方言，可直接粘贴）：

```cangjie
导入 标准集合.{向量}
类 我的类型 {}
函数 甲() {
    让 变量: 我的类型 = 我的类型()
    让 列表: 向量<整数> = 向量<整数>()
}
```

---

### `sema_wrong_number_of_arguments`

- **中文消息**：调用参数数量不匹配：`{q0}`
- **教学提示**：实参个数必须与形参个数一致：数一数调用处的参数，缺失或多余都会报错。
- **修复示例**（方言，可直接粘贴）：

```cangjie
函数 甲(参数: 整数) {}
甲(1)  // 实参 1 个，形参 1 个，匹配
```

## 三、回退策略

- 未收录的错误码/消息：**原样输出官方文本**，不翻译、不崩溃；
- 模板占位符 `{q0}`/`{q1}`：从完整消息提取引号对（`'...'`）捕获，避免前缀截断把闭引号当开引号；
- 模板无占位符时动态拼接残段，保证信息不丢失；
- 类型名本地化（`Int64` → `整数`、`Enum-Option<Int64>` → `枚举-选项<整数>`）在翻译后应用。
