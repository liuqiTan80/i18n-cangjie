## 17.1 定义：算法与复杂度（大 O）

**定义**：算法 = 解决问题的**步骤清单**（第 1 章的「菜谱」正式版）；数据结构 = 存数据的**组织形式**（第 11 章容器是现成的）。复杂度（大 O）衡量算法随数据规模增长的**时间/空间消耗趋势**：

| 大 O | 名称 | 例子 | 1 万条数据的感受 |
|---|---|---|---|
| O(1) | 常数时间 | 哈希查找、数组下标 | 瞬间 |
| O(log n) | 对数时间 | 二分查找 | 14 步 |
| O(n) | 线性时间 | 顺序查找、遍历 | 1 万步 |
| O(n log n) | 线性对数 | 快速排序 | 13 万步 |
| O(n²) | 平方时间 | 冒泡/选择排序 | 1 亿步（开始卡） |

**为什么**：同样的问题，算法不同耗时差出**数量级**——这就是算法学习的价值。写代码前先估复杂度，是「性能意识」的第一步。

**示例：顺序查找（O(n)）**：

```cangjie
函数 顺序查找(列表: 数组<整数>, 目标: 整数): 整数 {
    对于 (i in 0..列表.长度) {
        如果 (列表[i] == 目标) { 返回 i }
    }
    返回 -1        // 找不到
}

主函数() {
    打印行(顺序查找([3, 7, 2, 9, 5], 9))    // 3（下标从 0 数）
    打印行(顺序查找([3, 7, 2, 9, 5], 8))    // -1
}
```

## 17.2 二分查找：O(log n) 的「猜数字」策略

**定义**：在**已排序**的数组里，每次取中间值比较——大了去左半、小了去右半，每步排除一半。这就是第 11 章猜数字游戏的原理（2¹⁰ = 1024，10 步猜 1 到 1000）。

**前提**：**数组必须有序**——无序数组二分无效。

**中文语法**：

```cangjie
函数 二分查找(列表: 数组<整数>, 目标: 整数): 整数 {
    可变 低 = 0
    可变 高 = 列表.长度 - 1
    当 (低 <= 高) {
        让 中 = (低 + 高) / 2
        如果 (列表[中] == 目标) { 返回 中 }
        否则如果 (列表[中] < 目标) {
            低 = 中 + 1        // 目标在右半
        } 否则 {
            高 = 中 - 1        // 目标在左半
        }
    }
    返回 -1
}

主函数() {
    让 有序表 = [1, 3, 5, 7, 9, 11, 13]
    打印行(二分查找(有序表, 7))      // 3
    打印行(二分查找(有序表, 2))      // -1（找不到）
}
```

**注意事项**：`低 <= 高` 是循环条件（等号别漏）；`中 = (低 + 高) / 2` 用整数除法；每轮必更新 `低` 或 `高`——否则死循环。n 条数据最多 `log₂(n)+1` 步。

## 17.3 选择排序：O(n²) 的「选最小」

**定义**：每轮从未排序部分**选出最小**，放到已排序部分末尾——像打扑克时把最小的牌一张张挑出来。

**中文语法**：

```cangjie
导入 标准集合.*
函数 选择排序(列表: 数组<整数>): 数组<整数> {
    可变 结果 = 列表 |> 收集数组      // 拷贝副本（不改原数组）
    对于 (i in 0..结果.长度) {
        可变 最小位置 = i
        对于 (j in i + 1..结果.长度) {
            如果 (结果[j] < 结果[最小位置]) { 最小位置 = j }
        }
        如果 (最小位置 != i) {      // 交换（第 3 章的临时盒子套路）
            让 临时 = 结果[i]
            结果[i] = 结果[最小位置]
            结果[最小位置] = 临时
        }
    }
    返回 结果
}

主函数() {
    打印行(选择排序([5, 2, 9, 1, 7]))    // [1, 2, 5, 7, 9]
}
```

**注意事项**：两层循环 = O(n²)；「选最小 + 交换」是核心；`列表 |> 收集数组` 拷贝出副本（`收集数组` 消费迭代器成新数组，第 11 章），保证原数组不被改（函数式纪律）。**日常排序直接用 `排序`（第 11 章）**——自己写排序是为了理解原理。

## 17.4 冒泡排序：O(n²) 的「相邻交换」

**定义**：每轮从左到右**相邻比较**，大的往后冒——像气泡往上浮。与选择排序同为 O(n²)，但交换更频繁（性能稍差，教学价值高）。

**中文语法**：

```cangjie
导入 标准集合.*
函数 冒泡排序(列表: 数组<整数>): 数组<整数> {
    可变 结果 = 列表 |> 收集数组      // 拷贝副本（不改原数组）
    对于 (i in 0..结果.长度) {
        对于 (j in 0..结果.长度 - 1 - i) {
            如果 (结果[j] > 结果[j + 1]) {
                让 临时 = 结果[j]
                结果[j] = 结果[j + 1]
                结果[j + 1] = 临时
            }
        }
    }
    返回 结果
}

主函数() {
    打印行(冒泡排序([5, 2, 9, 1, 7]))    // [1, 2, 5, 7, 9]
}
```

**注意事项**：内层 `0..长度-1-i`——每轮末尾已排好，不用再比（优化点）；可以加「本轮无交换就提前结束」标志（最优情形 O(n)）。

## 17.5 快速排序：O(n log n) 的分治

**定义**：**分治**思想——选一个「基准」，把数组分成「小于基准」和「大于基准」两半，递归对两半排序。平均 O(n log n)，是实际应用最广的排序。

**中文语法**：

```cangjie
导入 标准集合.*
函数 快速排序(列表: 数组<整数>): 数组<整数> {
    如果 (列表.长度 <= 1) { 返回 列表 }       // 出口：空或单个元素已经有序
    可变 小于 = 向量<整数>()
    可变 大于等于 = 向量<整数>()
    对于 (i in 1..列表.长度) {                // 基准取第一个元素
        如果 (列表[i] < 列表[0]) {
            小于.添加(列表[i])
        } 否则 {
            大于等于.添加(列表[i])
        }
    }
    可变 结果 = 向量<整数>()                    // 结果也先存向量（数组不可变长）
    对于 (项 in 快速排序(小于 |> 收集数组)) { 结果.添加(项) }
    结果.添加(列表[0])
    对于 (项 in 快速排序(大于等于 |> 收集数组)) { 结果.添加(项) }
    返回 结果 |> 收集数组                       // 最后转回数组
}

主函数() {
    打印行(快速排序([5, 2, 9, 1, 7]))    // [1, 2, 5, 7, 9]
}
```

**注意事项**：**递归必须有两个部分**——「出口」（`长度 <= 1`）与「递进」（每次规模变小）；`向量 |> 收集数组` 完成向量→数组转换（消费迭代器成新数组，第 11 章）；`导入` 语句放文件**顶部**是惯例（本代码块已遵守）。

## 17.6 栈与队列：两种「排队」方式

**定义**：**栈**（Stack）= 后进先出（LIFO）——像叠盘子，后放的先拿；**队列**（Queue）= 先进先出（FIFO）——像排队买饭，先来的先买。

**中文语法**（用向量模拟）：

```cangjie
导入 标准集合.{向量}

结构体 栈 {
    公开 可变 数据: 向量<整数>
    初始化() { 本对象.数据 = 向量<整数>() }
    公开 函数 压入(值: 整数) { 本对象.数据.添加(值) }
    公开 函数 弹出(): 选项<整数> {
        如果 (本对象.数据.大小 == 0) { 返回 无值 }
        让 顶 = 本对象.数据[本对象.数据.大小 - 1]
        本对象.数据.删除(本对象.数据.大小 - 1..本对象.数据.大小)
        返回 有值(顶)
    }
    公开 函数 空(): 布尔 { 返回 本对象.数据.大小 == 0 }
}

主函数() {
    让 盘子 = 栈()
    盘子.压入(1)
    盘子.压入(2)
    盘子.压入(3)
    打印行(盘子.弹出().获取或抛出())    // 3（后进先出）
    打印行(盘子.弹出().获取或抛出())    // 2
    打印行(盘子.弹出().获取或抛出())    // 1
}
```

**注意事项**：栈的典型用途——函数调用栈（谁调用谁返回）、撤销操作（Ctrl+Z）、括号配对检查；队列的典型用途——任务排队、消息队列。`删除(区间)` 删除最后一个元素（第 11 章：删除只收区间）。

## 17.7 递归：函数调用自己

**定义**：递归 = 函数**调用自己**解决更小版本的同一问题。本质是「分治」的另一种写法——**把大问题拆成小问题，小问题的解拼成大问题的解**。

**中文语法**：

```cangjie
函数 阶乘(数: 整数): 整数 {
    如果 (数 <= 1) { 返回 1 }          // 出口：最小问题直接给答案
    返回 数 * 阶乘(数 - 1)             // 递进：问题变小（数-1），解拼起来（×数）
}

函数 斐波那契(数: 整数): 整数 {
    如果 (数 <= 1) { 返回 数 }         // 出口
    返回 斐波那契(数 - 1) + 斐波那契(数 - 2)   // 两个更小问题
}

主函数() {
    打印行(阶乘(5))        // 120（5×4×3×2×1）
    打印行(斐波那契(10))   // 55
}
```

**注意事项**：

- **递归两个要素缺一不可**：出口（终止条件）+ 递进（规模缩小）——缺出口 = 栈溢出崩溃；
- 递归 vs 循环：递归代码更接近数学定义（好读），循环性能更好（无调用开销）；深度太深（万级）用循环；
- 斐波那契的朴素递归有大量重复计算（O(2ⁿ)）——用循环或记忆化优化（练习 4）。

## 17.8 哈希原理：O(1) 的秘密

**定义**：哈希映射为什么 O(1)？——**哈希函数**把键（如字符串「旺财」）算成一个数字（桶号），直接跳到对应桶找值。查「旺财几岁」不用翻遍所有条目，算一下哈希就定位了。

**为什么是 O(1)**：不管数据多少条，哈希函数的计算时间都一样——「算一下 → 跳到桶 → 取出来」三步，与数据量无关。

**代价（第 11 章回顾）**：

- **无序**：桶号是哈希值决定的，与插入顺序无关——所以遍历顺序不保证；
- **键必须可哈希**：字符串、整数天然可哈希；自定义类型要实现 `可哈希` 接口；
- **冲突**：两个键算出同一桶（碰撞）——哈希映射内部用链表/开放寻址解决，冲突多时退化为 O(n)。

**中文语法**（用哈希映射做词频统计——哈希的经典应用）：

```cangjie
导入 标准集合.{哈希映射, 向量}

函数 词频统计(文本: 字符串): 哈希映射<字符串, 整数> {
    可变 统计 = 哈希映射<字符串, 整数>()
    让 词表 = 文本.分割(" ")
    对于 (词 in 词表) {
        统计[词] = 统计.获取(词).获取或默认({ => 0 }) + 1   // 计数套路
    }
    返回 统计
}

主函数() {
    让 统计 = 词频统计("苹果 香蕉 苹果 橘子 苹果 香蕉")
    对于 (词 in 统计.键()) {
        打印行("${词}：${统计[词]}次")
    }
}
```

**注意事项**：`统计.获取(词).获取或默认({ => 0 }) + 1`——「取旧值（没有就 0）→ 加 1 → 放回」是计数的标配三连（第 11 章）。

## 17.9 常用算法模板

**定义**：几个高频算法的「骨架」，背下来直接套：

```cangjie
导入 标准集合.{哈希映射}
// 模板 1：遍历求和（储蓄罐）
函数 数组和(列表: 数组<整数>): 整数 {
    可变 总和 = 0
    对于 (项 in 列表) { 总和 += 项 }
    返回 总和
}

// 模板 2：找最大（擂台赛）
函数 找最大(列表: 数组<整数>): 选项<整数> {
    如果 (列表.长度 == 0) { 返回 无值 }
    可变 最大 = 列表[0]
    对于 (项 in 列表) {
        如果 (项 > 最大) { 最大 = 项 }
    }
    返回 有值(最大)
}

// 模板 3：计数（第 11 章统计分组套路）
函数 计数(列表: 数组<整数>): 哈希映射<整数, 整数> {
    可变 统计 = 哈希映射<整数, 整数>()
    对于 (项 in 列表) {
        统计[项] = 统计.获取(项).获取或默认({ => 0 }) + 1
    }
    返回 统计
}

主函数() {
    打印行(数组和([1, 2, 3, 4]))       // 10
    打印行(找最大([3, 7, 2, 9]).获取或抛出())   // 9
    打印行(计数([1, 2, 1, 3, 1]).大小)  // 3（三种不同的数）
}
```

**注意事项**：空列表的「最大」不存在——返回 `选项`（预期失败用选项，第 14 章）；模板的边界（空、单元素、全相同）都要想到。

## 小结

- 大 O 衡量趋势：O(1) < O(log n) < O(n) < O(n log n) < O(n²)；
- 二分查找：**有序**数组每次排除一半（O(log n)）；循环条件 `低 <= 高`；
- 选择/冒泡排序：O(n²)，理解原理即可——日常用 `排序`；
- 快排：分治 + 递归，平均 O(n log n)；**递归 = 出口 + 递进**；
- 栈 LIFO（压入/弹出）、队列 FIFO；哈希 O(1) 的秘密是哈希函数直接定位；
- 计数三连：`统计.获取(键).获取或默认({ => 0 }) + 1`。
