# 第 7 章 函数初体验

> **本章学习目标**
> - 理解「函数」是把代码装进带名字的盒子，随用随取；
> - 学会定义函数：参数（原料）和返回（成品）；
> - 明白为什么函数让代码不重复、好修改、好读。
>
> **读完本章你能回答**：函数和变量盒子的区别？参数和返回值是什么？调用函数时会发生什么？

---

## 7.1 重复写的代码，收进函数

你发现「成绩评级」这段判断要被用三次。复制粘贴三遍？代码会又臭又长，改一处要改三处，漏改一处就出 bug。

**函数**就是解决方案：把一段代码装进一个「工具箱」，起个名字，随用随取。

## 7.2 定义函数

```cangjie
函数 评级(分数: 整数): 字符串 {
    如果 (分数 >= 90) { 返回 "优秀" }
    否则如果 (分数 >= 60) { 返回 "及格" }
    否则 { 返回 "加油" }
}

主函数() {
    打印行("小明的评级：${评级(85)}")
    打印行("小红的评级：${评级(95)}")
}
```

拆开看：

- `函数 评级`：定义一个叫「评级」的函数；
- `(分数: 整数)`：**参数**——函数工作需要的「原料」。这里要一个整数，叫 `分数`；
- `: 字符串`：**返回类型**——函数交出的「成品」是文字；
- `返回 "优秀"`：把成品交出去，函数**立刻结束**（后面的代码不再执行）；
- `评级(85)`：**调用**（使用）函数，把 85 递给它。

> 类比：函数像自动售货机——投币（参数），出货（返回）。投不同的币，出不同的货。

## 7.3 参数和返回：原料与成品

再举一个例子——算长方形的面积：

```cangjie
函数 求面积(宽: 浮点, 高: 浮点): 浮点 {
    返回 宽 * 高
}

主函数() {
    打印行("长 3 宽 4 的面积：${求面积(3.0, 4.0)}")
    打印行("长 5 宽 6 的面积：${求面积(5.0, 6.0)}")
}
```

注意几个细节：

- **参数必须写类型**（`: 浮点`）——这是函数和外面世界的「合同」：你给什么，我出什么，写清楚谁都不含糊；
- 参数是**只读**的（不能给参数重新赋值）——它像进门时递进来的原料，你不能把它退了换一个；
- 一个函数可以有多个参数（用逗号分开），也可以没有参数。

## 7.4 没有原料也没有成品也行

不需要参数和返回值时，直接空着：

```cangjie
函数 打招呼() {
    打印行("你好呀！")
}

主函数() {
    打招呼()
    打招呼()
}
```

- `函数 打招呼()`：括号里空着 = 不需要原料；
- 没有 `: 返回类型` = 没有成品（实际上它返回一个叫「单元」的空值，你不需要关心）；
- 调用两次，就打印两次——**写一次，用多次**。

## 7.5 为什么用函数？

1. **不重复**：同样的逻辑只写一次（改评级标准，只改一处）；
2. **好修改**：改一处，所有用到的地方都变；
3. **好读**：`评级(85)` 一眼看懂在干什么，比一长串 `如果` 清爽；
4. **好测**：小函数容易单独验证——给它一个数，看它返回什么（第 18 章会专门讲测试）。

> 函数命名的小规矩：用「动词 + 对象」——`计算总分`、`读取文件`、`求面积`，一看就知道它干什么。

## 7.6 动手练一练

1. 写一个 `求和(最大数: 整数): 整数` 函数，用循环算 `1+2+…+最大数`，然后调用它算 100 和 1000；
2. 写一个 `判断奇偶(数: 整数): 字符串` 函数：偶数返回「偶数」，奇数返回「奇数」（提示：`数 % 2 == 0` 表示能被 2 整除，`%` 是取余数）；
3. 想一想：`评级(85)` 里的 85 和函数里的 `分数`，是不是同一个盒子？——**不是**！调用时电脑会新建一个「分数」盒子放进 85，函数结束盒子就消失了；
4. 挑战：写一个 `画星星(个数: 整数)` 函数，打印一行 `个数` 个 `*`，然后调用它画 3 行（个数分别是 1、2、3）。

## ✳ 编程思想小贴士：抽象——藏起细节

函数最大的价值不是「少打字」，而是**抽象**：

- 用 `评级(85)` 的人，**不需要知道**评级内部是怎么判断的（不需要读那一长串 `如果`）；
- 就像你用洗衣机，不需要知道里面的电机怎么转——你只需要知道「放衣服、按按钮、取衣服」。

这就是抽象的威力：**把「怎么做」藏在里面，只把「做什么」露在外面**。程序的每一层都建立在这种「藏」上：

- 函数藏逻辑 → 主函数只关心调用；
- 类藏数据（第 12 章）→ 外面只看到方法；
- 语言包藏词表（第 1 章）→ 你只写中文。

**会写程序的人，就是会分层、会藏细节的人。**

## 🍳 日常算法小例子：自动售货机

把「评级」的比喻变成真代码——一台有四个按钮的售货机：

```cangjie
函数 售货(按钮: 整数): 字符串 {
    如果 (按钮 == 1) { 返回 "可乐" }
    否则如果 (按钮 == 2) { 返回 "橙汁" }
    否则如果 (按钮 == 3) { 返回 "矿泉水" }
    返回 "没有这个商品"      // 其他按钮都算无效
}

主函数() {
    打印行("按 1：${售货(1)}")
    打印行("按 2：${售货(2)}")
    打印行("按 9：${售货(9)}")
}
```

看这个例子的两个小技巧：

- **「兜底返回」**：最后一个 `返回` 不需要 `否则`——因为前面的 `返回` 都会立刻结束函数，走到最后一行说明前面的条件全不成立。这是函数式写法的惯用套路；
- **函数是「黑盒子」**：主函数只知道「按几号出什么」，完全不关心售货机内部怎么判断——这就是抽象。

## 小结

- `函数 名字(参数: 类型): 返回类型 { ... }`：定义函数；
- 参数是原料（**必须写类型**、只读），`返回` 交出成品并立刻结束；
- 调用：`名字(实参)`；写一次，用多次；
- 没有参数/返回值的函数：括号空着、不写返回类型；
- 函数四大好处：不重复、好修改、好读、好测；
- 思想：**抽象**——藏起「怎么做」，露出「做什么」。
