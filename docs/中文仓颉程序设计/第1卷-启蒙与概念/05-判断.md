# 第 5 章 电脑会思考：判断

> **本章学习目标**
> - 用 `如果`/`否则如果`/`否则` 让程序「走岔路」；
> - 认识比较符（`==`、`>`、`>=`……）和布尔值（`真`/`假`）；
> - 学会组合多个条件（`与`、`或`、`非`）。
>
> **读完本章你能回答**：判断从上到下怎么执行？`=` 和 `==` 有什么区别？条件里能放数字吗？

## 5.1 如果……就……

电脑最厉害的本事之一，就是**做判断**。语法跟说话一样：

```cangjie
主函数() {
    让 分数 = 85
    如果 (分数 >= 60) {
        打印行("及格了！")
    }
}
```

- `如果 (条件)`：**如果条件成立**，就执行花括号里的代码；
- `>=` 是「大于等于」。比较符号有：`==`（等于）、`!=`（不等于）、`>`（大于）、`<`（小于）、`>=`（大于等于）、`<=`（小于等于）。

> 记住：判断相等用 **两个** 等号 `==`。一个等号 `=` 是「放进盒子」（赋值），两个等号才是「比一比」（比较）。这是新手最常见的错误之一——好在仓颉会直接报错拦住你。

## 5.2 否则如果、否则：多分支判断

```cangjie
主函数() {
    让 分数 = 85
    如果 (分数 >= 90) {
        打印行("优秀！")
    } 否则如果 (分数 >= 60) {
        打印行("及格")
    } 否则 {
        打印行("加油，别灰心")
    }
}
```

像判断题：第一个条件不成立就试第二个，都不成立就走 `否则`。**从上到下，只走一条路**——第一个「成立」的条件是谁，就执行谁，后面的统统不看了。

## 5.3 真与假

判断的结果只有两种：`真`（成立）和 `假`（不成立）。这就是第 4 章见过的 `布尔` 类型：

```cangjie
主函数() {
    让 下雨 = 真
    如果 (下雨) {
        打印行("带伞！")
    }
}
```

`真` 和 `假` 可以直接存进变量，也可以由比较产生：`85 >= 60` 这个「算式」的结果就是 `真`。看，`如果 (分数 >= 60)` 其实就是在问：这个比较的结果是 `真` 还是 `假`？

> 注意：条件里**不能放数字**。`如果 (1)` 是错的——条件必须是真正的「真/假判断」，这杜绝了把「赋值」错写成「比较」的经典 bug（想想 `如果 (x = 1)` 会怎样）。

## 5.4 组合条件：与、或、非

一个条件不够，就用逻辑词组合：

```cangjie
主函数() {
    让 年龄 = 15
    让 有票 = 真
    如果 (年龄 >= 12 与 有票) { 打印行("可以入场") }
    如果 (年龄 < 6 或 年龄 > 80) { 打印行("免费") }
    如果 (非 有票) { 打印行("请买票") }
}
```

| 词 | 意思 | 例子 |
|---|---|---|
| `与` | 两个条件都成立才成立（AND） | `下雨 与 有伞` |
| `或` | 一个成立就成立（OR） | `下雨 或 下雪` |
| `非` | 反过来（NOT） | `非 下雨` = 没下雨 |

> **小秘密（短路）**：`假 与 任何` 直接就是 `假`——右边的条件电脑根本懒得看；`真 或 任何` 直接就是 `真`。这保证了一个安全写法：`列表.大小 > 0 与 列表[0] > 1`——第一个条件不成立时，右边的越界访问不会执行（第 11 章你会用到）。

## 5.5 动手练一练

1. 写一个程序：你的身高（比如 155），如果超过 150 打印「可以玩过山车」，否则打印「再长高一点」；
2. 给分数评级：`>=90` 优秀，`>=80` 良好，`>=60` 及格，否则加油——用上 `否则如果`；
3. 想一想：`如果 (5 > 3)` 和 `如果 (3 > 5)`，哪个会执行里面的代码？
4. 挑战：写一个「游乐场规则」——年龄在 8 到 18 岁之间 `与` 身高超过 130 才能玩，否则打印原因（提示：`年龄 >= 8 与 年龄 <= 18`）。

## ✳ 编程思想小贴士：判断 = 岔路口

`如果` 是程序第一次「思考」的地方——程序不再是一条直线，而是会**走岔路**。

这背后的思想是：**程序 = 顺序 + 分支 + 循环**。你写过的所有程序，都是由这三样拼起来的：

- **顺序**（第 2 章）：一步步做；
- **分支**（本章）：看情况选路；
- **循环**（第 6 章）：重复绕圈。

**任何复杂的程序，拆到底都是这三种结构**。这是计算机科学里著名的「结构化编程」思想——就像乐高只有几种基础积木，却能拼出一切。看到复杂程序别慌：找找它的「顺序、分支、循环」在哪。

## 🍳 日常算法小例子：成绩评级器

老师给全班评等级，这就是一个典型的多分支判断：

```cangjie
主函数() {
    让 分数 = 85
    如果 (分数 >= 90) {
        打印行("优秀")
    } 否则如果 (分数 >= 80) {
        打印行("良好")
    } 否则如果 (分数 >= 60) {
        打印行("及格")
    } 否则 {
        打印行("加油")
    }
}
```

注意判断的**顺序**：从高到低排（90 → 80 → 60）。如果先写 `如果 (分数 >= 60)`，那 85 分就永远到不了「良好」——60 的条件先成立，直接走人了。**分支顺序就是优先级**，这是多分支最容易踩的坑。

> 想想：把分数改成 95、70、40 各跑一次，看看分别输出什么。

## 小结

- `如果 (条件) { ... }`：条件成立才执行；
- `否则如果`、`否则`：多分支，**从上到下只走第一条成立的路**；
- 比较符：`== != > < >= <=`；判断相等用 `==`，赋值才用 `=`；
- 布尔：`真`/`假`；条件必须是布尔判断，不能放数字；
- 组合：`与`（都成立）、`或`（一个成立）、`非`（反过来）；
- 分支顺序 = 优先级：评级从高分往低分写。
