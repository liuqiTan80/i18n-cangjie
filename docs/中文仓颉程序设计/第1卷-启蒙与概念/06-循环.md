# 第 6 章 重复干活：循环

> **本章学习目标**
> - 用 `对于` 让代码数着做重复的事；
> - 用 `当` 让代码做到条件不满足才停；
> - 学会 `跳出` 和 `继续` 控制循环。
>
> **读完本章你能回答**：`1..5` 包含 5 吗？死循环怎么停下来？高斯是怎么秒算 1 加到 100 的？

---

## 6.1 重复的事交给电脑

让电脑从 1 加到 100？手动写 100 行？**循环**就是干这个的——让同一段代码反复执行。电脑最擅长重复劳动，它不会累、不会烦、不会数错。

## 6.2 对于：数着数着做

```cangjie
主函数() {
    对于 (i in 1..5) {
        打印行("第${i}次")
    }
}
```

- `1..5` 是一个**范围**：从 1 到 5（注意：到 5 就停，**不包含 5**）；
- `对于 (i in 1..5)`：每次把 `i` 依次变成 1、2、3、4，执行一遍花括号里的代码；
- 输出：`第1次`、`第2次`、`第3次`、`第4次`（没有第5次！）。

> 范围还有闭区间写法 `1..=5`（包含 5）。「半开区间 `1..5`」是编程界的主流约定，因为它的长度正好是 `5 - 1`，没有歧义。

### 传奇故事：高斯秒算 1 加到 100

数学家高斯 8 岁那年，老师让全班算 1 加到 100，别的小朋友埋头苦算，高斯几秒就写完了——他发现 `1+100=101`、`2+99=101`……一共 50 组，所以答案是 `50 × 101 = 5050`。

我们用循环写出来——高斯用巧劲，我们用笨功夫（但电脑不嫌笨）：

```cangjie
主函数() {
    可变 总和 = 0
    对于 (i in 1..101) {
        总和 = 总和 + i
    }
    打印行("1 加到 100 等于${总和}")
}
```

输出：`1 加到 100 等于5050`。注意看这个程序的「灵魂」：`可变 总和` 像个储蓄罐，每圈往里面加一个数——**循环里改 `可变` 变量**是编程最常用的组合。

## 6.3 当：直到不满足才停

`对于` 适合「数着做」，`当` 适合「做到某条件不成立为止」——**只要条件为真，就一直做**：

```cangjie
主函数() {
    可变 剩下面条 = 10
    当 (剩下面条 > 0) {
        打印行("还有${剩下面条}根面条")
        剩下面条 = 剩下面条 - 1
    }
    打印行("吃完了！")
}
```

> ⚠️ **危险提醒**：如果忘了写 `剩下面条 = 剩下面条 - 1`，条件永远为真，程序会一直循环下去——这叫**死循环**。看到程序不停刷屏，按 **Ctrl+C** 强制停止。

## 6.4 跳出和继续

- `跳出`：立刻结束整个循环（不想数了，直接走）；
- `继续`：跳过这一次，进入下一次。

```cangjie
主函数() {
    对于 (i in 1..10) {
        如果 (i == 3) { 继续 }      // 跳过 3
        如果 (i == 7) { 跳出 }      // 到 7 就停
        打印行("数到${i}")
    }
}
// 输出：数到1 数到2 数到4 数到5 数到6
```

## 6.5 动手练一练

1. 用 `对于` 打印九九乘法表的某一列：`1×7=7`、`2×7=14`……`9×7=63`；
2. 用 `当` 倒计时：从 10 数到 1，然后打印「发射！」；
3. 把「1 加到 100」改成「1 加到 1000」，看看答案对不对（公式：n×(n+1)/2）；
4. 挑战：用 `对于` 打印 1 到 50 里的所有偶数（提示：`i % 2 == 0` 就是偶数）。

## ✳ 编程思想小贴士：循环三要素

写循环之前，先回答三个问题（**循环三要素**）：

1. **从哪开始**？（起点：`i = 1` 或 `剩下面条 = 10`）
2. **什么时候停**？（条件：`i < 5` 或 `剩下面条 > 0`）
3. **每圈怎么变**？（步进：`i` 自动加 1，或 `剩下面条 = 剩下面条 - 1`）

任何循环，只要把这三件事想清楚，就不会写成死循环。死循环的本质就是：**「什么时候停」永远不成立**——检查三要素，立刻找到病根。

> 这也是「分解」思想的又一次胜利（第 1 章）：循环看起来很吓人，拆成三个问题，每个都简单。

## 🍳 日常算法小例子：九九乘法表

用「循环套循环」打印九九乘法表——这是所有程序员的入门仪式：

```cangjie
主函数() {
    对于 (行 in 1..10) {
        可变 一行 = ""
        对于 (列 in 1..=行) {
            一行 = 一行 + "${列}×${行}=${列 * 行} "
        }
        打印行(一行)
    }
}
```

- 外层循环管「行」（1 到 9），内层循环管「列」（1 到当前行）；
- **循环套循环**叫「嵌套循环」——外层每走一步，内层完整走一圈；
- 内层结束条件 `1..=行` 用了外层变量 `行`——内层圈数随外层变化，这是嵌套循环的精髓。

> 想想输出是什么样？第一行 `1×1=1 `，第二行 `1×2=2 2×2=4 `……你自己跑跑看！

## 小结

- `对于 (i in 范围)`：数着做；`1..5` 半开区间**不含 5**，`1..=5` 含 5；
- `当 (条件)`：条件为真就一直做，**小心死循环**（Ctrl+C 救命）；
- `跳出` 结束整个循环、`继续` 跳过本轮；
- 循环三要素：起点、停止条件、每圈变化；
- 循环里配合 `可变` 变量做累计（储蓄罐套路）；
- 嵌套循环：外层走一步，内层走一圈。
