# 第 3 章 记忆盒子：变量

> **本章学习目标**
> - 理解「变量」是贴了名字标签的盒子；
> - 分清 `让`（不可改动）与 `可变`（可以改）两种盒子；
> - 学会给变量起好名字。
>
> **读完本章你能回答**：`让` 和 `可变` 有什么区别？为什么编程界鼓励多用 `让`？`=` 在程序里是什么意思？

---

## 3.1 让电脑帮你记东西

你做题的时候，会先在草稿纸上写「已知：x = 5」。**变量**就是电脑的草稿纸：一个贴了名字标签的盒子，可以往里面放东西，随时拿出来用。

## 3.2 让：一个不可改动的盒子

```cangjie
主函数() {
    让 我的年龄 = 12
    打印行("我的年龄是${我的年龄}")
}
```

- `让 我的年龄 = 12`：拿出一个盒子，贴上「我的年龄」的标签，放进数字 `12`；
- `"我的年龄是${我的年龄}"`：`${}` 是**插值**——像填空一样，把盒子里东西的值填进这句话里。

运行结果：`我的年龄是12`。

`让` 的意思是「**定下来，不改了**」——盒子里的东西放进去了就不能换。如果你试着再写 `我的年龄 = 13`，编译器会毫不留情地报错：「不能给不可变值赋值」。

> 类比：`让` 像是刻在石头上的字（改不了）。

## 3.3 可变：一个可以改的盒子

有时候我们确实要改，比如数数：

```cangjie
主函数() {
    可变 计数 = 0
    计数 = 计数 + 1      // 从盒子里取出 0，加上 1，放回 1
    计数 = 计数 + 1      // 再取一次，现在变成 2
    打印行("数了两下：${计数}")
}
```

- `可变`：盒子里的东西可以**随时更换**；
- `=` 是**赋值**：把右边的东西放进左边名字的盒子里。注意它不是数学里的「等于」，而是「把……放进……」。所以 `计数 = 计数 + 1` 的意思是：把现在的 `计数` 取出来加 1，再放回去。

> 类比：`可变` 像是写在黑板上的字（能擦掉重写）。
>
> 怎么选？**默认用 `让`**——够用就锁死它；只有确实要改（数数、累计、倒计时）才用 `可变`。这样读代码的人一眼就能看出：标了 `可变` 的地方，才是会变的地方。

## 3.4 给盒子起名字的规矩

- 可以用中文！`我的年龄`、`总分`、`答案` 都行；
- 名字要**一看就懂**。`总分` 比 `a` 好一百倍——过两天你自己都看不懂 `a` 是什么；
- 不能是数字开头（`123abc` 不行），不能有空格；
- 可以加上类型标注，告诉电脑这个盒子装什么材料：

```cangjie
主函数() {
    让 名字: 字符串 = "小明"    // 这个盒子只装文字
    让 分数: 整数 = 95          // 这个盒子只装整数
    打印行("${名字}考了${分数}分")
}
```

不写标注也行——电脑很聪明，看放进去的东西就能猜到盒子类型（这叫**类型推断**）。但写上标注更保险：盒子标签写明「只装整数」，你往里面塞文字，电脑立刻拦住你。

## 3.5 常量：刻在石头上的字

还有一种更「硬」的盒子——`常量`：

```cangjie
常量 圆周率 = 3.14159
常量 学校名 = "第一中学"

主函数() {
    打印行("${学校名}，圆周率 ≈ ${圆周率}")
}
```

`常量` 和 `让` 都是不能改的，区别在于：`常量` 在**编译期**就确定好了（程序跑起来之前就写死了），速度更快、更安全。**能用 `常量` 就用 `常量`**——圆周率、学校名这种永远不变的值，就该用 `常量`。

## 3.6 动手练一练

1. 用 `让` 存你的生日，用 `可变` 存你的零花钱，然后打印出来；
2. 猜一猜：`让 分数 = 90` 之后，再写 `分数 = 95`，会发生什么？试试看！中文错误提示会告诉你答案；
3. 用 `常量` 定义你家到学校的距离，打印「我家离学校 X 公里」；
4. 挑战：用 `可变` 写一个「零花钱记账」——存 100 元，买文具花 25 元，买零食花 10 元，打印还剩多少。

## ✳ 编程思想小贴士：命名即文档

「给盒子起名字」这件小事，是编程里最重要的大事之一。

- 程序员读代码的时间是写代码的 5-10 倍；
- 你写的代码，主要是给**未来的你**和**别人**看的；
- 一个叫 `总分` 的变量，不用注释大家就懂；一个叫 `a` 的变量，你明天就忘。

**命名即文档**：好名字本身就是说明书。写代码时多花十秒钟想名字，能省掉将来几个小时的理解时间。这也叫「自文档化代码」——代码自己会说话，不需要额外解释。

## 🍳 日常算法小例子：交换两个盒子

小明有两个盒子：一个装可乐，一个装橙汁。他想把两个盒子里的东西换过来——但注意：**不能把两个盒子同时打开倒**（会洒一地）。

程序员的解法：再拿一个**空盒子**（临时变量）：

```
1. 把可乐倒进空盒子      // 临时 = 可乐
2. 把橙汁倒进可乐盒子    // 可乐 = 橙汁
3. 把空盒子里的倒进橙汁盒子  // 橙汁 = 临时
```

用代码写：

```cangjie
主函数() {
    可变 可乐 = "可乐"
    可变 橙汁 = "橙汁"
    可变 临时 = 可乐       // 1. 先存起来
    可乐 = 橙汁            // 2. 橙汁进可乐盒
    橙汁 = 临时            // 3. 原来的可乐进橙汁盒
    打印行("可乐盒里是：${可乐}")
    打印行("橙汁盒里是：${橙汁}")
}
```

这是所有程序员都会遇到的经典套路——**交换两个值**。核心思想：直接换会丢东西，所以先借一个「临时盒」保存。你以后写排序算法（第 17 章）还会遇到它。

## 小结

- 变量 = 贴了名字标签的盒子；`=` 是「把东西放进去」，不是数学的「等于」；
- `让`：不可改（默认选择）；`可变`：可以改（需要时才用）；`常量`：编译期就定死（永远不变的值用）；
- 命名规矩：能用中文、一看就懂、不能数字开头、不能有空格；
- 类型标注可选：`让 名字: 字符串 = "小明"`——标注了，装错材料立刻报错；
- 交换两个值：借一个临时盒子。
