# 第 4 章 数字与文字

> **本章学习目标**
> - 认识四种基本「材料」：整数、浮点、字符串、布尔；
> - 用电脑做加减乘除；
> - 用插值 `${}` 把文字和数字拼成一句话。
>
> **读完本章你能回答**：`12` 和 `"12"` 有什么区别？为什么 `7 / 2` 等于 3？电脑怎么把「小明考了 95 分」拼成一句话？

---

## 4.1 盒子里可以放什么？

到目前为止我们放了数字和文字，其实有四种基本「材料」：

| 材料 | 名字 | 例子 |
|---|---|---|
| 整数（没有小数点） | `整数` | `12`、`-3`、`0` |
| 小数（浮点） | `浮点` | `3.14`、`-0.5` |
| 文字（字符串） | `字符串` | `"你好"`、`"abc"` |
| 真/假（布尔） | `布尔` | `真`、`假` |

电脑分得清清楚楚：`12` 是数字，`"12"` 是文字——不信你把它们加一加试试，会报错！因为「12 个苹果 + 12 个字」没有意义。这就是**类型**：每种材料的规矩不一样，装错材料，电脑立刻拦住你（第 4 章最后有实验）。

## 4.2 电脑是计算器

```cangjie
主函数() {
    让 苹果价格 = 3
    让 梨价格 = 4
    让 一共 = 苹果价格 + 梨价格
    打印行("一共${一共}元")
    打印行("三个苹果${苹果价格 * 3}元")
    打印行("比梨多${梨价格 - 苹果价格}元")
}
```

运算符号：`+` 加、`-` 减、`*` 乘、`/` 除。

跟数学一样，**先乘除后加减**，想先算的加括号：`(苹果价格 + 梨价格) * 2`。

## 4.3 整数除法的小陷阱

```cangjie
主函数() {
    打印行(7 / 2)          // 输出 3，不是 3.5！
    打印行(7.0 / 2.0)      // 输出 3.5
    打印行(7 % 2)          // 输出 1（% 是取余数）
}
```

**整数除以整数，结果还是整数**（多余的部分直接丢掉）。`7 / 2` 得到 `3`，不是 `3.5`！想要 `3.5`，得用浮点：`7.0 / 2`。

`%` 是**取余数**：`7 % 2` 是 1。判断一个数是奇数还是偶数、取数字的末位，全靠它——第 5 章你会用到。

## 4.4 把文字拼起来：插值

想组合文字和数字，用 `${}` 填空最方便：

```cangjie
主函数() {
    让 名字 = "小明"
    让 分数 = 95
    打印行("${名字}考了${分数}分")
}
```

输出：`小明考了95分`。`${}` 里面可以放变量，甚至可以放计算式：

```cangjie
主函数() {
    让 苹果 = 3
    让 梨 = 4
    打印行("一共${苹果 + 梨}个水果")   // 一共7个水果
}
```

> 想换行输出？用 `\n`：`打印行("第一行\n第二行")` 会输出两行。`\n` 读作「换行符」。

## ✳ 编程思想小贴士：类型是「分类标签」

为什么电脑这么死板，非得分清 `12` 和 `"12"`？

因为**不同类型的值能做不同的事**：数字能加减乘除，文字能拼接查找，真/假能用来做判断（第 5 章）。如果电脑允许「数字 + 文字」，那 `1 + "2"` 到底等于 `3` 还是 `"12"`？——每个程序员都会想一套自己的答案，程序就乱了。

所以编程语言用**类型**给每个值贴标签：**类型决定这个值能做什么运算**。这就像厨房里的工具分类：菜刀切菜、锅炒菜，你不会拿菜刀去炒菜。

> 这也是仓颉的一个设计哲学：**消灭隐式转换**——绝不让电脑「自作聪明」地把数字变成文字。每个转换都要程序员明确写出来（第 9 章会讲怎么转）。死板，正是为了不出错。

## 🍳 日常算法小例子：找零钱

你去商店买东西：东西 7 元，你给了 20 元。老板怎么算找零？

```cangjie
主函数() {
    让 付的钱 = 20
    让 价钱 = 7
    让 找零 = 付的钱 - 价钱
    打印行("应找${找零}元")

    // 升级：如果只有 1 元、5 元、10 元三种纸币，怎么凑？
    让 十元 = 找零 / 10          // 20 - 7 = 13，13 / 10 = 1 张
    让 剩余 = 找零 % 10          // 余下 3 元
    让 五元 = 剩余 / 5           // 3 / 5 = 0 张
    让 一元 = 剩余 % 5           // 余下 3 元
    打印行("找${十元}张十元、${五元}张五元、${一元}张一元")
}
```

这个例子藏着两个算法思想：
- **`/` 和 `%` 是天生一对**：`除法` 得到「能换几张」，`取余` 得到「还剩多少」——组合起来就是「凑零钱」算法；
- 这个「先除后余」的套路，叫**贪心算法**的雏形：每次都先用最大的面额（第 17 章还会深入）。

## 小结

- 四种基本材料：`整数`、`浮点`、`字符串`、`布尔`（`真`/`假`）；
- 运算：`+ - * / %`；先乘除后加减，括号优先；
- **整数除以整数得整数**（`7 / 2` = 3）；要小数用浮点（`7.0 / 2`）；
- `%` 取余数：判断奇偶、凑零钱全靠它；
- 插值 `${}`：把变量或计算式填进字符串，`"${名字}考了${分数}分"`；
- 类型是分类标签：`12` 和 `"12"` 是两回事，电脑不搞「隐式转换」。
