# 第 2 章 第一个程序：你好，世界！

> **本章学习目标**
> - 亲手创建第一个程序并运行成功；
> - 认识程序的「入口」——`主函数`；
> - 学会用 `打印行` 让电脑说话。
>
> **读完本章你能回答**：程序从哪里开始执行？`打印行` 为什么叫「行」？你写的代码是怎么变成电脑能懂的东西的？

---

## 2.1 约定俗成的第一句话

全世界学编程的人，第一个程序都是让电脑说一句话：「你好，世界！」（Hello, World!）。这是编程界的传统，像学书法先写「人」字一样——第一笔虽然简单，但从此你就是一个会编程的人了。

## 2.2 创建你的项目

打开终端，输入：

```bash
zhc init 我的第一个程序
```

这会帮你建好一个叫「我的第一个程序」的文件夹，里面已经放好了一个能运行的小程序。

然后进入这个文件夹，打开 `src/main.zc` 文件（用记事本或任意文本编辑器）：

```cangjie
主函数() {
    打印行("你好，世界！")
}
```

就三行！我们来拆解它。

## 2.3 主函数：程序的入口

`主函数()` 是**程序的入口**——电脑运行你的程序时，从这里开始，像进家门先迈进门一样。

它后面的 `{` 和 `}`（花括号）像一扇门的**门框**：`{` 表示「门开了，里面的代码开始执行」，`}` 表示「门关了，到这里结束」。

> 💡 注意：入口写 `主函数()`，前面**不带**「函数」两个字——就像说「去主人家做客」而不是「去拜访主人人家」。写 `函数 主函数()` 是错的，编译器会提醒你。

## 2.4 打印行：让电脑说话

`打印行("你好，世界！")` 的意思是：**让电脑把「你好，世界！」显示在屏幕上**。

- 里面的 `"`（双引号）是文字的「包装盒」，告诉电脑：引号里面是一句话，不是代码；
- `打印行` 比 `打印` 多一个「行」，因为它打完字还会**换行**——像写完一行字按回车。下一句话会从新的一行开始。

## 2.5 运行你的程序

在终端输入：

```bash
zhc run src/main.zc
```

你会看到：

```
✅ 编译成功：替换方言标识符 2 处。
你好，世界！
```

**成功啦！** 你刚刚完成了所有程序员的第一课。

> 幕后小剧场：`zhc run` 做了三件事——① 把中文代码翻译成标准仓颉（查语言包词表，所以会说「替换方言标识符 2 处」）；② 让编译器把仓颉翻译成电脑能懂的 `0` 和 `1`；③ 运行它。你在 1.3 节认识的「翻译官」团队正式上岗了。

> **小实验**：把引号里的字改成你的名字，再运行一次。比如 `打印行("我是小明")`。电脑就会说「我是小明」。**你已经会改程序了！**

## 2.6 动手练一练

1. 让电脑连续说三句话：你的名字、你的年龄、你最喜欢吃的东西（提示：写三行 `打印行`）；
2. 猜一猜：如果去掉引号，写成 `打印行(你好)`，会发生什么？去试试！看看中文错误提示说什么——它是在帮你找问题，不是惩罚你；
3. 挑战：在 `主函数()` 后面加一行 `打印行("第二行")`，注意看输出顺序——是「你好，世界！」先出来还是「第二行」先出来？

## ✳ 编程思想小贴士：约定优于配置

学编程的第一天，你可能没注意到：**全世界第一个程序都是「你好，世界！」**。这不是巧合，而是一种「约定」。

编程世界里充满约定：入口叫 `主函数`、文件叫 `main.zc`、项目结构由工具自动生成……为什么大家要遵守这些约定？

- **省思考**：不用每次都想「入口该叫啥」，照着约定写就行；
- **省沟通**：全世界程序员看到 `main.zc` 都知道这是入口文件，不用解释；
- **工具好用**：正因为有约定，`zhc init` 才能一键生成项目——它知道你缺什么。

**约定优于配置**（Convention over Configuration）：让「默认做法」成为「好做法」，是软件设计的一条大智慧。以后你写代码，遇到「大家都这么写」的套路，先照做，再琢磨为什么。

## 🍳 日常算法小例子：你每天已经是个「程序」

想想你今天早晨是怎么度过的：

```
1. 起床
2. 刷牙
3. 吃早饭
4. 出门上学
```

这就是一段「程序」——从上到下，一步步执行。电脑也是这样：`主函数()` 里的代码**按顺序**一条一条执行，做完第一条做第二条。

记住这个画面：**程序 = 一步步按顺序做的菜谱**。第 3 章开始，我们往菜谱里加「记忆盒子」（变量）。

## 小结

- 第一个程序只要三行：`主函数()` 包住 `打印行("...")`；
- `主函数()` 是程序入口（不带「函数」前缀），花括号 `{}` 圈出程序范围；
- `打印行("文字")` 让电脑显示一行文字并换行，文字要放在双引号里；
- `zhc run src/main.zc` 运行程序：转译 → 编译 → 执行；
- 编程界约定：第一个程序都是「你好，世界！」。

## 思考题

1. 如果删掉 `主函数()` 外面的 `{` 和 `}`，程序还能运行吗？为什么？
2. `打印行` 和 `打印` 有什么区别？你猜 `打印` 存不存在？（提示：去语言包里查 `zhc/lang-packs/zh/stdlib.toml`）
3. 为什么 `"你好"` 要加引号，而 `主函数` 不加？它们有什么区别？
4. 试着在 `打印行("你好")` 前面加一行 `打印行("我是第一行")`，预测输出顺序，再验证。
