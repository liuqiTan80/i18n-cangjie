# 中文仓颉程序设计

一部「细而全」的中文仓颉（zhc 方言）编程教程：从零基础到专业开发者的完整学习路径。

> **实测基准**：全书 `cangjie` 代码块基于 **zhc 0.1.0 / 官方 cjc 1.0.5** 逐块实测（当前 19 章 + 3 附录 + 答案集共 150+ 代码块，全部通过；复现方法见 [验证说明](验证说明.md)）。
> **核心理念**
> - **只做一本，做到细而全**——像一本程序设计手册，每个语法点独立成小节，方便随时查阅；
> - **面向多层次读者**——初中生零基础（第一卷）→ 进阶开发者（第二卷）→ 高质量代码追求者（第三卷）；
> - **同步掌握思维**——语法背后是编程思想、软件工程与算法，学习语言的同时建立编程世界观；
> - **全中文**——所有代码使用中文关键字与中文 API（`函数`、`如果`、`打印行`…），全部示例实测通过。

## 学习建议

1. **零基础从第一卷开始**，每章大约 10-20 分钟；每章的「动手练一练」一定要亲手做；
2. **遇到不会的语法**，直接翻第二卷对应条目（定义 → 语法 → 示例 → 注意）或附录速查；
3. **卡住的错误提示**，对照第一卷环境排查表、第二卷错误处理章、附录速查；
4. **每章末尾的「编程思想小贴士」和「日常算法小例子」**是本书的隐藏宝藏——编程能力 = 语法 + 思想 + 算法，三者同步积累。

## 读完这本书之后

- **查漏补缺**：遇到不会的语法翻第二卷对应条目或附录 A/B 速查；程序跑不出预期，对照附录 C 踩坑速查——大概率是其中一条；
- **读官方文档**：本书所有中文名都能在附录 A/B 找到官方对应（如 `修剪` → `trimAscii`、`打印行` → `println`），对照着读官方仓颉文档零障碍；
- **动手做项目**：把第 19 章猜数字按 19.5-19.6 的流程（重构 → 提交 → 打标签）自己再走一遍；然后找身边的小工具（记账、待办清单、成绩统计）用同样的流程实现——测试先行 + 小步提交；
- **参与 zhc 生态**：为语言包补词（`zhc/lang-packs/zh/`）、报告新踩的坑（对照 [验证说明](验证说明.md) 复现）、或给教程提改进——你踩过的坑是下一版附录 C 的素材。
