# 附录 B：标准库速查字典（拼音索引）

> **使用说明**：全书用到的标准库名字按拼音首字母索引。条目格式：`中文名 → 官方名`｜功能｜最小示例｜详见章节。
> 模块路径对照：`标准集合`=std.collection、`正则`=std.regex、`转换`=std.convert、`排序`=std.sort、`数学`=std.math、`环境`=std.env、`标准同步`=std.sync、`随机`=std.random、`标准测试宏`=std.unittest.testmacro、`标准测试`=std.unittest。

## 附 1：常用导入速查（模块路径）

| `导入 正则.*` | std.regex | `正则()`/`匹配正则` |
| `导入 转换.*` | std.convert | `整数.解析`/`格式化` |
| `导入 排序.*` | std.sort | `排序` |

| `导入 环境.*` | std.env | `退出` |

## 附 2：官方没有的（别找）——1.0.5 实测

| 想找的功能 | 官方现状 | 替代写法 |
|---|---|---|
| `拼接`（join） | 无 | `收集字符串` 或 `映射` 后收集 |
| `反序`（reversed） | 无 | 下标倒着取（11.2） |
| `分组`（groupBy） | 无 | 哈希映射手写（11.3） |
| `去重`（distinct） | 无 | 哈希集合天然去重（11.4） |
| 向量 `删除(值)` | 无（只收区间） | 先找下标再 `删除(区间)` |
| `可重入锁` | 已弃用 | 统一用 `锁`（Mutex，本身可重入） |
| 独立 `格式化` 包 | 无 | `42.格式化("${0}")`（`导入 转换.*`） |

> 用法提示：所有「`真`/`假`」在运行时输出中显示为官方格式 `true`/`false`；`大小`/`长度` 是**属性**（不带括号），`键()`/`字符流()` 是**方法**（带括号）——附录 A 是关键字索引，本附录是标准库索引，两者配合查。
