# 附录 A：关键字速查字典（拼音索引）

> **使用说明**：全部 60 个中文关键字按拼音首字母索引。条目格式：`中文词 → 官方对应`｜功能｜最小示例｜详见章节。
> 数据来源：`zhc/lang-packs/zh/keywords.toml`（v0.2）。`[宏]` 节的 3 条只在 `@` 后使用。
> 详见列标「进阶」表示正文不展开讲解，条目本身即完整参考（示例均经 zhc 实测）。

## 附：@ 宏速查（`[宏]` 节专用）

| 中文词 → 官方 | 功能 | 最小示例 |
|---|---|---|
| `@测试` → @Test | 标记测试函数（框架自动收集） | `@测试 函数 测试加法() { ... }` |
| `@期望` → @Expect | 断言：表达式结果 == 期望值 | `@期望(加法(2, 3), 5)` |
| `@派生` → @Derive | 自动生成相等/比较/哈希等样板 | `结构体 学生 @派生(相等) { ... }` |

> 用法提示：`@测试`/`@期望` 需要 `导入 标准测试宏.*` 与 `导入 标准测试.*` 两个导入（第 15 章）；`@派生` 需要宏库先编译好（两步编译）。
