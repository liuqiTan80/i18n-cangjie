# 附录 C：踩坑速查（实测经验）

> **使用说明**：本书 19 章全部代码经 zhc 0.2.0 / 官方 cjc 1.0.5 实测。本附录把实测中遇到的**典型坑**按主题整理成速查：每条 = **症状**（报错或怪行为）→ **原因** → **修复**。
> `cangjie` 代码块均为修复后的**可运行示例**（全部实测通过）；标注 ❌ 的错误写法仅为示意——直接运行会编译失败。
> 报错信息看不懂？去 [错误信息字典](../../errors-dictionary.md) 按错误码反查。

## 一、声明与语法

### C1 主函数带了 `函数` 前缀

| 症状 | 原因 | 修复 |
|---|---|---|
| 编译报错（找不到入口 / `主函数` 位置错误） | `主函数` 是程序的**入口**，是特殊声明——不加 `函数` 前缀 | 删掉 `函数 `，直接写 `主函数() { ... }` |

```cangjie
主函数() {
    打印行("你好，世界！")
}
```

详见：第 2 章（第一个程序）、第 8 章 8.1。

### C2 导入写在了声明后面

| 症状 | 原因 | 修复 |
|---|---|---|
| 编译报错：import 必须在所有声明之前 | 官方语法要求 `导入` 只能出现在文件**最顶部**（注释之后、任何 `函数`/`常量`/`类` 之前） | 把所有 `导入` 集中提到文件开头 |

```cangjie
导入 数学.*          // 必须放在文件顶部

主函数() {
    打印行(开方(9.0))    // 3.0（数学函数来自顶部导入）
}
```

详见：第 9 章（模块导入）、第 10 章 10.6。

### C3 `where` 约束写错了位置

| 症状 | 原因 | 修复 |
|---|---|---|
| 编译报错：泛型参数处不认识约束 | `where`（中文 `其中`/约束）是**函数签名的一部分**，官方语序放在返回类型之后 | 写 `函数 名<T>(参数): 返回类型 where T <: 可比较<T> { ... }`——约束不在 `<T>` 里 |

```cangjie
函数 取最大<T>(列表: 数组<T>): T where T <: 可比较<T> {
    可变 最大 = 列表[0]
    对于 (项 in 列表) {
        如果 (项 > 最大) { 最大 = 项 }
    }
    返回 最大
}

主函数() {
    打印行(取最大([3, 7, 2, 9]))        // 9
}
```

详见：第 15 章 15.2（泛型约束）。

### C4 「不给也能调」的参数：默认参数写法暂不支持

| 症状 | 原因 | 修复 |
|---|---|---|
| `参数: 类型 = 默认值` 报「期望 `,`，实际得到 `)`」 | 官方默认参数语法 zhc 方言检查器**暂不支持** | 用**重载**实现同样的效果：无参版本内部调用带参版本 |

```cangjie
函数 打招呼(): 字符串 {
    返回 打招呼("朋友")       // 重载：省略参数 = 用默认值
}
函数 打招呼(名字: 字符串): 字符串 {
    返回 "你好，${名字}！"
}

主函数() {
    打印行(打招呼())           // 你好，朋友！
}
```

详见：第 8 章 8.8（默认参数）。

## 二、类型与转换

### C5 变量之间不能隐式转换

| 症状 | 原因 | 修复 |
|---|---|---|
| `让 比例: 浮点 = 分数`（分数是整数变量）报类型错误 | 仓颉**不做隐式转换**：字面量 `1` 可以按上下文自适应为浮点，但**变量**有固定类型 | 用构造器显式转换：`浮点(分数)`、`整数(3.9)` |

```cangjie
主函数() {
    让 分数: 整数 = 85
    让 比例: 浮点 = 浮点(分数)     // 整数 → 浮点：构造器显式转换
    打印行(比例 / 2.0)             // 42.5
}
```

详见：第 9 章 9.10（类型转换：全部显式）。

### C6 小数塞给整数变量

| 症状 | 原因 | 修复 |
|---|---|---|
| `让 x: 整数 = 1.5` 编译报错 | 1.5 会**截断**成 1——丢数据的行为语言直接拒绝，不悄悄发生 | 真想截断就显式写 `整数(1.5)`，让意图可见 |

```cangjie
主函数() {
    打印行(整数(3.9))    // 3（显式截断，向零取整）
}
```

详见：第 9 章 9.10。

## 三、字符串：字节陷阱

### C7 `长度` 是字节数，不是字数

| 症状 | 原因 | 修复 |
|---|---|---|
| `"你好".长度` 是 6 不是 2 | 字符串按 **UTF-8 字节**存储：1 个汉字 = 3 字节 | 按字符处理用 `字符流()` 遍历；写代码别把「长度」当字数 |

```cangjie
主函数() {
    打印行("你好".长度)                    // 6（字节数）
    对于 (字 in "你好".字符流()) {          // 按字符遍历的正确姿势
        打印行(字)                          // 依次输出：你、好
    }
}
```

详见：第 10 章 10.7（字节 ≠ 字符）。

### C8 下标取出的是字节

| 症状 | 原因 | 修复 |
|---|---|---|
| `"你好"[0]` 输出 228——不是「你」 | 字符串下标按**字节**索引，`[0]` 拿到第一个字节的数值（UTF-8 中「你」的首字节 E4 = 228） | 取字符用 `字符流()`；做切片要按 3 字节的整数倍切 |

```cangjie
主函数() {
    让 文本 = "你好"
    打印行(文本[0])            // 228：第一个字节的数值
    打印行(文本[0..3])         // 你（前 3 字节 = 1 个汉字）
}
```

详见：第 10 章 10.3（切片按字节）。

### C9 大小写/修剪方法名是 ASCII 版

| 症状 | 原因 | 修复 |
|---|---|---|
| 写 `"abc".toUpperCase()` 或 `.trim()` 报错 | zh 词表收录的是官方 ASCII 版方法：`大写`=toAsciiUpper、`小写`=toAsciiLower、`修剪`=trimAscii、`大小写不敏感`=equalsIgnoreAsciiCase | 用 `大写()`/`小写()`/`修剪()`；中文没有大小写，纯 ASCII 转换不受影响 |

```cangjie
主函数() {
    打印行("  AbC  ".修剪())     // AbC（去首尾空白）
    打印行("abc".大写())          // ABC
    打印行("ABC".小写())          // abc
}
```

详见：第 10 章 10.4（变换方法）。

### C10 用 `匹配正则` 判断「是不是数字」没加锚

| 症状 | 原因 | 修复 |
|---|---|---|
| 输入 `"a1"` 程序崩溃（`整数.解析` 抛异常） | `匹配正则` 是**包含匹配**：`正则("\\d+")` 对 `"a1"` 也返回真（匹配到了子串 `"1"`）——「先判断后解析」形同虚设 | 加锚 `^` 开头 + `$` 结尾：`正则("^\\d+$")` 整串都是数字才返回真 |

```cangjie
导入 正则.*
导入 转换.*

函数 解析数字(文本: 字符串): 选项<整数> {
    如果 (正则("^\\d+$").匹配正则(文本)) {   // 锚定：整串是数字才过
        返回 有值(整数.解析(文本))
    }
    返回 无值
}

主函数() {
    打印行(正则("\\d+").匹配正则("a1"))         // true：包含匹配（子串 "1"）
    打印行(正则("^\\d+$").匹配正则("a1"))       // false：加锚后整串判断
    打印行(解析数字("a1"))                       // None（不会崩）
}
```

详见：第 10 章 10.6（正则）、第 14/18/19 章（解析函数统一锚定）。

## 四、集合与容器

### C11 数组不能动态添加元素

| 症状 | 原因 | 修复 |
|---|---|---|
| `结果.添加(1)`（结果是数组）编译报错 | 数组长度**不可变**，没有 `添加` 方法 | 要动态收集用 `向量`（可增长），最后 `|> 收集数组` 转回数组 |

```cangjie
导入 标准集合.*

主函数() {
    可变 结果 = 向量<整数>()
    结果.添加(1)               // 向量可以动态添加
    结果.添加(2)
    打印行(结果 |> 收集数组)   // [1, 2]
}
```

详见：第 11 章（数组 vs 向量）、第 17 章 17.5（快速排序完整示例）。

### C12 区间是「半开」的：`1..5` 不含 5

| 症状 | 原因 | 修复 |
|---|---|---|
| `对于 (i in 1..5)` 只循环 4 次；删除元素差一个 | `a..b` 是半开区间 [a, b)，含头不含尾 | 想含尾用 `a..=b`；数循环次数先想清楚「到不到得了 b」 |

```cangjie
主函数() {
    可变 次数 = 0
    对于 (i in 1..5) { 次数 += 1 }    // i = 1,2,3,4
    打印行(次数)                        // 4（不含 5！）
    次数 = 0
    对于 (i in 1..=5) { 次数 += 1 }   // i = 1..5
    打印行(次数)                        // 5
}
```

详见：第 6 章 6.1（对于循环）、第 11 章 11.3（删除区间）。

### C13 哈希映射的遍历顺序不保证

| 症状 | 原因 | 修复 |
|---|---|---|
| 同一份数据两次遍历顺序不同 | 哈希映射按哈希桶存放，**顺序由哈希值决定**，不是插入顺序 | 依赖顺序的输出先 `排序` 或改用数组/向量 |

```cangjie
导入 标准集合.*

主函数() {
    让 成绩表 = 哈希映射<字符串, 整数>()
    成绩表.放入("小明", 90)
    成绩表.放入("小红", 95)
    对于 (名字 in 成绩表.键()) {          // 键() 是方法，记得带括号！
        打印行(名字)
    }
}
```

详见：第 11 章 11.4（哈希映射）、第 11 章思考题 3。

## 五、面向对象

### C14 `重写` 必须配 `公开`（父类方法还要 `开放`）

| 症状 | 原因 | 修复 |
|---|---|---|
| 子类 `重写 函数` 报错：找不到可重写的方法 | 仓颉的三道闸门：父类要 `开放 类` + 方法 `公开 开放`，子类要 `公开 重写`——任何一道缺失都会被编译器拒绝 | 三道声明写齐（漏写 = 编译错误，而不是悄悄失效） |

```cangjie
开放 类 动物 {
    公开 开放 函数 叫声(): 字符串 { "……" }
}

类 狗 <: 动物 {
    公开 重写 函数 叫声(): 字符串 { "汪汪" }   // 公开 + 重写 缺一不可
}

主函数() {
    打印行(狗().叫声())    // 汪汪
}
```

详见：第 12 章 12.3（开放与重写）。

### C15 结构体是拷贝、类是共享——选错类型会「互相影响」

| 症状 | 原因 | 修复 |
|---|---|---|
| 把对象存进两个变量，改一个另一个也变（或反过来：改了却不同步） | `结构体` 是**值语义**：赋值即拷贝、互不影响；`类` 是**引用语义**：赋值共享同一份数据 | 想要「独立副本」用结构体或显式拷贝；想要「大家看同一份」用类 |

```cangjie
结构体 盒子 {
    公开 可变 值: 整数
    初始化(值: 整数) { 本对象.值 = 值 }
}

主函数() {
    可变 甲 = 盒子(1)
    可变 乙 = 甲              // 结构体赋值 = 拷贝出独立的一份
    乙.值 = 99
    打印行(甲.值)           // 1（甲不受影响）
}
```

详见：第 12 章 12.7（怎么选：结构体还是类）。

## 六、控制流与函数式

### C16 `匹配` 的分支体必须是表达式

| 症状 | 原因 | 修复 |
|---|---|---|
| `情况 X => { 多语句 }` 报「期望 `=>`」 | 官方 1.0.5 实测：`匹配` 分支体要求**单表达式**，块体多语句不支持 | 多语句分支改用 `如果/否则`；单表达式（赋值、`返回`）用 `匹配` 更漂亮 |

```cangjie
枚举 方向 { 上 | 下 }

主函数() {
    让 当前方向 = 方向.上   // 变量名避开类型名，避免遮蔽
    让 描述 = 匹配 (当前方向) {
        情况 方向.上 => "向上走"
        情况 方向.下 => "向下走"
    }
    打印行(描述)            // 向上走
}
```

详见：第 13 章 13.3（匹配）、第 19 章 19.3（综合实战：为何改用如果/否则）。

### C17 lambda 里不能用 `返回`/`跳出`/`继续`

| 症状 | 原因 | 修复 |
|---|---|---|
| lambda 里写 `返回`/`跳出`/`继续` 编译报错 | lambda 是**表达式**不是语句块：它没有「自己的返回/循环」；`返回` 属于外层函数，混用会让控制流失去界限 | 提前结束遍历就用普通 `对于` + `跳出`；lambda 只做「逐元素变换/筛选」 |

```cangjie
主函数() {
    // lambda 适合纯计算：映射/过滤（第 11 章）
    让 翻倍 = { x: 整数 => x * 2 }
    打印行(翻倍(21))        // 42
}
```

详见：第 8 章 8.6（lambda）、第 11 章思考题 4。

### C19 全角符号与中文标点混入代码

| 症状 | 原因 | 修复 |
|---|---|---|
