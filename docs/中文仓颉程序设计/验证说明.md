# 《中文仓颉程序设计》代码验证说明

> 本书承诺：**所有 `cangjie` 代码块都经 zhc 实测可运行**。本文件说明如何复现验证，
> 以及新增/修改代码块时保持「可验证性」的写作约定。

## 验证环境

| 组件 | 版本/位置 |
|---|---|
| zhc（方言工具链） | 0.1.0（`zhc/lang-packs/zh` 为当前词表） |
| 官方仓颉编译器 | cjc 1.0.5 |
| 操作系统 | Linux x86_64 |

zhc 运行需要（以解压安装目录为例）：

```bash
export PATH=/path/to/zhc-0.1.0-linux-x86_64/bin:$PATH
export LD_LIBRARY_PATH=/path/to/zhc-0.1.0-linux-x86_64/lib:$LD_LIBRARY_PATH
```

## 一键复现（单条命令）

验证工具链随仓库分发：`.verify/`（extract/run_all/combo_check，产物不入库）+
`scripts/tutorial-check.sh`（一键入口，本地与 CI 共用；acceptance 第 12 段自动调用，
`ZHC_SKIP_TUTORIAL=1` 可跳过）：

```bash
bash scripts/tutorial-check.sh    # ① 清理 → ② 抽取 → ③ 串行实测 → ④ 组合验证，全过才退出 0
```

- `ZHC_BIN`/`ZHC_LANG_PACKS`/`VERIFY_ROOT` 可覆盖（默认开发构建 zhc + 仓库语言包 + `.verify/`）；
- CI 用临时目录（`VERIFY_ROOT="$WORK/tutorial-verify"`）避免产物入仓库。

分步复现（与上述等价）：

```bash
cd .verify
rm -rf src out exp exp2      # ① 清空上次抽取产物（避免新旧文件混杂）
python3 extract.py          # ② 抽取 docs/中文仓颉程序设计/ 全部 cangjie 代码块并分类
bash run_all.sh             # ③ 串行实测所有非宏代码块，结果写入 results.txt
```

- `extract.py` 输出统计：`complete`（含主函数，直接跑）/ `official`（官方对照， 直接跑）/
  `topdecl`（顶层声明，追加空主函数）/ `fragment`（片段，包进主函数）/ `macro`（宏语法示意，跳过）；
- `run_all.sh` 对每个块 `zhc run`，退出码 0 为通过；失败清单见 `results.txt` 中 非零行 + `out/*.log` 错误详情；
- 交互程序的标准输入由 `input.txt` 提供（含 `退出` 兜底，防止 EOF 死循环）。

**预期结果**（当前 19 章 + 附录 A/B/C + 答案集，约 150 个非宏代码块）：全部通过，**唯一例外**是
19 章 19.5 重构片段（文件名含 `-19-综合实战-3.zc`，编号随文件增减漂移）——它引用 19.3 的 `玩一局` ，
需要**组合验证**（tutorial-check.sh 自动执行，无需手工）：

```bash
python3 combo_check.py    # ④ 19.3 核心逻辑（剥离入口）+ 19.5 重构版入口 → exp2/combo.zc（按文件名特征自动定位）
zhc run exp2/combo.zc < input.txt
```

## 新增代码块的四条写作约定

修改本书（或新增章节）时，遵守以下约定才能保证 `extract.py` 分类正确、验证不误报：

1. **错误示例禁止放 `cangjie` 代码块**：故意编译失败的写法用普通代码块（``` 无语言标记）
   或行内代码展示——放进 ```cangjie 块会被抽取实测，必然误报失败；
2. **代码块尽量自足**：优先给完整程序（含 `主函数()`）或纯顶层声明；
   片段（如 19.5 重构示例）必须注明「与第 X 节完整代码组合使用」，并登记到 `combo_check.py`；
3. **块首行不要是注释**：`extract.py` 按首行关键字分类，注释开头的顶层声明块
   会被误判为 fragment 包进主函数导致语法错误；
4. **新文件的代码同样会被全量扫描**：`extract.py` 用 `rglob("*.md")` 扫描书目录全部
   Markdown——新增文件（如附录、答案）里的代码自动纳入验证，无需改脚本。

## 语言包与代码的同步检查

教程用词必须被语言包覆盖。修改语言包后重跑全量验证；需要精确比对词表覆盖时：

```bash
python3 check_langpack.py   # 提取教程代码用词，比对 zhc/lang-packs/zh/stdlib.toml
```

当前状态：仓库版语言包为教程代码的全覆盖超集（0 缺失、0 映射冲突）。
