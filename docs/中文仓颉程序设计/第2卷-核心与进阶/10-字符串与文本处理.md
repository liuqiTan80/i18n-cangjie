# 第 10 章 字符串与文本处理

> **本章学习目标**：熟练使用字符串插值与字符串方法群，学会导入语句，初识正则表达式。
> **读完本章你能回答**：字符串长度为什么和字数不一样？切出半个汉字会发生什么？`\d` 在字符串里为什么要写成 `\\d`？

---

## 10.1 定义：字符串是什么

**定义**：字符串（`字符串` = 官方 String）是**不可变的 Unicode 字符序列**——一经创建不能修改，所有「修改」操作都返回新字符串。底层按 **UTF-8 字节**存储：中文 1 个汉字 = 3 字节。

## 10.2 插值：${} 拼模板

**定义**：字符串里用 `${表达式}` 嵌入变量或表达式——仓颉拼字符串的主要方式。

**中文语法**：

```cangjie
主函数() {
    让 名字 = "仓颉"
    让 版本 = 1
    打印行("${名字} 语言，版本 ${版本}.0")   // 仓颉 语言，版本 1.0
    打印行("四则：${3 + 4 * 2}")             // 四则：11（里面可以是任意表达式）
    打印行("嵌套：${名字.长度}")             // 嵌套：6（方法调用也支持）
}
```

**注意事项**：

- 插值段内会**二次转译**：方言词（`长度` 等）在 `${}` 里同样被翻译成官方名；
- 插值里**只放变量和表达式**，别放关键字——`"${函数}"` 里的插值段会被当作代码二次转译，塞关键字会编译报错；
- 字符串拼接用 `+`（少量）；批量拼接用 `收集字符串`（10.5）。

## 10.3 字符串方法群：查询 / 裁剪 / 变换 / 拆分

**定义**：字符串处理是最高频的编程场景，方言把常用方法全部母语化，覆盖四大类。

```cangjie
导入 正则.*
主函数() {
    让 文本 = "  仓颉 编程 语言  "
    // ① 查询
    打印行(文本.长度)                     // 24（字节数！UTF-8 下每个汉字 3 字节）
    打印行(文本.查找("编程"))             // 8（字节下标；找不到返回 -1）
    打印行(文本.以开头("  仓颉"))         // true（运行时输出官方格式）
    打印行(文本.以结尾("语言  "))         // true
    // ② 裁剪（字符串切片按字节——1 个汉字要切 3 字节）
    打印行("仓颉编程"[0..3])              // 仓（前 3 字节 = 1 个汉字）
    打印行("(${文本.修剪()})")            // (仓颉 编程 语言)（去首尾空白）
    // ③ 变换
    打印行("abc".大写())                  // ABC
    打印行("ABC".小写())                  // abc
    打印行("甲-乙".替换("-", "→"))        // 甲→乙
    // ④ 拆分
    让 部分 = 文本.修剪().分割(" ")
    打印行(部分.长度)                     // 3（分割返回数组）
    // ⑤ 判断（正则匹配）
    打印行(正则("\\d+").匹配正则("123"))  // true
}
```

**四条真相（记住它们）**：

| 真相 | 说明 |
|---|---|
| **长度是字节数** | `"仓颉".长度` 是 6 不是 2；按字符数遍历用 `字符流()` |
| **切片按字节** | `文本[0..3]` 切 1 个汉字；切错字节边界会得到乱码甚至崩溃 |
| **大小写是纯 ASCII** | `大写()`/`小写()` 只转换英文字母，中文没有大小写概念 |
| **正则用 `匹配正则`** | = 官方 `matches`，返回布尔；`正则("\\d+")` 里的 `\\` 是转义后的 `\` |

## 10.4 导入语句

**定义**：`导入`：把其他模块的名字「把门打开」。路径用 `.` 分隔。

**中文语法**：

```cangjie
导入 标准集合.{向量, 哈希映射};    // 精确导入：只引入花括号里的名字
导入 标准集合.*                     // 通配导入：引入该模块全部名字
导入 正则.*                         // std.regex：正则类型与匹配
导入 数学.*                         // std.math：开方、绝对值等
导入 转换.*                         // std.convert：格式化、转换字符串等
```

**注意事项**：

- `标准集合` = `std.collection`（语言包「模块路径」节）；花括号里的母语名逐个被替换；
- 结尾分号可省可留（与官方一致）；
- 导入未安装的包 → zhc 报「找不到包」方言错误；未使用的导入是警告；
- 通配导入可能名字冲突（同名时用 `包.名字` 限定）。

## 10.5 拼接与收集：收集字符串

**定义**：`收集字符串` 把元素**连成字符串**（官方 collectString）——批量拼接的正确姿势；字符串插值 `${}` 覆盖「拼模板」需求。

```cangjie
导入 标准集合.*
主函数() {
    可变 名单 = 向量<字符串>()
    名单.添加("甲"); 名单.添加("乙"); 名单.添加("丙")
    打印行(名单 |> 收集字符串(分隔符: ""))   // 甲乙丙（无分隔符）
    打印行("圆周率 = ${3.14159}")            // 字符串插值输出浮点数
}
```

**注意事项**：

- 官方 1.0.5 **没有** `拼接`（join）——要带分隔符就 `映射` 后收集，或自行处理；
- `分隔符` 是**命名参数**（官方 delimiter）；
- `格式化`（format）是**数字的成员方法**（`42.格式化("${0}")`，需 `导入 转换.*`）——**没有**独立的 `格式化` 包，别写 `导入 格式化.*`。

## 10.6 正则初体验

**定义**：正则表达式 = 描述「字符串模式」的小语言——`\d` 数字、`+` 一个以上、`[0-9]` 范围、`.` 任意字符。正则对象由 `正则("模式")` 构造（官方 `Regex`，需 `导入 正则.*`）。

**中文语法**：

```cangjie
导入 正则.*
主函数() {
    打印行(正则("\\d+").匹配正则("123"))       // true（123 全是数字）
    打印行(正则("\\d+").匹配正则("12a"))       // true！匹配到子串 "12"——包含匹配
    打印行(正则("^\\d+$").匹配正则("12a"))     // false（加 ^ 开头 $ 结尾 = 整串完整匹配）

    让 电话 = "138-1234-5678"
    打印行(正则("\\d{3}-\\d{4}-\\d{4}").匹配正则(电话))  // true（{3} 表示正好 3 个）
}
```

**注意事项**：

- **转义陷阱**：正则的 `\d` 在字符串里要写成 `\\d`（字符串的 `\\` 才是真正的 `\`）——这是新手最常见报错；
- `匹配正则` 返回**布尔**（是否**匹配到**——注意是包含匹配：`正则("\\d+")` 对 `"12a"` 也返回真，因为匹配到了子串 `"12"`；要判断「整串都是数字」必须加锚 `^` 开头 + `$` 结尾）；要提取内容需更高级 API（官方文档）；
- 正则适合「判断格式」，复杂文本解析（嵌套、递归）不适合正则——那需要手写解析器。
## ✳ 设计思想

**① 编码意识：字节 ≠ 字符**。中文在 UTF-8 下占 3 字节，「字符串长度」是字节数——这是新手最容易踩的坑。字符串本质是字节序列，按字符处理要走 `字符流()`。仓颉区分「文本」（字符）与「字节」（二进制）——文件、网络、加密处理的是字节流，不是字符。把两者混为一谈是经典 bug 来源。

**② 不可变字符串**：字符串不可修改，每次操作产生新值——这保证字符串可以安全共享（传参不担心被改），代价是大量拼接时性能差（所以有 `收集字符串`）。

**③ 声明式文本处理**：`分割` → `过滤` → `收集字符串` 的管道比手写循环更直读——「拆开 → 挑拣 → 拼回」是文本处理的标准心智模型。

## 小结

- 插值 `${}` 内放变量和表达式，会二次转译；字符串 `+` 拼接少量、`收集字符串` 批量；
- 方法群四类：查询（`查找`/`以开头`/`以结尾`）、裁剪（切片/`修剪`）、变换（`大写`/`小写`/`替换`）、拆分（`分割`）；
- `长度` 是字节数（中文 3 字节/字）、切片按字节、大小写纯 ASCII；
- `导入` 两种形态：精确（`{名字}`）与通配（`*`）；模块路径见语言包；
- 正则：`正则("模式").匹配正则(文本)` 返回布尔；`\d` 在字符串里写 `\\d`。
