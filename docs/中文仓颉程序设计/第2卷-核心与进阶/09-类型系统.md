# 第 9 章 类型系统

> **本章学习目标**：掌握「存数据」的全部基础——三种绑定（`让`/`可变`/`常量`），从整数到元组的类型体系，类型推断与显式转换。
> **读完本章你能回答**：为什么默认用 `让`？为什么仓颉不做隐式类型转换？类型标注什么时候必须写？

---

## 9.1 定义：类型是数据的分类标签

**定义**：类型决定数据**能存什么**（范围）、**能做什么运算**（方法）、**占多大空间**（位宽）。仓颉是**强静态类型**语言：每个值在编译期就有确定的类型，装错类型立刻报错。

**基础类型总览**：

| 方言类型 | 官方类型 | 说明 | 例子 |
|---|---|---|---|
| `整数` | `Int64` | 64 位有符号整数（默认） | `42` |
| `整数32` | `Int32` | 32 位整数 | `42`（标注后） |
| `无符号整数` | `UInt64` | 非负整数 | `7u64` |
| `浮点` | `Float64` | 64 位浮点数（默认） | `3.14` |
| `浮点32` | `Float32` | 32 位浮点数 | `1.75f32` |
| `字符串` | `String` | 不可变 Unicode 文本 | `"仓颉"` |
| `布尔` | `Bool` | 真/假 | `真`、`假` |
| `字符` | `Rune` | 单个 Unicode 字符 | `'颉'` |
| `单元` | `Unit` | 无返回值的类型 | `空` |
| `空类型` | `Nothing` | 没有值的类型 | `退出(1)` 的返回 |

**注意**：三个「空」别混淆——`空类型`（Nothing，没有值）、`空`（Unit 的唯一值）、`无值`（Option 家族的「没有」，第 14 章）。

## 9.2 三种绑定：让 / 可变 / 常量

**定义**：把名字绑到值上的三种方式，可变性递增：

| 绑定 | 官方 | 语义 | 适用 |
|---|---|---|---|
| `让` | let | 创建后**不可修改**（默认选择） | 绝大多数声明 |
| `可变` | var | 可重新赋值（申请来的特权） | 计数、累计、状态 |
| `常量` | const | **编译期**确定、零运行时开销 | 圆周率等永远不变的值 |

**中文语法**：

```cangjie
常量 圆周率 = 3.14159

主函数() {
    让 出生年 = 2000          // 类型自动推断为 整数
    // 出生年 = 2001          // ❌ 不能给不可变值赋值

    可变 计数 = 0
    计数 += 1                  // 复合赋值：计数 = 计数 + 1
    打印行("计数 = ${计数}")   // 计数 = 1
    打印行("圆周率 ≈ ${圆周率}")
}
```

**注意事项**：

- `让` 是绑定不是「变量」——绑定关系不可变；但绑定的**对象**如果是引用类型（类），对象内部仍可变化（第 12 章）；
- `常量` 的值必须编译期能算出（字面量、其他常量表达式）；
- 编译器报「不能给不可变值赋值」→ 把 `让` 改成 `可变`；反之变量从未被修改 → 改回 `让`（lint 会提醒）。

## 9.3 整数族与位宽

**定义**：整数按位宽分档——`整数`（64 位默认）、`整数32`、`整数8`……位宽 = 存储空间与取值范围。默认 64 位是「最不会溢出的通用选择」。

```cangjie
主函数() {
    让 a: 整数 = 100          // 64 位（默认）
    让 b: 整数32 = 100        // 32 位
    让 c: 无符号整数 = 100    // 非负
    打印行(a + 整数(b))        // 不同位宽不能直接相加：显式转成 整数（见 9.10）
}
```

**注意事项**：

- `整数32`/`浮点32` 与默认位宽类型**不能直接混算**（官方不自动提升，报「二元表达式无效」——要显式转换）；
- 无符号数 `-1` 是编译错误（范围检查）；
- 后缀全表：整数 `i8/i16/i32/i64/u8/u16/u32/u64`，浮点 `f16/f32/f64`；**后缀必须小写**（`42U8` 是语法错误）。

## 9.4 浮点族

**定义**：小数用浮点——`浮点`（Float64 默认）、`浮点32`（Float32）。浮点是**近似值**（二进制无法精确表示所有小数），别用 `==` 比较浮点。

```cangjie
导入 数学.*
主函数() {
    让 身高: 浮点32 = 1.75f32
    让 体重: 浮点32 = 65.5f32
    打印行(身高 * 体重)        // 同类型（浮点32 × 浮点32）直接算

    // 浮点比较的正确姿势：误差范围
    让 a = 0.1 + 0.2
    打印行(绝对值(a - 0.3) < 0.0001)   // true（绝对值 在 数学 模块）
}
```

**注意事项**：浮点字面量默认 `浮点`（Float64）；后缀 `f32`/`f64` 强制位宽；`绝对值` 在 `数学` 模块（`导入 数学.*`）。

## 9.5 布尔

**定义**：只有两个值——`真`、`假`。条件是**必须是**布尔表达式（不能放数字）。

```cangjie
函数 年龄判断(岁: 整数): 布尔 { 返回 岁 >= 18 }

主函数() {
    让 成年 = 真
    打印行(成年 与 年龄判断(18))   // true
    // 如果 (1) { }                 // ❌ 条件里不能放数字
}
```

**注意事项**：方言别名 `真`/`假`；**运行时输出保持官方格式**——`打印行(真)` 输出 `true`（方言只转译代码，不翻译运行时输出）。

## 9.6 字符与字符串

**定义**：`字符`（Rune）= 单个 Unicode 字符（单引号）；`字符串`（String）= 不可变 Unicode 字符序列（双引号）。

```cangjie
导入 标准集合.*
主函数() {
    让 c = '颉'
    打印行(c)                          // 颉
    打印行("仓颉".长度)               // 6 —— 是【字节数】！UTF-8 下每个汉字 3 字节
    打印行("仓颉编程"[0..3])          // 仓（切片按字节切，1 汉字 = 3 字节）
    打印行("仓颉".字符流() |> 第一个) // Some(仓)（第一个 返回选项，取真值用 获取或抛出()）
}
```

**注意事项（新手必踩两坑）**：

- **坑 1**：`字符串[i]` 返回的是**字节**（UInt8）——中文会取到半个字！`"仓颉"[0]` 不是「仓」；
- **坑 2**：切片 `s[起..止]` 按字节切——起止必须落在汉字边界上，否则**运行时抛异常**；
- 按字符处理用 `字符流()`（惰性迭代器）；字符串用 `+` 拼接（少量），批量拼接用 `收集字符串`（第 10 章）。

## 9.7 数组与元组

**定义**：`数组<T>`：定长、连续内存、下标 O(1) 访问；元组 `(T1, T2, ...)`：把**不同类型**打包成一个。

```cangjie
主函数() {
    // 数组：定长
    让 固定 = [10, 20, 30]
    打印行(固定[1])              // 20
    让 空数组: 数组<整数> = []   // 空数组必须标注类型

    // 元组：类型可混装
    让 学生 = (1, "小明", 真)
    打印行(学生[0])            // 1（元组用 [下标] 访问）
    让 (编号, 名字, 在籍) = 学生   // 解构：一次拆包
    打印行(名字)               // 小明
}
```

**注意事项**：数组**不可改变长度**（动态增删用 `向量`，第 11 章）；下标越界运行时抛异常；`(1)` 是数字不是元组——单元素元组写 `(1,)`。

## 9.8 范围（Range）

**定义**：`起点..终点`（半开区间，不含终点）与 `起点..=终点`（闭区间，含终点）——循环、切片、判断归属的通用抽象。

```cangjie
导入 标准集合.*
主函数() {
    对于 (i in 1..5) { 打印行(i) }     // 1 2 3 4（半开区间，不含尾）
    对于 (i in 1..=5) { 打印行(i) }    // 1 2 3 4 5（闭区间）
    打印行((1..10) |> 包含(3))         // true（区间包含判断，注意区间要加括号）
}
```

**注意事项**：范围默认升序；`5..1` 是空范围（不报错）；判断归属用管道 `(1..10) |> 包含(3)`。

## 9.9 类型推断与标注

**定义**：局部变量不写类型，编译器从初始值推断——「写起来像动态语言，查起来像静态语言」。**可推断处不写，关键处必写**。

```cangjie
主函数() {
    让 分数 = 90              // 推断为 整数
    让 名字 = "小明"          // 推断为 字符串
    让 列表 = [1, 2, 3]       // 推断为 数组<整数>
    让 年龄: 整数32 = 12      // 强制 32 位（必须标注）
}
```

**必须标注的场景**：

- 空容器/空数组（`[]`、`向量<整数>()` 无法推断）；
- 需要特定位宽（`整数32`、`浮点32`）；
- **函数参数**（不推断——参数是接口契约的一部分）。

**注意**：标注与推断冲突时以标注为准（`让 x: 浮点 = 1` 合法，字面量自适应为 1.0）。

## 9.10 类型转换：全部显式

**定义**：仓颉**不做隐式转换**——每个转换点都要显式写出。隐式转换是 bug 温床（`"1" + 1` 到底是啥？），显式让每个转换点可见、可控、可审。

**中文语法**：

```cangjie
导入 转换.*
主函数() {
    让 分数 = 95
    打印行(分数.转换字符串())        // "95"（toString）

    让 比例: 浮点 = 浮点(分数)       // 整数 → 浮点（构造器）
    让 整 = 整数(3.9)                // 3（截断小数，向零截断：整数(-3.9) → -3）
    打印行(整)

    打印行(整数.解析("12"))         // 12（解析返回 整数；输入非法会抛异常——先判断更安全，第 14 章）
}
```

**转换方式对照**：

| 场景 | 写法 |
|---|---|
| 数字族互转 | 构造器：`整数(x)`、`浮点(x)`、`整数32(x)` |
| 数字 → 字符串 | `分数.转换字符串()`（需 `导入 转换.*`） |
| 字符串 → 数字 | `整数.解析("42")`（非法输入抛异常，先判断或捕获） |
| 类型层次转换 | `作为`（as）——只用于类层次，**不能**用于数字（第 12 章） |

**注意事项**：`作为`（as）与数值构造器是两回事——`整数(3.9)` 是数值转换，`(宠物 作为 狗)` 是类型层次转换（第 12 章）。

## 9.11 官方对照

```cangjie
// 官方仓颉：同样的代码
main() {
    let age: Int64 = 18
    let name: String = "小明"
    var count = 0
    count += 1
    let tuple = (1, "小明", true)
    let (id, n, ok) = tuple
    println("${name} ${age} 岁")
}
```

## ✳ 设计思想

1. **不可变默认（let 优先）**：可变性 = 意外修改 + 并发竞争 + 难以推理。把「不可变」设为默认，`可变` 变成需要申请的特权——扫一眼 `可变` 就知道哪里可能变化；
2. **强类型 + 全量推断**：兼得两派优点——动态语言的书写体验 + 静态语言的安全性。原则：可推断处不写，关键处必写（参数、边界、契约）；
3. **消灭隐式转换**：隐式转换让「类型」失去意义（编译器不知道、读者不知道、运行时才知道）。显式转换是「把错误挡在编译期」哲学的落地；
4. **值类型与引用类型分工**（第 12 章展开）：值类型拷贝语义（可预测、线程安全），引用类型共享语义（高效、多态）。类型作者决定语义，而不是调用方；
5. **字面量多态**：`42` 没有固定类型、按上下文取型——但**变量**间绝不隐式转换：字面量是「没有过去」的值，变量有。

## 小结

- 三种绑定：`让`（默认，不可变）/ `可变`（申请来的特权）/ `常量`（编译期）；
- 类型体系：整数族/浮点族/字符串/布尔/字符/单元/空类型；后缀小写（i64/u64/f32/u8）；
- 字符串按**字节**计长与切片——按字符用 `字符流()`；数组定长、元组打包、范围半开；
- 推断可省标注，但空容器/特定位宽/参数必须标注；
- 转换全部显式：构造器（数字互转）、`转换字符串`/`解析`（字符串↔数字）、`作为`（类层次）。
