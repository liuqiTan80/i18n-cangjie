# 第 8 章 函数深入

> **本章学习目标**：把函数用透——返回的细节、多返回值、命名参数、重载、lambda 与闭包。
> **读完本章你能回答**：为什么参数必须标注类型？lambda 和普通函数什么关系？「闭包」捕获了什么？

---

## 8.1 定义：函数的完整语法

**定义**：一段可复用、有名字、可调用的代码块。完整形态：

```
函数 名称(参数1: 类型, 参数2: 类型): 返回类型 {
    函数体
    ...
    返回 结果
}
```

**中文语法要点**：

| 部分 | 写法 | 说明 |
|---|---|---|
| 关键字 | `函数` | = 官方 `func` |
| 入口 | `主函数()` | **不带**「函数」前缀——`函数 主函数` 是语法错误（官方 `func main` 同样错误） |
| 参数 | `(分数: 整数)` | **必须显式标注类型**（不推断）——参数是接口契约 |
| 返回类型 | `: 字符串` | 无返回值可省略（隐式返回 `单元`） |
| 返回值 | `返回 值` | 交出结果并**立即结束**函数 |

**示例**：

```cangjie
函数 两倍(数: 整数): 整数 {
    返回 数 * 2
}

函数 求面积(宽: 浮点, 高: 浮点): 浮点 {
    返回 宽 * 高
}

主函数() {
    打印行(两倍(21))          // 42
    打印行(求面积(3.0, 4.0))  // 12.0
}
```

**注意事项**：

- 参数是**只读绑定**——不能给参数重新赋值；
- 声明了 `: 字符串` 就必须**所有路径**都返回——漏一条编译器报「函数缺少返回」；
- 函数名用「动词 + 对象」风格（`计算总分`、`读取文件`）。

## 8.2 返回与提前返回

**定义**：`返回 值` 把结果交出去并立即结束函数；函数体**最后一条表达式的值**也会自动作为返回值（尾部表达式）——但推荐显式 `返回` 更清楚。

```cangjie
函数 绝对值(数: 整数): 整数 {
    如果 (数 < 0) {
        返回 -数        // 提前返回：负数直接取反结束
    }
    返回 数             // 走到这里说明 数 >= 0
}

主函数() {
    打印行(绝对值(-5))   // 5
    打印行(绝对值(3))    // 3
}
```

**注意事项**：

- `返回` 后不能有语句（不可达代码警告）；
- **兜底返回**是惯用套路：前面的 `返回` 都立刻结束函数，最后一行 `返回` 不需要 `否则` 包裹；
- 无返回值的函数可以不写 `返回`。

## 8.3 多返回值：元组 + 解构

**定义**：一个函数只能返回一个值，但可以是**元组**——把多个值打包。调用方用**解构**一次拆开。

```cangjie
函数 求最值(列表: 数组<整数>): (整数, 整数) {
    返回 (列表[0], 列表[列表.长度 - 1])
}

主函数() {
    让 (最小, 最大) = 求最值([3, 7, 2, 9])
    打印行("最小${最小} 最大${最大}")   // 最小3 最大9
}
```

**注意事项**：

- 元组用 `[下标]` 访问（`学生[0]`），解构用 `让 (a, b) = 元组`；
- `(1)` 是普通数字不是元组——单元素元组要写 `(1,)`；
- 超过 12 个元素考虑建结构体/类（第 12 章）。

## 8.4 命名参数：不怕记错顺序

**定义**：参数多的时候，按位置传参容易记错顺序。声明时参数名后加 `!`，调用时按 `名字: 值` 传。

**中文语法**：

```cangjie
函数 设置(年龄: 整数, 名字!: 字符串, 班级!: 字符串) {
    打印行("${名字} ${年龄}岁 ${班级}")
}

主函数() {
    设置(12, 名字: "小明", 班级: "初一2班")
}
```

**注意事项**：

- **未命名参数必须在前**（`设置(12, ...)`），命名参数写在后；
- 参数名写错报「找不到参数」；
- 命名参数是接口**自文档化**的手段——调用处直接看到「这个名字配这个值」。

## 8.5 函数重载：一个名字，多种语义

**定义**：同名函数、**参数不同**（个数或类型），编译器按实参选版本。

```cangjie
函数 描述(x: 整数): 字符串 { 返回 "整数：${x}" }
函数 描述(x: 字符串): 字符串 { 返回 "文本：${x}" }

主函数() {
    打印行(描述(1))        // 整数：1
    打印行(描述("嗨"))     // 文本：嗨
}
```

**注意事项**：

- **仅返回类型不同不能重载**（会冲突）；
- 重载解析有歧义时编译器优先精确匹配。

## 8.6 lambda：没有名字的函数

**定义**：函数字面量——`{ x => x * 2 }`，花括号包整体，`参数 => 表达式`。lambda 是**一等公民**：可赋值、可传参、可返回。

```cangjie
导入 标准集合.*
函数 应用两次(f: (整数) -> 整数, x: 整数): 整数 {
    返回 f(f(x))
}

主函数() {
    让 翻倍 = { x => x * 2 }
    打印行(应用两次(翻倍, 3))      // 12（函数可赋值、可传参）

    可变 名单 = 向量<整数>()
    名单.添加(1); 名单.添加(2); 名单.添加(3)
    让 双倍后 = 名单 |> 映射({ x => x * 2 }) |> 收集数组
    打印行(双倍后)                   // [2, 4, 6]
}
```

**注意事项**：

- 多参数写法：`{ x, y => x + y }`；
- lambda 参数类型通常由上下文推断；
- 函数类型写法：`(整数) -> 整数`；
- `\x => ...` 是其他语言的语法，仓颉**不认**。

## 8.7 闭包：能记住环境的函数

**定义**：lambda 能**捕获**定义处作用域的变量——函数「记住」了诞生时的环境，即使那个变量已经离开了原来的作用域。

```cangjie
函数 造加法器(增量: 整数): (整数) -> 整数 {
    返回 { x => x + 增量 }       // 捕获 增量
}

主函数() {
    让 加5 = 造加法器(5)
    打印行(加5(10))              // 15
}
```

**注意事项**：

- 捕获的是**变量本身**（不是快照值）——如果被捕获变量在 lambda 调用前被修改，lambda 看到的是新值；
- 闭包是「函数 + 环境」的组合，是回调和事件处理的基石。

## 8.8 默认参数：不给也能调

**定义**：参数声明时给默认值，调用时可以不传——官方 1.0.5 写法是 `参数: 类型 = 默认值`。**实测：zhc 方言检查器暂不支持该写法**（会报「期望 `,`，实际得到 `)`」），教学阶段用**重载**实现同样的效果（以后写官方仓颉时，默认参数自然切换）：

```cangjie
函数 打招呼(): 字符串 {
    返回 打招呼("朋友")      // 重载：无参版本复用带参版本
}

函数 打招呼(名字: 字符串): 字符串 {
    返回 "你好，${名字}！"
}

主函数() {
    打印行(打招呼())           // 你好，朋友！（用默认值）
    打印行(打招呼("小明"))     // 你好，小明！
}
```

**注意事项**：

- 官方默认参数要放在参数列表**末尾**（有默认值的参数之后不能再有必传参数）；重载按参数个数/类型区分，注意别让两个版本互相歧义；
- 与命名参数 `!` 配合使用更清晰。

## 8.9 官方对照

```cangjie
// 官方仓颉：同样的代码
func 评级(分数: Int64): String {
    if (分数 >= 90) { return "优秀" }
    else if (分数 >= 60) { return "及格" }
    else { return "加油" }
}

main() {
    let f = { x => x * 2 }
    println(f(21))    // 42
    println(评级(85))
}
```

方言与官方对应：`函数`→func、`返回`→return、`主函数`→main、`数组`→Array、`向量`→ArrayList。

## ✳ 设计思想

1. **显式接口契约**：函数参数必须标注类型——接口的每个细节写在明面上，调用方与编译器看到同一份契约；
2. **一等函数**：函数可以像值一样传递（lambda）——这是函数式风格（`映射`/`过滤`，第 11 章）的地基；
3. **闭包是延迟执行**：`造加法器(5)` 没有立即算出结果，而是把「计算配方」存起来等调用——「把动作存起来，晚点再执行」是回调、定时器等一切异步设计的思想原型；
4. **少即是多**：重载、命名参数、默认参数都服务于同一个目标——**让调用点好读**。接口设计的第一原则：调用方体验优先。

## 小结

- `函数 名(参数: 类型): 类型 { 返回 ... }`；参数必须标注、只读；所有路径必须返回；
- 多返回值 = 元组 + 解构 `让 (a, b) = ...`；
- 命名参数：声明加 `!`、调用按 `名: 值`，未命名参数在前；
- 重载按参数（个数/类型）区分，仅返回类型不同不行；
- lambda `{ x => x * 2 }` 是一等公民；闭包捕获定义处环境；「不给也能调」用重载实现（官方默认参数 `= 默认值` 放末尾，zhc 暂不支持）。
