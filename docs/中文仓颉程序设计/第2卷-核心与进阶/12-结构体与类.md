# 第 12 章 结构体与类

> **本章学习目标**：掌握组织数据的两种方式——`结构体`（值语义）与 `类`（引用语义），理解开放/重写/接口/多态的显式设计，学会用属性、类型测试写出安全的面向对象代码。
> **读完本章你能回答**：结构体和类有什么区别？为什么仓颉的类默认不能继承？`重写` 忘写会发生什么？

---

## 先导故事：相关的东西，捆在一起

描述一个点：横坐标 x、纵坐标 y。分开写两个变量，还得时刻记住「x 配 y」。**结构体**把相关的数据捆成一个整体——像一张**体检表**，表格把身高、体重、视力固定在一起：

```cangjie
结构体 点 {
    公开 可变 x: 整数
    公开 可变 y: 整数
    初始化(x: 整数, y: 整数) {
        本对象.x = x
        本对象.y = y
    }
    公开 函数 距离平方(): 整数 {
        返回 本对象.x * 本对象.x + 本对象.y * 本对象.y
    }
}

主函数() {
    让 原点 = 点(3, 4)
    打印行("坐标（${原点.x}，${原点.y}）")
    打印行("到原点距离的平方：${原点.距离平方()}")
}
```

- `结构体 点`：定义一种「点」形状的盒子，里面装 x 和 y；
- `初始化(...)`：**构造**——造这个盒子时把原料放进去；
- `本对象`：指「当前这个盒子自己」，`本对象.x` 就是「我自己里面的 x」；
- `点(3, 4)`：按图纸造一个 x=3、y=4 的点（勾股定理：3²+4²=25，输出 25）。

**类**和结构体很像，但更强大——最酷的是**继承**：狗是动物的一种，狗「继承」动物的一切，再加上自己的特点：

```cangjie
开放 类 动物 {
    公开 可变 名字: 字符串
    初始化(名字: 字符串) {
        本对象.名字 = 名字
    }
    公开 开放 函数 叫声(): 字符串 { 返回 "……" }
}

类 狗 <: 动物 {
    初始化(名字: 字符串) {
        超类(名字)
    }
    公开 重写 函数 叫声(): 字符串 { 返回 "汪汪" }
}

主函数() {
    让 旺财 = 狗("旺财")
    打印行("${旺财.名字}说：${旺财.叫声()}")
}
```

- `类 狗 <: 动物`：狗「小于冒号」动物——**狗是动物的一种**，继承动物的所有东西；
- `超类(名字)`：把名字交给「爸爸」动物去处理（借爸爸的构造方法）；
- `重写`：狗把「叫声」从「……」改成「汪汪」——**重写**（覆盖）。

> 为什么需要类和继承？现实世界本身就是一层一层的：「动物 → 狗」「车 → 电动车」。程序照现实写，就好懂、好扩展——以后想加一只猫，不用改动物，只需新写一个 `猫` 类。为什么 `动物` 必须标 `开放`？正文 12.4 会回答。

## 12.1 定义：值语义 vs 引用语义

**定义**：把一组相关数据打包成一个整体，两种方式：

| | `结构体` | `类` |
|---|---|---|
| 语义 | **值类型**：赋值/传参是**整体拷贝** | **引用类型**：赋值/传参是**共享引用** |
| 赋值后 | 改副本**不影响**原件 | 多个变量指向**同一对象**，改一处处处可见 |
| 能力 | 不能继承、无多态 | 可继承、可多态（需 `开放`） |
| 适用 | 小、独立、要安全的数据（坐标、颜色、金额） | 同一份数据多方使用的对象（学生档案、银行账户） |

**经验法则：数据小且独立用结构体，需要多态/共享用类。**

## 12.2 结构体：值类型

**中文语法**：

```cangjie
结构体 点 {
    公开 可变 x: 整数
    公开 可变 y: 整数

    初始化(x: 整数, y: 整数) {
        本对象.x = x
        本对象.y = y
    }

    公开 函数 距离平方(): 整数 {
        返回 本对象.x * 本对象.x + 本对象.y * 本对象.y
    }
}

主函数() {
    让 原点 = 点(3, 4)
    打印行("点坐标：(${原点.x}, ${原点.y})")
    打印行("距离平方：${原点.距离平方()}")   // 25

    可变 拷贝 = 原点                        // 值语义：整体拷贝
    拷贝.x = 100                            // 只改拷贝
    打印行("${原点.x} ${拷贝.x}")           // 3 100（原点不受影响）
}
```

**注意事项**：

- `初始化` 是构造器，构造器里用 `本对象` 指当前实例；
- 成员默认**私有**，对外可见要标 `公开`；
- 结构体**不能继承**、不能有抽象成员——「小数据 + 无多态」场景的默认选择。

## 12.3 类：引用类型

**中文语法**：

```cangjie
类 学生 {
    公开 可变 名字: 字符串
    公开 可变 分数: 整数

    初始化(名字: 字符串, 分数: 整数) {
        本对象.名字 = 名字
        本对象.分数 = 分数
    }

    公开 函数 评级(): 字符串 {
        如果 (本对象.分数 >= 90) { 返回 "优秀" }
        返回 "加油"
    }
}

主函数() {
    让 小明 = 学生("小明", 95)
    让 小红 = 小明                        // 引用语义：指向同一对象
    小红.分数 = 70
    打印行("${小明.名字}：${小明.评级()}")   // 小明：加油（小明也被改了！）
}
```

**注意事项**：字段默认私有（类外不可见）；类默认**不可继承**（要 `开放`）——两条都是显式安全设计。

## 12.4 开放与重写：默认封闭的继承

**定义**：继承会打破封装（子类依赖父类内部细节），所以仓颉把继承做成**需要显式申请的特权**——`开放` 是「我允许别人扩展我」的声明，`重写` 是「我确实在覆盖父类方法」的声明。

**中文语法**：

```cangjie
开放 类 动物 {
    公开 开放 函数 叫声(): 字符串 { 返回 "……" }
}

类 狗 <: 动物 {
    公开 重写 函数 叫声(): 字符串 { 返回 "汪汪" }
}

主函数() {
    让 旺财: 动物 = 狗()       // 父类类型装子类对象
    打印行(旺财.叫声())        // 汪汪（动态分派：运行时决定用哪个实现）
}
```

**三条硬规则（官方 1.0.5 实测）**：

| 规则 | 后果 |
|---|---|
| 非 `开放` 类被继承 | 编译错误「非开放类型不能被继承」 |
| 父类方法没标 `开放` 却重写 | 编译错误（不能重写） |
| 重写时不写 `重写` 关键字 | 编译错误——`重写` 是**强制声明**，防止「想重写却拼错名字变成新方法」的经典 bug |

## 12.5 继承与超类

**定义**：「狗属于动物」的「属于」关系用 `类 狗 <: 动物` 表达（`<:` 读作「子类型于」）。子类继承父类的一切，并可用 `超类(...)` 调父类构造器、`超类.方法()` 复用父类逻辑。

**中文语法**：

```cangjie
开放 类 动物 {
    公开 可变 名字: 字符串
    初始化(名字: 字符串) { 本对象.名字 = 名字 }
    公开 开放 函数 介绍(): 字符串 { 返回 "我是${本对象.名字}" }
}

类 狗 <: 动物 {
    初始化(名字: 字符串) {
        超类(名字)              // 第一句：调用父类构造器
    }
    公开 重写 函数 介绍(): 字符串 {
        返回 "${超类.介绍()}，一只狗"    // 复用父类逻辑再扩展
    }
}

主函数() {
    打印行(狗("旺财").介绍())   // 我是旺财，一只狗
}
```

**注意事项**：

- 仓颉**单继承**（一个类只能有一个父类）；
- 子类构造器**必须先调 `超类(...)`** 再初始化自己的字段；
- 字段与构造参数同名时**必须**用 `本对象.` 区分——否则 `名字 = 名字` 是自己赋自己，字段未初始化，编译器报错。

## 12.6 接口：能力清单

**定义**：只声明方法签名（可带默认实现）、不含状态的**纯行为契约**。类只能单继承，但可以实现**多个接口**——接口是「能力清单」。

**中文语法**：

```cangjie
接口 会叫 {
    函数 叫声(): 字符串
}

类 狗 <: 会叫 {
    公开 函数 叫声(): 字符串 { 返回 "汪汪" }
}

类 猫 <: 会叫 {
    公开 函数 叫声(): 字符串 { 返回 "喵" }
}

主函数() {
    让 宠物: 会叫 = 狗()
    让 猫咪: 会叫 = 猫()
    打印行(宠物.叫声() + 猫咪.叫声())   // 汪汪喵
}
```

**注意事项**：接口方法默认**公开**；`<:` 同时用于继承与实现接口；实现类**必须实现所有无默认方法**（漏一个编译报错）；接口变量只能调用接口声明的方法。

## 12.7 抽象与静态

**定义**：**抽象类** = 标记「未完成品」——抽象类**不能实例化**，只用来被继承；抽象方法没有函数体，强制子类实现。**静态成员** = 属于**类本身**（而非实例）。

**中文语法**：

```cangjie
抽象 类 形状 {
    公开 函数 面积(): 浮点        // 抽象方法：不写函数体即可
}

类 正方形 <: 形状 {
    公开 可变 边长: 浮点
    初始化(边长: 浮点) { 本对象.边长 = 边长 }
    公开 重写 函数 面积(): 浮点 { 返回 本对象.边长 * 本对象.边长 }
}

类 工具 {
    静态 函数 两倍(数: 整数): 整数 { 返回 数 * 2 }
    静态 可变 调用次数: 整数 = 0
}

主函数() {
    打印行(正方形(3.0).面积())    // 9.0
    工具.调用次数 += 1
    打印行(工具.两倍(21))        // 42
}
```

**注意事项**：抽象类**自动开放**；子类不实现全部抽象方法就必须也标 `抽象`；静态方法**不能访问实例字段/`本对象`**；静态可变成员是全局状态（并发要加同步）。

## 12.8 属性与访问器：封装的平衡点

**定义**：**属性**：外部像字段一样读写、内部由 `获取()` 控制的成员——「数据可见但不可篡改」；**可变属性**：可读可写，`获取()` 与 `设置(值)` 成对出现。

**中文语法**：

```cangjie
类 书 {
    私有 可变 书名值: 字符串 = ""
    公开 属性 书名: 字符串 {
        获取() { 返回 本对象.书名值 }
    }
    初始化(书名: 字符串) { 本对象.书名值 = 书名 }
}

类 温度计 {
    私有 可变 摄氏值: 浮点 = 0.0
    公开 修改 属性 摄氏: 浮点 {
        获取() { 返回 本对象.摄氏值 }
        设置(值) { 本对象.摄氏值 = 值 }    // 参数是赋入的新值
    }
}

主函数() {
    让 书 = 书("仓颉字典")
    打印行(书.书名)              // 仓颉字典
    // 书.书名 = "别的"  ← 编译错误：属性 只读，不能赋值

    让 计 = 温度计()
    计.摄氏 = 36.5               // 走 设置
    打印行(计.摄氏)              // 36.5（走 获取）
}
```

**注意事项**：`属性` **只读**——只能定义 `获取()`；`修改 属性` 必须同时提供 `获取()` 和 `设置(参数)`；`获取()` 的括号**不能省略**（官方 1.0.5 语法）；访问器在类内部，可以访问私有字段。

## 12.9 修改：结构体可变成员函数

**定义**：结构体是值类型，`让` 绑定又不可变——若成员函数能悄悄改写字段，拷贝出的副本会「偷偷变化」。`修改` 把「这个函数会改变自身」变成**可见的许可**。

**中文语法**：

```cangjie
结构体 计数器 {
    公开 可变 值: 整数
    初始化(值: 整数) { 本对象.值 = 值 }
    公开 修改 函数 自增() {
        本对象.值 += 1           // 修改 函数才能修改结构体自身
    }
}

主函数() {
    可变 数 = 计数器(1)
    数.自增()
    打印行(数.值)               // 2
}
```

**三条硬规则（官方 1.0.5 实测）**：

| 规则 | 后果 |
|---|---|
| `让` 绑定的实例上调 `修改` 函数 | 编译错误（`让` 不可变，需 `可变`） |
| `修改` 修饰类的方法 | 编译错误（类的方法天然能改字段，禁止加 `修改`） |
| `修改` 修饰参数/成员变量/静态函数 | 编译错误（`修改` **只能**修饰结构体/接口的实例成员函数） |

## 12.10 类型测试与转换（是 / 作为）

**定义**：拿到父类类型变量，想知道它到底是不是某个子类——`是` 类型测试返回布尔；`作为` 向下转换返回 `选项<T>`。

**中文语法**：

```cangjie
开放 类 动物 {}

类 狗 <: 动物 {
    公开 函数 摇尾巴(): 字符串 { 返回 "摇尾巴" }
}

类 猫 <: 动物 {}

主函数() {
    让 宠物: 动物 = 狗()            // 向上转换（子→父）：自动、永远安全
    如果 (宠物 是 狗) {             // `是`：类型测试，返回布尔
        打印行("是狗")
    }
    打印行(宠物 是 猫)               // false（运行时输出官方格式）

    让 旺财 = (宠物 作为 狗).获取或抛出()   // 向下转换（父→子）：必须 作为
    打印行(旺财.摇尾巴())
}
```

**注意事项**：向下转换可能失败（动物不一定是狗）——`作为` 返回 **`选项<T>`**（失败是 `无值`），用 `.获取或抛出()` 解包或 `匹配` 处理；更稳妥是先 `是` 判断再 `作为`；**数字转换与类型层次转换是两回事**（`整数(3.9)` 是数值转换，第 9 章）。

## 12.11 多态与动态绑定

**定义**：接口/父类类型变量可以装任意实现/子类对象，调用方法时**运行时**决定执行哪个版本——**面向接口编程**：代码依赖「抽象」而不是「具体」。

**中文语法**：

```cangjie
接口 会叫 {
    函数 叫声(): 字符串
}

类 狗 <: 会叫 {
    公开 函数 叫声(): 字符串 { 返回 "汪汪" }
}

类 猫 <: 会叫 {
    公开 函数 叫声(): 字符串 { 返回 "喵" }
}

函数 齐声叫(宠物们: 数组<会叫>) {
    对于 (宠物 in 宠物们) {
        打印行(宠物.叫声())        // 动态绑定：各自叫各自的
    }
}

主函数() {
    齐声叫([狗(), 猫()])
}
```

**注意事项**：多态只对**引用类型**（类/接口）有效——结构体是值类型，没有动态绑定；`开放` + `重写` + 接口实现共同构成多态三件套。
## ✳ 设计思想

**① 值语义 vs 引用语义：先想清「数据怎么被共享」**。结构体赋值即拷贝——适合「小、独立、要安全」的数据；类实例引用共享——适合「同一份数据多方使用」的对象。

**② 默认封闭：安全设计让「继承」变昂贵而显式**。继承会打破封装——仓颉要求 `开放` 才可继承、`重写` 才可覆盖，把「扩展点」变成类作者的显式决策：写类时想清楚哪些部分是留给后人扩展的，其余默认封死。

**③ 封装的三个层次**：`公开 可变`（全开放）→ `属性`/`修改 属性`（数据可见但读写受控）→ `私有`（完全隐藏）。先用最简的，需要校验/缓存再升级成属性，调用方代码不用改。

**④ 组合优于继承**：结构体可以嵌套在类里。能用组合表达的「拥有」关系不要硬造继承——继承适合「属于」关系且确有多态需求时。

**⑤ 面向接口编程**：`齐声叫` 只依赖 `会叫`，不知道也不关心具体是狗还是猫。把「变化的部分」抽象成接口，是软件可扩展性的核心手段。

**⑥ 显式优于隐式**：`重写` 强制声明防止拼错名字、`修改` 可见许可防止副本悄悄变化、`作为` 显式转换防止类型错配——仓颉把「可能出错的地方」都变成显式的编译期检查。

## 练习

1. 定义 `结构体 矩形`（宽/高 + `面积()` 方法），验证赋值拷贝互不影响；
2. 定义 `类 学生`（名字/成绩 + `评级()`），用 `向量` 保存 3 个学生，遍历打印平均分；
3. 定义 `接口 会移动`（`移动(距离: 整数)`），让 `类 汽车` 和 `类 自行车` 实现它，写一个接受接口数组并让全部移动的函数；
4. 给 `温度计` 的 `设置` 加校验：只接受 -50 到 150 之间的值，否则抛异常；
5. 思考：为什么 `让 数 = 计数器(1); 数.自增()` 会编译报错？`可变 数` 后为什么就好了？

## 小结

- `结构体` 值语义（赋值即拷贝）、`类` 引用语义（赋值共享）；字段默认私有；
- 继承/接口实现用 `<:`；继承与重写需父类 `开放` + 子类 `重写` 双显式标注；
- `超类(...)` 调父类构造器（必须第一句）、`超类.方法()` 复用父类逻辑；单继承、可多实现接口；
- `属性` 只读、`修改 属性` 可读写（`获取()`/`设置(值)` 成对）；`修改` 只修饰结构体/接口的实例成员函数；
- `枚举` 可带数据、匹配强制穷尽；`是` 测试类型、`作为` 向下转换（返回 `选项`）；
- 多态 = 接口/父类变量 + 运行时动态绑定，只对引用类型有效。

## 思考题

1. 为什么仓颉要求父类 `开放` + 子类 `重写` 双声明？去掉任何一个会带来什么 bug？（提示：拼错方法名、意外继承）
2. 结构体赋值是拷贝——两个变量指向同一块数据，还是两块独立数据？为什么说这「线程安全」？
3. `作为` 向下转换返回 `选项`——为什么不是直接返回对象或抛异常？（提示：预期失败 vs 意外错误，第 14 章）
4. 多态只对引用类型有效——结构体为什么不能多态？「值类型没有动态绑定」意味着什么？
