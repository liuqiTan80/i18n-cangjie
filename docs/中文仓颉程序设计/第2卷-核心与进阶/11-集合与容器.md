# 第 11 章 集合与容器

> **本章学习目标**：熟练使用三种容器——向量（动态列表）、哈希映射（键值对）、哈希集合（去重），学会用 `映射`/`过滤`/`求和`/`排序` 做声明式数据处理。
> **读完本章你能回答**：什么时候用向量、什么时候用哈希映射？取不存在的键会发生什么？`映射` 为什么不立刻出结果？

---

## 先导故事：一个盒子装不下怎么办？

班里 45 个同学的成绩，难道写 45 个变量？**向量**（动态列表）就是用来装一长串东西的「书包」：

```cangjie
导入 标准集合.{向量}

主函数() {
    可变 成绩单 = 向量<整数>()
    成绩单.添加(95)
    成绩单.添加(88)
    成绩单.添加(76)
    打印行("一共有${成绩单.大小}个成绩")
    打印行("第一个成绩：${成绩单[0]}")
}
```

- `向量<整数>()`：一个专门装整数的空书包；
- `成绩单.添加(95)`：往书包里放一个；
- `成绩单.大小`：数一数有几个（直接读属性，不加括号）；
- `成绩单[0]`：取第 1 个（**编号从 0 开始**——0 是第一个、1 是第二个，这是编程界的规矩）。

但「按第几个找」有时不够：想输入「旺财」马上知道它几岁，按名字找更自然。**哈希映射**（字典）就是点名册——一格放**钥匙**（名字）、一格放**值**（信息）：

```cangjie
导入 标准集合.{哈希映射}

主函数() {
    可变 宠物年龄 = 哈希映射<字符串, 整数>()
    宠物年龄["旺财"] = 3
    宠物年龄["咪咪"] = 5
    让 旺财年龄 = 宠物年龄["旺财"]
    打印行("旺财${旺财年龄}岁")
    打印行("家里有${宠物年龄.大小}只宠物")
}
```

> 类比：向量像**排队**（第 0 个、第 1 个……按顺序找）；哈希映射像**点名册**（按名字找，不用排队）。

这两个直觉就是本章的核心：先想清「我要按什么查」，再选容器。取不存在的键会发生什么？正文 11.3 会回答。

## 11.1 定义：三种容器各回答一个问题

**定义**：容器 = 装一长串数据的「书包」。先想清「我要查什么、按什么查」，再选容器——这比记住 API 重要得多：

| 容器 | 官方 | 回答的问题 | 代价 |
|---|---|---|---|
| `数组`/`向量` | Array/ArrayList | 「按顺序存什么」 | 查找要遍历 O(n) |
| `哈希映射` | HashMap | 「这个键对应什么」 | 无序、键要可哈希 |
| `哈希集合` | HashSet | 「这个值在不在」 | 无序、不能重复 |

- **数组**（第 9 章）：定长、不可增删；
- **向量**：可动态增删的列表——不知道会加多少元素时用它（**动态列表的默认选择**）；
- **哈希映射**：`键 → 值` 对应表，按名字查数据，平均 O(1) 查询；
- **哈希集合**：只关心「在不在」，元素不重复，`包含` 判断 O(1)。

## 11.2 向量（向量 / ArrayList）：动态列表

**中文语法**：

```cangjie
导入 标准集合.{向量}
主函数() {
    可变 成绩单 = 向量<整数>()
    成绩单.添加(95)               // 追加 = add
    成绩单.添加(88)
    成绩单.添加(76)
    打印行(成绩单.大小)           // 3（大小 是属性，不带括号）
    打印行(成绩单[0])             // 95（下标访问）
    成绩单.删除(1..2)             // 删除只收区间：删下标 1（88）
    打印行(成绩单.大小)           // 2
    对于 (成绩 in 成绩单) {
        打印行("成绩：${成绩}")   // 遍历
    }
}
```

**注意事项（易错）**：

- `大小` 是**属性**不是方法（`.大小`，不带括号；`.长度` 用在字符串/数组上也是属性）；
- 下标越界**运行时抛异常**（如 `成绩单[9]`）——先看 `大小` 再取；
- **向量 `删除` 只收区间**（官方 remove(Range)）：`删除(1..2)` 删 1 个、`删除(1..3)` 删 2 个；按「值」删除没有现成方法，先找下标再删；
- 数组 ↔ 向量互转：`向量.from(数组)`；
- 官方**没有** `反序`（reversed）方法，倒序用下标倒着取：

```cangjie
导入 标准集合.{向量}
主函数() {
    让 原 = [1, 2, 3]
    可变 倒 = 向量<整数>()
    对于 (i in 0..原.长度) {
        倒.添加(原[原.长度 - 1 - i])   // 从最后一个往前取
    }
    打印行(倒[0])                      // 3（原容器不变）
}
```

## 11.3 哈希映射（哈希映射 / HashMap）：键值对

**中文语法**：

```cangjie
导入 标准集合.{哈希映射}
主函数() {
    可变 宠物年龄 = 哈希映射<字符串, 整数>()
    宠物年龄["旺财"] = 3               // 存：映射[键] = 值
    宠物年龄["咪咪"] = 5
    打印行(宠物年龄["旺财"])           // 3（取：映射[键]）
    打印行(宠物年龄.大小)              // 2
    对于 (名字 in 宠物年龄.键()) {      // 键() 取全部键，遍历字典的标配
        打印行("${名字}${宠物年龄[名字]}岁")
    }
}
```

**注意事项（易错）**：

- **取不存在的键会运行时抛异常**（`宠物年龄["不存在"]` 崩溃）——取之前先 `包含` 判断，或用 `获取或默认` 兜底；
- 键必须可哈希：字符串、整数天然可以；自定义类型要实现 `可哈希`（第 12 章）；
- **遍历顺序不保证**（哈希无序）：同一映射两次遍历顺序可能不同，别依赖顺序；
- 改值用 `映射[键] = 新值`；删除用 `映射.删除(键)`（按键删，与向量的区间删除不同）；
- `键()` 是方法（带括号）；返回的是**视图**——遍历时不要增删映射。

**综合实战：统计分组**（官方没有 groupBy，用哈希映射手写——「组名 → 计数」是标准套路）：

```cangjie
导入 标准集合.{向量, 哈希映射}
主函数() {
    可变 成绩 = 向量<整数>()
    成绩.添加(95); 成绩.添加(45); 成绩.添加(70)
    可变 分组 = 哈希映射<字符串, 整数>()
    对于 (分 in 成绩) {
        让 组名 = 如果 (分 >= 60) { "及格" } 否则 { "不及格" }
        分组[组名] = 分组.获取(组名).获取或默认({ => 0 }) + 1
    }
    打印行(分组.大小)       // 2
    打印行(分组["及格"])    // 2
}
```

> `获取(键)` 返回 `选项`，`.获取或默认({ => 0 })` 在键不存在时用 0 起步——这是「计数」的标配写法（`选项` 详解见第 14 章）。

## 11.4 哈希集合（哈希集合 / HashSet）：不重复集合

**中文语法**：

```cangjie
导入 标准集合.{哈希集合}
主函数() {
    可变 已读 = 哈希集合<整数>()
    已读.添加(1)
    已读.添加(1)            // 重复，被忽略
    已读.添加(2)
    打印行(已读.大小)       // 2
    打印行(已读.包含(2))    // true
}
```

**典型应用：去重**（官方没有 distinct 方法，哈希集合天然去重）：

```cangjie
导入 标准集合.{向量, 哈希集合}
主函数() {
    可变 名单 = 向量<整数>()
    名单.添加(1); 名单.添加(2); 名单.添加(1)
    可变 唯一 = 哈希集合<整数>()
    对于 (数 in 名单) { 唯一.添加(数) }   // 重复的 1 被忽略
    打印行(唯一.大小)       // 2
}
```

**注意事项**：哈希集合**无序**（不保证原顺序）；要「保序去重」就手写循环 + `包含` 判断（`如果 (非 结果.包含(数)) { 结果.添加(数) }`）。

## 11.5 高阶函数：映射 / 过滤 / 遍历

**定义**：三个高频「声明式」操作，方言用管道 `容器 |> 函数` 书写：

| 操作 | 作用 | 返回 |
|---|---|---|
| `映射({ x => ... })` | 每个元素做变换 | 惰性迭代器 |
| `过滤({ x => ... })` | 保留满足条件的元素 | 惰性迭代器 |
| `遍历({ x => ... })` | 对每个元素执行动作（打印等） | 单元 |

```cangjie
导入 标准集合.*
主函数() {
    可变 名单 = 向量<整数>()
    名单.添加(1); 名单.添加(2); 名单.添加(3)
    // 映射：每个元素 ×2
    让 翻倍 = 名单 |> 映射({ x => x * 2 }) |> 收集数组
    打印行(翻倍[0])                // 2
    // 过滤：保留 ≥60 的
    可变 成绩 = 向量<整数>()
    成绩.添加(95); 成绩.添加(45); 成绩.添加(70)
    让 及格 = 成绩 |> 过滤({ x => x >= 60 }) |> 收集数组
    打印行(及格.大小)              // 2
    // 遍历：只做动作不要结果
    可变 名单2 = 向量<字符串>()
    名单2.添加("甲"); 名单2.添加("乙")
    名单2 |> 遍历({ 名字 => 打印行("你好，${名字}") })
}
```

**三条真相**：

- **惰性**：`映射`/`过滤` 返回**迭代器**，此刻还没计算——`|> 收集数组` 消费时才逐个算（省内存，可无限链式组合）；
- **原容器不变**：它们产生新序列，不改动原向量；
- `遍历` 返回单元，与 `对于` 循环等价（纯偏好）；lambda 里**不能用** `跳出`/`继续`（它不是循环）——需要提前结束就用 `对于`。

## 11.6 求和 / 累加 / 排序

**定义**：`求和`（fold）：从初始值开始逐个累积；`累加`（reduce）：没有初始值，用第一个元素起步（空容器返回 `选项`）；`排序`：**原地排序**（直接修改原数组）。

**中文语法**：

```cangjie
导入 标准集合.*
导入 排序.*
主函数() {
    // 求和：初始值 0 决定返回类型
    可变 成绩 = 向量<整数>()
    成绩.添加(95); 成绩.添加(85)
    让 总和 = 成绩 |> 求和(0, { 累积, 分 => 累积 + 分 })
    打印行(总和)                   // 180

    // 累加：无初始值，返回 选项（空容器 → 无值）
    让 总和2 = 成绩 |> 累加({ 累积, 分 => 累积 + 分 })
    打印行(总和2.获取或抛出())     // 180

    // 排序：原地修改数组，顶层函数
    可变 分数 = [88, 95, 70]
    排序(分数)                       // 原地升序
    打印行(分数[0])                  // 70
    排序(分数, 降序: 真)             // 原地降序（降序 是命名参数）
    打印行(分数[0])                  // 95
}
```

**注意事项**：

- `排序` 接受**数组**，要求元素可比较；向量要先 `收集数组`（或 `向量.from(数组)` 反向转换）再排；
- 官方旧 API `稳定排序` 已废弃——用 `排序(数据, 稳定: 真)` 表达「相等元素保持原顺序」；
- 想不改变原数据？排序前先拷贝一份。

## 11.7 官方对照

```cangjie
// 官方仓颉
import std.collection.{HashMap, ArrayList}

main() {
    var scores = ArrayList<Int64>()
    scores.add(90)
    scores.add(80)
    println("size = ${scores.size}")
    println("first = ${scores[0]}")

    let book = HashMap<String, Int64>()
    book["小明"] = 10086
    println("小明号码：${book["小明"]}")
}
```

方言与官方一一对应：`向量`→ArrayList、`哈希映射`→HashMap、`添加`→add、`大小`→size、`映射[键]=`→put、`获取`→get、`键()`→keys()。

## ✳ 设计思想

**① 容器选择是「数据结构」决策**：先想清「我要查什么、按什么查」，再选容器——按顺序 → 向量；按名字 → 哈希映射；只问在不在 → 哈希集合。

**② 可变性纪律：原地 vs 新容器**：`排序` 原地修改（不产生新值），`映射`/`过滤` 产生新序列（不动原容器）。函数式风格偏向后一种——原数据是「输入」，不会被悄悄改掉，调试时心智负担小。

**③ 声明式 > 命令式**：`成绩 |> 过滤({ x => x >= 60 }) |> 收集数组` 读起来就是「过滤掉不及格的，收集成数组」——意图直说；手写循环则要读者自己「翻译」意图。声明式代码把「做什么」与「怎么做」分开。

**④ 惰性求值：用多少算多少**：迭代器不一次性算完，链式组合时每个元素只过一遍管道——这是「映射为什么不出结果」的答案：它还没被消费。

## 练习

1. 用 `哈希映射` 实现「单词 → 释义」小字典（至少 3 条），用 `键()` 遍历打印全部条目；
2. 用 `向量` 收集 1..100 的偶数，再用 `求和` 算出总和（提示：`过滤({ x => x % 2 == 0 })`）；
3. 用 `向量` 存 3 个学生的成绩，`排序` 后打印从高到低（提示：`降序: 真`）；
4. 思考：为什么 `映射` 的结果必须用 `收集数组` 才能反复使用？直接打印迭代器会看到什么？
5. 挑战：把 11.3 的分组统计改成「按分数段（优/良/及格/不及格）」四组。

## 小结

- 三容器：向量（动态列表，`删除` 只收区间）、哈希映射（键值对，取不存在的键**抛异常**）、哈希集合（去重）；
- 高阶函数管道：`容器 |> 映射/过滤/遍历/求和/累加 |> 收集数组`——惰性、不动原容器；
- `排序` 是顶层函数（`导入 排序.*`），原地修改，`降序`/`稳定` 命名参数；
- 运行时输出保持官方格式（`真` → `true`）。

## 思考题

1. 查一个值：数组要 O(n) 遍历，哈希映射要 O(1)——为什么哈希映射快？代价是什么？（提示：无序 + 键必须可哈希）
2. `成绩单.删除(1..2)` 删了几个元素？`删除(1..3)` 呢？（提示：半开区间）
3. 遍历哈希映射的顺序每次可能不同——写代码时怎么避免依赖顺序的 bug？
4. 为什么 lambda 里不能用 `跳出`/`继续`？想提前结束遍历时怎么办？
