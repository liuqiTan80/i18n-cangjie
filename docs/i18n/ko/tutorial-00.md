# 튜토리얼 안내 — 0과 (한국어)

내비게이션：[튜토리얼 정본(zh)](../../中文仓颉程序设计/README.md) · [English](../en/README.md) · [Français](../fr/README.md) · [Deutsch](../de/README.md) · [Español](../es/README.md) · **한국어** · [日本語](../ja/README.md) · [Русский](../ru/README.md)

정본 튜토리얼 **《中文仓颉程序设计》**는 매뉴얼 스타일의 체계적 강좌입니다:
**3권 20장 + 부록 3편 + 해답집**, **150개 이상의 코드 블록을 공식 `cjc 1.0.5`로
전부 검증**했습니다. 이 페이지는 한국어 0과이며, 정본 본문은 중국어입니다 —
아래 방언 예제와 함께 병행해서 읽어 보세요.

## 세 권의 구성

| 권 | 이런 분께 | 내용 |
|---|---|---|
| 1권 입문 | 완전 초보 | 환경 구축, 첫 프로그램, 변수, 숫자, 조건, 반복, 함수 |
| 2권 핵심과 심화 | 문법 체계 정리 | 함수, 타입 시스템, 문자열, 컬렉션, 객체지향, 열거형, 오류 처리, 제네릭과 매크로 |
| 3권 공학과 사고 | 품질 중심 개발자 | 설계 사고, 알고리즘과 자료구조, 소프트웨어 공학, 종합 프로젝트 |

## 1과: 첫 프로그램

한국어 방언으로 작성해 보세요:

```kc
메인() {
    두다 인사: 문자열 = "안녕, Cangjie!"
    출력(인사)
}
```

`hello.kc`로 저장한 뒤 `ZHCLANG=ko zhc run hello.kc`로 실행합니다. 모든 방언은
정확히 이 표준 코드로 트랜스파일됩니다 — 바뀌는 것은 여러분 언어의 대응표에
따른 키워드와 타입 이름뿐입니다. 현재 제공 방언: `en`/`ru`/`ja`/`ko`/`fr`/
`es`/`de`.

## 어디를 볼까 (빠른 참조)

- 완전 초보 시작 → 1권 01–07장 (각 10–20분, 연습 문제 포함)
- 문법 체계 정리 → 2권 08–15장 (정의 → 문법 → 예제 → 주의)
- 품질과 공학 → 3권 16–19장
- 키워드/표준 라이브러리 조회, 오류 해독 → 부록 A/B/C
