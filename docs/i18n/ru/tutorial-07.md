# Глава 7. Первое знакомство с функциями

> **Цели главы**
> - Понять, что «функция» — это код, упакованный в именованную коробку: берём, когда нужно;
> - Научиться определять функцию: параметры (сырьё) и возврат (готовый продукт);
> - Увидеть, почему функции избавляют от повторов и делают код понятнее.
>
> **Прочитав главу, вы сможете ответить**: чем функция отличается от переменной-коробки? Что такое параметры и возвращаемое значение? Что происходит, когда мы вызываем функцию?

---

## 7.1 Повторяющийся код — в функцию

Вы заметили, что «оценка работы» нужна в трёх местах. Скопировать три раза? Код станет длинным и запутанным: изменишь в одном месте — придётся править три, а где-то забудешь — и вот тебе ошибка.

**Функция** — это решение: упаковать кусок кода в «коробку с инструментами», дать ей имя и доставать, когда нужно.

## 7.2 Определяем функцию

```rc
функция оценка(балл: целое): строка {
    если (балл >= 90) { возврат "Отлично" }
    иначе если (балл >= 60) { возврат "Зачёт" }
    иначе { возврат "Старайся" }
}

главная() {
    печать("Оценка Васи: ${оценка(85)}")
    печать("Оценка Маши: ${оценка(95)}")
}
```

Разберём по частям:

- `функция оценка`: определяем функцию с именем «оценка»;
- `(балл: целое)`: **параметр** — «сырьё», нужное функции для работы. Здесь нужно целое число с именем `балл`;
- `: строка`: **тип возврата** — «готовый продукт», который функция отдаёт наружу, — здесь текст;
- `возврат "Отлично"`: отдаём продукт, и функция **немедленно заканчивается** (код после этого не выполняется);
- `оценка(85)`: **вызов** (использование) функции: передаём ей 85.

> Сравнение: функция — как торговый автомат: бросаешь монетку (параметр) — получаешь товар (возврат). Разные монетки — разный товар.

## 7.3 Параметры и возврат: сырьё и продукт

Ещё один пример — посчитаем площадь прямоугольника:

```rc
функция площадь(ширина: плавающее, высота: плавающее): плавающее {
    возврат ширина * высота
}

главная() {
    печать("Площадь 3×4: ${площадь(3.0, 4.0)}")
    печать("Площадь 5×6: ${площадь(5.0, 6.0)}")
}
```

Несколько деталей:

- **У параметра обязательно указывается тип** (`: плавающее`) — это «договор» функции с внешним миром: что даёшь, что получаешь — всё написано, никакой неясности;
- Параметр **только для чтения** (переприсвоить его нельзя) — это сырьё, переданное на вход: вернуть его и обменять нельзя;
- У функции может быть несколько параметров (через запятую), а может не быть ни одного.

## 7.4 Можно и без сырья, и без продукта

Когда ни параметры, ни возвращаемое значение не нужны — просто оставьте пусто:

```rc
функция приветствие() {
    печать("Привет!")
}

главная() {
    приветствие()
    приветствие()
}
```

- `функция приветствие()`: пустые скобки = сырьё не нужно;
- Нет `: тип возврата` = нет продукта (на самом деле она возвращает пустое значение типа `единица`, но вам об этом думать не нужно);
- Вызвали дважды — напечаталось дважды. **Написал один раз — используешь много**.

## 7.5 Зачем нужны функции?

1. **Нет повторов**: одна и та же логика написана один раз (поменять критерии оценки — правишь одно место);
2. **Легко менять**: изменил в одном месте — изменилось везде, где используется;
3. **Легко читать**: `оценка(85)` сразу понятна, она чище длинной цепочки `если`;
4. **Легко проверять**: маленькую функцию просто проверить отдельно — дай число и посмотри, что вернётся (глава 18 посвящена тестированию).

> Небольшое правило именования функций: «глагол + объект» — `посчитать_итог`, `прочитать_файл`, `площадь`. По имени сразу видно, что функция делает.

## 7.6 Пробуем сами

1. Напишите функцию `сумма(предел: целое): целое`, которая циклом считает `1+2+…+предел`, и вызовите её для 100 и 1000;
2. Напишите функцию `чётность(число: целое): строка`: для чётного возвращает «чётное», для нечётного — «нечётное» (подсказка: `число % 2 == 0` означает делимость на 2, `%` — остаток от деления);
3. Подумайте: 85 в вызове `оценка(85)` и `балл` внутри функции — это одна и та же коробка? — **Нет**! При вызове компьютер создаёт новую коробку `балл` и кладёт туда 85; когда функция заканчивается, коробка исчезает;
4. Вызов: напишите функцию `звёзды(количество: целое)`, печатающую строку из `количество` звёздочек `*`, и вызовите её для 3 строк (количество 1, 2 и 3).

## ✳ Советы программисту: абстракция — прячем детали

Главная ценность функции — не «меньше печатать», а **абстракция**:

- Тому, кто пишет `оценка(85)`, **не нужно знать**, как внутри устроена оценка (не нужно читать длинную цепочку `если`);
- Как со стиральной машиной: вам не нужно знать, как вращается мотор внутри — достаточно знать «заложить бельё, нажать кнопку, достать бельё».

Вот в чём сила абстракции: **«как делать» спрятано внутри, наружу видно только «что делать»**. Каждый слой программы строится на таком «прятанье»:

- Функция прячет логику → главная заботится только о вызовах;
- Класс прячет данные (глава 12) → снаружи видны только методы;
- Языковой пакет прячет словарь (глава 1) → вы просто пишете по-русски.

**Кто умеет программировать — тот умеет строить слои и прятать детали.**

## 🍳 Алгоритм из жизни: торговый автомат

Превратим метафору «оценки» в настоящий код — автомат с четырьмя кнопками:

```rc
функция продажа(кнопка: целое): строка {
    если (кнопка == 1) { возврат "Кола" }
    иначе если (кнопка == 2) { возврат "Апельсиновый сок" }
    иначе если (кнопка == 3) { возврат "Минеральная вода" }
    возврат "Нет такого товара"      // остальные кнопки недействительны
}

главная() {
    печать("Нажать 1: ${продажа(1)}")
    печать("Нажать 2: ${продажа(2)}")
    печать("Нажать 9: ${продажа(9)}")
}
```

В этом примере два маленьких приёма:

- **«Страховочный возврат»**: последнему `возврат` не нужен `иначе` — предыдущие `возврат` немедленно заканчивают функцию, а раз управление дошло до последней строки, значит, все прежние условия не сработали. Излюбленный приём функционального стиля;
- **Функция — «чёрный ящик»**: главная знает только «какая кнопка — какой товар», и совсем не интересуется, как автомат устроен внутри, — это и есть абстракция.

## Итоги

- `функция имя(параметры: типы): тип_возврата { ... }`: определение функции;
- Параметры — сырьё (**тип обязателен**, только для чтения), `возврат` отдаёт продукт и немедленно заканчивает функцию;
- Вызов: `имя(аргументы)`; написал один раз — используешь много;
- Функция без параметров/возврата: пустые скобки, тип возврата не пишем;
- Четыре плюса функций: нет повторов, легко менять, легко читать, легко проверять;
- Идея: **абстракция** — прячем «как делать», показываем «что делать».

## Вопросы для размышления

1. Выполнится ли код после `возврат`? Попробуйте написать `возврат 1`, а строкой ниже — `печать("ещё здесь")`, и посмотрите на вывод — а потом подумайте, почему компилятор предупреждает вас;
2. `оценка(85)` и `оценка(85.5)` — что правильно? Почему? (подсказка: тип параметра — `целое`);
3. При вызове функции коробка параметра и переменная снаружи — это одно и то же? (задача 3 из 7.6) От чего это защищает?
4. Вызов: напишите функцию `максимум(а: целое, б: целое): целое`, возвращающую большее число, а потом подумайте, как сравнить три числа.
