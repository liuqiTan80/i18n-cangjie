# Глава 5. Компьютер думает: ветвление

> **Цели главы**
> - Заставить программу «сворачивать» с помощью `если`/`иначе если`/`иначе`;
> - Познакомиться с операторами сравнения (`==`, `>`, `>=`…) и логическими значениями (`истина`/`ложь`);
> - Научиться комбинировать условия (`и`, `или`, `не`).
>
> **Прочитав главу, вы сможете ответить**: как ветвление выполняется сверху вниз? Чем `=` отличается от `==`? Можно ли поставить число в условие?

---

## 5.1 Если…… то……

Одно из самых сильных умений компьютера — **принимать решения**. Синтаксис — как в разговоре:

```rc
главная() {
    пусть балл = 85
    если (балл >= 60) {
        печать("Сдал!")
    }
}
```

- `если (условие)`: **если условие истинно**, выполняется код в фигурных скобках;
- `>=` — «больше или равно». Операторы сравнения: `==` (равно), `!=` (не равно), `>` (больше), `<` (меньше), `>=` (больше или равно), `<=` (меньше или равно).

> Запомните: для проверки равенства нужен **двойной** знак `==`. Одинарный `=` — «положить в коробку» (присваивание), двойной — «сравнить». Это одна из самых частых ошибок новичков — к счастью, Cangjie сразу остановит вас ошибкой.

## 5.2 Иначе если, иначе: несколько веток

```rc
главная() {
    пусть балл = 85
    если (балл >= 90) {
        печать("Отлично!")
    } иначе если (балл >= 60) {
        печать("Зачёт")
    } иначе {
        печать("Не сдавайся")
    }
}
```

Как тест: если первое условие не выполняется — пробуем второе, если ни одно — идём в `иначе`. **Сверху вниз, только одна дорога** — чьё условие сработало первым, тот и выполняется, остальные уже не смотрят.

## 5.3 Истина и ложь

У решения есть только два исхода: `истина` (выполняется) и `ложь` (не выполняется). Это тот самый тип `логическое` из главы 4:

```rc
главная() {
    пусть дождь = истина
    если (дождь) {
        печать("Возьми зонт!")
    }
}
```

`истина` и `ложь` можно класть прямо в переменные, а можно получать из сравнения: результат «выражения» `85 >= 60` — это `истина`. Видите, `если (балл >= 60)` на самом деле спрашивает: результат этого сравнения — `истина` или `ложь`?

> Внимание: в условие **нельзя ставить числа**. `если (1)` — ошибка: условие обязано быть настоящим «истина/ложь». Так исключается классический баг, когда «присваивание» пишут вместо «сравнения» (подумайте, что было бы при `если (x = 1)`).

## 5.4 Комбинируем условия: и, или, не

Одного условия не хватает — комбинируйте логическими словами:

```rc
главная() {
    пусть возраст = 15
    пусть есть_билет = истина
    если (возраст >= 12 и есть_билет) { печать("Можно войти") }
    если (возраст < 6 или возраст > 80) { печать("Бесплатно") }
    если (не есть_билет) { печать("Купите билет") }
}
```

| слово | смысл | пример |
|---|---|---|
| `и` | истинно, только когда истинны оба условия (AND) | `дождь и зонт` |
| `или` | истинно, когда истинно хотя бы одно (OR) | `дождь или снег` |
| `не` | переворачивает (NOT) | `не дождь` = дождя нет |

> **Маленький секрет (короткое замыкание)**: `ложь и что угодно` — сразу `ложь`, правое условие компьютер даже не смотрит; `истина или что угодно` — сразу `истина`. Отсюда безопасный приём: `список.размер > 0 и список[0] > 1` — если первое условие ложно, обращение справа не выполнится (пригодится в главе 11).

## 5.5 Пробуем сами

1. Напишите программу: ваш рост (например, 155). Если он больше 150 — печать «Можно на американские горки», иначе — «Подрасти немного»;
2. Оцените баллы: `>=90` отлично, `>=80` хорошо, `>=60` зачёт, иначе — старайся. Используйте `иначе если`;
3. Подумайте: `если (5 > 3)` и `если (3 > 5)` — в каком случае выполнится код внутри?
4. Вызов: напишите «правила парка развлечений» — пускают, только если возраст от 8 до 18 `и` рост больше 130, иначе печать причину (подсказка: `возраст >= 8 и возраст <= 18`).

## ✳ Советы программисту: ветвление = перекрёсток

`если` — место, где программа впервые «думает»: она больше не прямая линия, а **сворачивает**.

Идея за этим такая: **программа = последовательность + ветвление + циклы**. Всё, что вы написали, собрано из этих трёх кирпичиков:

- **последовательность** (глава 2): делать шаг за шагом;
- **ветвление** (эта глава): выбирать дорогу по обстоятельствам;
- **циклы** (глава 6): повторять по кругу.

**Любая сложная программа разбирается на эти три структуры**. Это знаменитая идея «структурного программирования» — как LEGO: базовых деталей немного, а собрать можно всё. Не пугайтесь сложных программ: найдите в них «последовательность, ветвление и цикл».

## 🍳 Алгоритм из жизни: оценка работ

Учитель ставит оценки всему классу — типичное ветвление с несколькими ветками:

```rc
главная() {
    пусть балл = 85
    если (балл >= 90) {
        печать("Отлично")
    } иначе если (балл >= 80) {
        печать("Хорошо")
    } иначе если (балл >= 60) {
        печать("Зачёт")
    } иначе {
        печать("Старайся")
    }
}
```

Обратите внимание на **порядок**: от высоких к низким (90 → 80 → 60). Если сначала написать `если (балл >= 60)`, то 85 баллов никогда не дойдут до «Хорошо» — условие 60 сработает первым, и программа тут же уйдёт. **Порядок веток — это приоритет**, самое частое «минное поле» ветвления со многими ветками.

> Попробуйте: поменяйте балл на 95, 70 и 40 и запустите — посмотрите, что выводится.

## Итоги

- `если (условие) { ... }`: выполняется, только когда условие истинно;
- `иначе если`, `иначе`: несколько веток, **сверху вниз идём по первой сработавшей дороге**;
- операторы сравнения: `== != > < >= <=`; для равенства — `==`, для присваивания — `=`;
- логическое: `истина`/`ложь`; условие обязано быть логическим, числа нельзя;
- комбинирование: `и` (оба сработали), `или` (хотя бы одно), `не` (наоборот);
- порядок веток = приоритет: оценки пишем от высоких к низким.
