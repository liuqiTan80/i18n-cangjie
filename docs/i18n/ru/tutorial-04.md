# Глава 4. Числа и текст

> **Цели главы**
> - Познакомиться с четырьмя базовыми «материалами»: целое, плавающее, строка, логическое;
> - Считать на компьютере: сложение, вычитание, умножение, деление;
> - Интерполяцией `${}` собирать текст и числа в одно предложение.
>
> **Прочитав главу, вы сможете ответить**: чем отличается `12` от `"12"`? Почему `7 / 2` равно 3? Как компьютер собирает фразу «Вася получил 95 баллов»?

---

## 4.1 Что можно положить в коробку?

Пока мы клали числа и текст. На самом деле базовых «материалов» четыре:

| Материал | Имя | Примеры |
|---|---|---|
| Целое число (без точки) | `целое` | `12`, `-3`, `0` |
| Дробное число (плавающее) | `плавающее` | `3.14`, `-0.5` |
| Текст (строка) | `строка` | `"Привет"`, `"abc"` |
| Истина/ложь (логическое) | `логическое` | `истина`, `ложь` |

Компьютер различает строго: `12` — число, а `"12"` — текст. Не верите — попробуйте их сложить, будет ошибка! Ведь «12 яблок + 12 букв» смысла не имеют. Это и есть **тип**: у каждого материала свои правила, положили не тот материал — компьютер сразу остановит (в конце главы есть эксперимент).

## 4.2 Компьютер — калькулятор

```rc
главная() {
    пусть цена_яблок = 3
    пусть цена_груш = 4
    пусть всего = цена_яблок + цена_груш
    печать("Всего ${всего} руб.")
    печать("Три яблока: ${цена_яблок * 3} руб.")
    печать("Груши дороже на ${цена_груш - цена_яблок} руб.")
}
```

Знаки операций: `+` сложение, `-` вычитание, `*` умножение, `/` деление.

Как в математике, **сначала умножение и деление, потом сложение и вычитание**. Хотите другое — ставьте скобки: `(цена_яблок + цена_груш) * 2`.

## 4.3 Ловушка целочисленного деления

```rc
главная() {
    печать(7 / 2)          // выведет 3, а не 3.5!
    печать(7.0 / 2.0)      // выведет 3.5
    печать(7 % 2)          // выведет 1 (% — остаток от деления)
}
```

**Целое делим на целое — результат целый** (дробная часть просто отбрасывается). `7 / 2` даёт `3`, а не `3.5`! Хотите `3.5` — используйте плавающее: `7.0 / 2`.

`%` — это **остаток от деления**: `7 % 2` равен 1. Проверить, чётно ли число, взять последнюю цифру — всё через него. Пригодится в главе 5.

## 4.4 Собираем текст: интерполяция

Чтобы соединить текст и числа, удобнее всего заполнять пропуски `${}`:

```rc
главная() {
    пусть имя = "Вася"
    пусть балл = 95
    печать("${имя} набрал ${балл} баллов")
}
```

Вывод: `Вася набрал 95 баллов`. Внутрь `${}` можно класть не только переменные, но и выражения:

```rc
главная() {
    пусть яблоки = 3
    пусть груши = 4
    печать("Всего ${яблоки + груши} фруктов")   // всего 7 фруктов
}
```

> Нужен перевод строки? Используйте `\n`: `печать("Первая строка\nВторая строка")` выведет две строки. `\n` читается как «символ новой строки».

## 4.5 Попрактикуйтесь

1. Посчитайте: если каждый день добавлять к карманным деньгам 2 руб., сколько добавится за год (365 дней)? Сосчитайте программой;
2. Напечатайте фразу: «Мой рост» + ваш рост (через интерполяцию `${}`);
3. Попробуйте `печать(1 + "2")` и посмотрите, что скажет ошибка — как она объясняет несоответствие типов? (примечание: редкие диагностические коды показываются официальным английским шаблоном — языковой пакет постоянно пополняется, программа от этого не ломается);
4. Вызов: прокачайте «учёт карманных денег» из главы 3 — храните деньги как плавающее (например, 100.5), потратьте 25.3, напечатайте остаток (посмотрите на число знаков после запятой в выводе).

## ✳ Мысль о программировании: тип — это «классификационный ярлык»

Почему компьютер такой строгий и обязательно различает `12` и `"12"`?

Потому что **с разными типами значений можно делать разное**: числа складывать и делить, текст соединять и искать, истина/ложь — использовать в условиях (глава 5). Если бы компьютер разрешил «число + текст», то чему равно `1 + "2"` — `3` или `"12"`? Каждый программист придумал бы свой ответ, и программы разъехались бы.

Поэтому язык программирования наклеивает на каждое значение **тип**: **тип определяет, какие операции с этим значением возможны**. Как на кухне: ножом режут, в сковороде жарят — не станете же вы жарить ножом.

> Это и философия дизайна Cangjie: **никаких неявных преобразований** — компьютер никогда не «додумает» сам и не превратит число в текст. Каждое преобразование программист пишет явно (как — в главе 9). Строгость — ради безошибочности.

## 🍳 Бытовой алгоритм: сдача

Вы покупаете в магазине: товар стоит 7 руб., вы дали 20 руб. Как продавец посчитает сдачу?

```rc
главная() {
    пусть отдано = 20
    пусть цена = 7
    пусть сдача = отдано - цена
    печать("Сдачи: ${сдача} руб.")

    // прокачка: как выдать сдачу купюрами по 10, 5 и 1 руб.?
    пусть десятки = сдача / 10          // 20 - 7 = 13, 13 / 10 = 1 купюра
    пусть остаток = сдача % 10          // осталось 3 руб.
    пусть пятерки = остаток / 5         // 3 / 5 = 0 купюр
    пусть единицы = остаток % 5         // осталось 3 руб.
    печать("Выдать: ${десятки} по 10, ${пятерки} по 5, ${единицы} по 1 руб.")
}
```

В этом примере спрятаны две идеи алгоритмов:
- **`/` и `%` — пара от природы**: деление даёт «сколько купюр помещается», остаток — «сколько осталось». Вместе это алгоритм «размена денег»;
- Приём «сначала делим, потом берём остаток» — зародыш **жадного алгоритма**: каждый раз берём самый крупный номинал (глубже — в главе 17).

## Итоги

- Четыре базовых материала: `целое`, `плавающее`, `строка`, `логическое` (`истина`/`ложь`);
- Операции: `+ - * / %`; сначала умножение/деление, потом сложение/вычитание, скобки — выше всех;
- **Целое на целое — целое** (`7 / 2` = 3); нужно дробное — берите плавающее (`7.0 / 2`);
- `%` — остаток: чётность, размен денег — всё на нём;
- Интерполяция `${}`: подставляет переменную или выражение в строку, `"${имя} набрал ${балл} баллов"`;
- Тип — классификационный ярлык: `12` и `"12"` — разное, компьютер без «неявных преобразований».

## Вопросы для размышления

1. Что выведет `печать(10 / 3)`? А `печать(10 % 3)`? Сначала угадайте, потом проверьте;
2. Почему `1 + "2"` — ошибка? А если разрешить, что станет с миром? (подсказка: если `"1" + "2"` — это `"12"`, то чему быть `1 + "2"`?)
3. Можно ли положить внутрь `${}` вызов `печать("...")`? Почему? (подсказка: интерполяции нужно «значение», а печать — «действие»)
4. Напишите через `%` программу: чётно ли число 123 (подсказка: чётное — то, что делится на 2 без остатка).
