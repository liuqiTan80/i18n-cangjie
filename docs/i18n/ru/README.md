# zhc — Программируйте на Cangjie на родном языке

Language / Langue / Sprache / Idioma / 언어 / 言語 / Язык：[中文](../../../README.md) · [English](../en/README.md) · [Français](../fr/README.md) · [Deutsch](../de/README.md) · [Español](../es/README.md) · [한국어](../ko/README.md) · [日本語](../ja/README.md) · **Русский**

**zhc** — учебный фреймворк «родного языка» для языка программирования Cangjie
(仓颉): он транслирует диалектный исходный код (например, китайский `.zc`,
японский `.jc`, французский `.fc`) в стандартный Cangjie и переводит
диагностику компилятора в обучающие сообщения на выбранном языке (код ошибки →
таблица сообщений → локализация типов → примеры исправления). Диалект
выбирается переменной окружения `ZHCLANG` (по умолчанию `zh`); всё управляется
**языковым пакетом**.

## Быстрый старт (около 10 минут)

**1. Установите SDK Cangjie** (единственная внешняя зависимость): скачайте
версию **1.0.5** с cangjie-lang.cn/download, распакуйте и выполните
поставляемый `envsetup.sh`, чтобы `cjc` и `cjpm` попали в `PATH`. Проверка:

```bash
cjc --version    # Cangjie Compiler: 1.0.5 (cjnative)
```

**2. Соберите zhc** (без сети, без сторонних зависимостей):

```bash
cd zhc
cjpm build       # создаёт target/release/bin/main
```

**3. Запустите первую программу** (пример на китайском диалекте из репозитория):

```bash
export ZHC_LANG_PACKS=$PWD        # от корня репозитория: zhc/
zhc run examples/hello.zc
# ✅ 编译成功：替换方言标识符 8 处。
# 消息：你好，仓颉！
```

## Пишите на своём языке

Работает любой язык, для которого есть пакет в `zhc/lang-packs/<код>/` —
`en` (тождественное отображение = официальный Cangjie), `ru`, `ja`, `ko`,
`fr`, `es`, `de` включены. Например, русский (`ZHCLANG=ru`):

```rc
главная() {
    пусть имя: строка = "仓颉"
    печать("Привет, ${имя}！")
}
```

Запуск: `ZHCLANG=ru zhc run hello.rc`. Немецкий и испанский диалекты работают
так же (`Haupt/Lege/Zeige`, `principal/defina/mostrar`).

## Переводы сторонних библиотек

Отображения API библиотек живут в общем репозитории переводов, а не в вашем
исходном дереве — скачивайте только нужный язык и нужную библиотеку:

```bash
zhc share list                     # обзор общего реестра
zhc share fetch csv4cj --lang ru   # скачать одно отображение на своём языке
zhc share publish мой_файл.toml    # поделиться своим переводом
```

Скачанные отображения проходят контрольную сумму и проверки качества (формат,
официальные имена, коллизии с зарезервированными словами) перед установкой в
`~/.zhc/lang-packs/<язык>/crates/`. При отсутствии перевода — мягкий откат на
китайский; программа работает в любом случае.

## Терминология (единообразно во всей русской документации)

| Русский | В коде/доках | Примечание |
|---|---|---|
| диалект | `.zc` `.jc` `.fc` … | Cangjie, написанный на родном языке |
| языковой пакет | `lang-packs/<код>/` | таблицы ключевых слов/псевдонимов + диагностика + тексты UI |
| отображение | `crates/<язык>/<библиотека>.toml` | родное имя = официальное имя API |
| транспиляция | `zhc run` / `zhc check` | диалект → стандартный Cangjie |
| общий репозиторий | `zhc share …` | централизованный реестр переводов |
| базовая линия | `zh@<контрольная сумма>` | отпечаток синхронизации китайского оригинала |
