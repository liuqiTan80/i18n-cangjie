# Глава 3. Коробки памяти: переменные

> **Цели главы**
> - Понять, что «переменная» — это коробка с наклейкой-именем;
> - Различать `пусть` (нельзя менять) и `переменная` (можно менять);
> - Научиться хорошо называть переменные.
>
> **Прочитав главу, вы сможете ответить**: чем отличаются `пусть` и `переменная`? Почему программисты советуют чаще использовать `пусть`? Что означает `=` в программе?

---

## 3.1 Пусть компьютер запоминает за вас

Решая задачу, вы сначала пишете на черновике «Дано: x = 5». **Переменная** — это черновик компьютера: коробка с наклейкой-именем, в которую можно что-то положить и в любой момент достать.

## 3.2 пусть: коробка, которую нельзя менять

```rc
главная() {
    пусть мой_возраст = 12
    печать("Мой возраст: ${мой_возраст}")
}
```

- `пусть мой_возраст = 12`: взять коробку, наклеить ярлык «мой_возраст» и положить число `12`;
- `"Мой возраст: ${мой_возраст}"`: `${}` — это **интерполяция**: как заполнение пропуска, значение из коробки подставляется в предложение.

Результат: `Мой возраст: 12`.

`пусть` означает «**решено, больше не меняем**» — положенное в коробку нельзя заменить. Если попробовать написать `мой_возраст = 13`, компилятор безжалостно выдаст ошибку: «Нельзя присвоить значение неизменяемой переменной».

> Аналогия: `пусть` — как надпись, высеченная на камне (не изменить).

## 3.3 переменная: коробка, которую можно менять

Иногда менять действительно нужно. Например, считаем:

```rc
главная() {
    переменная счетчик = 0
    счетчик = счетчик + 1      // достали 0, прибавили 1, положили 1
    счетчик = счетчик + 1      // ещё раз — теперь 2
    печать("Сосчитал дважды: ${счетчик}")
}
```

- `переменная`: содержимое коробки можно **менять в любой момент**;
- `=` — это **присваивание**: положить то, что справа, в коробку с именем слева. Внимание: это не математическое «равно», а «положить... в...». Поэтому `счетчик = счетчик + 1` означает: взять текущий `счетчик`, прибавить 1 и положить обратно.

> Аналогия: `переменная` — как надпись мелом на доске (можно стереть и переписать).
>
> Как выбирать? **По умолчанию `пусть`** — если хватает, запираем. `переменная` — только когда менять действительно нужно (счёт, накопление, обратный отсчёт). Тогда читающий код сразу видит: помеченные `переменная` места — единственные, где значение меняется.

## 3.4 Правила имён для коробок

- Можно по-русски! `мой_возраст`, `итог`, `ответ` — пожалуйста;
- Имя должно быть **понятно с первого взгляда**. `итог` в сто раз лучше, чем `a` — через два дня вы сами не вспомните, что такое `a`;
- Нельзя начинать с цифры (`123abc` нельзя), нельзя ставить пробелы;
- Можно добавить аннотацию типа — сказать компьютеру, из какого материала эта коробка:

```rc
главная() {
    пусть имя: строка = "Вася"    // эта коробка — только для текста
    пусть балл: целое = 95        // эта коробка — только для целых чисел
    печать("${имя} получил ${балл} баллов")
}
```

Можно и без аннотации — компьютер умный, по положенному внутрь угадает тип (это называется **вывод типов**). Но с аннотацией спокойнее: на ярлыке написано «только целые», и при попытке положить текст компьютер сразу остановит вас (сообщение «Несовпадение типов»).

## 3.5 Константа: высечено на камне

Есть и более «жёсткая» коробка — `константа`:

```rc
константа число_пи = 3.14159
константа название_школы = "Первая школа"

главная() {
    печать("${название_школы}, пи ≈ ${число_пи}")
}
```

`константа` и `пусть` обе нельзя менять. Разница в том, что `константа` определяется ещё **на этапе компиляции** (зашита до запуска программы) — быстрее и безопаснее. **Где можно `константа` — используйте `константа`**: число пи, название школы — вечные значения должны быть константами.

## 3.6 Попрактикуйтесь

1. В `пусть` сохраните свой день рождения, в `переменная` — свои карманные деньги, и напечатайте оба;
2. Угадайте: после `пусть балл = 90` написать `балл = 95` — что произойдёт? Попробуйте! Сообщение об ошибке расскажет;
3. Через `константа` задайте расстояние от дома до школы и напечатайте «От дома до школы X км»;
4. Вызов: на `переменная` напишите «учёт карманных денег» — было 100 руб., потратили 25 руб. на канцелярию и 10 руб. на снеки, напечатайте, сколько осталось.

## ✳ Мысль о программировании: имя — это документация

«Дать коробке имя» — маленькое дело, но одно из самых важных в программировании.

- Программист читает код в 5-10 раз дольше, чем пишет;
- Ваш код читают в первую очередь **будущий вы** и другие люди;
- Переменная `итог` понятна без комментариев; переменная `a` — и через день забыта.

**Имя — это документация**: хорошее имя само по себе инструкция. Потратьте десять секунд на имя при написании — сэкономите часы понимания в будущем. Это также называют «самодокументирующийся код»: код говорит сам, без дополнительных объяснений.

## 🍳 Бытовой алгоритм: меняем местами две коробки

У Васи две коробки: в одной кола, в другой апельсиновый сок. Он хочет поменять их содержимое — но нельзя **открывать и переливать обе одновременно** (всё разольётся).

Решение программиста: взять ещё одну **пустую коробку** (временную переменную):

```
1. Перелить колу в пустую коробку   // временная = кола
2. Перелить сок в коробку из-под колы   // кола = сок
3. Перелить из пустой коробки в коробку из-под сока  // сок = временная
```

В коде:

```rc
главная() {
    переменная кола = "Кола"
    переменная сок = "Апельсиновый сок"
    переменная временная = кола       // 1. сначала сохранили
    кола = сок                        // 2. сок — в коробку колы
    сок = временная                   // 3. прежнюю колу — в коробку сока
    печать("В коробке «кола»: ${кола}")
    печать("В коробке «сок»: ${сок}")
}
```

Это классический приём, который проходит каждый программист, — **обмен двух значений**. Главная мысль: менять напрямую — потерять; сначала сохранить в «запасной коробке». Вы ещё встретите его в алгоритмах сортировки (глава 17).

## Итоги

- Переменная = коробка с наклейкой-именем; `=` — «положить внутрь», а не математическое «равно»;
- `пусть`: нельзя менять (выбор по умолчанию); `переменная`: можно (когда нужно); `константа`: фиксируется при компиляции (для вечных значений);
- Правила имён: можно по-русски, понятно с первого взгляда, не с цифры, без пробелов;
- Аннотация типа необязательна: `пусть имя: строка = "Вася"` — с ней ошибка материала обнаружится сразу;
- Обмен двух значений: взять запасную коробку.

## Вопросы для размышления

1. Почему в программировании по умолчанию `пусть`, а не `переменная`? (подсказка: коробка не меняется тайком — читать код спокойнее)
2. `счетчик = счетчик + 1` в математике абсурдно (x = x + 1 не имеет решения). Почему в программе это законно?
3. Найдите в жизни примеры «пусть» и «переменная»: что однажды задано — не меняется (номер паспорта)? Что меняется каждый день (карманные деньги)?
4. Попробуйте: не давая коробке имя, написать прямо `печать("${12}")` — напечатается ли `12`? О чём это говорит?
