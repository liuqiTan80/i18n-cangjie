# Глава 6. Повторяем работу: циклы

> **Цели главы**
> - С помощью `для` заставить код считать и повторять;
> - С помощью `пока` повторять, пока условие не перестанет выполняться;
> - Освоить `прервать` и `продолжить` для управления циклом.
>
> **Прочитав главу, вы сможете ответить**: входит ли 5 в `1..5`? Как остановить бесконечный цикл? Как Гаусс мгновенно сложил числа от 1 до 100?

---

## 6.1 Повторяющуюся работу — компьютеру

Сложить числа от 1 до 100? Писать вручную 100 строк? **Цикл** — именно для этого: заставить один и тот же код выполняться снова и снова. Компьютер лучше всех справляется с однообразной работой — он не устаёт, не скучает и не сбивается со счёта.

## 6.2 Для: считаем и делаем

```rc
главная() {
    для (i в 1..5) {
        печать("Раз ${i}")
    }
}
```

- `1..5` — это **диапазон**: от 1 до 5 (внимание: на 5 он останавливается, **5 не входит**);
- `для (i в 1..5)`: каждый раз `i` по очереди принимает значения 1, 2, 3, 4, и код в фигурных скобках выполняется ещё раз;
- Вывод: `Раз 1`, `Раз 2`, `Раз 3`, `Раз 4` (пятого раза нет!).

> У диапазона есть и закрытая запись `1..=5` (включает 5). «Полуоткрытый диапазон `1..5`» — общепринятое соглашение в программировании: его длина ровно `5 - 1`, без всякой двусмысленности.

### Легенда: Гаусс мгновенно складывает числа от 1 до 100

Когда математику Гауссу было восемь лет, учитель велел классу сложить числа от 1 до 100. Другие дети корпели над столбиками, а Гаусс дописал за несколько секунд — он заметил, что `1+100=101`, `2+99=101`… всего 50 пар, значит ответ — `50 × 101 = 5050`.

Запишем это циклом — Гаусс схитрил, а мы поработаем честным перебором (компьютер перебора не стыдится):

```rc
главная() {
    переменная сумма = 0
    для (i в 1..101) {
        сумма = сумма + i
    }
    печать("Сумма от 1 до 100 = ${сумма}")
}
```

Вывод: `Сумма от 1 до 100 = 5050`. Обратите внимание на «душу» этой программы: `переменная сумма` — как копилка, каждый круг мы бросаем туда по одному числу. **Изменять `переменную` внутри цикла** — самое частое сочетание в программировании.

## 6.3 Пока: стоим, пока условие выполняется

`для` подходит, когда «считаем и делаем», `пока` — когда «делаем, пока условие не перестанет выполняться»: **пока условие истинно, делай**.

```rc
главная() {
    переменная осталось = 10
    пока (осталось > 0) {
        печать("Осталось ${осталось} лапшинок")
        осталось = осталось - 1
    }
    печать("Съедено!")
}
```

> ⚠️ **Важное предупреждение**: если забыть строку `осталось = осталось - 1`, условие всегда будет истинным, и программа закрутится вечно — это **бесконечный цикл**. Если программа без остановки сыплет строками — нажмите **Ctrl+C**, чтобы прервать её.

## 6.4 Прервать и продолжить

- `прервать`: немедленно закончить весь цикл (не хочу больше считать — ухожу);
- `продолжить`: пропустить этот круг и перейти к следующему.

```rc
главная() {
    для (i в 1..10) {
        если (i == 3) { продолжить }   // пропускаем 3
        если (i == 7) { прервать }     // дошли до 7 — стоп
        печать("Считаю ${i}")
    }
}
// вывод: Считаю 1 Считаю 2 Считаю 4 Считаю 5 Считаю 6
```

## 6.5 Пробуем сами

1. С помощью `для` напечатать один столбик таблицы умножения: `1×7=7`, `2×7=14`… `9×7=63`;
2. С помощью `пока` устроить обратный отсчёт: от 10 до 1, а потом напечатать «Пуск!»;
3. Поменяйте «от 1 до 100» на «от 1 до 1000» и проверьте ответ (формула: n×(n+1)/2);
4. Вызов: с помощью `для` напечатать все чётные числа от 1 до 50 (подсказка: чётное — это `i % 2 == 0`).

## ✳ Советы программисту: три элемента цикла

Прежде чем писать цикл, ответьте на три вопроса (**три элемента цикла**):

1. **С чего начать?** (начало: `i = 1` или `осталось = 10`)
2. **Когда остановиться?** (условие: `i < 5` или `осталось > 0`)
3. **Как меняться каждый круг?** (шаг: `i` сам прибавляет 1, или `осталось = осталось - 1`)

В любом цикле достаточно продумать эти три вещи — и бесконечного цикла не будет. Суть бесконечного цикла: **«когда остановиться» никогда не выполняется** — проверьте три элемента и сразу найдёте причину.

> Это ещё одна победа идеи «разбиения» (глава 1): цикл выглядит страшно, но разбей его на три вопроса — и каждый прост.

## 🍳 Алгоритм из жизни: таблица умножения

Напечатаем таблицу умножения «циклом внутри цикла» — это обряд посвящения всех программистов:

```rc
главная() {
    для (строка в 1..10) {
        переменная одна_строка = ""
        для (столбец в 1..=строка) {
            одна_строка = одна_строка + "${столбец}×${строка}=${столбец * строка} "
        }
        печать(одна_строка)
    }
}
```

- Внешний цикл ведёт «строки» (от 1 до 9), внутренний — «столбцы» (от 1 до текущей строки);
- **Цикл внутри цикла** называется «вложенным циклом» — внешний делает один шаг, внутренний проходит полный круг;
- Условие внутреннего цикла `1..=строка` использует переменную внешнего — число кругов внутреннего меняется вместе с внешним, в этом и суть вложенных циклов.

> Как вы думаете, что выведется? Первая строка `1×1=1 `, вторая `1×2=2 2×2=4 `… запустите и посмотрите сами!

## Итоги

- `для (i в диапазон)`: считаем и делаем; `1..5` — полуоткрытый диапазон, **5 не входит**, `1..=5` включает 5;
- `пока (условие)`: пока условие истинно, делаем; **осторожно с бесконечным циклом** (Ctrl+C спасает);
- `прервать` заканчивает весь цикл, `продолжить` пропускает текущий круг;
- Три элемента цикла: начало, условие остановки, шаг;
- Внутри цикла копим результат в `переменной` (приём с копилкой);
- Вложенные циклы: внешний шагает, внутренний проходит круг.

2. Как правильно написать бесконечный цикл через `пока`? (подсказка: условие всегда истинно; когда он нужен? пригодится в игре «угадай число» в главе 11)
3. Почему говорят «компьютер не боится глупого перебора»? Какие плюсы и минусы у компьютерного и математического способов в истории Гаусса?
4. Вызов: циклом напечатайте треугольник — в первой строке один `*`, во второй два `*`… всего 5 строк (подсказка: сначала продумайте три элемента).
