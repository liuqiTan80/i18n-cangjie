# Введение в учебник — Урок 0 (Русский)

Навигация：[Оригинал учебника (zh)](../../中文仓颉程序设计/README.md) · [English](../en/README.md) · [Français](../fr/README.md) · [Deutsch](../de/README.md) · [Español](../es/README.md) · [한국어](../ko/README.md) · [日本語](../ja/README.md) · **Русский**

Канонический учебник **《中文仓颉程序设计》** — систематический курс в стиле
справочника: **3 тома, 20 глав + 3 приложения + сборник ответов**, **150+
блоков кода проверены на официальном `cjc 1.0.5`**. Эта страница — урок 0 на
русском; канонический текст на китайском — читайте параллельно с диалектными
примерами ниже.

## Три тома

| Том | Для кого | Содержание |
|---|---|---|
| Том 1 Первые шаги | полный новичок | установка, первая программа, переменные, числа, условия, циклы, функции |
| Том 2 Ядро и углубление | системная грамматика | функции, система типов, строки, коллекции, ООП, перечисления, ошибки, обобщения и макросы |
| Том 3 Инженерия и мышление | качество и инженерия | мышление проектирования, алгоритмы и структуры данных, ПО-инженерия, итоговый проект |

## Урок 1: первая программа

Напишите её на русском диалекте:

```rc
главная() {
    пусть привет: строка = "Привет, Cangjie!"
    печать(привет)
}
```

Сохраните как `hello.rc` и выполните `ZHCLANG=ru zhc run hello.rc`. Каждый
диалект транслируется ровно в этот стандартный код — заменяются только
ключевые слова и имена типов по таблице соответствия вашего языка.
Доступные диалекты: `en`/`ru`/`ja`/`ko`/`fr`/`es`/`de`.

## Где искать (быстрая шпаргалка)

- Системная грамматика → Том 2, главы 08–15 (определение → синтаксис → пример → заметки)
- Качество и инженерия → Том 3, главы 16–19
