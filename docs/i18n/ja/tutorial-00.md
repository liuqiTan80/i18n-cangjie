正本チュートリアル **《中文仓颉程序设计》**（中国語で倉頡をデザインする）は、
ハンドブック形式の体系的なコースです：**全 3 巻・20 章 + 付録 3 点 + 解答集**、
**150 以上のコードブロックはすべて公式 `cjc 1.0.5` で実測済み**。このページは
日本語の第 0 課です。正本は中国語ですが、本ガイドと並行して読むか、下の方言
サンプルから始めてください。

| 巻 | こんな人に | 内容 |
|---|---|---|
| 第 1 巻 はじめての一歩 | 完全な初心者 | 環境構築、最初のプログラム、変数、数と文字、判断、繰り返し、関数 |

## 第 1 課：最初のプログラム

日本語方言（`.jc` 拡張子）で書いてみましょう：

```jc
// ファイル名: hello.jc —— ZHCLANG=ja zhc run hello.jc で実行
メイン() {
    おく 名前: 文字列 = "世界"
    ひょうじ("こんにちは、${名前}！")
}
```

`hello.jc` として保存し、実行：

```bash
ZHCLANG=ja zhc run hello.jc
```

どの方言もまったく同じ標準コードへトランスパイルされます — 書き換わるのは、
各言語パックの対応表に従ったキーワードと型名だけです。同梱の言語パック：
`zh`/`en`/`ru`/`ja`/`ko`/`fr`/`es`/`de`（各言語のクイックスタートを参照）。

> 型注釈なしでも動きます：`おく 名前 = "世界"`。文字列型 `文字列`（= 公式 `String`）
> は標準ライブラリのエイリアスで、型名を覚えたい人向けの明示書きです。

## 用語（本書共通の日本語訳）

| 日本語 | コード表記 | 備考 |
|---|---|---|
| 方言 | `.jc` `.zc` … | 母語で書いた倉頡コード |
| メイン | `メイン()` | プログラムの入口（公式 `main`） |
| おく | `おく` | 不変の値を宣言（公式 `let`） |
| ひょうじ | `ひょうじ()` | 一行表示（公式 `println`） |
| 文字列 | `文字列` | 文字の並び（公式 `String`） |
| トランスパイル | `zhc run` | 方言 → 標準倉頡の変換 |
