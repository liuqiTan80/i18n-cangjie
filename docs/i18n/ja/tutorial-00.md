# チュートリアル導学 — 第 0 課（日本語）

ナビゲーション：[チュートリアル正本（zh）](../../中文仓颉程序设计/README.md) · [English](../en/README.md) · [Français](../fr/README.md) · [Deutsch](../de/README.md) · [Español](../es/README.md) · [한국어](../ko/README.md) · **日本語** · [Русский](../ru/README.md)

正本チュートリアル **《中文仓颉程序设计》** はマニュアル形式の体系的講座です：
**全 3 巻 20 章 + 付録 3 点 + 解答集**、**150 以上のコードブロックを公式
`cjc 1.0.5` で全件実測**済み。このページは日本語の第 0 課です。正本の本文は
中国語なので、下の方言例と並行して読み進めてください。

## 三巻の構成

| 巻 | こんな人に | 内容 |
|---|---|---|
| 第 1 巻 入門 | 完全初心者 | 環境構築、最初のプログラム、変数、数値、条件分岐、ループ、関数 |
| 第 2 巻 コアと進階 | 文法を体系的に | 関数、型システム、文字列、コレクション、オブジェクト指向、列挙型、エラー処理、ジェネリクスとマクロ |
| 第 3 巻 工程と思想 | 品質重視の開発者 | 設計思想、アルゴリズムとデータ構造、ソフトウェア工学、総合実践 |

## 第 1 課：最初のプログラム

日本語方言で書いてみましょう：

```jc
メイン() {
    おく あいさつ: 文字列 = "こんにちは、仓颉"
    ひょうじ(あいさつ)
}
```

`hello.jc` として保存し、`ZHCLANG=ja zhc run hello.jc` で実行します。すべての
方言は正確にこの標準コードへトランスパイルされます — たとえば中国語方言では
`main` を `主函数`、`let` を `让`、`println` を `打印行` と書きます。提供方言：
`en`/`ru`/`ja`/`ko`/`fr`/`es`/`de`。
