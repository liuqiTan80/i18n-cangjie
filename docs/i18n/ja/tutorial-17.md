# 第 17 章 アルゴリズムとデータ構造

> **この章の学習目標**：アルゴリズム思考を築く——O 記法（ランダウの記号）、探索、ソート、スタックとキュー、再帰と分割統治、ハッシュの原理。すべて日本語の倉頡で実装して実測する。
> **この章を読み終えると答えられる問い**：なぜハッシュ探索は O(1) なのか？二分探索の前提は何か？再帰にどうして「出口」が必須なのか？

---

## 17.1 定義：アルゴリズムと計算量（O 記法）

**定義**：アルゴリズム = 問題を解く**手順のリスト**（第 1 章の「レシピ」の正式版）。データ構造 = データの**格納のしかた**（第 11 章のコンテナは既製品）。計算量（O 記法）はデータ規模の増加に対するアルゴリズムの**時間/空間消費の傾向**を測る：

| O 記法 | 名称 | 例 | 1 万件のデータの感覚 |
|---|---|---|---|
| O(1) | 定数時間 | ハッシュ探索、配列の添字 | 一瞬 |
| O(log n) | 対数時間 | 二分探索 | 14 ステップ |
| O(n) | 線形時間 | 順番探索、走査 | 1 万ステップ |
| O(n log n) | 線形対数 | クイックソート | 13 万ステップ |
| O(n²) | 二乗時間 | バブル/選択ソート | 1 億ステップ（カクつき始める） |

**なぜか**：同じ問題でもアルゴリズム次第で所要時間が**桁違い**になる——これがアルゴリズム学習の価値。コードを書く前に計算量を見積もるのが「性能意識」の第一歩。

**例：順番探索（O(n)）**：

```jc
関数 じゅんばんさがし(データ: はいれつ<せいすう>, 目標: せいすう): せいすう {
    それぞれ (i in 0..データ.ながさ) {
        もし (データ[i] == 目標) { かえす i }
    }
    かえす -1        // 見つからない
}

メイン() {
    ひょうじ(じゅんばんさがし([3, 7, 2, 9, 5], 9))    // 3（添字は 0 から）
    ひょうじ(じゅんばんさがし([3, 7, 2, 9, 5], 8))    // -1
}
```

## 17.2 二分探索：O(log n) の「数字当て」戦略

**定義**：**ソート済み**の配列で、毎回真ん中の値と比較する——大きければ左半分へ、小さければ右半分へ。一歩ごとに半分を除外する。これが第 11 章の数字当てゲームの原理（2¹⁰ = 1024。10 歩で 1 から 1000 を当てる）。

**前提**：**配列がソート済みであること**——ソートされていなければ二分は無効。

**日本語の書き方**：

```jc
関数 にぶんたんさく(データ: はいれつ<せいすう>, 目標: せいすう): せいすう {
    変数 低 = 0
    変数 高 = データ.ながさ - 1
    あいだ (低 <= 高) {
        おく 中 = (低 + 高) / 2
        もし (データ[中] == 目標) { かえす 中 }
        またもし (データ[中] < 目標) {
            低 = 中 + 1        // 目標は右半分
        } でなければ {
            高 = 中 - 1        // 目標は左半分
        }
    }
    かえす -1
}

メイン() {
    おく じゅんじょ = [1, 3, 5, 7, 9, 11, 13]
    ひょうじ(にぶんたんさく(じゅんじょ, 7))      // 3
    ひょうじ(にぶんたんさく(じゅんじょ, 2))      // -1（見つからない）
}
```

**注意事項**：`低 <= 高` がループ条件（イコールを忘れるな）。`中 = (低 + 高) / 2` は整数の割り算。各周回で必ず `低` か `高` を更新する——さもないと無限ループ。n 件のデータで最大 `log₂(n)+1` ステップ。

## 17.3 選択ソート：O(n²) の「最小を選ぶ」

**定義**：各周回で未ソート部分から**最小を選び**、ソート済み部分の末尾へ置く——トランプで小さい札を一枚ずつ選り分けるようなもの。

**日本語の書き方**：

```jc
いれる 標準コレクション.*
関数 選択ソート(データ: はいれつ<せいすう>): はいれつ<せいすう> {
    変数 けっか = データ |> はいれつあつめ      // コピーを取る（元の配列は変えない）
    それぞれ (i in 0..けっか.ながさ) {
        変数 最小位置 = i
        それぞれ (j in i + 1..けっか.ながさ) {
            もし (けっか[j] < けっか[最小位置]) { 最小位置 = j }
        }
        もし (最小位置 != i) {      // 交換（第 3 章の一時箱の型）
            おく 一時 = けっか[i]
            けっか[i] = けっか[最小位置]
            けっか[最小位置] = 一時
        }
    }
    かえす けっか
}

メイン() {
    ひょうじ(選択ソート([5, 2, 9, 1, 7]))    // [1, 2, 5, 7, 9]
}
```

**注意事項**：二重ループ = O(n²)。「最小を選ぶ + 交換」が核心。`データ |> はいれつあつめ` でコピーを作る（`はいれつあつめ` がイテレータを消費して新しい配列にする。第 11 章）。元の配列を変更しないという関数式の規律を守る。**日常のソートは `ならべる`（第 11 章）を直接使おう**——自分でソートを書くのは原理を理解するため。

## 17.4 バブルソート：O(n²) の「隣同士の交換」

**定義**：各周回で左から右へ**隣同士を比較**し、大きいのを後ろへ泡立たせる——気泡が浮き上がるように。選択ソートと同じく O(n²) だが、交換がより頻繁（性能はやや劣る。教学の価値は高い）。

**日本語の書き方**：

```jc
いれる 標準コレクション.*
関数 バブルソート(データ: はいれつ<せいすう>): はいれつ<せいすう> {
    変数 けっか = データ |> はいれつあつめ      // コピーを取る（元の配列は変えない）
    それぞれ (i in 0..けっか.ながさ) {
        それぞれ (j in 0..けっか.ながさ - 1 - i) {
            もし (けっか[j] > けっか[j + 1]) {
                おく 一時 = けっか[j]
                けっか[j] = けっか[j + 1]
                けっか[j + 1] = 一時
            }
        }
    }
    かえす けっか
}

メイン() {
    ひょうじ(バブルソート([5, 2, 9, 1, 7]))    // [1, 2, 5, 7, 9]
}
```

**注意事項**：内側は `0..ながさ-1-i`——各周回の末尾はソート済みなので、もう比べなくてよい（最適化ポイント）。「その周回で交換がなければ早期終了」のフラグを足す手もある（最良のとき O(n)）。

## 17.5 クイックソート：O(n log n) の分割統治

**定義**：**分割統治**の思想——「基準」を一つ選び、配列を「基準より小さい」と「基準以上」の二つに分け、再帰で両半分をソートする。平均 O(n log n)。実際に最も広く使われるソート。

**日本語の書き方**：

```jc
いれる 標準コレクション.*
関数 クイックソート(データ: はいれつ<せいすう>): はいれつ<せいすう> {
    もし (データ.ながさ <= 1) { かえす データ }       // 出口：空か 1 要素ならソート済み
    変数 ちいさい = リスト<せいすう>()
    変数 おおきい = リスト<せいすう>()
    それぞれ (i in 1..データ.ながさ) {                // 基準は先頭の要素
        もし (データ[i] < データ[0]) {
            ちいさい.くわえる(データ[i])
        } でなければ {
            おおきい.くわえる(データ[i])
        }
    }
    変数 けっか = リスト<せいすう>()                    // けっかもまずリストに（配列は可変長でない）
    それぞれ (こうもく in クイックソート(ちいさい |> はいれつあつめ)) { けっか.くわえる(こうもく) }
    けっか.くわえる(データ[0])
    それぞれ (こうもく in クイックソート(おおきい |> はいれつあつめ)) { けっか.くわえる(こうもく) }
    かえす けっか |> はいれつあつめ                       // 最後に配列へ戻す
}

メイン() {
    ひょうじ(クイックソート([5, 2, 9, 1, 7]))    // [1, 2, 5, 7, 9]
}
```

**注意事項**：**再帰には二つの部分が必須**——「出口」（`ながさ <= 1`）と「前進」（毎回規模が小さくなる）。`リスト |> はいれつあつめ` でリスト→配列の変換を完了する（イテレータを消費して新しい配列にする。第 11 章）。`いれる` 文はファイル**先頭**に置くのが慣例（このコードブロックは従っている）。

## 17.6 スタックとキュー：二つの「並び方」

**定義**：**スタック**（Stack）= 後入れ先出し（LIFO）——皿を重ねるようなもの。後で置いたのを先に取る。**キュー**（Queue）= 先入れ先出し（FIFO）——ご飯を買う列のようなもの。先に来たのが先に買える。

**日本語の書き方**（リストで模擬する）：

```jc
いれる 標準コレクション.{リスト}

構造体 スタック {
    おおやけ 変数 データ: リスト<せいすう>
    初期化() { これ.データ = リスト<せいすう>() }
    おおやけ 関数 おしこむ(値: せいすう) { これ.データ.くわえる(値) }
    おおやけ 関数 とりだす(): オプション<せいすう> {
        もし (これ.データ.ながさ == 0) { かえす なし }
        おく 頂 = これ.データ[これ.データ.ながさ - 1]
        これ.データ.のぞく(これ.データ.ながさ - 1..これ.データ.ながさ)
        かえす あり(頂)
    }
    おおやけ 関数 から(): しんぎ { かえす これ.データ.ながさ == 0 }
}

メイン() {
    おく 皿 = スタック()
    皿.おしこむ(1)
    皿.おしこむ(2)
    皿.おしこむ(3)
    ひょうじ(皿.とりだす().なければれいがい())    // 3（後入れ先出し）
    ひょうじ(皿.とりだす().なければれいがい())    // 2
    ひょうじ(皿.とりだす().なければれいがい())    // 1
}
```

**注意事項**：スタックの典型用途——関数呼び出しスタック（誰が呼んで誰が返るか）、操作の取り消し（Ctrl+Z）、かっこの対応チェック。キューの典型用途——タスクの並び、メッセージキュー。`のぞく(区間)` で末尾の要素を削除する（第 11 章：のぞく は区間しか受け取らない）。

## 17.7 再帰：関数が自分を呼ぶ

**定義**：再帰 = 関数が**自分自身を呼んで**、同じ問題のより小さい版を解く。本質は「分割統治」のもう一つの書き方——**大きな問題を小さな問題に砕き、小さな問題の解を組み立てて大きな問題の解にする**。

**日本語の書き方**：

```jc
関数 かいじょう(数: せいすう): せいすう {
    もし (数 <= 1) { かえす 1 }          // 出口：最小の問題は答えを直接出す
    かえす 数 * かいじょう(数 - 1)             // 前進：問題が小さくなり（数-1）、解を組み立てる（×数）
}

関数 フィボナッチ(数: せいすう): せいすう {
    もし (数 <= 1) { かえす 数 }         // 出口
    かえす フィボナッチ(数 - 1) + フィボナッチ(数 - 2)   // 二つのより小さい問題
}

メイン() {
    ひょうじ(かいじょう(5))        // 120（5×4×3×2×1）
    ひょうじ(フィボナッチ(10))   // 55
}
```

**注意事項**：

- **再帰の二要素はどちらも欠かせない**：出口（終了条件）+ 前進（規模が縮小）。出口なし = スタックオーバーフローでクラッシュ；
- 再帰 vs ループ：再帰のコードは数学的定義に近い（読みやすい）。ループは性能が良い（呼び出しのオーバーヘッドがない）。深さが深すぎる（万の桁）ならループで；
- フィボナッチの素朴な再帰には大量の重複計算がある（O(2ⁿ)）——ループかメモ化で最適化しよう（練習 4）。

## 17.8 ハッシュの原理：O(1) の秘密

**定義**：マップはなぜ O(1) なのか？——**ハッシュ関数**がキー（たとえば文字列「ポチ」）を一つの数（バケット番号）に計算し、そのバケットへ直接ジャンプして値を探す。「ポチは何歳？」を調べるのに全エントリをめくる必要はない。ハッシュを計算すれば位置が決まる。

**なぜ O(1) なのか**：データが何件あっても、ハッシュ関数の計算時間は同じ——「計算する → バケットへ跳ぶ → 取り出す」の 3 ステップはデータ量と無関係。

**代償（第 11 章の振り返り）**：

- **順序がない**：バケット番号はハッシュ値が決めるので、挿入順とは無関係——だから走査の順序は保証されない；
- **キーはハッシュ可能でなければならない**：文字列、整数は自然にハッシュ可能。独自型は `ハッシュ可能` インタフェースを実装する必要がある；
- **衝突**：二つのキーが同じバケットに計算される（コリジョン）——マップの内部はリンクリスト/オープンアドレッシングで解決する。衝突が多いと O(n) へ劣化する。

**日本語の書き方**（マップで語の頻度統計——ハッシュの古典的应用）：

```jc
いれる 標準コレクション.{マップ, リスト}

関数 ごひんど(ぶん: 文字列): マップ<文字列, せいすう> {
    変数 とうけい = マップ<文字列, せいすう>()
    おく たんご = ぶん.わける(" ")
    それぞれ (ご in たんご) {
        とうけい[ご] = とうけい.取得(ご).なければきてい({ => 0 }) + 1   // カウントの型
    }
    かえす とうけい
}

メイン() {
    おく とうけい = ごひんど("りんご バナナ りんご みかん りんご バナナ")
    それぞれ (ご in とうけい.キー()) {
        ひょうじ("${ご}：${とうけい[ご]}回")
    }
}
```

**注意事項**：`とうけい.取得(ご).なければきてい({ => 0 }) + 1`——「古い値を取る（なければ 0）→ 1 足す → 戻す」はカウントの定番三連（第 11 章）。

## 17.9 よく使うアルゴリズムの型

**定義**：頻出アルゴリズムの「骨格」。覚えてそのまま当てはめる：

```jc
いれる 標準コレクション.{マップ}
// 型 1：走査して合計（貯金箱）
関数 そうわ(データ: はいれつ<せいすう>): せいすう {
    変数 ごうけい = 0
    それぞれ (こうもく in データ) { ごうけい += こうもく }
    かえす ごうけい
}

// 型 2：最大を探す（トーナメント）
関数 さいだいち(データ: はいれつ<せいすう>): オプション<せいすう> {
    もし (データ.ながさ == 0) { かえす なし }
    変数 さいだい = データ[0]
    それぞれ (こうもく in データ) {
        もし (こうもく > さいだい) { さいだい = こうもく }
    }
    かえす あり(さいだい)
}

// 型 3：カウント（第 11 章のグループ集計の型）
関数 かぞえ(データ: はいれつ<せいすう>): マップ<せいすう, せいすう> {
    変数 とうけい = マップ<せいすう, せいすう>()
    それぞれ (こうもく in データ) {
        とうけい[こうもく] = とうけい.取得(こうもく).なければきてい({ => 0 }) + 1
    }
    かえす とうけい
}

メイン() {
    ひょうじ(そうわ([1, 2, 3, 4]))       // 10
    ひょうじ(さいだいち([3, 7, 2, 9]).なければれいがい())   // 9
    ひょうじ(かぞえ([1, 2, 1, 3, 1]).ながさ)  // 3（三種類の異なる数）
}
```

**注意事項**：空リストの「最大」は存在しない——`オプション` を返す（予期した失敗はオプション。第 14 章）。型の境界（空、単一要素、全部同じ）まで必ず考える。

## 練習

1. `あいだ` ループで二分探索を実装しよう（範囲を使わず、手書きのループ制御を練習）；
2. `選択ソート` に `降順: しんぎ = 偽` の引数を足して、降順ソートをサポートしよう；
3. スタックで「かっこの対応チェック」を模擬しよう：`"(()())"` は対応成功、`"(()"` は失敗（ヒント：`(` に出会ったらおしこむ、`)` に出会ったらとりだす。最後にスタックが空なら対応している）；
4. ループ（非再帰）でフィボナッチを実装し、再帰版との性能差を比べよう；
5. 挑戦：「二分挿入ソート」を実装しよう——挿入位置を二分探索で決め、その計算量を分析しよう。

## まとめ

- O 記法は傾向を測る：O(1) < O(log n) < O(n) < O(n log n) < O(n²)；
- 二分探索：**ソート済み**配列で毎回半分を除外（O(log n)）。ループ条件は `低 <= 高`；
- 選択/バブルソート：O(n²)。原理の理解で足りる——日常は `ならべる`；
- クイックソート：分割統治 + 再帰。平均 O(n log n)。**再帰 = 出口 + 前進**；
- スタックは LIFO（おしこむ/とりだす）、キューは FIFO。ハッシュ O(1) の秘密はハッシュ関数の直接定位；
- カウント三連：`とうけい.取得(キー).なければきてい({ => 0 }) + 1`。
