# 第 3 章 記憶ボックス：変数

> **この章の目標**
> - 「変数」が名前ラベル付きのボックスであることを理解する；
> - `おく`（変更不可）と `変数`（変更可）の二種類のボックスを区別する；
> - 変数に良い名前を付ける方法を学ぶ。
>
> **この章を読み終えると答えられる**：`おく` と `変数` はどう違う？なぜプログラミング界は `おく` を推奨するの？プログラムの中の `=` はどういう意味？

---

## 3.1 コンピューターに物を覚えてもらう

問題を解くとき、あなたはまず下書き用紙に「既知：x = 5」と書きますね。**変数**はコンピューターの下書き用紙です：名前ラベルの付いたボックスで、中に物を入れておき、必要なときにいつでも取り出せます。

## 3.2 おく：変更できないボックス

```jc
メイン() {
    おく 私の年齢 = 12
    ひょうじ("私の年齢は${私の年齢}")
}
```

- `おく 私の年齢 = 12`：ボックスを取り出し、「私の年齢」というラベルを貼り、数字の `12` を入れます；
- `"私の年齢は${私の年齢}"`：`${}` は**補間**——穴埋めのように、ボックスの中の値を文の中に埋め込みます。

実行結果：`私の年齢は12`。

`おく` の意味は「**ここで決める。もう変えない**」——ボックスに入れた物は入れ替えられません。もし `私の年齢 = 13` と書こうものなら、コンパイラは容赦なくエラーを出します：「変更不可の値に代入できません」。

> たとえ話：`おく` は石に刻んだ文字（変えられない）。

## 3.3 変数：変更できるボックス

ときには本当に変更したいこともあります。たとえば数を数えるとき：

```jc
メイン() {
    変数 カウント = 0
    カウント = カウント + 1      // ボックスから 0 を取り出し、1 を足して、1 を戻す
    カウント = カウント + 1      // もう一度。今度は 2 になる
    ひょうじ("2回数えた：${カウント}")
}
```

- `変数`：ボックスの中身は**いつでも入れ替え可能**；
- `=` は**代入**：右側の物を、左側の名前のボックスに入れること。数学の「等しい」ではありません。「……を……に入れる」です。だから `カウント = カウント + 1` は「今の `カウント` を取り出して 1 を足し、戻す」という意味になります。

> たとえ話：`変数` は黒板に書いた文字（消して書き直せる）。
>
> どう選ぶ？**基本は `おく`**——足りていればロック。本当に変更が必要なとき（数える、足し算を重ねる、カウントダウン）だけ `変数` を使います。こうすれば、コードを読む人にひと目で伝わります：`変数` と書かれた場所こそ、値が変わる場所だと。

## 3.4 ボックスに名前を付けるルール

- 日本語で OK！`私の年齢`、`合計点`、`答え` など何でも使えます；
- 名前は**一目で分かる**ものに。`合計点` は `a` より百倍まし——2 日たてば自分でも `a` が何か分からなくなります；
- 数字から始めてはいけません（`123abc` はダメ）、スペースも入れられません；
- 型注釈を付けて、このボックスが何の材料を入れる箱かをコンピューターに教えられます：

```jc
メイン() {
    おく 名前: 文字列 = "たろう"    // このボックスは文字だけ
    おく 点数: せいすう = 95          // このボックスは整数だけ
    ひょうじ("${名前}は${点数}点でした")
}
```

注釈なしでも動きます——コンピューターは賢いので、入れた物を見れば型を当てられます（これを**型推論**と呼びます）。ただし注釈があると安心：ラベルに「整数のみ」と書いてあれば、文字を入れようとした瞬間にコンピューターが止めてくれます。

## 3.5 定数：石に刻んだ文字

もう一つ「もっと硬い」ボックス——`定数`：

```jc
定数 円周率 = 3.14159
定数 学校名 = "第一中学校"

メイン() {
    ひょうじ("${学校名}、円周率 ≈ ${円周率}")
}
```

`定数` も `おく` も変更不可ですが、違いは：`定数` は**コンパイル時**（プログラムが動き出す前）に値が確定します。より速く、より安全です。**使えるなら `定数` を使いましょう**——円周率や学校名のように永遠に変わらない値こそ、`定数` の出番です。

## 3.6 やってみよう

1. `おく` で自分の誕生日を、`変数` でおこづかいを保存し、表示してみましょう；
2. 予想しよう：`おく 点数 = 90` の後に `点数 = 95` と書いたら、どうなる？実際に試して、エラーメッセージに答えてもらいましょう；
3. `定数` で家から学校までの距離を定義し、「家から学校まで X km」と表示しましょう；
4. 挑戦：`変数` で「おこづかい帳」を作ろう——100 円もらう、文房具で 25 円使う、おやつで 10 円使う。残りはいくら？

## ✳ プログラミング思想の小話：命名はドキュメント

「ボックスに名前を付ける」という小さな作業は、プログラミングで最も大事なことの一つです。

- プログラマーがコードを読む時間は、書く時間の 5〜10 倍；
- あなたの書いたコードは、主に**未来の自分**と**ほかの人**が読みます；
- `合計点` という変数は、コメントなしでも誰にでも伝わります。`a` という変数は、明日のあなたが忘れます。

**命名はドキュメント**：良い名前はそれ自体が説明書です。コードを書くときに名前を考える 10 秒が、将来の数時間の理解時間を省いてくれます。これは「自己文書化コード」とも呼ばれます——コード自身が語り、追加の説明を必要としない。

## 🍳 日常アルゴリズム小話：二つのボックスを交換する

たろう君は二つのボックスを持っています：一つにはコーラ、もう一つにはオレンジジュース。中身を入れ替えたいのですが——**注意：二つのボックスを同時に開けて注ぐことはできません**（床がびしょ濡れになります）。

プログラマーの解き方：もう一つ**空のボックス**（一時変数）を用意します：

```
1. コーラを空のボックスに注ぐ      // 一時 = コーラ
2. オレンジジュースをコーラの箱に注ぐ  // コーラ = オレンジジュース
3. 空のボックスの中身をジュースの箱に注ぐ  // オレンジジュース = 一時
```

コードで書くと：

```jc
メイン() {
    変数 コーラ = "コーラ"
    変数 ジュース = "オレンジジュース"
    変数 一時 = コーラ       // 1. 先に取っておく
    コーラ = ジュース        // 2. ジュースをコーラの箱へ
    ジュース = 一時          // 3. もとのコーラをジュースの箱へ
    ひょうじ("コーラの箱の中身：${コーラ}")
    ひょうじ("ジュースの箱の中身：${ジュース}")
}
```

これは全プログラマーが出会う定番の手筋——**2 つの値を交換する**ことです。核心は：直接入れ替えると物を失うので、先に「一時ボックス」を借りて保存する。将来ソートアルゴリズム（第 17 章）を書くときにもまた出会います。

## まとめ

- 変数 = 名前ラベル付きのボックス；`=` は「物を入れる」であって、数学の「等しい」ではない；
- `おく`：変更不可（既定の選択）；`変数`：変更可（必要なときだけ）；`定数`：コンパイル時に確定（永遠に変わらない値に使う）；
- 命名ルール：日本語 OK、一目で分かる、数字始まり NG、スペース NG；
- 型注釈は任意：`おく 名前: 文字列 = "たろう"`——付けておけば、違う材料を入れた瞬間にエラーになる；
- 2 つの値の交換：一時ボックスを借りる。

## 練習問題

1. なぜプログラミング界は `変数` ではなく `おく` を既定にするの？（ヒント：ボックスがこっそり変わらないので、コードを読むのが安心）
2. `カウント = カウント + 1` は数学では奇妙（x = x + 1 は解なし）。プログラムではなぜ正しい？
3. 生活の中から「おく」と「変数」の例を探そう：一度決めたら変わらないもの（例：生年月日）と、毎日変わるもの（例：おこづかいの残高）。
4. 試してみよう：ボックスに名前を付けず、直接 `ひょうじ("${12}")` と書く——`12` は表示できる？これは何を意味する？
