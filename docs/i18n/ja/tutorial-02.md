# 第 2 章 最初のプログラム：こんにちは、世界！

> **この章の目標**
> - 最初のプログラムを自分で作り、実行に成功させる；
> - プログラムの「入口」——`メイン` を知る；
> - `ひょうじ` でコンピューターにしゃべらせる。
>
> **この章を読み終えると答えられる**：プログラムはどこから実行が始まる？`ひょうじ`（println）の「行」って何？あなたの書いたコードはどうやってコンピューターに伝わるの？

---

## 2.1 世界共通の最初の一言

世界中のプログラミング学習者が、最初に作るプログラムは「こんにちは、世界！」（Hello, World!）とコンピューターに言わせるものです。これはプログラミング界の伝統——書道で最初に「人」という字を書くようなもの。最初の一筆は簡単ですが、これを機にあなたは「プログラミングができる人」の仲間入りです。

## 2.2 はじめてのファイルを作る

エディタ（メモ帳でも何でも）を開いて、次の 3 行を `hello.jc` という名前で保存します：

```jc
メイン() {
    ひょうじ("こんにちは、世界！")
}
```

たった 3 行です。これを分解して見ていきましょう。

> zhc はプロジェクトの雛形も生成できます（`zhc init プロジェクト名`）。雛形の `src/main.zc` は中国語方言なので、日本語で書きたいときは上の 3 行のように `.jc` ファイルを直接作るのが簡単です。単一ファイルは `zhc run hello.jc` でそのまま動きます。

## 2.3 メイン：プログラムの入口

`メイン()` は**プログラムの入口**——コンピューターはプログラムを実行するとき、ここから始まります。家に帰ってまず玄関をくぐるのと同じです。

その後の `{` と `}`（波かっこ）はドアの**枠**のようなもの：`{` は「ドアが開いた。中身のコードが実行される」、`}` は「ドアが閉まった。ここで終わり」。

> 💡 注意：入口は `メイン()` と書きます。前に `関数`（func）を**付けません**。「社長室を訪ねる」と言うべきところを「訪ねる社長室を」と言うようなもの。`関数 メイン()` と書くのは間違いで、コンパイラが教えてくれます。

## 2.4 ひょうじ：コンピューターにしゃべらせる

`ひょうじ("こんにちは、世界！")` の意味は：**コンピューターに「こんにちは、世界！」を画面に表示させる**ことです。

- 中の `"`（二重引用符）は文字の「包装箱」。コンピューターに「引用符の中は言葉であって、コードではない」と教えます；
- `ひょうじ` は公式の `println`（print **l**i**ne**）に対応——表示したあとに**改行**します。ちょうど一行書き終えて Enter を押すようなもの。次の言葉は新しい行の先頭から始まります。

## 2.5 プログラムを実行する

ターミナルで：

```bash
zhc run hello.jc
```

すると：

```
✅ Compilation OK: replaced 2 dialect identifier(s).
こんにちは、世界！
```

（画面文言は言語パックの言語で表示されます。日本語パックは未翻訳の文言を英語にフォールバックするため、上の 1 行目は英語表示です）

**成功です！** あなたはちょうど、すべてのプログラマーの最初の授業を終えました。

> 舞台裏の小劇場：`zhc run` は三つのことをします——① 日本語コードを標準倉頡に翻訳する（言語パックの単語表を引くので「2 個の方言識別子を置換」と出ます）；② コンパイラに倉頡をコンピューターの分かる `0` と `1` に翻訳させる；③ 実行する。1.3 節で出会った「通訳者チーム」が正式に働き始めました。

> **小実験**：引用符の中の文字を自分の名前に変えて、もう一度実行してみましょう。たとえば `ひょうじ("私はたろう")`。コンピューターが「私はたろう」と言います。**あなたはもうプログラムを編集できる人です！**

## 2.6 やってみよう

1. コンピューターに三つのことを続けて言わせましょう：あなたの名前、年齢、一番好きな食べ物（ヒント：`ひょうじ` を 3 行書く）；
2. 予想しよう：引用符を外して `ひょうじ(こんにちは)` と書いたら、どうなる？実際に試してみましょう！日本語のエラー表示が何と言うか見てください——それはあなたを罰しているのではなく、**問題を探してくれている**のです；
3. 挑戦：`メイン()` の中に `ひょうじ("二行目")` をもう 1 行足して、出力の順序をよく見てください——「こんにちは、世界！」と「二行目」はどちらが先に出ますか？

## 2.7 エラーは怖くない：エラー表示を読み解く

プログラムのエラーは、コンピューターがあなたを罰しているのではなく、**問題を探してくれている**のです。zhc の一番うれしい点：**エラーが母語で表示される**うえ、💡 の解説と修正例付き——「どこが、なぜ、どう直す」まで書いてあります。

試しに、`ひょうじ("こんにちは、世界！")` の `ひょうじ` をわざと `ひょうじ2` に変えて（2.6 の練習 2 の答え）、`zhc run hello.jc` を実行すると、次のような表示になります（ja 言語パックの文言。未訳キーは中国語へ自動フォールバックします）：

```text
[エラー] 未宣言の識別子 `ひょうじ2`  hello.jc:2:5
  💡 未定義の名前を使っています：つづりを確認；変数は宣言してから使います。
  修正例（そのまま貼り付けられます）：
  ...
```

各部分を分解してみましょう：

| 表示 | 意味 |
|---|---|
| `[エラー]` | これはエラー（警告は「直した方がいいが動くもの」） |
| 未宣言の識別子 `ひょうじ2` | コンピューターが `ひょうじ2` という名前を知らない |
| `hello.jc:2:5` | **場所**：2 行目の 5 文字目あたり |
| 💡 解説 | なぜこのエラーが出たか + どう直すか |
| 修正例 | そのまま貼れる正しいコード |

> たとえ話：エラー表示はお医者さんの出す**検査結果書**——どこが痛いか（場所）、何の病気か（原因）、どう治すか（修正例）が全部書いてあります。

初心者に一番多いエラーは三つ：

**1. 名前の書き間違い**——`ひょうじ` を `ひょうじ2` に、`文字列` を `文字列2` に → 「未宣言の識別子」。つづりを確認しましょう。

**2. 型の不一致**——`おく 年齢: せいすう = "12"`：文字を数字の箱に入れた → 「型が一致しない」。箱のラベルと入れるものを合わせます（第 3・4 章を学ぶとよく出会います）。

**3. かっこ/引用符の対応漏れ**——`ひょうじ("こんにちは"` で `)` が一つ足りない → 「閉じられていない区切り記号」。`(` と `)`、`"` と `"` がそれぞれ対になっているか数えてみましょう。

**デバッグ 3 ステップ**：

1. **表示を読む**：まず `[エラー]` の後の文を読む——何の名前・型・記号の話をしている？
2. **場所を見る**：`ファイル:行:列` を見つけてその行へ跳び、前後を眺める。
3. **直して実行**：💡 と修正例に従って直し、もう一度実行する。**一度に一か所だけ**直し、直したらすぐ実行。

> アドバイス：エラーの**最初の一件**が本当の原因であることが多い。後のエラーは「連鎖反応」の場合があります。最初の一件から直しましょう。

## ✳ プログラミング思想の小話：規約が設定に勝る

プログラミングを学ぶ初日、あなたは気づかなかったかもしれません：**世界の最初のプログラムはみな「こんにちは、世界！」**。これは偶然ではなく、一つの「規約」です。

プログラミングの世界には規約があふれています：入口は `メイン`、公式コードのファイル名は `main.cj`、プロジェクトの構造はツールが自動生成……なぜみんなこれらの規約に従うのでしょう？

- **考える手間が減る**：毎回「入口は何と呼ぼう」と考えず、規約通りに書けばいい；
- **伝える手間が減る**：世界中のプログラマーが `main` を見れば入口ファイルだと分かる。説明不要；
- **ツールが使いやすくなる**：規約があるからこそ、`zhc init` はワンクリックでプロジェクトを生成できる——あなたに何が足りないか分かるからです。

**規約が設定に勝る**（Convention over Configuration）：「既定のやり方」を「良いやり方」にすることは、ソフトウェア設計の大きな知恵です。これからコードを書いていて「みんなこう書いているな」という型に出会ったら、まずその通りにしてみて、それから理由を考えましょう。

## 🍳 日常アルゴリズム小話：あなたは毎日すでに「プログラム」

今朝のあなたの過ごし方を思い出してください：

```
1. 起きる
2. 歯を磨く
3. 朝ごはんを食べる
4. 家を出て学校へ行く
```

これこそ「プログラム」——上から下へ、一歩ずつ実行されます。コンピューターも同じ：`メイン()` の中のコードは**順番に**一文ずつ実行され、最初の文が終わると次の文へ進みます。

このイメージを覚えておいてください：**プログラム = 順番に実行されるレシピ**。第 3 章から、このレシピに「記憶ボックス」（変数）を足していきます。

## まとめ

- 最初のプログラムは 3 行だけ：`メイン()` が `ひょうじ("...")` を包む；
- `メイン()` はプログラムの入口（`関数` の接頭辞は付けない）。波かっこ `{}` がプログラムの範囲を囲む；
- `ひょうじ("文字")` は一行の文字を表示して改行する。文字は二重引用符に入れる；
- `zhc run hello.jc` で実行：トランスパイル → コンパイル → 実行；
- プログラミング界の規約：最初のプログラムは「こんにちは、世界！」。

## 練習問題

1. `メイン()` の外側の `{` と `}` を消したら、プログラムは動くでしょうか？なぜ？
2. `ひょうじ` と公式の `println` の違いは？`だす`（print、改行なし）とどう使い分ける？ヒント：`zhc/lang-packs/ja/stdlib.toml` で確認してみよう。
3. なぜ `"こんにちは"` には引用符が要るのに、`メイン` には要らないの？どこが違う？
4. `ひょうじ("こんにちは")` の前に `ひょうじ("私は一行目")` を足して、出力の順序を予想し、検証してみよう。
