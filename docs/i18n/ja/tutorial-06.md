# 第 6 章 繰り返し仕事：ループ

> **この章の目標**
> - `それぞれ` でコードに数を数えながら繰り返し仕事をさせる；
> - `あいだ` で条件が満たされなくなるまで続けさせる；
> - `ぬける` と `つづける` でループを制御する。
>
> **この章を読み終えると答えられる**：`1..5` は 5 を含む？無限ループはどうやって止める？ガウスはどうやって 1 から 100 までの和を一瞬で出したの？

---

## 6.1 繰り返しの仕事はコンピューターに

1 から 100 まで足すプログラム？100 行手書きする？**ループ**こそそのための仕組み——同じコードを繰り返し実行させます。コンピューターは繰り返しの仕事が一番得意。疲れないし、うんざりしないし、数え間違えもしません。

## 6.2 それぞれ：数えながらやる

```jc
メイン() {
    それぞれ (i in 1..5) {
        ひょうじ("${i}回目")
    }
}
```

- `1..5` は**範囲**：1 から 5 まで（注意：5 の手前で止まり、**5 を含みません**）；
- `それぞれ (i in 1..5)`：毎回 `i` を 1、2、3、4 と順に変えて、波かっこの中のコードを一回ずつ実行します；
- 出力：`1回目`、`2回目`、`3回目`、`4回目`（5回目はありません！）。

> 範囲には閉区間の書き方 `1..=5`（5 を含む）もあります。「半開区間 `1..5`」はプログラミング界の主流の約束です。なぜなら長さがちょうど `5 - 1` になり、あいまいさがないから。

### 伝説の話：ガウス、1 から 100 までの和を一瞬で

数学者ガウスは 8 歳のとき、先生がクラス全員に 1 から 100 までの和を計算させました。ほかの子どもたちが懸命に計算する中、ガウスは数秒で書き終えました——彼は `1+100=101`、`2+99=101`……の組が全部で 50 あることに気づき、答えは `50 × 101 = 5050` だと見抜いたのです。

これをループで書いてみましょう——ガウスは賢い手を使い、私たちは地道な力技（でもコンピューターは力技を嫌いません）：

```jc
メイン() {
    変数 合計 = 0
    それぞれ (i in 1..101) {
        合計 = 合計 + i
    }
    ひょうじ("1 から 100 まで足すと${合計}")
}
```

出力：`1 から 100 まで足すと5050`。このプログラムの「魂」に注目：`変数 合計` はまるで貯金箱。一周ごとに数を一つずつ入れていきます——**ループの中で `変数` を書き換える**のは、プログラミングで最もよく使う組み合わせです。

## 6.3 あいだ：条件が満たされなくなるまで

`それぞれ` は「数を数えながら」向き、`あいだ` は「ある条件が成り立たなくなるまで」向き——**条件が真である限り、やり続けます**：

```jc
メイン() {
    変数 残りの麺 = 10
    あいだ (残りの麺 > 0) {
        ひょうじ("あと${残りの麺}本の麺")
        残りの麺 = 残りの麺 - 1
    }
    ひょうじ("食べ終わった！")
}
```

> ⚠️ **危険の注意**：もし `残りの麺 = 残りの麺 - 1` を書き忘れると、条件が永遠に真のままで、プログラムは回り続けます——これが**無限ループ**。画面が止まらなくなったら **Ctrl+C** で強制停止です。

## 6.4 ぬけるとつづける

- `ぬける`：ループ全体をすぐ終わらせる（もう数えたくない、さっさと出ていく）；
- `つづける`：今回の一周を飛ばして、次の一周へ。

```jc
メイン() {
    それぞれ (i in 1..10) {
        もし (i == 3) { つづける }      // 3 は飛ばす
        もし (i == 7) { ぬける }        // 7 で止める
        ひょうじ("${i}まで数えた")
    }
}
// 出力：1まで数えた 2まで数えた 4まで数えた 5まで数えた 6まで数えた
```

## 6.5 やってみよう

1. `それぞれ` で九九の表の一列を表示：`1×7=7`、`2×7=14`……`9×7=63`；
2. `あいだ` でカウントダウン：10 から 1 まで数えて、「発射！」と表示；
3. 「1 から 100 まで」を「1 から 1000 まで」に変えて、答えが合っているか確認（公式：n×(n+1)/2）；
4. 挑戦：`それぞれ` で 1 から 50 までの偶数を全部表示（ヒント：`i % 2 == 0` なら偶数）。

## ✳ プログラミング思想の小話：ループの三要素

ループを書く前に、三つの質問に答えましょう（**ループの三要素**）：

1. **どこから始める？**（開始点：`i = 1` や `残りの麺 = 10`）
2. **いつ止まる？**（条件：`i < 5` や `残りの麺 > 0`）
3. **一周ごとにどう変わる？**（歩み：`i` が自動で +1、または `残りの麺 = 残りの麺 - 1`）

どんなループも、この三つさえはっきりしていれば、無限ループにはなりません。無限ループの本質は「**いつ止まるか**」が永遠に成立しないこと——三要素を点検すれば、病巣はすぐ見つかります。

> これも「分解」思想の再勝利です（第 1 章）：ループは一見こわいけど、三つの質問に分ければ、どれも簡単。

## 🍳 日常アルゴリズム小話：九九の表

「ループの中のループ」で九九の表を表示する——これは全プログラマーの入門儀式です：

```jc
メイン() {
    それぞれ (行 in 1..10) {
        変数 一行 = ""
        それぞれ (列 in 1..=行) {
            一行 = 一行 + "${列}×${行}=${列 * 行} "
        }
        ひょうじ(一行)
    }
}
```

- 外側のループが「行」（1 から 9）を担当し、内側のループが「列」（1 から現在の行まで）を担当；
- **ループの中にループ**を「ネストしたループ（入れ子）」と呼びます——外側が一歩進むたびに、内側が一周まるごと回ります；
- 内側の終了条件 `1..=行` が外側の変数 `行` を使っています——内側の周回数が外側に応じて変わる。これが入れ子ループの真髄です。

> 出力はどんな形？一行目は `1×1=1 `、二行目は `1×2=2 2×2=4 `……自分で実行して確かめてみましょう！

## まとめ

- `それぞれ (i in 範囲)`：数えながら実行；`1..5` は半開区間で**5 を含まない**、`1..=5` は 5 を含む；
- `あいだ (条件)`：条件が真の間やり続ける。**無限ループに注意**（Ctrl+C が命綱）；
- `ぬける` でループ全体を終了、`つづける` で今週をスキップ；
- ループの三要素：開始点、停止条件、一周ごとの変化；
- ループの中で `変数` と組み合わせて累計（貯金箱の手筋）；
- 入れ子ループ：外側が一歩、内側が一周。
