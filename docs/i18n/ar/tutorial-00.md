# دليل البرنامج التعليمي — الدرس 0 (بالعربية)

اللغات：[البرنامج التعليمي الأصلي (zh)](../../中文仓颉程序设计/README.md) · [English](../en/README.md) · [Français](../fr/README.md) · [Deutsch](../de/README.md) · [Español](../es/README.md) · [한국어](../ko/README.md) · [日本語](../ja/README.md) · [Русский](../ru/README.md) · **العربية**

البرنامج التعليمي الكنسي **《中文仓颉程序设计》** («تصميم برامج كانغجي
باللغة الصينية») — دورة منهجية بأسلوب الكتيب: **3 أجزاء، 20 فصلًا + 3
ملاحق + حلول التمارين**، و**أكثر من 150 مقطع شيفرة مُختبرة فعليًا على
`cjc 1.0.5` الرسمي**. هذه الصفحة هي الدرس 0 بالعربية؛ النص الكنسي
صيني — اقرأه بالتوازي مع أمثلة اللهجات أدناه، أو ابدأ من عيّنة اللهجة.

## تكوين الأجزاء الثلاثة

| الجزء | لمن | المحتوى |
|---|---|---|
| الجزء 1 الخطوات الأولى | المبتدئ تمامًا | إعداد البيئة، أول برنامج، المتغيرات، الأعداد والنصوص، الشروط، الحلقات، الدوال |
| الجزء 2 النواة والتعمّق | من يريد إتقان القواعد | تعمّق الدوال، نظام الأنواع، النصوص، المجموعات، البرمجة الكائنية، التعداد، الأخطاء، الأنواع العامة والماكرو |
| الجزء 3 الهندسة والفكر | من يستهدف جودة الكود | فكر التصميم، الخوارزميات وهياكل البيانات، هندسة البرمجيات، مشروع شامل |

## الدرس 1: أول برنامج

اكتبه باللهجة العربية (الامتداد `.ac`):

```ac
// اسم الملف: hello.ac —— يشغَّل بـ ZHCLANG=ar zhc run hello.ac
رئيسية() {
    دع اسم: نص = "العالم"
    اعرض("مرحبا، ${اسم}!")
}
```

احفظه باسم `hello.ac` ونفّذ:

```bash
ZHCLANG=ar zhc run hello.ac
```

كل اللهجات تُحوَّل إلى نفس الشيفرة القياسية تمامًا — لا يتغير إلا
الكلمات المفتاحية وأسماء الأنواع حسب جداول حزم اللغة. الحزم التسع
المرفقة: `zh`/`en`/`ru`/`ja`/`ko`/`fr`/`es`/`de`/`ar` (انظر البدء
السريع لكل لغة).

> يعمل بدون تصريح النوع أيضًا: `دع اسم = "العالم"`. النوع `نص`
> (= الرسمي `String`) هو اسم مستعار من المكتبة القياسية، كتابة صريحة
> لمن يريد تعلّم أسماء الأنواع.

## من أين تبدأ (مرجع سريع)

- من الصفر → الجزء 1، الفصول 01–07 (10–20 دقيقة لكل فصل، مع تمارين)
- القواعد بشكل منهجي → الجزء 2، الفصول 08–15 (تعريف → صيغة → مثال → ملاحظات)
- الجودة والهندسة → الجزء 3، الفصول 16–19
- البحث عن الكلمات المفتاحية/المكتبة القياسية وفك أخطاء التشخيص → الملاحق أ/ب/ج

## المصطلحات (ترجمات موحّدة في كل أجزاء الكتاب)

| العربية | رمز الشيفرة | ملاحظة |
|---|---|---|
| اللهجة | `.ac` `.zc` … | شيفرة كانغجي مكتوبة باللغة الأم |
| الرئيسية | `رئيسية()` | مدخل البرنامج (الرسمي `main`) |
| دَع | `دع` | يُصرَّح بقيمة غير قابلة للتغيير (الرسمي `let`) |
| اعرض | `اعرض()` | طباعة سطر (الرسمي `println`) |
| نص | `نص` | تسلسل حروف (الرسمي `String`) |
| التحويل (transpile) | `zhc run` | اللهجة → كانغجي القياسية |
