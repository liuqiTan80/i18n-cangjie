# zhc — برمجة لغة كانغجي بلغتك الأم

اللغات：[الصينية (zh)](../../../README.md) · [English](../en/README.md) · [Français](../fr/README.md) · [Deutsch](../de/README.md) · [Español](../es/README.md) · [한국어](../ko/README.md) · [日本語](../ja/README.md) · [Русский](../ru/README.md) · **العربية**

**zhc** هو إطار تعليمي «باللغة الأم» للغة البرمجة كانغجي Cangjie: يحوّل
الشفرة المصدرية المكتوبة باللهجات (مثل الصينية `.zc`، اليابانية `.jc`،
العربية `.ac`) إلى كانغجي القياسية، ويترجم تشخيصات المترجم إلى رسائل
تعليمية بلغة حزمة اللغة المختارة (رمز الخطأ → جدول الرسائل → ترجمة
الأنواع → أمثلة الإصلاح). تُختار اللهجة بمتغير البيئة `ZHCLANG`
(الافتراضي `zh`)؛ كل شيء تتحكم فيه **حزمة اللغة**.

## بدء سريع (حوالي 10 دقائق)

**1. ثبّت حزمة أدوات كانغجي** (الاعتماد الخارجي الوحيد): حمّل إصدار
**1.0.5** من cangjie-lang.cn/download وفك الضغط ونفّذ `envsetup.sh`
المرفق حتى يصبح `cjc` و `cjpm` في `PATH`. تحقق:

```bash
cjc --version    # Cangjie Compiler: 1.0.5 (cjnative)
```

**2. ابنِ zhc** (بدون شبكة، بدون تبعيات خارجية):

```bash
cd zhc
cjpm build       # ينشئ target/release/bin/main
```

**3. شغّل أول برنامج** (مثال باللهجة العربية من المستودع):

```bash
export ZHC_LANG_PACKS=$PWD        # من جذر المستودع: zhc/
ZHCLANG=ar zhc run demo/hello.ar.ac
# ✅ نجح التحويل البرمجي: استُبدلت 7 معرفات للهجة.
```

## اكتب بلغتك

يعمل أي لغة لها حزمة في `zhc/lang-packs/<الرمز>/` — تشمل الحزم التسع:
`zh`/`en` (مستوى كامل full)، `ru`/`ja`/`ko`/`fr`/`es`/`de` (مستوى قياسي
standard)، و`ar` (تجربة RTL الأولى، مستوى تجريبي demo، اتجاه الكتابة من
اليمين إلى اليسار). مثال بالعربية (`ZHCLANG=ar`):

```ac
رئيسية() {
    دع اسم: نص = "العالم"
    اعرض("مرحبا، ${اسم}!")
}
```

شغّله: `ZHCLANG=ar zhc run hello.ac`. اللهجة العربية امتداد `.ac`،
والكلمات المفتاحية والأنواع تُستبدل حسب جدول حزمة اللغة — الشفرة بعد
التحويل مطابقة تمامًا للغة القياسية.

## ترجمات المكتبات الخارجية

خرائط واجهات المكتبات تعيش في مستودع الترجمات المشترك، وليس في شجرة
مصدرك — حمّل فقط اللغة والمكتبة اللذين تحتاجهما:

```bash
zhc share list                     # نظرة عامة على السجل المشترك
zhc share fetch csv4cj --lang ar   # حمّل خريطة واحدة بلغتك
zhc share publish ملفي.toml         # شارك ترجمتك
```

تُفحص الخرائط المحمّلة (المجموع الاختباري، التنسيق، الأسماء الرسمية،
التصادم مع الكلمات المحجوزة) قبل تثبيتها في
`~/.zhc/lang-packs/<اللغة>/crates/`. عند غياب ترجمة — تراجع ناعم إلى
الصينية؛ البرنامج يعمل على أي حال.

## المصطلحات (موحّدة في كل الوثائق العربية)

| العربية | في الكود/الوثائق | ملاحظة |
|---|---|---|
| اللهجة | `.zc` `.jc` `.ac` … | كانغجي مكتوب باللغة الأم |
| حزمة اللغة | `lang-packs/<الرمز>/` | جداول الكلمات/الأنواع + التشخيص + نصوص الواجهة |
| الخريطة/المطابقة | `crates/<اللغة>/<المكتبة>.toml` | الاسم الأم = اسم الواجهة الرسمي |
| التحويل (transpile) | `zhc run` / `zhc check` | اللهجة → كانغجي القياسية |
| السجل المشترك | `zhc share …` | سجل مركزي للترجمات |
| خط الأساس | `zh@<المجموع>` | بصمة مزامنة الأصل الصيني |
